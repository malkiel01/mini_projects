# 03 — ייבוא: HTML, Word, EPUB, PDF וסריקות — לטיוטה

**תלויה ב:** 02 (טיוטות), 01 (תור משימות). **מקור:** §9, §2 ("כלי ייבוא ייבנו בשלב א'… ייבוא אינו מעניק הרשאה לפרסם").
📦 דוגמאות ייבוא מכל פורמט (§24) — עד שיגיעו, בודקים על קבצי דוגמה שהצ'אט מכין, ומסמנים זאת.

## 1. מה בונים

התהליך (§9): **העלאה ← בדיקת קובץ ← עיבוד (משימת רקע) ← טיוטה ← תיקון ומיפוי ← תצוגה מקדימה ← פרסום** (הפרסום — 02).

| פורמט | התנהגות | איך ⚙️ |
| --- | --- | --- |
| HTML | ניקוי למבנה של 02 | הניקוי של 02 |
| Word (`.docx`) | טקסט ועיצוב נתמך; כותרות ← מקטעים; RTL וניקוד נשמרים | `ZipArchive` + קריאת `word/document.xml` ב-DOM; `Heading1..3` ← `sf-section`/`sf-anchor`; מודגש/נטוי ← `b`/`i` |
| EPUB | מבנה, טקסט ותמונות; **רק בהרשאת בעליו** — תיבת אישור בהעלאה | `ZipArchive`; סדר לפי ה-`spine` ב-OPF; כל XHTML עובר ניקוי; תמונות לתיקיית הספר |
| PDF עם טקסט | שומרים את המקור; טקסט לטיוטה; **לא מסומן כמוגה** | חילוץ בדפדפן של המנהל (pdf.js, עותק בתוך `sforno/`) ← נשלח לשרת כטיוטה. בשרת אין כלי PDF מובטח |
| PDF סרוק / תמונות | עמודים מקוריים בלבד; בלי חיפוש ובלי OCR | המקור נשמר; תצוגה כעמודים |

- **PDF בשתי תצוגות** (§9): עמודים מקוריים, וטקסט זורם — רק אם המנהל סימן שהטקסט נבדק.
- **מקור נשמר:** `data/sources/<pid>/` — הקובץ המקורי ותמונות שחולצו. נתיב תחת `data/` (מוחרג).

## 2. מגבלות והגנות (§9, §19)

- סוגים: רק הסיומות למעלה, ובדיקת תוכן (חתימת קובץ), לא רק סיומת.
- גודל: ברירת מחדל 50MB לקובץ, ומגבלת השרת מ-01 (`upload_max_filesize`) — הנמוך מהשניים, מוצג למנהל לפני ההעלאה.
- קבצים דחוסים (docx/epub): עד 2,000 רשומות, עד 200MB אחרי פריסה, בלי נתיבים יוצאים (`../`) — נגד zip bomb ו-zip slip.
- עיבוד במשימת רקע (01) עם התקדמות באחוזים, זמן מקסימלי, וכשל ברור ("עמוד 34: טבלה לא נתמכת").
- תמונות: רק `png`/`jpeg`/`webp`, מוקטנות לרוחב מקסימלי, בלי EXIF.

## 3. מיפוי ותיקון

מסך אחרי העיבוד: עץ המקטעים שזוהו (אפשר לגרור, למזג, לשנות כותרת), רשימת אזהרות (ניקוד חסר? עמודות? הערות שוליים),
ומעבר לעורך של 02. **אין פרסום אוטומטי**, ו-`public_allowed` לא משתנה.
