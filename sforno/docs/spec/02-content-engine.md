# 02 — מנוע התוכן: כותרים, מהדורות, תגיות, עורך ומחזור פרסום

**תלויה ב:** 01. **מקור:** §6, §15, §16 ("מחזור תוכן"), §18 ("רכיבי נתונים", הפרדת כותר/מהדורה/מוצר), §2 (שמע — מבנה
בלבד; ייבוא אינו פרסום). קריאה לפני הקוד: `00` §3–4.

## 1. מה בונים

1. מודל: כותר → מהדורות → גרסאות; מקטעים, נקודות ציון וקטעים — כולם עם מזהה יציב.
2. שפת סימון אחת, מתועדת, עם רשימת רכיבים ותכונות מותרים.
3. ניקוי ובדיקת תקינות בשרת בכל שמירה.
4. מנוע תצוגה אחד (JS) — אותו קוד בתצוגה המקדימה ובקורא הציבורי (04).
5. עורך בניהול: סימון טקסט + כפתור ייעודי, ועריכת HTML ידנית.
6. מחזור: טיוטה → תצוגה מקדימה (טלפון ומחשב) → פרסום → שחזור; התרעה על עריכה מקבילה.
7. אינדקס חיפוש מנורמל שנבנה בפרסום (החיפוש עצמו — 04).
8. מבנה לשמע — טבלה ותגית, בלי השמעה.

## 2. מה לא

ייבוא קבצים (03) · הקורא, תנאי מנהגים בפועל (04) · בחירת גרסה אצל המשתמש (06) · מוצרי חנות (09).

## 3. המודל 🟢 (שמות ⚙️)

```
titles            כותר: "סידור עדות המזרח", "תהילים"
  id, pid, name, kind (siddur | tehillim | book), author, description
  public_allowed  INT   רק מנהל מדליק. בשלב א' — רק סידור ותהילים (§2). ייבוא לא מדליק (§2)
  access          free | future_paid      הכנה בלבד (§2 "מסחר דיגיטלי"); future_paid לא מוגש לעולם בשלב א'
  created_at, updated_at, deleted_at

editions          מהדורה של כותר (נוסח, הוצאה)
  id, pid, title_id, label, created_at

revisions         גרסת תוכן של מהדורה. רק מוסיפים
  id, pid, edition_id, n (1,2,3…), based_on_revision_id NULL
  status          draft | published | superseded
  source_html     ה-HTML המנוקה — המקור
  source_hash
  created_by → staff, created_at, published_by, published_at

segments          נגזרת של revision בפרסום — לא נערכת ידנית
  id, revision_id, sid (המזהה היציב), kind (section | anchor | block), parent_sid, ord, title
  text_norm       הטקסט המנורמל לחיפוש

audio_links       מבנה בלבד (§2): sid ↔ קובץ שמע עתידי. ריקה בשלב א'
  id, edition_id, sid, url NULL, start_ms NULL, end_ms NULL
```

- **מזהה יציב (`sid`)** — נקבע בפעם הראשונה שהרכיב נוצר (אקראי, 8 תווים), ו**נשמר** בכל עריכה ובכל גרסה. עליו נשענים
  סימניות, הערות, מיקום קריאה, קישורים פנימיים ושמע (§6, §15). העורך לא משנה `sid` קיים; מחיקה ויצירה מחדש = `sid` חדש.
- **נקודת ציון ≠ סימניה** (§6): `anchor` שייך למהדורה, `bookmark` (05) שייך למשתמש.
- **כותר ≠ מוצר ≠ הרשאה** (§18): מוצר WooCommerce מקושר לכותר בטבלת קישור (09); אין שכפול תוכן.

## 4. שפת הסימון 🟢 (שמות התגיות ⚙️)

תגיות עם קידומת `sf-` — כדי לא להתנגש בתגיות HTML תקניות (SPEC §11.6 ממצא 4):

| תגית | מה | תכונות |
| --- | --- | --- |
| `<sf-section>` | מקטע | `sid`, `title` |
| `<sf-anchor>` | נקודת ציון — לתוכן עניינים ולקפיצה | `sid`, `title` |
| `<sf-style>` | סגנון מותר | `v` — **שם** מרשימה סגורה (`large`, `small`, `bold`, `red`, `gray`, `center`…); לא CSS חופשי |
| `<sf-cond>` | תנאי הצגה | `rule` — מזהה כלל מובנה מרשימת המנהגים (04); **לא קוד** (§6) |
| `<sf-note>` | הוראה / פירוש | `kind` = `instruction` \| `commentary` |
| `<sf-link>` | קישור פנימי | `to` = `sid` (באותה מהדורה) או `pid:sid` |
| `<sf-audio>` | עוגן שמע עתידי | `sid` |

**HTML מותר בתוך התגיות:** `p`, `br`, `h2`–`h4`, `b`, `strong`, `i`, `em`, `small`, `span`, `ul`, `ol`, `li`, `table`
בסיסית, `img` (רק מקבצי הספר עצמו). **תכונות מותרות:** רק אלה שבטבלה, ו-`dir`, `lang`. כל השאר — נזרק בניקוי. אין
`style`, `class`, `on*`, `script`, `iframe`, קישור חיצוני ב-`src`.

## 5. ניקוי ובדיקת תקינות (§6)

בשרת, ב-`DOMDocument` (לא regex — SPEC §11.6 ממצא 5). בכל שמירה:

| בדיקה | חומרה |
| --- | --- |
| תגית לא סגורה / קינון שבור | ❌ חוסם שמירה |
| `sid` כפול | ❌ |
| `sf-link` ל-`sid` שלא קיים | ⚠️ (חוסם פרסום) |
| `sf-cond` עם כלל שלא קיים, או שני תנאים סותרים על אותו קטע | ⚠️ (חוסם פרסום) |
| `sf-style` עם ערך לא מהרשימה | הניקוי מסיר, ⚠️ |
| רכיב / תכונה אסורים | הניקוי מסיר, ⚠️ עם הרשימה |

הניקוי **שומר** ניקוד וטעמים כמו שהם; ההסתרה היא פעולת תצוגה בלבד (§6, 04).

## 6. מנוע התצוגה

`assets/js/render.js` — מקבל `source_html` של גרסה ומפיק DOM: מקטעים, נקודות ציון, תנאים (לפי הגדרות שהקורא מעביר),
הערות שנפתחות בלחיצה. בונה עם `DOMParser` ו-`createElement` — לא `innerHTML` עם קלט. **אותו מודול** בתצוגה המקדימה
ובקורא (§6). התאמות אישיות לא משנות את המקור.

## 7. העורך ⚙️

- שני מצבים, באותו מסך: **חזותי** (סימון טקסט + כפתורים: מקטע, נקודת ציון, סגנון, תנאי, הוראה, פירוש, קישור) ו-**HTML**.
- הספרייה: לפי רישוי ומצב התחזוקה במועד הפיתוח (§18 — לא לאמץ את TinyMCE 6 אוטומטית). חובה: מתארחת בתוך `sforno/`
  (לא CDN), רישיון שמתיר את השימוש, עברית ו-RTL. חלופה מותרת: עורך `contenteditable` משלנו. ההכרעה — `team/decisions.md`.
- **תצוגה מקדימה** — אותו `render.js`, בשני רוחבים (360 ו-1024) זה לצד זה במחשב, או במתג בטלפון.

## 8. מחזור הפרסום (§16)

1. **טיוטה** — לכל מהדורה לכל היותר טיוטה פתוחה אחת. לא נגישה לשום כתובת ציבורית (§21.14).
2. **פרסום** — עובר את סעיף 5, יוצר `revision` חדשה ב-`published`, מסמן את הקודמת `superseded`, בונה `segments` ואינדקס.
   בלי אישור אדם נוסף (§16). נרשם `content.publish`.
3. **שחזור** — יוצר טיוטה חדשה מתוכן גרסה קודמת (`based_on_revision_id`); **לא מוחק** היסטוריה (§16, §21.14).
4. **עריכה מקבילה** — שמירה נושאת את מספר הטיוטה שנפתחה; מנהל אחר שמר בינתיים ← "מנהל אחר שינה — לטעון את השינויים?"
   בלי דריסה שקטה.
5. **ציבורי** = `public_allowed` + גרסה `published`. בשלב א' המנהל יכול להדליק רק כותר מסוג `siddur` / `tehillim`.

## 9. האינדקס המנורמל (§8)

בפרסום, לכל `segment`: `text_norm` = הטקסט בלי ניקוד וטעמים (U+0591–U+05C7), אותיות סופיות מאוחדות, רווחים מאוחדים.
מיפוי כתיב מלא/חסר וקיצורים — מילון מבוקר בטבלה `search_aliases` שהמנהל עורך; החיפוש עצמו ב-04.
