# 09 — החנות: קטלוג WooCommerce

**תלויה ב:** 01 (תור, cron), 05 (מועדפים מסונכרנים — אופציונלי). **מקור:** §13, §18. **קבלה מ-§21:** 12. **פתוח:** ⏳ ש4
(חיבור ישיר). 📦 כתובת החנות, גרסה, גישת בדיקה, מפתחות קריאה, ואיפה מאוחסנים מחבר / הוצאה / מהדורה (§24).

## 1. העיקרון (§13)

**WooCommerce הוא מקור האמת** למוצרים, מחירים, מלאי, מבצעים, וריאציות והזמנות. ספורנו **לא משנה** נתוני מסחר, **לא אוספת**
פרטי תשלום, ואין בה סל. כפתור הרכישה מעביר לעמוד המוצר באתר.

## 2. החיבור ⚙️

- WooCommerce REST API (`/wp-json/wc/v3/`), מפתח **קריאה בלבד** (`consumer_key`/`secret`), שנשמר ב-`data/woo.json` — בשרת,
  לעולם לא בדפדפן (§18). מסך בניהול להזנה ולבדיקה (המפתח לא מוצג אחרי שמירה).
- **סנכרון מתוכנן** — משימת רקע (01) כל שעה: מוצרים, קטגוריות, מחירים ומבצעים, מלאי, תמונות (קישור, לא העתקה), ביקורות
  ודירוגים קיימים. רענון מלא בלילה. שינויים בלבד ביום (`modified_after`).
- **מטמון** (`store_products`, `store_categories`, `store_reviews`) עם `synced_at` לכל רשומה.
- **מיפוי שדות** (📦): מחבר, הוצאה, מהדורה, כריכה, תוכן עניינים, דפי דוגמה — הגדרה בניהול: איזה attribute / meta / tag של
  WooCommerce הוא כל שדה. שדה שלא מופה ← לא מוצג (§13: "מידע שלא קיים לא יומצא").
- **קישור לכותר** (§18): טבלת `title_products` (רבים-לרבים) — "יש גם ספר דיגיטלי" בעמוד המוצר, בלי שכפול תוכן.

## 3. מה הקונה רואה (§13)

- **קטלוג:** חיפוש, סינון לפי קטגוריה, מחבר ומחיר; מועדפים (אורח — במכשיר; רשום — מסונכרן, 05). תמונות בטעינה עצלה (§20).
- **עמוד מוצר:** תיאור, תמונות, מחבר והוצאה, תוכן עניינים ודפי דוגמה, ספרים קשורים, ביקורות ודירוגים קיימים, מחיר מבצע
  קיים. **בלי כתיבת ביקורות**, בלי קופונים, בלי בחירת כמות.
- **"לרכישה באתר"** ← כתובת המוצר ב-WooCommerce, בחלון / לשונית חדשה. נספר כ"מעבר לחנות" (10).

## 4. כשל (§13)

- סנכרון שנכשל ← הקטלוג השמור מוצג, עם "המחירים והמלאי עודכנו לאחרונה ב-…; המחיר הסופי באתר". **אין מחיר או מלאי
  שמוצגים כמאומתים** כשהם ישנים מ-24 שעות.
- בניהול: מצב הסנכרון האחרון, מספר מוצרים, שגיאות; ובדיקת תקינות ב-01 (`health_register`).
