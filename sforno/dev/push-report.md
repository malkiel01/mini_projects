# ספורנו — בדיקת התראות על מכשירים אמיתיים (אפיון 08 §6, קריטריון 9; §12.2, §22.1)

**המסמך הזה קובע מה מובטח — לא מבטיחים מראש.** כל שורה מתמלאת מבדיקה אמיתית במכשיר, אחרי הפריסה. שורה ריקה = לא נבדק,
ולא מוצג למשתמשים כ"עובד".

## לפני הבדיקה

1. **cron רץ** — במסך המפתח ← ⚙️ רקע: "המתזמן — הצליח לפני X דקות". מומלץ **כל דקה** (`* * * * *`) — כל 5 דקות = עד 5
   דקות איחור. בלי cron: "התראת ניסיון" עובדת (נשלחת מיד), אבל תזכורת מתוזמנת **לא תישלח** כשהאפליקציה סגורה.
2. בכל מכשיר: ⏰ תזכורות ← "הפעלת התראות במכשיר הזה" ← לאשר ← "התראת ניסיון".
3. תזכורת "שעה קבועה" בעוד 4–6 דקות ← לסגור את האפליקציה (לא רק למזער) ← לחכות.
4. "בלי רשת" — מצב טיסה לפני מועד התזכורת, ולבטל אותו כעבור 2–3 דקות אחרי המועד: האם ההתראה מגיעה כשהרשת חוזרת
   (ה-TTL שנשלח: 15 דקות)?

## מה ידוע מראש (לא תחליף לבדיקה)

- **Web Push דורש רשת** ברגע שהספק מוסר את ההודעה. בלי רשת אין התראה מקומית מתוזמנת (אין API כזה ב-PWA); הורדת נתוני חודש
  אינה הוכחה ליכולת להתריע (§12.2).
- **iPhone:** רק PWA מותקנת (iOS 16.4+), ורק אחרי אישור מתוך האפליקציה המותקנת.
- **"נשלח" אינו "התקבל"** (§12.4): הלוג במסך המפתח רושם שהספק קיבל (HTTP 201), לא שהמשתמש ראה.
- ספק שמחזיר 404/410 — המנוי מסומן "לא פעיל" (המשתמש מפעיל מחדש מהמסך).
