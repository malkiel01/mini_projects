# מסכה וקטורית (vectorMask)

`vectorMask: { d, feather, enabled }` על שכבה (`creative-suite/docs/mbe-format.md` סעיף 3). בתוך הנתיב — נראה, מחוצה
לו — מוסתר. קצה חד שלא תלוי ברזולוציה, ואפשר לרכך אותו בלי לגעת בפיקסלים.

## בעורך

- **יצירה:** 🔷 באפשרויות של כלי הבחירה — הנתיב של הבחירה הנוכחית, על השכבה הפעילה. מחליפה מסכה וקטורית קיימת.
- **מה אפשר להפוך לנתיב:** מלבן, אליפסה (ארבע עקומות C) ולאסו. כמה צורות — רק הוספות. חיסור, בחירה הפוכה ומטה קסם
  — אין להם נתיב פשוט, ומקבלים הודעה.
- **בלוח השכבות:** 🔷 בשורה, ומתחת — ריכוך (0–64), השבתה ומחיקה. כל שינוי הוא צעד ביטול אחד.
- **עם מסכת שכבה:** שתיהן חלות, אחת כפול השנייה.
- **עם סגנונות שכבה:** האפקטים נוצרים מהשכבה אחרי שתי המסכות.
- **מה מזיז אותה:** חיתוך והזזת קבוצה. הזזה של תוכן בכלי ההזזה — לא, כמו מסכת השכבה.

## בפורמט

- **`d`:** פקודות מוחלטות `M L C Q Z` בלבד, ביחידות המשטח (בקנבס רסטר — פיקסלים). נבדק גם ב-`pathProblem` של הליבה.
- **`feather`:** ריכוך הקצה, באותן יחידות. בציור — טשטוש גאוסי עם σ = feather / 2. עד 64.
- **`enabled: false`:** נשמרת, ולא חלה.
- **המתכון:** `src` אפוי (כפול כל המסכות, עם האפקטים), ולצדו `source` ו-`baked`. בשכבת התאמה או מילוי — במקום `source`,
  ה-`adjust` / `fill` שלהן.
- **בפתיחה:** נטענת רק כש-`baked` תואם ו-`d` תקין. אחרת — `src` כתמונה רגילה, והמתכון נשמר כמו שהוא.
- **ORA ו-PNG:** אפויה (בדוח הפערים: `vector-mask → baked`).

## במנוע

- **רסטריזציה:** הנתיב מרוסטר לכל אריח ב-`OffscreenCanvas`, אל R8.
- **מטמון:** `layer._vm`, עד שה-`d`, הריכוך או הזזת הקבוצה משתנים. אריח כולו בחוץ / כולו בפנים — המסכות הקבועות, בלי מרקם חדש.
- **בהרכבה:** הכיסוי מוכפל ב-`blend` / `lerp` (מרקם רביעי), וב-`fxsrc` של סגנונות השכבה — מרופד בשכניו.
