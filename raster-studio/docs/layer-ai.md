# שכבת raster ומודול ה-AI לשכבות — מה משותף עם סטודיו העיצוב

מסמך של עיצוב רסטר (הבעלים של "שכבות וצבע" ושל "בינה מלאכותית לשכבות", `master-spec.md` סעיף 4). נכתב בתשובה
לשאלה 3 ב-`greeting-cards/spec/12-layered-ai-and-mbe.md`.

## 1. חיתוך, מסכה, היפוך ופילטרים — היום (פורמט 1.x)

**בפורמט אין להם שדות.** שכבת `raster` היא `src` (PNG) עם `opacity`, ‏`blend`, ‏`visible` ו-`locked`. בעיצוב רסטר ה-PNG
הוא בגודל הקנבס, במקום 0,0, והפיקסלים הם התוצאה הסופית.

**ההמלצה עד ר2 — לאפות:**

- **`src`:** התמונה אחרי חיתוך, מסכה, היפוך ופילטרים, כ-PNG שקוף. זה מה שכל אפליקציה מציגה ועורכת.
- **`box`:** המיקום בעמוד, אם המשטח שלכם הוא `page` ולא קנבס. השדה קיים בסכמה, כמו במסגרת התמונה של העימוד.
- **`apps/greeting-cards/`:** המקור והפרמטרים לעריכה חוזרת אצלכם: התמונה המקורית ב-`media/`, ‏crop, ‏mask, ‏flip,
  ‏filters ו-shadow.
- **זיהוי שינוי:** שמרו שם גם את ה-`src` שאפיתם. אם בפתיחה ה-`src` במסמך אחר, אפליקציה אחרת (למשל הרסטר) ערכה את
  הפיקסלים. במקרה כזה הפרמטרים שלכם כבר לא נכונים, ומציגים את השכבה כתמונה רגילה.
- **צל:** שכבה נפרדת מתחת, אפויה גם היא, או אפוי לתוך ה-PNG. `effects` קיים היום רק בפריט טקסט בשכבת `vector`.

## 2. בר2 — מבנה משותף, בבקשת פורמט אחת

> **הוגשה:** `creative-suite/docs/requests/raster-studio-r2.md` (2026-10-25). שם המבנה הסופי — הבקשה גוברת על הטיוטה
> כאן: `clip` נקרא שם `crop`, המסכה הווקטורית יצאה לשדה משלה (`vectorMask`), ונוספו `source` ו-`baked` (זיהוי שינוי —
> המנגנון שלכם ב-`apps/greeting-cards/`, עכשיו בפורמט).

בר2 הרסטר צריך מסכות שכבה, שכבות התאמה ופילטרים לא הורסים. זו בדיוק הרשימה שלכם. לכן לא נבנה שני מבנים: הבקשה
`creative-suite/docs/requests/raster-studio-r2.md` (אצל הצ'אט המתכלל) תכסה גם את הצרכים שלכם. הכיוון, טיוטה לדיון:

| צורך | שדה מוצע בשכבה | הערות |
| --- | --- | --- |
| חיתוך | `clip: [x, y, w, h]` | בפיקסלים של ה-`src` (לא שברים) — אותה יחידה בכל אפליקציה |
| היפוך / סיבוב / קנה מידה | `transform: [a, b, c, d, e, f]` | כמו ב-`vector` (6 מספרים). היפוך אופקי = `[-1,0,0,1,w,0]` |
| מסכה | `mask: { src: "media/…png" }` או `mask: { d: "M…Z", feather: 4 }` | ‏`src` — מסכת גוונים (רסטר); ‏`d` — מסכה וקטורית (עיגול / פינות מעוגלות), אותן פקודות מוחלטות כמו ב-`vector`; ‏`feather` — ריכוך הקצה, ביחידות המשטח (בעמוד — pt). ביקש סטודיו העיצוב |
| פילטרים | `filters: [{ type: "brightness", value: 0.2 }, …]` | ‏`type` — רשימה פתוחה; לפחות brightness, contrast, saturation, hue, blur |
| צל | `effects: [{ type: "shadow", … }]` | אותו מבנה כמו בפריט טקסט ב-`vector` |

**כלל קריאה:** אפליקציה שלא מכירה שדה מציגה את `src` כמו שהוא. לכן `src` יישאר תמיד התוצאה האפויה, והשדות הם
"מתכון" לעריכה חוזרת. כך קורא 1.0 לא נשבר.

לפני שאגיש את הבקשה, אשלח לכם את הטיוטה. אם חסר לכם משהו (למשל מסכה עם ריכוך), הוסיפו בתשובה.

## 3. מודול ה-AI לשכבות — הממשק

> **נבנה (2026-11-01):** `raster-studio/assets/js/layer-ai.js` מעל `drives.ai` של מודול הכוננים (ענן החבילה), והעורך —
> `ai-panel.js` (✨ בכותרת). כשאפליקציה נוספת תצטרך אותו — יעבור למודול משותף מסונכרן.

**מתי:** ר3, אחרי ר2. **הספק — לא נקבע:** שכבת הספקים בבעלות ענן החבילה, והמודול הזה יושב מעליה בלי תלות בספק (ראו "ספקים והרשאות" למטה). עד אז בנו מאחורי אותו ממשק (מימוש זמני
אצלכם). כשהמודול ייכנס, מחליפים את הייבוא.

**איך הוא מגיע:** כמו הליבה — מקור אחד, ועותק מסונכרן לכל אפליקציה. ב-JS הוא בדפדפן, וב-PHP הוא נקודת קצה בשרת של
כל אפליקציה. מפתח הספק לא מגיע לדפדפן, וכל אפליקציה נשארת עצמאית, עם השרת והמפתח שלה.

### JS — `layer-ai.js`

כל הפונקציות מחזירות PNG ב-sRGB, אלפא ישר, בקואורדינטות של תמונת הקלט. הן לא תלויות במודל של אף אפליקציה.

```js
import { createLayerAI } from './layer-ai/layer-ai.js';
const ai = createLayerAI({ cloud });   // לקוח ענן החבילה (cloud.ai); בלי ענן — הכול "לא זמין"

await ai.capabilities();          // { removeBackground: true, decompose: false, generate: true, fill: true } — מ-cloud.ai.capabilities
await ai.removeBackground(blob, { signal });              // → { png: Blob, mask: Blob }  (mask — גוונים, לבן = נשאר)
await ai.decompose(blob, { maxLayers: 6, signal });       // → { background: Blob, layers: [{ png, box: [x,y,w,h], label }] }
await ai.generate(prompt, { width, height, transparent: true, style, signal });   // → { png: Blob }
await ai.fill(blob, maskBlob, { prompt, signal });        // → { png: Blob }  (inpainting: המסכה הלבנה מתמלאת)
```

- **שגיאות:** `Error` עם `code`, כמו ב-`cloud.ai`: ‏`no-provider` / ‏`not-allowed` (להציג "לא זמין — דרך הצ'אט (סקיל)"),
  ‏`quota`, ‏`too-big`, ‏`provider`, ‏`aborted`.
- **ביטול:** כל פעולה מקבלת `signal` (AbortController).

### מאיפה הקריאה לספק — ענן החבילה

**אין שרת AI באפליקציה** (ענן החבילה, `suite-cloud/docs/spec-3-ai.md`, ‏#921). `layer-ai.js` רץ בדפדפן וקורא ללקוח הענן
(`cloud.ai`, מסונכרן לכל אפליקציה). הלקוח קורא ישר לשרת של הענן, עם האסימון הקצר של החיבור. המפתחות, ההרשאות לכל משתמש
והמכסה — שם. ב-`api.php` של האפליקציה אין `ai_*`, ואין PHP של ספקים.

### ספקים והרשאות — אצל ענן החבילה

**חלוקת הבעלות** (master-spec, הכרעות 2026-10-30, ‏#905, ‏#907, ‏#908):
- **שכבת הספקים — ענן החבילה:** ממשק מנהל אחד לכל החבילה, ספק ומפתח לכל אפליקציה, מתאם לכל ספק, מכסה ועלות.
- **המודול הזה — רסטר:** עיבוד הפיקסלים מעל שכבת הספקים (הסרת רקע, פירוק, יצירה שקופה, מילוי), בלי לדעת מי הספק.
- **המסלול הידני** (סקיל שמועבר לצ'אט) נשאר תמיד, לצד ה-API.

**דרישת בעל המערכת לשכבת הספקים** (2026-10-30, בצ'אט הזה): **כל הספקים נתמכים, והמנהל מחליט לכל משתמש אילו מהם
מותרים לו** (ומכסה). הועבר לענן החבילה דרך הצ'אט המתכלל.

**מה המודול צריך משכבת הספקים** — הוסכם עם ענן החבילה (`spec-3-ai.md` סעיפים 2 ו-4):

```js
await cloud.ai.capabilities();
//  → { tasks: { 'remove-background', segment, 'generate-image', inpaint: bool }, providers: [{ id, name, tasks }], default, quota }
await cloud.ai.run(task, { image, mask, prompt, size, transparent, provider }, { signal });
//  → { png: Blob } (אולי עם transparent: false) | segment: { masks: [{ png: Blob, label, box: [x, y, w, h] }] }
//  שגיאות: Error.code — no-provider / not-allowed / quota / too-big / provider / aborted
```

- **הפלט:** PNG ב-sRGB, אלפא ישר, בגודל ובקואורדינטות של הקלט. קלט עד 20MB ועד 4096 פיקסלים בצלע.
- **`segment`:** מסכת גוונים לכל עצם (לבן = העצם). מזה המודול בונה "פירוק לשכבות": חיתוך לפי המסכה, והשלמת הרקע ב-`inpaint`.
- **`generate-image`** עם `transparent: false` בתשובה — המודול מסיר רקע בעצמו (`remove-background`).
- **הספקים הראשונים** (הכרעת בעל המערכת): OpenAI, ‏Google ו-Replicate.

**המודול עושה את השאר בעצמו:** הקטנה לגודל שהספק מקבל, החזרה לגודל ולמיקום, קצוות רכים למסכה, הרכבה לשכבות
(`box`, `label`), וניקוי — בלי לדעת מי הספק. עד ששכבת הספקים מוכנה — `capabilities()` מחזיר הכול false, והכפתורים
מציגים "לא זמין — אפשר דרך הצ'אט (סקיל)".
