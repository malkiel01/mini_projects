## 1. העיקרון: הכול בענן, ולאפליקציה רק קריאה

| איפה | מה |
| --- | --- |
| **שרת `suite-cloud`** | מתאם לכל ספק, המפתחות (מוצפנים), ההרשאות לכל משתמש, המכסה, העלות, יומן השימוש, וממשק המנהל |
| **לקוח הענן** (מסונכרן לכל אפליקציה) | `cloud.ai.capabilities()` ו-`cloud.ai.run(…)`: קריאה דקה ל-API של הענן. אין בו שום פרט של ספק |
| **האפליקציה** (רסטר, סטודיו) | עיבוד הפיקסלים מעל הקריאה: הקטנה, החזרה למקום, ריכוך, הרכבה לשכבות. המודול של הרסטר (`layer-ai`) יושב כאן |

- **ספק חדש = מתאם אחד בענן.** אף אפליקציה לא משתנה.
- **התשובה לשאלה 1 של הרסטר:** הקריאה **לא** רצה בשרת של כל אפליקציה. הדפדפן של האפליקציה קורא ישר לענן, עם האסימון
  הקצר של החיבור (`spec-1-skeleton.md` סעיף 7.4). אפשר גם שרת-לשרת, בחתימה (סעיף 7.3). המפתח לא מגיע לדפדפן ולא
  לאפליקציה.
- **בלי ענן, או בלי ספק מותר למשתמש** → `capabilities()` מחזיר הכול `false`. האפליקציה מציגה "לא זמין — דרך הצ'אט
  (סקיל)". **המסלול הידני נשאר תמיד.**

## 2. המשימות

ארבע המשימות של הרסטר. השמות כאן הם השמות ב-API.

| משימה | קלט | פלט |
| --- | --- | --- |
| `remove-background` | `image` | `png` שקוף, בגודל הקלט |
| `segment` | `image` | `masks: [{png, label, box:[x,y,w,h]}]` — מסכת גוונים לכל עצם (לבן = העצם) |
| `generate-image` | `prompt`, `size`, `transparent?` | `png` |
| `inpaint` | `image`, `mask` (לבן = למלא), `prompt?` | `png` בגודל הקלט |

- **כל הפלט:** PNG ב-sRGB, אלפא ישר, בקואורדינטות של תמונת הקלט. אם הספק החזיר גודל אחר, הענן מחזיר לגודל הקלט.
- **`transparent`:** ספק שלא תומך בשקיפות לא נפסל. הענן מחזיר `{png, transparent:false}`, והרסטר מסיר רקע בעצמו
  (כמו שהציע).
- **רשימה פתוחה:** משימה חדשה (למשל `upscale`, `describe`) נוספת כאן ובמתאמים. אפליקציה שלא מכירה אותה — לא מבקשת.

## 3. הספקים — מתאם לכל אחד

```php
interface AiAdapter {
    public function id(): string;                         // 'openai', 'google', 'replicate', …
    public function tasks(): array;                       // אילו משימות הוא יודע
    public function run(string $task, array $in, array $key): array;   // → ['png' => bytes] | ['masks' => …]
    public function estimate(string $task, array $in): float;          // עלות משוערת בדולר, למכסה
}
```

- המתאמים יושבים ב-`suite-cloud/lib/ai/<id>.php`, והקריאה לספק נעשית ב-cURL מה-PHP (עיקרון 4).
- **הראשונים — שלושתם יחד** (הכרעת בעל המערכת, 2026-10-31, סעיף 9): OpenAI (`generate-image`, `inpaint`), Google
  (`generate-image`, `inpaint`), ו-Replicate (`remove-background` ו-`segment` במודלים פתוחים, כמו SAM ו-rembg). לשתי
  המשימות האלה אין ל-OpenAI ול-Google API ייעודי.
- **בדיקת מפתח:** "בדיקה" בממשק המנהל שולחת קריאה זולה לספק ומחזירה תקין / לא תקין, בלי לחשוף את המפתח.

## 4. ה-API

`suite-cloud/api.php`. אפליקציה מחוברת צריכה את ההרשאה `ai` (בנוסף ל-`files` / `libs`).

| פעולה | גוף | תשובה |
| --- | --- | --- |
| `ai_capabilities` | — | `{tasks:{'remove-background':bool, segment:bool, 'generate-image':bool, inpaint:bool}, providers:[{id, name, tasks}], default:{<task>: <provider>}, quota:{used, limit, unit}}` |
| `ai_run` | `multipart/form-data`: ‏`task`, ‏`image?`, ‏`mask?`, ‏`prompt?`, ‏`size?` (`"1024x1024"`), ‏`transparent?`, ‏`provider?` | `image/png` לפלט יחיד; ל-`segment` — JSON: `{masks:[{png:<base64>, label, box}]}` |

**השגיאות** (`{"error":"…","code":"…"}`), אותם קודים כמו אצל הרסטר:

| `code` | מתי |
| --- | --- |
| `no-provider` | למשימה אין אף ספק מוגדר בענן |
| `not-allowed` | יש ספק, אבל אינו מותר למשתמש הזה, או לאפליקציה הזו |
| `quota` | המכסה החודשית של המשתמש נגמרה |
| `too-big` | קלט מעל 20MB, או מעל 4096 פיקסלים בצלע |
| `provider` | הספק החזיר שגיאה, או לא ענה תוך 120 שניות. ההודעה בעברית, והפרטים ביומן |
| `aborted` | בצד הלקוח, כשהבקשה בוטלה (`signal`) |

**בלקוח הענן (JS)** — אותה צורה שהרסטר ביקש:

```js
await cloud.ai.capabilities();
await cloud.ai.run('inpaint', { image, mask, prompt }, { signal });   // → { png: Blob } | { masks: [{ png: Blob, label, box }] }
```

**זמן:** יצירת תמונה לוקחת 10–60 שניות. בשלב הראשון הקריאה סינכרונית (`set_time_limit(130)`). אם השרת יחתוך
בקשות ארוכות, נעבור ל-`ai_job` + `ai_job_status` בלי לשנות את `cloud.ai.run` (הלקוח ימתין בעצמו).

## 5. הרשאות ומכסה — מנהל הענן מחליט לכל משתמש

זו דרישת בעל המערכת שהגיעה דרך הרסטר: "כל הספקים נתמכים, והמנהל מחליט לכל משתמש אילו מותרים לו".

| רמה | מה קובעים |
| --- | --- |
| **ספק** | מפתח, דלוק / כבוי |
| **אפליקציה** | אילו משימות מותרות לה, והספק ברירת המחדל לכל משימה |
| **משתמש** | אילו ספקים מותרים לו (ברירת מחדל: אף אחד), ומכסה חודשית בדולר משוער |

- **ברירת המחדל סגורה:** משתמש חדש לא מקבל AI עד שהמנהל מתיר. כך גם הנפח בכונן.
- **`provider` בבקשה** — רק מתוך המותרים למשתמש. בלי — ברירת המחדל של האפליקציה למשימה.
- **המכסה נבדקת לפני הקריאה** (לפי `estimate`), ונרשמת אחריה. יומן: מי, איזו אפליקציה, משימה, ספק, עלות, זמן, הצלחה.
  **התמונות עצמן לא נשמרות בענן.**

## 6. המפתחות — בלי סוד בקוד ובלי סוד בצ'אט

- **בעל המערכת מכניס את המפתח בעצמו**, בממשק הניהול של הענן (⚙️ ← 🤖 בינה מלאכותית ← ספק ← "מפתח"). המפתח לא עובר
  בצ'אט, ולא נכנס לגיט.
- **הצפנה:** `sodium_crypto_secretbox`, עם מפתח הצפנה בקובץ `data/secret.key`. הקובץ נוצר בשרת בהפעלה הראשונה
  (הרשאות 0600), והוא מוחרג בפריסה (`suite-cloud/data/*`). במסד נשמר רק הטקסט המוצפן.
- **בממשק** רואים רק את 4 התווים האחרונים. אחרי שמירה אי אפשר לקרוא את המפתח בחזרה, רק להחליף או למחוק.

## 7. ממשק המנהל — לשונית "🤖 בינה מלאכותית" בניהול

1. **ספקים:** שורה לכל ספק — מצב (✓ / אין מפתח), המשימות שלו, ✏️ מפתח, "בדיקה".
2. **אפליקציות:** לכל אפליקציה מחוברת — משימות מותרות, וספק ברירת מחדל לכל משימה (בורר מקטעים).
3. **משתמשים:** בגיליון המשתמש הקיים (המכסה בכונן) נוספים ספקים מותרים ומכסה חודשית.
4. **שימוש:** כרטיס סיכום ("החודש: $12.40 · 318 קריאות"), ומתחתיו שורות לפי אפליקציה ולפי משתמש.

## 8. הסדר

1. **האפיון הזה.** הערות מהרסטר ומהסטודיו לפני קוד.
2. **חיבור אפליקציה** (`connect`, אסימון, ההרשאות `files` / `libs` / `ai`) — תנאי לכל צרכן.
3. **שכבת ה-AI בשרת:** המתאמים, המפתחות, ההרשאות, המכסה, הניהול, ו-`ai_capabilities` / `ai_run`. **ולקוח הענן**
   עם `cloud.ai`. מכאן הרסטר והסטודיו מחליפים את המימוש הזמני (`capabilities()` שמחזיר הכול `false`) בקריאה אמיתית.
4. ספריית הגופנים (`spec-2-fonts.md`).

**עד שלב 3:** המימוש הזמני של הרסטר — הכול `false`, עם "לא זמין — דרך הצ'אט (סקיל)" — נכון בדיוק. הממשק לא ישתנה.
