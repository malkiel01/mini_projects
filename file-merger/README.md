# איחוד ופיצול קבצים

* **איחוד** — תמונות ו/או קבצי PDF, בסדר שבוחרים, לקובץ PDF אחד.
* **פיצול** — כל עמוד ב-PDF מומר לתמונה, והכל נארז ל-ZIP.

רץ כולו בדפדפן (pdf-lib · pdf.js · JSZip, שמורות ב-`vendor/`). אין backend, אין העלאה,
אין קריאות רשת אחרי הטעינה — ולכן אין כאן `api.php` כמו בכלים האחרים בריפו.

## תחזוקה

כל הנתיבים יחסיים, כך שהתיקייה עובדת מכל מיקום בשרת.

האפליקציה רושמת service worker (עבודה ללא אינטרנט) בהיקף `.../file-merger/` בלבד —
הוא לא נוגע בשאר הכלים בריפו. **אחרי כל שינוי בקבצים כאן חובה להעלות את `CACHE_VERSION`
ב-`service-worker.js`**, אחרת מבקרים חוזרים ימשיכו לקבל את הגרסה הישנה מהמטמון.

מקור עצמאי ומלא (עם רישיון והוראות עדכון הספריות): https://github.com/malkiel01/file-merger
