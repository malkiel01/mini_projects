# תיבת-מייל (`mailbox/`)

ממשק קריאה לתיבות דואר אמיתיות (IMAP), בדפדפן. נבנה לסרט-ההדרכה של "חברה קדישא": המערכת שולחת
מייל עם קוד אימות או קישור לחתימה, והמצולם פותח את התיבה, רואה את ההודעה ומעתיק את הקוד.
Gmail ו-Outlook חוסמים דפדפן אוטומטי, ולכן יש ממשק משלנו מעל תיבה ב-cPanel.

**הכתובת:** https://mbe-plus.com/mini_projects/mailbox/

## כניסה

רק דרך הכלים הדיגיטליים. אין סיסמה משלה ואין קובץ `.env`.
- `app.json` עם `"gate": true` ו-`"restricted": true`. הרשאה לקטגוריה לא פותחת את האפליקציה; בעל המערכת
  מאשר כל משתמש ישירות עליה (⚙️ ← משתמשים ← ✓ מותר).
- המשתמש מגיע מ-`$_SERVER['PLATFORM_USER']` (`sub`, `name`, `email`, `platform_admin`). כשאין
  משתמש (אפליקציה מנותקת), אין כניסה בכלל.

## מה יש (שלב א׳: קריאה בלבד)

- **דואר נכנס:** 50 ההודעות האחרונות, עם שולח, נושא, תקציר ושעה בשעון ישראל.
  - נקודה ליד הודעה שלא נקראה, 📎 לצרופות, ו-🔑 כשיש קוד אימות.
  - רענון כל 15 שניות (וכפתור ⟳). הודעה חדשה מודגשת ומסומנת "חדש".
- **הודעה:**
  - HTML מסונן בשרת ומוצג בתוך `<iframe sandbox>` בלי `allow-scripts`, עם CSP.
  - טקסט רגיל כגיבוי, וקישורים בלשונית חדשה.
  - הפתיחה מסמנת את ההודעה כנקראה (`\Seen`).
- **צ'יפ קוד אימות:** 4 עד 8 ספרות ליד "קוד", "אימות", code או OTP. מוצג בראש ההודעה עם "העתק".
- **צרופות:** הורדה. PDF נפתח בצופה בתוך הדף (pdf.js מ-`vendor/pdfjs`, שעובד גם באנדרואיד), עם
  דפדוף, זום וצביטה.
- **תיבות (☰, או לחיצה על השם בכותרת):**
  - כמה תיבות לכל משתמש, ומעבר ביניהן.
  - ✏️ פותח שם לתצוגה ("דואר — חברה קדישא"), שיתוף לקריאה לפי מייל, והסרה מהאפליקציה.
- טלפון: רשימה ← הודעה. מחשב: שתי עמודות. מצב כהה אוטומטי.

**אין:** שליחה, מחיקה, תיקיות וחיפוש. אלה שלב ב׳.

## איך מוסיפים תיבה

☰ ← "+ תיבה":
- **מייל וסיסמה** של התיבה.
- **שרת IMAP:** ברירת המחדל `box2054.bluehost.com`. **לא** `mail.mbe-plus.com`, כי שם בדיקת התעודה נכשלת.
- **פורט:** 993 (SSL) או 143 (STARTTLS).

החיבור נבדק מול השרת לפני השמירה, והתעודה תמיד נבדקת (בלי `novalidate-cert`). הסיסמה נשמרת מוצפנת,
ולעולם לא חוזרת לדפדפן.

**ייבוא חד-פעמי מהשרת:**
- כל קובץ `~/.mailbox/*.json` (`{email, imap_host, imap_port, password}`) נכנס כתיבה של בעל המערכת,
  בפעם הראשונה שהוא (`platform_admin`) נכנס.
- התיבה נשמרת מוצפנת במסד, **והקובץ נמחק**.

## כתובות חדשות אצלנו (@mbe-plus.com)

הדואר יושב אצלנו, כמו ב-Gmail: "+ תיבה" ← "כתובת חדשה אצלנו" ← בוחרים שם ← "יצירה". **אף משתמש לא נכנס ל-cPanel**,
כי הוא אזור של המפתח בלבד (הכרעת בעל המערכת, 2026-10-26).

- **פתיחה:** האפליקציה פותחת את התיבה בשרת דרך UAPI של cPanel (`Email::add_pop`, 1GB), עם סיסמה אקראית ומוצפנת
  במסד. המשתמש לא צריך סיסמה.
- **מכסה:** כל משתמש עד 3 כתובות. מנהל הפלטפורמה בלי הגבלה.
- **שמות:** שמות שמורים (admin, postmaster, info…) חסומים, וכתובת תפוסה נדחית.
- **מחיקה:** "מחיקת הכתובת לצמיתות" מוחקת את התיבה מהשרת (`Email::delete_pop`) עם כל הדואר, אחרי אישור.
  תיבה שחוברה מבחוץ רק מתנתקת.
- **הפעלה חד-פעמית, רק למפתח:**
  1. ב-cPanel: Security ← Manage API Tokens ← Create.
  2. מדביקים את האסימון בממשק ("+ תיבה" ← "כתובת חדשה אצלנו" ← "הפעלה"). רק מנהל הפלטפורמה רואה את השדה.
  3. האסימון נבדק מול השרת ונשמר מוצפן.

  חלופה: הקובץ `~/.mailbox/cpanel.json` (`{"token": "…"}`) נקלט בכניסה הבאה של המנהל, ונמחק.
  אם PHP בשרת רשאי להריץ את `uapi`, זה עובד גם בלי אסימון.
- **Outlook:** "חיבור תיבה קיימת" ← Outlook מציג את הכתובות של המשתמש אצלנו עם כפתור העתקה, ואת הצעדים להפעלת
  העברה ב-Outlook. חיבור ישיר (OAuth של מיקרוסופט) יבוא בהמשך.

## כמה תיבות

- כל משתמש מוסיף כמה תיבות שהוא רוצה (☰ ← "+ תיבה").
- **מעבר בין תיבות:** לחיצה על שם התיבה בכותרת (▾ מופיע כשיש יותר מתיבה אחת), או ☰.
- ברשימת התיבות מופיע לכל תיבה מספר ההודעות שלא נקראו.
- האפליקציה זוכרת את התיבה האחרונה בכל מכשיר.

## חיבור Gmail וספקים חיצוניים

בטופס "הוספת תיבה" ← "חיבור תיבה קיימת" יש בחירת ספק: Gmail, Outlook, Yahoo, iCloud, mbe-plus.com (כתובת קיימת) או אחר. לכל ספק מוצג **מדריך בתוך הממשק**: הצעדים אצל הספק (עם קישור לדף המדויק), והשרת, הפורט, שם המשתמש והסיסמה שממלאים. הבחירה ממלאת את שם השרת לבד. ב-Outlook מוצג רק מדריך להעברה לכתובת אצלנו, בלי שדות ובלי שמירה.

| ספק | שרת | סיסמה |
| --- | --- | --- |
| השרת שלנו (cPanel) | `box2054.bluehost.com` | הסיסמה של התיבה |
| Gmail | `imap.gmail.com` | **סיסמת אפליקציה** (16 תווים) |
| Yahoo | `imap.mail.yahoo.com` | **סיסמת אפליקציה** |
| iCloud | `imap.mail.me.com` | סיסמה ייעודית לאפליקציה (appleid.apple.com) |
| Outlook / Hotmail | — | **לא נתמך** |

**Gmail, צעד אחר צעד:**
1. בחשבון Google מפעילים "אימות דו-שלבי".
2. נכנסים ל-myaccount.google.com/apppasswords, יוצרים סיסמה בשם "תיבת-מייל" ומעתיקים את 16 התווים.
3. באפליקציה: "+ תיבה" ← Gmail ← המייל וסיסמת האפליקציה ← "בדיקה ושמירה".

**חשבון Workspace (Gmail ארגוני):** המנהל צריך לאפשר סיסמאות אפליקציה ו-IMAP.

**Outlook:** מיקרוסופט חסמה כניסה בסיסמה ל-IMAP. **הפתרון היום:** פותחים כתובת אצלנו, ומגדירים ב-Outlook העברה אליה (המדריך בממשק). חיבור ישיר דורש כניסת OAuth (רישום אפליקציה ב-Azure), וזה עבודה לשלב ב׳.

## שיתוף

הבעלים מוסיפים מייל של משתמש בכלים הדיגיטליים. ההרשאה היא קריאה בלבד.
- השיתוף מתקשר ל-`sub` של המשתמש בכניסה הראשונה שלו, ורק אם הפלטפורמה אימתה את המייל.
- המשתמש צריך גם הרשאה לאפליקציה עצמה (היא `restricted`).
- רק הבעלים יכולים לשנות שם, לשתף או להסיר.

## אחסון ואבטחה

```
api.php               ה-API (JSON). בקשה משנה חייבת את הכותרת X-Mailbox
lib/db.php            SQLite, והצפנה ב-sodium (crypto_secretbox)
lib/auth.php          PLATFORM_USER, הרשאות לתיבות, ייבוא חד-פעמי
lib/imap.php          ext-imap: רשימה, הודעה, צרופה, פענוח, קוד אימות
lib/sanitize.php      סינון HTML ברשימה לבנה
lib/cpanel.php        כתובות חדשות: UAPI של cPanel (אסימון מוצפן במסד, או uapi)
data/mailbox.sqlite   התיבות, השיתופים ומטמון הכותרות. לא בגיט, מוחרג בפריסה
data/secret.key       מפתח ההצפנה. נוצר בשרת בפעם הראשונה. לא בגיט, מוחרג בפריסה
vendor/pdfjs/         pdf.js 3.11.174, קבצים מוכנים (אין Node בשרת)
tests/                בדיקות מקומיות. לא נפרסות
```

- **מטמון:** כותרות ותקציר לכל הודעה נשמרים במסד לפי `(תיבה, UIDVALIDITY, UID)`, כי הודעה ב-IMAP לא
  משתנה. מצב "נקרא" תמיד טרי מהשרת.
- **רשימה בלי סימון:** כל קריאת גוף היא `FT_PEEK`, ולכן הרשימה לא מסמנת הודעות כנקראו.
- **HTML זדוני — שתי שכבות:**
  1. בשרת: `script`, `iframe`, `form`, `object`, `svg`, `on*` ו-`javascript:` נמחקים. ב-CSS: `@import`,
     `expression()` ו-`url(javascript:)`.
  2. בדפדפן: `sandbox` בלי `allow-scripts`, ו-CSP עם `default-src 'none'`.
- **צרופה:** מוגשת עם `nosniff` ו-`CSP: sandbox`. HTML ו-SVG תמיד יורדים כקובץ, ולא מוצגים.
