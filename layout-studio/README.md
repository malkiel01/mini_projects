# עימוד (`layout-studio/`)

תוכנת עימוד בסגנון InDesign — ספרים, חוברות ועלונים. עמודים ועמודי אב, מסגרות טקסט שהטקסט זורם ביניהן, מסגרות
תמונה, סגנונות, ופלט PDF להדפסה. שומרת ופותחת `.mbe` מסוג `layout`. פרויקט 4 בחבילת היצירה — ההנחיות:
`creative-suite/docs/projects/layout-studio.md`.

> סטטוס: **שלד** — רישום, דף פתיחה, משתמשים משלה וספריית מסמכים בשרת. עריכת העמודים — השלב הבא.
> ההכרעות של בעל המערכת (2026-10-24) — בטבלה למטה.

כתובת: https://mbe-plus.com/mini_projects/layout-studio/

## מה עובד

- **רישום** (`app.json`): שער (`gate`), `restricted` בזמן הפיתוח — רק מי שאושר לו ישירות.
- **משתמשים משלה** (`lib/auth.php`, לפי `platform/docs/sso.md` סעיף 0): הזהות מגיעה מהשער ב-`PLATFORM_USER`;
  חשבון מקושר ל-`sub`, איחוד לפי מייל לחשבון לא מקושר, אחרת — חשבון חדש, פעיל. **הראשון — מנהל העימוד.** אין
  סיסמה ואין עוגייה: כל בקשה מזוהה מחדש מהשער.
- **ספריית מסמכים** (`lib/docs.php`): רשימה, מסמך חדש (שם + גודל עמוד: A4 · A5 · B5 · 17×24 · אחר במ"מ), מחיקה
  (רכה — `deleted_at`). גודל העמוד נשמר ב-`pt`, כמו ב-`.mbe`.
- **API** (`api.php`): ‏POST עם JSON ‏`{action}` וכותרת `X-Layout-Studio: 1` (הגנת CSRF). פעולות: `me`, `docs_list`,
  `doc_create`, `doc_delete`.
- **נתונים:** `data/layout.sqlite` (גרסת מסד ב-`user_version`), ו-`data/files/` למשאבים בהמשך — שניהם מוחרגים
  ב-`deploy.yml`; `data/` ו-`lib/` חסומים לגישה ישירה.

**בדיקות:** `php layout-studio/tests/run.php` — משתמשים (זהות חסרה/פגומה, ראשון מנהל, איחוד לפי מייל) ומסמכים
(גדלים, ולידציה, בעלות, מחיקה).

## העיקרון

**מודל אחד, שני מציירים.** מנוע העימוד שלנו (JS) מחשב מכל שטף טקסט את השורות — איזו מילה באיזו שורה, באיזו
מסגרת, באיזה עמוד ובאיזה מיקום, **עד מיקום כל גליף**. הקנבס מצייר את השורות האלה, וה-PDF מצייר **את אותן שורות
בדיוק**. כך מה שרואים הוא מה שמודפס, ושבירת עמוד לא "זזה" בייצוא.

| שאלה | הכרעה | מה זה מחייב |
| --- | --- | --- |
| מנוע התצוגה | **קנבס** | הכול שלנו: סמן, בחירה, הקלדה (`textarea` נסתר ל-IME ולמקלדת הטלפון), bidi, מדידה. לנגישות — שכבת DOM שקופה עם הטקסט של העמוד הנראה. מציירים רק עמודים שנראים |
| פלט PDF | **מחכים למנוע של עורך התמלילים** | לא כותבים PDF משלנו. מה שהעימוד צריך מהמנוע — בבקשה `creative-suite/docs/requests/layout-studio-pdf.md`. עד אז: עימוד, `.mbe` ו-`preview.png` (מהקנבס) — בלי `document.pdf` |
| המסמך הראשון | **ספר מנוקד / תפילה** | ניקוד (ואולי טעמים) **בגרסה 1**. דורש עיצוב גליפים אמיתי (shaping) — מיקום סימנים לפי טבלאות GPOS של הגופן, לא "תו אחרי תו". מועמד: HarfBuzz ב-WASM (רישיון MIT) בתוך התיקייה. גופנים: חופשיים עם ניקוד מלא (Frank Ruhl Libre, David Libre; לטעמים — לבדוק רישיון) |
| אחסון | **ספרייה בשרת מההתחלה** | משתמשים משלה (השער, עוגייה משלה), מסד SQLite ומשאבים בשרת, גרסאות. **`--exclude` ב-`deploy.yml` לפני הכתיבה הראשונה.** הורדה ופתיחה של `.mbe` מהמכשיר — גם כן |

## גרסה 1 — בתחום

| תחום | מה |
| --- | --- |
| **ספרייה** | מסמכים בשרת לכל משתמש, גרסאות, הורדה ופתיחה של `.mbe` |
| **מסמך** | גודל עמוד (A4, A5, B5, מותאם — ב-`pt`), שוליים פנימיים/חיצוניים, **עמודים כפולים** (spread, כריכה מימין — ספר עברי), גלישה (bleed) |
| **עמודי אב** | עמוד אב לזוגי ולאי-זוגי, מסגרות שחוזרות, **מספור עמודים** אוטומטי (כולל אותיות עבריות), התחלה ממספר |
| **מסגרות טקסט** | מלבניות; **שטף (threading)** בין מסגרות ועמודים; טורים ומרווח; "הוסף עמודים עד סוף הטקסט"; סימון גלישה (➕ אדום) |
| **טקסט** | עברית מימין לשמאל מהיסוד, bidi, **ניקוד** (shaping), יישור לשני הצדדים, אלמנות ויתומות |
| **סגנונות** | פסקה ותו, עם ירושה (`basedOn`); עריכה משנה את כל המסמך |
| **מסגרות תמונה** | הצבה מקובץ, חיתוך בתוך המסגרת, התאמה (מלא / התאם / מרכז); גלישת טקסט סביב מלבן המסגרת |
| **ייבוא** | `.mbe` של עורך התמלילים (`kind: "text"` — השטף נכנס כמו שהוא); docx — דרך עורך התמלילים (שמירה כ-`.mbe` שם, פתיחה כאן) |
| **פלט** | `.mbe` עם `preview.png`; PDF להדפסה — כשמנוע עורך התמלילים זמין (ראו הכרעות) |
| **טלפון** | צפייה ודפדוף בעמודים, תיקוני טקסט קטנים בתוך שטף; עימוד מלא — טאבלט ומחשב |

## לא בגרסה 1

IDML, CMYK והפרדות צבע, צורות לא-מלבניות (מגיעות כשכבות `vector`), עריכת תמונה במקום, תוכן עניינים ואינדקס
אוטומטיים, הערות שוליים, עבודה משותפת בזמן אמת, docx כפלט.

## המודל ב-`.mbe`

לפי `creative-suite/docs/mbe-format.md` — בלי שדות חדשים במעטפת:

- כל עמוד = `surface` מסוג `page`, ו-`master` מפנה לעמוד אב (משטח מסוג `master`).
- מסגרת טקסט = שכבת `frame` עם `box` ו-`flow`. **סדר המסגרות בשטף** — נדרש שדה (למשל `flowIndex`) — יוגש כבקשה
  ב-`creative-suite/docs/requests/layout-studio-frames.md` כשהמודל ייסגר, לא לפני.
- מסגרת תמונה = `frame` עם `src: "media/<sha256>.<ext>"` וחיתוך.
- שטף = ProseMirror JSON (`engine: "prosemirror"`), כמו שעורך התמלילים שומר — כדי שייבוא ממנו לא ידרוש תרגום.
- מצב תצוגה (זום, עמוד אחרון) — ב-`apps/layout-studio/`.

## מה טרם הוכרע

1. **HarfBuzz ב-WASM** — ניסוי ראשון: ניקוד וטעמים בקנבס, ומדידה זהה לזו שה-PDF יצטרך. אם לא מספיק — חוזרים לבעל המערכת.
2. גופן לטעמים (רישיון שמותר להטמיע).
3. שדה סדר המסגרות בשטף — בקשה לצ'אט המתכלל כשהמודל ייסגר.
4. ממשק מנוע ה-PDF — לפי תשובת עורך התמלילים.
