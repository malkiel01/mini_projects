# עימוד (`layout-studio/`)

תוכנת עימוד בסגנון InDesign — ספרים, חוברות ועלונים. עמודים ועמודי אב, מסגרות טקסט שהטקסט זורם ביניהן, מסגרות
תמונה, סגנונות, ופלט PDF להדפסה. שומרת ופותחת `.mbe` מסוג `layout`. פרויקט 4 בחבילת היצירה — ההנחיות:
`creative-suite/docs/projects/layout-studio.md`.

> סטטוס: **עמודי אב** — ספרייה בשרת, ועורך בקנבס: שוליים, עמודים כפולים, זום ודפדוף, עמוד אב עם מספר עמוד וכותרת רצה. הטקסט — בשלבים הבאים.
> ההכרעות של בעל המערכת (2026-10-24) — בטבלה למטה.

כתובת: https://mbe-plus.com/mini_projects/layout-studio/

## מה עובד

- **רישום** (`app.json`): שער (`gate`), `restricted` בזמן הפיתוח — רק מי שאושר לו ישירות.
- **משתמשים משלה** (`lib/auth.php`, לפי `platform/docs/sso.md` סעיף 0): הזהות מגיעה מהשער ב-`PLATFORM_USER`;
  חשבון מקושר ל-`sub`, איחוד לפי מייל לחשבון לא מקושר, אחרת — חשבון חדש, פעיל. **הראשון — מנהל העימוד.** אין
  סיסמה ואין עוגייה: כל בקשה מזוהה מחדש מהשער.
- **ספריית מסמכים** (`lib/docs.php`): רשימה, מסמך חדש (שם + גודל עמוד: A4 · A5 · B5 · 17×24 · אחר במ"מ), מחיקה
  (רכה — `deleted_at`). גודל העמוד נשמר ב-`pt`, כמו ב-`.mbe`.
- **API** (`api.php`): ‏POST עם JSON ‏`{action}` וכותרת `X-Layout-Studio: 1` (הגנת CSRF). פעולות: `me`, `docs_list`,
  `doc_create`, `doc_get`, `doc_save` (המודל כמחרוזת JSON + `rev`), `doc_delete`.
- **נתונים:** `data/layout.sqlite` (גרסת מסד ב-`user_version`), ו-`data/files/` למשאבים בהמשך — שניהם מוחרגים
  ב-`deploy.yml`; `data/` ו-`lib/` חסומים לגישה ישירה.

- **העורך** (`editor.html?id=…`): העמודים בקנבס, פריסה אחרי פריסה (כמו לוח העמודים של InDesign). רק הפריסות שנראות
  מצוירות; הגלילה — של הדפדפן (תנופה בטלפון), והקנבס בגודל החלון בלבד (`assets/js/view.js`).
  - **זום:** − / % / +, ‏Ctrl+גלגלת ו-Ctrl ‏+ / − / 0, וצביטה בטלפון — מגדילה רק את המסמך. לחיצה על האחוז — התאמה למסך.
  - **דפדוף:** › ‹ בין פריסות, PageUp / PageDown; בסרגל — "2–3 / 6".
  - **הגדרות** (⚙️): גודל עמוד, שוליים במ"מ (עליון, תחתון, פנימי, חיצוני), עמודים כפולים, צד הכריכה, מספר עמודים.
    "+ עמודים" מוסיף פריסה בסוף.
  - **שמירה:** כל שינוי נשמר אחרי רגע; בכותרת — נשמר / שומר / לא נשמר. שמירה מלשונית שבינתיים התיישנה נדחית (`rev`)
    ומציעה לטעון מחדש — לא דורסת.
  - **עמוד אב A** (בהגדרות): **מספר עמוד** (למטה / למעלה × בחוץ / באמצע / בפנים — "בחוץ" מתחלף לבד בין זוגי
    לאי-זוגי) ו**כותרת רצה** (טקסט לעמוד אי-זוגי ולזוגי, למשל שם הפרק ושם הספר). כל עמוד חדש משויך ל-A.
  - **מספור:** מאיזה מספר מתחילים, ובספרות או באותיות (א, ב… טו, טז… קטו, א׳ה).
  - **עמוד נבחר:** הקשה על עמוד בוחרת אותו (מסגרת כחולה), ו"📄 עמוד N" בסרגל קובע לו עמוד אב — A או ללא (שער,
    עמוד ריק), גם לעמוד השני בפריסה ולכל העמודים שאחריו. מתחת לכל עמוד — המספר ועמוד האב ("5 · A").
  - הטקסט של עמוד האב מצויר בינתיים בגופן מערכת; הגופנים המוטמעים ועיצוב הגליפים — בשלב הטקסט.
- **הגאומטריה** (`assets/js/pages.js`, בלי DOM): פריסות, צד השדרה, שוליים פנימיים/חיצוניים ומיקום כל עמוד.
  **כריכה מימין** (ספר עברי): עמוד 1 לבד משמאל לשדרה, ואחריו זוגות — זוגי מימין, אי-זוגי משמאל.

**בדיקות:** `php layout-studio/tests/run.php` (52) · `node --test layout-studio/tests/pages.test.mjs` (19) — משתמשים (זהות חסרה/פגומה, ראשון מנהל, איחוד לפי מייל) ומסמכים
(גדלים, ולידציה, בעלות, מחיקה, שמירה עם `rev`, בדיקת המודל, מסמך מגרסת מסד 1).

## העיקרון

**מודל אחד, שני מציירים.** מנוע העימוד שלנו (JS) מחשב מכל שטף טקסט את השורות — איזו מילה באיזו שורה, באיזו
מסגרת, באיזה עמוד ובאיזה מיקום, **עד מיקום כל גליף**. הקנבס מצייר את השורות האלה, וה-PDF מצייר **את אותן שורות
בדיוק**. כך מה שרואים הוא מה שמודפס, ושבירת עמוד לא "זזה" בייצוא.

## המודל ב-`.mbe`

לפי `creative-suite/docs/mbe-format.md` — בלי שדות חדשים במעטפת:

- כל עמוד = `surface` מסוג `page`, ו-`master` מפנה לעמוד אב (משטח מסוג `master`). גרסה 1 — כל העמודים באותו גודל.
- **`layout`** — שדה בשורש המסמך (ממומש, `lib/model.php`): `facing` (עמודים כפולים), `binding` (‏`right` / `left`),
  `margins` (‏`top`, `bottom`, `inside`, `outside` ב-pt; `inside` = צד השדרה), `numbering` (‏`start`, ‏`style`:
  ‏`arabic` / `hebrew`).
- **עמוד אב** = משטח `{type: "master", id, name, size, layers, running}`; ‏`running.folio` (מספר עמוד) ו-`running.header`
  (‏`odd` / `even`) — מיקום סמנטי (‏`position`: ‏`top` / `bottom`, ‏`align`: ‏`outside` / `center` / `inside`), לא
  קואורדינטות, כך ששינוי שוליים או כריכה מזיז אותם לבד. מסגרות על עמוד האב — ב-`layers`, בשלב המסגרות. לאפליקציות אחרות זה שדה לא מוכר —
  נשמר בית-לבית. הוגש לצ'אט המתכלל: `creative-suite/docs/requests/layout-studio-model.md`.
- מסגרת טקסט = שכבת `frame` עם `box` ו-`flow`. **סדר המסגרות בשטף** — נדרש שדה (למשל `flowIndex`) — יוגש כבקשה
  ב-`creative-suite/docs/requests/layout-studio-frames.md` כשהמודל ייסגר, לא לפני.
- מסגרת תמונה = `frame` עם `src: "media/<sha256>.<ext>"` וחיתוך.
- שטף = ProseMirror JSON (`engine: "prosemirror"`), כמו שעורך התמלילים שומר — כדי שייבוא ממנו לא ידרוש תרגום.
- מצב תצוגה (זום, עמוד אחרון) — ב-`apps/layout-studio/`.

## ניסוי הניקוד (2026-10-24)

`lab/shaping.html` — כל דוגמה פעמיים: HarfBuzz (כך העימוד יצייר וימדוד) מול `fillText` של הדפדפן.

  השורה זהה לדפדפן.
- **גופנים:** Noto Serif Hebrew — 0 סימנים חסרים; Frank Ruhl Libre — חסרים טעמים (ובדפדפן זה מוסתר, כי הוא לוקח
