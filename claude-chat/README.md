# צ'אט Claude

צ'אט אישי מול Claude Platform (Messages API), רץ על השרת השיתופי ב-PHP. בלי Node ובלי תהליך רקע.

## איך זה עובד

- **הדפדפן** שולח את השיחה ל-`api.php?action=chat` וקורא זרם תשובה (SSE).
- **השרת** קורא את מפתח ה-API מ-`<home>/claude-secrets/anthropic.key`, מעביר את הבקשה ל-`api.anthropic.com` ומחזיר את הזרם.
- **המפתח** לא בריפו, לא נפרס ולא מגיע לדפדפן. התיקייה `claude-secrets` יושבת מחוץ לאתר ו-rsync לא נוגע בה.
- **השיחות** נשמרות בדפדפן בלבד (`localStorage`). אין נתונים בשרת, ולכן אין צורך ב-`--exclude` ב-`deploy.yml`.
- **כניסה:** השער של הפלטפורמה (`gate` + `restricted`). בנוסף `api.php` דורש `PLATFORM_USER`, כך שגם בלי השער אי אפשר לשרוף קרדיטים בלי זהות.

## הקמה חד-פעמית בשרת

1. ב-cPanel (מנהל הקבצים), בתיקיית הבית — **לא** ב-`public_html`: תיקייה `claude-secrets` (הרשאה 700).
2. בתוכה קובץ `anthropic.key` עם המפתח בלבד, שורה אחת (הרשאה 600).
3. המפתח נוצר ב-Claude Console ← API keys, ב-Workspace `Development-Chat`.
4. לבדיקה: פתיחת הכלי. אם מופיע אזור אדום — המפתח חסר או לא תקין, וההודעה אומרת מה.

## מגבלות (מהאבחון של השרת)

- אין Node, ולכן אין Agent SDK. זה צ'אט מול ה-API בלבד.
- בקשה אחת מוגבלת לכ-115 שניות. שיחה: עד 40 הודעות ו-60,000 תווים.
- מודלים: Sonnet 5.5 (ברירת מחדל), Opus 5.5, Haiku 5.5.

## טרם הוכרע

- מגבלת קצב ותקציב לכל משתמש (כרגע רק השער).
- שמירת שיחות בשרת ושיתוף בין מכשירים.
