# קובץ המטלות בקוד (`items_file` ב-`.devloop.json`, בדרך כלל `<app>/dev/open-items.json`)

```json
{
  "updated": "2026-10-14",
  "repo": "OWNER/REPO",
  "note": "הסבר קצר שמוצג בראש המסך",
  "items": [
    {
      "code": "PM-018", "area": "DevLoop",
      "status": "verify", "status_at": "2026-10-14T13:40:00Z",
      "kind": "feature", "priority": "normal", "opened": "2026-10-14",
      "title": "…", "detail": "…",
      "acceptance": "משפט אחד — איך יודעים שזה עובד",
      "steps": ["צעד במסך", "…", "מה אמור לקרות"],
      "questions": [],
      "pr": 295, "closed": "2026-10-14"
    }
  ]
}
```

- **קוד חדש** — רק `next_code` מהפיד. מטלות שנפתחות במסך, מ-🐞 ומשגיאות ביומן מקבלות קודים בייצור, ואתה לא רואה
  אותן בלי הפיד; קוד מנוחש עלול להתנגש (מטלה בקובץ מסתירה מטלה מהמסך עם אותו קוד). בלי גישה לפיד — אל תפתח קוד חדש
  בקובץ; עדכן מטלה קיימת, או בקש מהמפתח לפתוח מהמסך.
- **`status_at`** — מתי הקובץ קבע את המצב (UTC, לא בעתיד). מצב שנקבע מבחוץ (✅ / ↩️ של המפתח, `devapi-comment`,
  הפריסה) גובר על הקובץ עד שהקובץ מתעדכן עם `status_at` חדש יותר. אל תדרוס ✅ שלו בלי סיבה בשיח.
- `closed` + `pr` כשנסגרה (אחרי ✅ שלו). מטלה מהמסך (`source: user`) חיה בטבלה — מעדכנים אותה ב-`devapi-comment`.
