# `<app>/dev/open-items.json` — מה ש-Claude מנהל בקוד

```json
{
  "updated": "2026-10-14",
  "repo": "malkiel01/mini_projects",
  "note": "הסבר קצר שמוצג בראש המסך",
  "items": [
    {
      "code": "PM-018", "id": "devloop-2", "area": "DevLoop",
      "status": "verify", "status_at": "2026-10-14T13:40:00Z",
      "kind": "feature", "priority": "normal", "opened": "2026-10-14",
      "title": "…", "detail": "…",
      "acceptance": "משפט אחד — איך יודעים שזה עובד",
      "steps": ["צעד בטלפון", "…", "מה אמור לקרות"],
      "questions": [],
      "pr": 295, "closed": "2026-10-14"
    }
  ]
}
```

- **קוד חדש** — `next_code` מהפיד, או הגבוה בקובץ ובמסך + 1. קוד לא משתנה ולא נמחק.
- **`status_at`** — מתי הקובץ קבע את המצב. מצב שנקבע מבחוץ (האימות של המשתמש, `devapi-comment`, הפריסה)
  נשמר בטבלה וגובר על הקובץ **עד שהקובץ מתעדכן עם `status_at` חדש יותר**. לכן: `status_at` = עכשיו (UTC), לעולם
  לא בעתיד (נחתך לעכשיו), ואל תדרוס מצב שהמשתמש קבע — אם הוא סגר (✅), אל תפתח מחדש בקובץ בלי סיבה בשיח.
- `closed` + `pr` כשהמטלה נסגרה (אחרי ✅ שלו).
- מטלה שהמשתמש פתח מהמסך (`source: user`) — חיה בטבלה, לא בקובץ; מעדכנים אותה ב-`devapi-comment`.
