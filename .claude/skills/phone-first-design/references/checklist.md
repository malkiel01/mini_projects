# רשימת בדיקה לפני "זה מוכן"

## בטלפון
- [ ] צילום מסך ב-390×860 וב-320px — אין גלילה אופקית לדף, שום דבר לא נחתך באמצע מילה בלי …
- [ ] כל יעד לחיצה ≥ 40px; כפתורי אייקון עם `aria-label`
- [ ] שדות 16px; מספרים/טלפון — `dir="ltr"` ו-`inputmode`
- [ ] חלון עריכה = גיליון מלא; "שמירה" בכותרת הדביקה; הגוף נגלל כשהמקלדת פתוחה
- [ ] צביטה בצופה מגדילה רק את המסמך, לא את הדף
- [ ] חזרה מחזירה למסך הקודם באפליקציה; במסך הראשי אין חץ
- [ ] שום קובץ/קישור פנימי לא פותח לשונית חדשה

## מראה
- [ ] רק המשתנים מ-`tokens.css` — בלי צבעים / ריווחים / רדיוסים "חדשים"
- [ ] רשימות = שורות בתוך מסגרת אחת עם קו מפריד, לא כרטיסים צפים
- [ ] טקסט ארוך — שורה אחת עם …; בחירה — בורר מקטעים שממלא את המקום (גריד אם הרבה)
- [ ] סיכום בראש, פירוט אחריו; מסך ארוך — לשוניות
- [ ] בחירת פעולה — אריחים; רשומות קשורות — שורות עם אייקון; תגיות — רק לסטטוס
- [ ] לא מקופל מה שלא צריך (הערות, רשימות קצרות)
- [ ] פעולה מוכרת = אייקון; הפעולה העיקרית = עם מילה
- [ ] מסך לא מובן מאליו — שורת `.hint` קצרה בראשו; מצב ריק אומר מה לעשות

## נגישות ושפות
- [ ] `lang` / `dir` על `<html>`; רק תכונות לוגיות (`inline-start/end`) — אין `left/right` בעיצוב
- [ ] פוקוס גלוי, ניגודיות AA, תווית לכל שדה, `role` / `aria-selected` / `aria-pressed` / `aria-live`
- [ ] מצב כהה (`prefers-color-scheme: dark`) נראה תקין
- [ ] `prefers-reduced-motion` מכובד
- [ ] אם יש תרגום — צילום גם באנגלית (LTR): שום דבר לא מתהפך לא נכון

## לפני מסירה
- [ ] צילום מסך הוצג למשתמש
- [ ] בלי שגיאות בקונסול (`pageerror`, `console.error`)
