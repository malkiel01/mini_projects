# הסוכן המנהל

סוכן אחד לכל הריפו. הוא לא צ'אט קבוע — הוא **משימה מתוזמנת שפותחת צ'אט חדש כל שעה**. הצ'אט קורא את המצב מהגיט,
עושה סבב, כותב את המצב בחזרה ונסגר. כך אין לו זיכרון שמתמלא ואין מה להחליף.

הבקרה של כל צוות מנהלת את הפיתוח שלו. המנהל רק מוודא שהצוותים חיים, שצ'אטים מתחלפים בזמן, ושהמכסה מתחלקת.

## הזיכרון: `.claude/teams/STATE.md`

קובץ אחד, קצר. שורה לכל צוות:

| עמודה | מה |
| --- | --- |
| אפליקציה | `<app-id>` ושם |
| מצב | פעיל / מושהה עד … / גמור |
| בקרה | מזהה ה-session של הבקרה הנוכחית |
| שלב | מה בעבודה עכשיו (מהלוח של הצוות) |
| בדיקה אחרונה | מתי, ומה נמצא |

ומתחת לטבלה: מה המכסה, ומה ממתין לבעלים מכל הצוותים. **המקור של כל צוות הוא `<app>/team/` שלו** — כאן רק תקציר.
`.claude/teams/` מוחרגת מהפריסה.

## ההפעלה

פעם אחת, מצ'אט במצב Auto:

```
create_trigger(
  name: "מנהל הצוותים",
  cron_expression: "13 * * * *",          # כל שעה; דקה לא עגולה
  create_new_session_on_fire: true,
  initiation: "human_request",
  prompt: <הסבב, למטה>
)
```

`notifications` — רק אם הבעלים ביקש. הצ'אט שנפתח מהשעון נשען על ההרשאות שב-`.claude/settings.json`.

## הסבב (הפרומפט של המשימה)

```
אתה הסוכן המנהל של הצוותים ב-mini_projects. קרא את הסקיל app-team ואת `.claude/teams/STATE.md` מ-main.
לכל צוות שמצבו "פעיל":
1. `get_session` לבקרה שלו ולמזהים שב-`<app>/team/sessions.json`.
2. בקרה שלא זזה יותר משעתיים, או שהשעון שלה לא קיים (`list_triggers` עם recurring) — `send_message` אליה עם הצעד הבא מה-STATE שלה.
3. צ'אט שעבר כ-400K (`external_metadata.context_usage.used_tokens`) — הודעה לבקרה שלו להחליף אותו (סעיף 9). בקרה שעברה — היא מחליפה את עצמה.
4. צ'אט שנכשל (`status_bucket` failed) — הודעה לבקרה.
לכל צוות "מושהה עד <תאריך>" שהתאריך שלו עבר — הודעה לבקרה שלו: "ההשהיה הסתיימה".
בסוף: עדכן את STATE.md (commit ל-`claude/teams-manager`, PR, squash — רק אם השתנה משהו).
לבעלים לא כותבים, אלא אם צוות תקוע ואין לו בקרה חיה. מכסה באזהרה (`rate_limit_info`) — לא מעירים אף צוות; רושמים ויוצאים.
סבב קצר: לא קוראים קוד, לא מבקרים PR.
```

## בקשות לפלטפורמה ולפרויקטים אחרים

צוות לא עורך פרויקט אחר. צריך משהו — הבקרה כותבת בקשה ב-`.claude/teams/requests/<נושא>.md`: מי מבקש, מה בדיוק, למה,
ומה הצוות עושה עד אז. הבעלים מחליט ומעביר לצוות של אותו פרויקט. בקשה פתוחה מופיעה ב-STATE של המנהל.

## צוות חדש או סגירת צוות

- **צוות חדש** — שורה ב-STATE, מצב "פעיל".
- **אפליקציה גמורה** — הבקרה מכבה את השעון שלה, מצב "גמור", והצ'אטים — `archive_session`.
- **צוות שמוחלף כולו** (כמו קול מרוקו) — הישנים `archive_session`, והשורה מתעדכנת למזהים החדשים.
