# חבילת היצירה (`creative-suite/`)

חבילת אפליקציות לעריכת מסמכים ותמונות, בהשראת חבילת אדובי — עימוד, רסטר, וקטורי, ועורך התמלילים הקיים —
שכולן חולקות קובץ אחד: **`‎.mbe`**. התיקייה הזו היא **המתכלל**: תוכנית האב, אפיון הפורמט, והנחיות לכל פרויקט.
אין כאן קוד אפליקציות.

כתובת: https://mbe-plus.com/mini_projects/creative-suite/
