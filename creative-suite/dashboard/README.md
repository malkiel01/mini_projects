# דשבורד חבילת היצירה

**בעלים:** הצ'אט "חבילת היצירה · מרכז הניהול" (מ-2026-11-01). **האפיון:** `creative-suite/docs/spec/command-center.md`.

| קובץ | מה הוא עושה |
| --- | --- |
| `index.php` | הדשבורד: פרויקטים, יעדים ו"קוד אחד לכל החבילה". נקרא מהמסמכים (`docs/master-spec.md`, `docs/projects/`, `docs/integration.md`) |
| `center.php` + `assets/center.js` | **מרכז הניהול** (שלב 5): ❓ ממתין לך, הפרויקטים לפי מצב, מדיניות האישורים והמסלול. נקרא מהלוח "מטלות לקלוד" |
| `import.php` + `assets/import.js` | **ייבוא חד-פעמי** (שלב 4): רשימות `- [ ]` / `- [x]` מ-`docs/projects/` הופכות למטלות בלוח. אפשר להריץ שוב בלי ליצור כפילויות |
| `lib/docs.php` | קריאת המסמכים. משותף לשלושת הדפים |
| `lib/board.php` | מה שהדשבורד יודע על הלוח: השם שמזהה פרויקט של החבילה, קטלוג האישורים (סעיף 1.3), ותוכנית הייבוא |

## איך המרכז מדבר עם הלוח

- **מהדפדפן, עם עוגיית הלוח של בעל המערכת.** שני הכלים יושבים באותו דומיין, ולכן `fetch('../../claude-tasks/api.php')` נשלח
  עם העוגייה `CLAUDETASKS`. **בדשבורד לא נשמר שום אסימון**, וכל תשובה נרשמת על שם מי שכתב אותה.
- לא מחובר ללוח? המרכז מציג "צריך להתחבר ללוח", עם קישור.
- הלוח הוא פרויקט אחר (CLAUDE.md). משתמשים רק ב-API שלו. מה שחסר בו — כתוספת ב-`docs/requests/claude-tasks-command-center.md`.

## זיהוי זמני (עד שהלוח יוסיף את התוספות 10–12 לבקשה)

- פרויקט של החבילה: השם מתחיל ב-`חבילת היצירה · `.
- נושא של פרויקט: השם מתחיל ב-`<שם הפרויקט> · ` (למשל `עיצוב רסטר · ר2`).
