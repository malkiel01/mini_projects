קיצורי מקלדת — גם במקלדת עברית

Ctrl+Z, Ctrl+Shift+Z, Ctrl+S, Ctrl+=, ו-V — נסו עם המקלדת בעברית. בתוך שדה טקסט רק Ctrl+S פועל.

קנבס — זום, הזזה, צביטה

אצבע אחת / עכבר — עיפרון (הכלי של האפליקציה). שתי אצבעות — צביטה. רווח, גלגלת לחוצה או "יד" — הזזה. Ctrl+גלגלת — זום.

ידיות — גודל, סיבוב, הצמדה

פינה — יחס נשמר (Shift משחרר), צד — ציר אחד, Alt — מהמרכז. העיגול למעלה — סיבוב: נצמד ל-45°, Shift — מדרגות 15°. הקצוות נצמדים למלבן האפור (Ctrl — בלי).
