## ג3 — יסודות מקצועיים + עריכה משותפת

### 1. סדר העבודה בתוך ג3

1. **מודל המסמך על CRDT** ([`collab.md`](collab.md)) — לפני כל שאר היכולות, כי כל יכולת חדשה נכתבת ישר עליו.
2. **מדויק:** פנל טרנספורמציה, סרגלים וקווי עזר, הצמדה חכמה — מה שכל השאר משתמש בו.
3. **נתיבים וצורות חיות**, **בוליאני חי**, **Appearance**, **צבע גלובלי**, **מתאר משתנה**.
4. **טקסט באזור**, **ייצוא נכסים**, **ביצועים** (WebGL) — לאורך כל השלב, עם מדידה.

### 2. עריכה משותפת — מה רואים ועושים

- **שיתוף** (📁 ← "שיתוף"): לפי מייל, תפקיד צפייה / תגובות / עריכה; "קישור עריכה לאורח" עם ביטול ותוקף — **כמו בעורך
  התמלילים**, אותן מילים ואותו חלון, כדי שהמשתמש לא ילמד פעמיים.
- **בכותרת:** עיגולים של מי שבציור (ראשי תיבות, צבע לכל אחד); הקשה על עיגול — **מעקב** אחרי התצוגה שלו (זום ומיקום).
- **בקנבס:** הסמן של כל אחד עם השם; **מסגרת הבחירה** של אחר בצבע שלו; פריט שאחר גורר — זז אצלי בזמן אמת.
- **ביטול (↶) — רק שלי** (Yjs UndoManager לפי מקור), כמו בעורך התמלילים.
- **בלי רשת:** תג "לא מחובר — השינויים נשמרים במכשיר"; כשחוזר — מתמזג, בלי שאלות.
- **טלפון:** העיגולים מתקפלים ל"👥 3"; הסמנים של אחרים — רק נקודה צבעונית (אין עכבר).
- **תגובות על הקנבס** — ג6 (המודל כבר מוכן: Y.Doc נפרד).

### 3. מדויק

| יכולת | התנהגות | טלפון |
| --- | --- | --- |
| **פנל טרנספורמציה** | X / Y / W / H / זווית, נקודת עוגן (תשע נקודות), נעילת יחס; שדה מקבל חשבון (`120+12`, `50%`) ויחידות (`10mm`) | גיליון "📐" |
| **סרגלים וקווי עזר** | גרירה מהסרגל — קו עזר; קו עזר לכל לוח או לכל המסמך; נעילה והסתרה | סרגלים מוסתרים כברירת מחדל |
| **הצמדה חכמה** | קצוות, מרכזים, **מרווחים שווים** (הצגת המרחק), קווי עזר, נקודות עיגון, זווית 15°; קווים ורודים עם מידה | כן, עם רדיוס גדול יותר |
| **מדידה** | Alt מעל אובייקט — מרחק לכל צד מהבחירה | לחיצה ארוכה |

**בקובץ:** קווי עזר — `apps/vector-studio/` (פרטי לאפליקציה; אחרים לא צריכים אותם).

### 4. נתיבים וצורות חיות

- **פעולות נתיב:** Offset (פנימה/החוצה, פינה עגולה/חדה), מתאר → צורה ✅⏳, פישוט (מחוון), החלקה, **מספריים** (חיתוך בנקודה),
  **סכין** (משיכה שחותכת צורות), **מחק נתיב**, חיבור שתי נקודות קצה, פיצול נתיב.
- **Spiro / B-Spline** — מצב בעט: נקודות בלבד, העקומה מחושבת. נשמר כ-`d` רגיל + `shape: { type: "spiro", points }`
  (כמו צורה חיה היום — מי שלא מכיר מצייר את `d`).
- **פינות לכל נקודה:** עגולה / משופעת / הפוכה, ברדיוס. ידית עגולה קטנה בפינה (כמו Affinity / Figma) — גרירה = רדיוס.
  נשמר ב-`shape` (`corners: [{ at, type, r }]`) ו-`d` מחושב.
- **צורות חדשות:** ספירלה, קשת, רשת (טבלה) — כצורות חיות.

### 5. בוליאני חי ו-Shape Builder 📨

- **חי:** "איחוד / חיסור / חיתוך / החרגה" יוצרים **קבוצה בוליאנית**: הילדים נשארים עריכים, והתוצאה מתעדכנת. "החל"
  (או הקשה כפולה ← "החל") — הופך לנתיב אחד, כמו היום.
- **Shape Builder** (‏⊕): גרירה על אזורים — מאחד; Alt+גרירה — מוחק אזור. בטלפון — הקשה על אזור מאחד, לחיצה ארוכה מוחקת.
- **בקובץ (בקשה):** קבוצה עם `boolean: "union" | "subtract" | "intersect" | "exclude"` ו-`d` **מחושב** בקבוצה עצמה —
  קורא שלא מכיר מצייר את `d` של הקבוצה ולא את הילדים. **שונה מכלל הקבוצה היום** (קבוצה בלי `d`) — לכן בקשה.

### 6. Appearance — כמה מילויים ומתארים 📨

- **בלוח המאפיינים:** רשימה "מראה" — שכבות מילוי ומתאר, בסדר, עם 👁 , שקיפות ומצב מיזוג לכל אחת; גרירה לסדר; "+ מילוי",
  "+ מתאר". דוגמה: מתאר עבה כתום מתחת למתאר דק לבן — "קו כפול" בלי לשכפל צורה.
- **בקובץ (בקשה):** `fills: [...]`, `strokes: [...]` (כל אחד במבנה של `fill` / `stroke` היום, + `blend`, `visible`).
  `fill` / `stroke` הבודדים **נשארים** = הראשון ברשימה, כדי שקורא ישן יצייר משהו נכון. בייצוא SVG — כמה `<path>` זהים.

### 7. צבע

- **צבע גלובלי:** דוגמית "גלובלית" — שינוי אחד משנה את כל השימושים. **בקובץ (בקשה):** `document.swatches: { "<id>": {
  name, color } }`, ובצבע: `{ "color": "#1f3a5f", "swatch": "<id>" }` — **הצבע עצמו תמיד כתוב** (קורא שלא מכיר — מצייר
  אותו). שינוי הדוגמית מעדכן את כל ה-`color` שמפנים אליה.
- **בורר:** HSB / RGB / HEX, טפטפת (גם מתוך תמונה ומחוץ לחלון — `EyeDropper` API היכן שיש), הרמוניות (משלים, משולש,
  אנלוגי), אחרונים.
- **מעבר צבע על הקנבס:** ידיות לנקודות ולעצירות, גרירה; הוספת עצירה בהקשה על הקו.
- **"צבעים וסגנונות שמורים" של גרסה 2** — פלטה של המשתמש בשרת, לכל הציורים. **גלובלי = בתוך ציור אחד.** משיכה מהפלטה
  לציור יוצרת דוגמית גלובלית בו.

### 8. מתאר, טקסט, לוחות, ייצוא, ביצועים

- **מתאר:** יישור פנימה / מרכז / החוצה; **רוחב משתנה** (Width Tool — גרירה על הקו מוסיפה נקודת רוחב; פרופילים מוכנים);
  מקווקו עם יישור לפינות. **בקובץ (בקשה):** `stroke.align`, `stroke.profile: [{ at: 0..1, w }]`; בייצוא SVG — מתאר → צורה
  (`gaps: ["stroke-profile → outline"]`), כי ל-SVG אין רוחב משתנה.
- **טקסט באזור:** טקסט שזורם בתוך צורה כלשהי (לא רק מלבן). **בקובץ:** פריט `text` עם `area: "<id של נתיב>"`. ניקוד
  וטעמים — דרך `shapeLine` של העימוד (המודול המשותף "גופנים עבריים ו-bidi"), לא מנוע שני.
- **לוחות:** רבים ✅; + שכפול לוח עם התוכן, סידור אוטומטי ברשת, שם לכל לוח, ייצוא לפי לוח.
- **ייצוא נכסים:** סימון אובייקט / לוח "לייצוא" עם גדלים (×1 ×2 ×3, `512w`) ופורמטים (SVG / PNG / JPG / WebP / PDF);
  "ייצוא הכול" — ZIP. SVG נקי לאתרים (בלי מטא, מזהים קצרים, מעוגל ל-2 ספרות).
- **ביצועים:** יעד — **20,000 אובייקטים**, 60 פריימים בגרירה במחשב, 30 בטלפון בינוני; זום עד 100,000%. הדרך: מטמון
  אריחים לכל רמת זום, ציור מחדש רק של מה שהשתנה, ובהמשך WebGL. **מדידה קודם** — קובץ בדיקה של 20,000 אובייקטים
  בבדיקות, והמספרים ב-README.
