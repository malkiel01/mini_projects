### מה הבדיקות מכסות

**`tests/run.php` (165):**
- **חשבון ומכסה:** חשבון מהשער ומכסה 0 עד אישור.
- **העלאה והתנגשויות:** העלאה בחלקים, כולל המשך אחרי ניתוק. `if_rev`, ושלושת מצבי ההתנגשות.

- **AI:** כל ארבעת הספקים מול HTTP מדומה — מכסה, מפתח שנדחה, סכמה, סירוב.
- **גופנים:** של המשתמש ומובנים — `fvar`, ולא ניתנים לשינוי או למחיקה.

**`drives/tests/run.php` (37):** כל המסלול בין אפליקציה לענן באותו תהליך, וגם Dropbox:

- רענון אסימון, ביטול אצל Dropbox, `unlink`, ואפליקציה בדומיין משלה.

**`js.mjs` (25):** צד הדפדפן:

## 4. מה לא עובד / חסר

- **שום ספק חיצוני לא נבדק מול הדבר האמיתי.** Dropbox, OpenAI, Google, Replicate ו-Anthropic נבדקו רק מול HTTP מדומה, כי אין מפתחות. הצורות נלקחו מהתיעוד של כל ספק, אבל הקריאה הראשונה האמיתית היא הבדיקה האמיתית.
- **Dropbox לא מופיע באפליקציות** עד שבעל המערכת מזין App key, כי בלי מזהה הכונן מוסתר בכוונה.
  - אחרי ההזנה: עד 5 דקות עד שהאפליקציות רואות אותו.
  - החלפת key קיים: עד שעה.
- **Google Drive, OneDrive, SFTP / WebDAV ותיקייה במחשב — טרם נבנו.** אותו ממשק (`drives.<כונן>`) מחכה להם.
- **`bad_state` מהדיווח של בעל המערכת:**
  - **מה תוקן:** הדף כבר לא מציג JSON, וחזרה כפולה לא נכשלת (#980). כל כשל נרשם ביומן עם הסיבה: `missing` / `user` / `expired` / `used`.
  - **מה לא ידוע:** סיבת השורש לא אומתה. ההשערה שנבדקה: החיבור נפתח בדפדפן אחר מזה של האפליקציה.
- **גופנים מובנים שלא נכנסו:** Alef, Karantina, Suez One ו-Varela Round. בריפו יש מהם רק תת-קבוצות woff2 (בכרטיסי ברכה), לא קבצים שלמים.
- **"שלי" בבורר הגופנים של האפליקציות:** `fonts_list` בלי `builtin=1` מחזיר רק את הגופנים של המשתמש, כמו קודם, כדי לא לשבור אפליקציות. אפליקציה שרוצה את המובנים מבקשת אותם במפורש.
- **מחיקת חשבון היא מחיקה מלאה.**
  - **מה נמחק:** קבצים, גופנים, חיבורים והרשאות AI. התוכן נמחק מהדיסק רק כשאף חשבון אחר לא מחזיק אותו.
  - **מה לא נשמר:** הנפח שהמנהל הקצה, ויומן השימוש ב-AI של אותו חשבון.
  - **כניסה מחדש:** פותחת חשבון ריק עם נפח 0 עד שהמנהל מאשר.
- **צוותים, צבעים, סגנונות, נכסים, גרסאות וחיפוש** — לא היו ביעד, וטרם נבנו.

## 5. מה בעל המערכת צריך לבדוק בעצמו

כל הצעדים בכתובת `https://mbe-plus.com/mini_projects/suite-cloud/`, אחרי כניסה לכלים הדיגיטליים.

1. **הכונן:** ב-⚙️ ניהול ← חשבונות ← החשבון שלך — לתת לעצמך נפח (למשל 5 ג"ב). אחר כך ב-☁️ קבצים:
   - ליצור תיקייה ולהעלות קובץ גדול (100MB ומעלה) — פס ההתקדמות מתקדם.
   - לסגור את הדף באמצע העלאה, ולהעלות שוב — ההעלאה ממשיכה מאיפה שעצרה.
2. **הגופנים:** 🔤 גופנים ← ⬆️ גופן — להעלות `.ttf` משלך ולאשר את אזהרת הרישיון.
   - הגופן מופיע תחת "שלי", עם תצוגה מקדימה בעברית.
   - למטה, תחת "מובנים", יש 8 משפחות; 📄 פותח את הרישיון.
3. **Dropbox (כחמש דקות, פעם אחת):** לפי "ממתין לבעל המערכת" ב-`creative-suite/docs/projects/suite-cloud.md`:
   1. ליצור אפליקציה ב-Dropbox: Scoped access, App folder.
   2. לסמן את ההרשאות `files.metadata.read`, `files.content.read`, `files.content.write`.
   3. להוסיף את ה-Redirect URI שמוצג בניהול, ולאפשר PKCE.
   4. להדביק את ה-App key ב-⚙️ ניהול ← 🗂️ כוננים חיצוניים ← 🔑.
   5. אחרי 5 דקות, באפליקציה שמשתמשת במודול: לחבר Dropbox. חוזרים עם `?drive=connected`, ונוצרת תיקייה בשם האפליקציה ב-Dropbox שלך.
4. **בינה מלאכותית:** ⚙️ ניהול ← 🤖 ← 🔑 — מפתח לספק אחד לפחות, ואז "בדיקה" (מציגה "המפתח תקין ✓").
   - אחר כך: חשבונות ← החשבון שלך ← לסמן את הספק ולקבוע מכסה חודשית.
   - בסטודיו העיצוב או ברסטר — ✨ פעולה אחת. העלות מופיעה ב-"החודש".
5. **חיבור אפליקציה:** באפליקציה שמשתמשת במודול (כרטיסי ברכה, רסטר או עימוד) — "☁️ חיבור לענן החבילה" ← מסך האישור בענן ← חזרה מחוברת.
   - בענן, ב-🔗 חיבורים, האפליקציה מופיעה.
   - ניתוק משם ← באפליקציה החיבור נעלם.
6. **תפריט המשתמש:**
   - העיגול בסרגל ← ⚙️ הגדרות אישיות ← "כהה": כל הדף מתחלף.
   - 🔑 החשבון ← "ייצוא כל הנתונים שלי": יורד JSON עם העץ, הגופנים והחיבורים.
   - **לא ללחוץ "מחיקת החשבון"** על החשבון האמיתי, כי היא מוחקת הכול. בודקים בחשבון ניסיון.
