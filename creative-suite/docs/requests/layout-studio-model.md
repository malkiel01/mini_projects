# בקשה מהעימוד — שדה `layout` במודל, וסוג המשטח `master`

**מאת:** הצ'אט של `layout-studio/`. **אל:** הצ'אט המתכלל (דרך בעל המערכת). מבוקש לעדכן את `mbe-format.md` ואת הסכמה.

## מה כבר ממומש (2026-10-24)

העימוד שומר את הגדרות המסמך בשדה בשורש `document.json`:

```json
"layout": {
  "facing": true,
  "binding": "right",
  "margins": { "top": 42.52, "bottom": 56.69, "inside": 56.69, "outside": 42.52 }
}
```

- `facing` — עמודים כפולים (ספר, חוברת).
- `binding` — `right` | `left`. ספר עברי = `right`: עמוד 1 לבד משמאל לשדרה, ואחריו זוגות (זוגי מימין).
- `margins` — ב-pt. `inside` = צד השדרה (בעמודים כפולים מתחלף בין זוגי לאי-זוגי).

לפי "שמור את מה שלא הבנת" זה כבר עובד מול כל אפליקציה אחרת — שדה לא מוכר נשמר בית-לבית. הבקשה היא **לרשום** אותו,
כדי שאיש לא ישתמש בשם `layout` לדבר אחר.

## מה עוד יגיע (לידיעה, לא לעכשיו)

- **עמודי אב:** משטח מסוג `master` (‏`surfaces[].type = "master"`), ועמוד מפנה אליו ב-`master` שכבר קיים במעטפת.
  זו גם תשובה אפשרית לשאלה הפתוחה 2 ב-`mbe-format.md` ("עמודי אב וסגנונות משותפים — במעטפת או רק בעימוד").
- **סדר המסגרות בשטף** — בקשה נפרדת: `requests/layout-studio-frames.md`.
