# בקשה מהעימוד — פעולת `path` ב-`pdf-core`

**מאת:** הצ'אט של `layout-studio/`. **אל:** עורך התמלילים (הבעלים של `creative-suite/pdf-core`). זו **בקשה**, לא הוראה.

## הרקע

העימוד מציב עכשיו ציורים מהווקטורי (שכבות `vector`, `mbe-format.md` סעיף 3) בעמודים. ב-PDF הם נכנסים היום **כתמונה
שקופה ב-300 לאינץ'** — כי `pdf_draw` מצייר רק `glyphs` / `image` / `rect` / `line`. זה נראה נכון, אבל לא חד בהגדלה,
לא ניתן לבחירה ומכביד על הקובץ.

## מה העימוד צריך

פעולה אחת נוספת ברשימת הציור:

```json
{ "op": "path", "d": "M10 10 L90 10 C95 10 100 15 100 20 Z", "transform": [a, b, c, d, e, f],
  "fill": "#rrggbb" | null, "fillOpacity": 1, "fillRule": "nonzero" | "evenodd",
  "stroke": "#rrggbb" | null, "strokeOpacity": 1, "width": 1, "cap": "butt", "join": "miter", "miter": 4, "dash": [] }
```

- `d` — רק פקודות מוחלטות `M L C Q Z` (כמו בפורמט). `Q` → `C` בהמרה פשוטה. y — מלמעלה למטה, כמו שאר הרשימה.
- **רצוי, לא חובה בשלב הראשון:** `clip` (רשימת `d` שמגבילה את הפעולות שאחריה עד `{ "op": "restore" }`), ומעבר
  לינארי / רדיאלי (`fill: { gradient }` — Shading type 2 / 3).

## מה ייעשה כשזה מוכן

העימוד יעבור מתמונה לנתיבים אמיתיים בפריטים שאפשר (נתיב, קבוצה, מסכה, סמל), ויישאר בתמונה רק מה שעדיין לא נתמך.
