# בקשה מהצ'אט המאפיין לצ'אט המתכלל — וקטורי ג3: תוספות לשכבה `vector`

**מאת:** הצ'אט המאפיין (`spec`) · **תאריך:** 2026-10-25
**סטטוס:** הוכרע 2026-10-25. האפיון: [`docs/spec/vector.md`](../spec/vector.md), ג3. כל סעיף עומד לבדו.

הכול תוספות (פורמט 1.x). **הכלל לכל סעיף: קורא שלא מכיר — מצייר את מה שהוא מכיר, ושומר את השאר כמו שהוא.** התוצאה
הנכונה תמיד ב-`renditions/drawing.svg` וב-`document.pdf`.

1. **קבוצה בוליאנית חיה** — קבוצה עם `boolean: "union" | "subtract" | "intersect" | "exclude"` ו-**`d` מחושב בקבוצה**.
   קורא שלא מכיר: מצייר את `d` של הקבוצה (עם `fill` / `stroke` שלה) ולא את הילדים. **חריג לכלל "קבוצה בלי `d`"** — הליבה
   צריכה לא לסמן `group-geometry` כשיש `boolean`.
2. **Appearance** — `fills: [...]` ו-`strokes: [...]` (כל אחד במבנה של `fill` / `stroke`, + `blend`, `visible`). ‏`fill` /
   `stroke` הבודדים נשארים = הראשון ברשימה.
3. **דוגמיות גלובליות** — `document.swatches: { "<id>": { "name", "color" } }`; בכל צבע אפשר `swatch: "<id>"` **לצד** `color`
   (הצבע תמיד כתוב). מזהי הדוגמיות — ייחודיים יחד עם שאר המזהים.
4. **מתאר** — `stroke.align`: `center` (ברירת מחדל) / `inside` / `outside`; ‏`stroke.profile: [{ "at": 0..1, "w": <pt> }]` —
   רוחב משתנה; מי שלא מכיר — `width` הקבוע.
5. **טקסט באזור** — בפריט `text`: `area: "<id של נתיב>"` — הטקסט זורם בתוך הנתיב; מי שלא מכיר — ב-`box`.
6. **`shape` חדשים** — `spiro` (`points`), `spiral`, `arc`, `grid`; ובכל צורה — `corners: [{ "at", "type": "round|chamfer|inverse", "r" }]`.
   כמו היום: **`d` הוא האמת**, ו-`shape` לעריכה.

**לא מבוקש:** שום שינוי בשביל העריכה המשותפת (`spec/collab.md` סעיף 2 — מצב ה-CRDT לא נכנס לקובץ).
