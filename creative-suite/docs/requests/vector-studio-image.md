# בקשה מווקטורי (`vector-studio/`) לצ'אט המתכלל — פריט `image` בשכבת `vector`

**מאת:** הצ'אט של פרויקט 3 (`vector-studio/`) · **תאריך:** 2026-10-25
**סטטוס:** ממתין להכרעה. עד שתוכרע — וקטורי כותב לפי ההצעה (כמו ב-`radial`); אם תוכרע צורה אחרת, משנים באפליקציה.

## למה

גרסה 2, "תמונה בתוך הציור": תמונה (PNG / JPG / WebP) כ**אובייקט** בציור — מזיזים, משנים גודל, מסובבים, מסדרים
מעל ומתחת לצורות, ומקבצים איתן (ובהמשך — חותכים במסכה, `clip`). שכבת `raster` שלמה לא מתאימה: היא שכבה, לא
אובייקט בין הצורות, ואי אפשר לקבץ או לסדר אותה בין נתיבים.

## ההצעה — תוספת לטבלה "תוכן שכבה `vector`" (`mbe-format.md` סעיף 3)

```json
{ "id": "i1", "type": "image", "src": "media/3f2a….png", "box": [40, 60, 300, 200],
  "transform": [1, 0, 0, 1, 0, 0], "opacity": 0.8, "name": "רקע" }
```

| שדה | חובה | מה |
| --- | --- | --- |
| `type` | כן | `"image"` |
| `src` | כן | נתיב ב-`media/` של הקובץ (כמו `src` של שכבת `raster`); הבתים — ב-`media/`, ברשימת ה-manifest |
| `box` | כן | `[x, y, w, h]` ב-`pt` — התמונה נמתחת לתיבה (היחס נשמר בעורך, לא בפורמט) |
| `transform` | לא | כמו בנתיב — סיבוב / היפוך |
| `opacity` | לא | 0–1, ברירת מחדל 1 |
| `name`, `hidden`, `locked` | לא | כמו בנתיב |

**קורא שלא מכיר `image`** — מדלג עליו (כמו על כל סוג לא מוכר); `renditions/drawing.svg` ו-`document.pdf` מראים אותו.
בליבה 1.1 — סוג לא מוכר נשמר כמו שהוא, ו-`id` כבר חובה. מה שכדאי לליבה לבדוק: ש-`src` קיים ב-`media/`.

## לא נוגעים

- לא בסכמה עכשיו (`paths` פתוח לסוגים); לא בקבצים קיימים.
