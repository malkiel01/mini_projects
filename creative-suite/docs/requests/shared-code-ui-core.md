## למה

כ-900 שורות CSS זהות בחמש אפליקציות; שבעה טוסטים; ~30 `confirm`/`prompt` מקוריים; חמש רשימות גופנים; ארבעה
מימושי זום; שלושה ביטול/ביצוע; ושלוש אפליקציות שהקיצורים שלהן כנראה לא עובדים במקלדת עברית. הפירוט — בתוכנית.
