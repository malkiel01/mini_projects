# בקשה מווקטורי (`vector-studio/`) לצ'אט המתכלל — תוספות לפורמט לגרסה 2

**מאת:** הצ'אט של פרויקט 3 (`vector-studio/`) · **תאריך:** 2026-10-25
**סטטוס:** ממתין להכרעה. כל סעיף עומד לבדו — אפשר לאשר חלק. סעיף שלא אושר — וקטורי לא כותב אותו לקובץ.
(עד ההכרעה האפליקציה עובדת על מה שלא דורש שינוי: עיפרון ומברשת, תמונה כשכבת רסטר, צבעים שמורים.)

הכול תוספות לטבלה "תוכן שכבה `vector`" ב-`mbe-format.md` (סעיף 3), בלי שינוי במה שכבר אושר. קורא שלא מכיר
תוספת — מתעלם ממנה ומצייר כמו היום; ובכל מקרה `renditions/drawing.svg` ו-`document.pdf` מראים את התוצאה הנכונה.

## 1. מתאר: מעבר צבע וחצים

```json
"stroke": { "gradient": { "type": "linear", "from": [0, 0], "to": [100, 0], "stops": [...] },
            "width": 4, "start": "none", "end": "arrow" }
```

- `stroke.gradient` — בדיוק כמו ב-`fill` (במקום `color`).
- `start` / `end` — קצה הנתיב הפתוח: `"none"` (ברירת מחדל) / `"arrow"` / `"circle"` / `"bar"`, בגודל יחסי לעובי.

## 2. אפקטים על פריט

```json
"effects": [{ "type": "shadow", "dx": 4, "dy": 4, "blur": 6, "color": "#000000", "opacity": 0.35 },
            { "type": "glow", "blur": 8, "color": "#ffd34d", "opacity": 0.8 },
            { "type": "blur", "radius": 3 }]
```

רשות, על כל פריט (נתיב, טקסט, קבוצה). מרחקים ב-`pt`. ב-PDF — האפקט כתמונה מתחת לפריט (וכתוב ב-`gaps`).

## 3. סמלים

```json
"symbols": { "sym1": { "name": "לוגו", "paths": [ ...פריטים כמו בשכבה... ] } }      ← ברמת document
{ "id": "u1", "type": "use", "symbol": "sym1", "transform": [1, 0, 0, 1, 120, 40] }    ← פריט בשכבה
```

- `document.symbols` — הגדרות, בקואורדינטות משלהן. `use` — מופע: אותו תוכן, עם `transform` משלו.
- עריכה של ההגדרה משנה את כל המופעים. "פירוק מופע" — מעתיק את התוכן לפריטים רגילים.

## 4. טקסט על נתיב

```json
{ "id": "t1", "type": "text", "text": "שלום עולם", "font": {...}, "fill": {...},
  "onPath": { "d": "M0 100 C50 0 150 0 200 100", "start": 0.5, "side": "above" } }
```

- `onPath.d` — הנתיב (אותן פקודות כמו `d`); `start` — מיקום על הנתיב 0–1 לפי `align` (מרכז בברירת מחדל);
  `side` — מעל / מתחת לקו. `box` מחושב (כמו היום), לחיפוש ולתמונה הממוזערת.

## 5. מסכת חיתוך

```json
{ "id": "g1", "type": "group", "clip": true, "children": [ { ...הצורה החותכת... }, ...התוכן... ] }
```

- קבוצה עם `clip: true` — הילד הראשון הוא הצורה (רק הצורה שלה, בלי צבע), ושאר הילדים נראים רק בתוכה.

## לא נוגעים

- לא בליבה ולא בסכמה: `paths` עדיין `array` עד 1.1, ו-`document-1.json` כבר מתיר שדות נוספים ברמת המסמך
  (אין בו `additionalProperties: false`), אז `symbols` עובר את הבדיקה כמו שהוא.
- `.mbe` שכבר נשמרו — לא משתנים.

**בסכמה — אין שינוי עכשיו.** גרסה 1.1 של הליבה כבר בודקת כל פריט ב-`paths` (`id` חובה, `d` לנתיב בלבד) ומשאירה שדות פתוחים,
ולכן `use` (סוג לא מוכר לליבה — נשמר כמו שהוא), `effects`, `onPath`, `clip` ו-`symbols` עוברים אימות כבר היום. בדיקת ייחודיות
המזהים גם בתוך `symbols` — נרשמה כשיפור לליבה.

**לעימוד ולרסטר:** נרשם באפיון ש-`use` ו-`clip` הם הראשונים שכדאי לתמוך בהם בהצגת שכבות `vector`; עד אז — `drawing.svg`.
