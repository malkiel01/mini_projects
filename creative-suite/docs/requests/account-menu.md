# תפריט המשתמש, "המסמכים שלי" וחיבור לכל ענן — אחד לכל האפליקציות

**מאת:** בעל המערכת (2026-10-31). **הכרעת הצ'אט המתכלל:** למטה. **הבעלים:** הקוד המשותף (הממשק), ענן החבילה (הכוננים).

## מה ביקש בעל המערכת

> בשום אפליקציה בחבילה אין לי את האייקון של המשתמש למעלה עם התפריט שלו — כל ההגדרות האישיות, האפשרויות וההתאמות.
> אין גם מקום לנהל את המסמכים ואת הענן המותאם. צריך לשנות אצל כולן: כל אחת היא אפליקציה מתוך משפחה, אבל גם
> אפליקציה עצמאית לכל דבר, וניתן יהיה לחבר אותה לענן כלשהו או לענן שלנו, ולתת הגדרות מתאימות ואישיות.

**המצב היום:** אין תפריט משתמש באף אפליקציה. בווקטורי יש עיגול שם (`#me`) בלי תפריט. בסטודיו העיצוב יש "התנתק" בתוך מסך
אחר. החלון לפתיחה ושמירה שונה בכל אפליקציה, ואף אחת עוד לא מחוברת לענן.

## הכרעת הצ'אט המתכלל (2026-10-31)

### 2. עצמאית וגם ממשפחה — שינוי באפיון "איחוד כוחות"

עד היום (`spec/shared.md` סעיף 2): כוננים חיצוניים רק **דרך** ענן החבילה. **מעכשיו:** אפליקציה יכולה להתחבר **ישירות** לכל
ענן (Drive, Dropbox, OneDrive, SFTP / WebDAV / FTP), **או** לענן החבילה, **או** לכמה מהם יחד, **או** לאף אחד (עובדת כמו
היום). כך אפליקציה שיוצאת לדומיין משלה ממשיכה לעבוד עם הענן של המשתמש. הקוד של החיבור — אותו מודול בכולן.
- **סודות:** מזהי ה-OAuth של כל ספק — בהגדרות השרת של כל אפליקציה (או מתקבלים מענן החבילה כשהיא מחוברת אליו).
  לעולם לא בקוד ולא בצ'אט. בלי מזהה של ספק — הכפתור שלו פשוט לא מופיע.
- **ענן החבילה** נשאר המקום שבו כל הכוננים יחד, ספריות הגופנים והצבעים, והעדפות שמסתנכרנות בין האפליקציות.

### 3. מה יש בתפריט — אותו סדר בכל אפליקציה

👤 **העיגול של המשתמש** — תמונה או ראשי תיבות, בפינה העליונה של הסרגל (בצד שמאל, ב-RTL), בכל מסך. לחיצה — תפריט; בטלפון
— גיליון שעולה מלמטה (החלון של `ui-core`).

| # | פריט | מה בפנים |
| --- | --- | --- |

### 4. החוזה בין `ui-core` לאפליקציה (כיוון; הפירוט — אצל הקוד המשותף)

```js
accountMenu(anchor, {
  user:   () => ({ name, email, avatar, admin }),          // מהאפליקציה
  prefs:  { get(ns), set(ns, value) },                    // נשמר במסד של האפליקציה (+ ענן, אם מחובר)
  drives: drivesClient,                                   // מהמודול של הכוננים
  docs:   { list, open, save, rename, remove, versions }, // הספרייה של האפליקציה = לשונית "באפליקציה"
  sections: [{ id, title, render }],                      // הגדרות של האפליקציה עצמה
  admin:  url | null, help: url, logout: () => …,
})
```

### 5. הסדר

1. **הקוד המשותף:** `account.js` (העיגול, התפריט, הגדרות כלליות, הקטע של האפליקציה) — **הבא בתור** אחרי שלב 4. אחריו
   `files-window.js` ("המסמכים שלי") — בהתחלה רק לשונית "באפליקציה", ולשוניות הענן נוספות כשהכוננים מוכנים.
2. **ענן החבילה:** המודול של הכוננים — קודם ענן החבילה (`connect`) ו-Dropbox, אחריהם Drive, OneDrive, SFTP / WebDAV.
   לפי הסדר שכבר באפיון.
3. **כל אפליקציה:** מצטרפת ומחליפה את מה שיש לה (העיגול של וקטורי, "התנתק" של הסטודיו, חלון הפתיחה והשמירה). הסימון — רק
   בטבלה `docs/integration.md`, שורות 19–21.
4. **הצ'אט המאפיין:** לעדכן את `spec/shared.md` סעיפים 2 ו-7 — חיבור ישיר לכל ענן, והתפריט במקום "כפתור בהגדרות".
