# פרויקט 3 — וקטורי (`vector-studio/`)

**תפקיד:** עורך גרפיקה וקטורית בסגנון Illustrator — לוגואים, אייקונים, איורים ושרטוטים: צורות, נתיבי בזייה וטקסט,
ושמירה ל-`.mbe` מסוג `vector` עם SVG ו-PDF מוכנים בפנים. בעלים של המודול המשותף **גאומטריה ונתיבים**.

קרא קודם: CLAUDE.md (מבנה כלי, `app.json`, השער, **אפליקציה עצמאית מהמעטפת**, צ'אט לא נוגע בפרויקט אחר) ·
`creative-suite/docs/master-spec.md` (בעיקר סעיף 4 — "עבודה במקביל" ו"כלל השתיים") · `creative-suite/docs/mbe-format.md`
(מחייב) · `creative-suite/mbe-core/README.md` · הסקיל `phone-first-design`.

## תיקייה ותחום

`vector-studio/` — אפליקציה עצמאית: `app.json`, `gate: true`, משתמשים ונתונים משלה, בלי `require` מחוץ לתיקייה.
נתונים בשרת → `--exclude` ב-`deploy.yml` **לפני** הכתיבה הראשונה. לא נוגעים ב-`creative-suite/` מלבד המסמך הזה.
המראה (סרגל, לוח שכבות, לוח מאפיינים) — כמו ברסטר, לפי `phone-first-design`; לא מעתיקים קוד מ-`raster-studio/`.

## גרסה 1 — מה בתחום (הצעה; האפיון שלך מכריע אחרי שאלות לבעל המערכת)

- **מסמך:** לוחות עבודה (artboards) בגודל נבחר; פתיחה ושמירה של `.mbe` (`kind: "vector"`); ייבוא SVG.
- **צורות:** מלבן (עם פינות מעוגלות), אליפסה, מצולע, כוכב, קו.
- **עט (pen tool):** נתיבי בזייה, עריכת נקודות וידיות, סגירת נתיב.
- **סגנון:** מילוי ומתאר (צבע, עובי, קצוות, מקווקו), שקיפות, מעבר צבע ליניארי.
- **סידור:** קבוצות, שכבות, יישור ופיזור, סדר הצגה, הצמדה לרשת ולאובייקטים.
- **טקסט:** שורה או פסקה קצרה, עברית מימין לשמאל, גופנים חופשיים.
- **ביטול / ביצוע**.
- **שמירה:** `.mbe` עם `renditions/preview.png`, ‏`drawing.svg` ו-`document.pdf`. ייצוא SVG / PNG / PDF.
- **טלפון:** צפייה, זום, בחירה והזזה; ציור מלא — טאבלט / מחשב.
