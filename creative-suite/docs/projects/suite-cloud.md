# ענן החבילה (`suite-cloud/`) — פרויקט 6

**בחבילה:** ה-Creative Cloud של החבילה — חשבון חבילה אחד, כוננים זה לצד זה, וספריות משותפות לכל האפליקציות.
**אפליקציה עצמאית:** משתמשים, מסד ונתונים משלה; האחרות מתחברות אליה ב-HTTPS, ובלעדיה עובדות כמו היום.

**האפיון:** `creative-suite/docs/spec/shared.md` (של הצ'אט המאפיין). **ההכרעה:** `requests/spec-shared.md`.

## חובות (לפני הכתיבה הראשונה לשרת)

- **`--exclude` ב-`deploy.yml`** לכל תיקיית נתונים (`suite-cloud/data/`) — בלי זה הפריסה הבאה דורסת קבצי משתמשים.
- **סודות** (מזהי OAuth של Google ו-Dropbox, מפתח הצפנת האסימונים) — רק בהגדרות השרת, לעולם לא בקוד ולא בצ'אט.
- **לקוח הענן** (JS + PHP) — מודול מסונכרן לכל אפליקציה, כמו `mbe-core`: מקור אחד, `apps.json`, שער בפריסה.
