# ענן החבילה (`suite-cloud/`) — פרויקט 6

**בחבילה:** ה-Creative Cloud של החבילה — חשבון חבילה אחד, כוננים זה לצד זה, וספריות משותפות לכל האפליקציות.
**אפליקציה עצמאית:** משתמשים, מסד ונתונים משלה; האחרות מתחברות אליה ב-HTTPS, ובלעדיה עובדות כמו היום.

**האפיון:** `creative-suite/docs/spec/shared.md` (של הצ'אט המאפיין). **ההכרעה:** `requests/spec-shared.md`.

## חובות (לפני הכתיבה הראשונה לשרת)

- **`--exclude` ב-`deploy.yml`** לכל תיקיית נתונים (`suite-cloud/data/`) — בלי זה הפריסה הבאה דורסת קבצי משתמשים.
- **סודות** (מזהי OAuth של Google ו-Dropbox, מפתח הצפנת האסימונים) — רק בהגדרות השרת, לעולם לא בקוד ולא בצ'אט.
- **לקוח הענן** (JS + PHP) — מודול מסונכרן לכל אפליקציה, כמו `mbe-core`: מקור אחד, `apps.json`, שער בפריסה.

## ממתין לבעל המערכת

מה רק אתה יכול לעשות. מסמנים `[x]` כשבוצע.

- [ ] **Dropbox — App key** (5 דקות, פעם אחת):
  1. https://www.dropbox.com/developers/apps → **Create app** → **Scoped access** → **App folder** → שם, למשל "חבילת היצירה".
  2. בלשונית **Permissions**: לסמן `files.metadata.read`, `files.content.read`, `files.content.write` → **Submit**.
  3. בלשונית **Settings** → **OAuth 2 / Redirect URIs**: `https://mbe-plus.com/mini_projects/suite-cloud/oauth/dropbox.php` → **Add**.
     באותו מקום: **Allow public clients (Implicit Grant & PKCE)** = Allow.
  4. להעתיק את **App key** (לא את ה-App secret) → בענן: ⚙️ ניהול ← 🗂️ כוננים חיצוניים ← 🔑 Dropbox.
  5. עד 50 משתמשים — מצב Development מספיק; מעבר לזה: **Apply for production** באותו דף.
- [ ] מזהה OAuth של Google — כש-Google Drive מגיע; מדריך מדויק יינתן כאן
- [x] נפח ברירת מחדל לאחסון הפנימי ותקרה לקובץ — הוכרע 2026-10-30: 0 עד אישור, 500MB לקובץ (משתנה ב-⚙️ ניהול)
