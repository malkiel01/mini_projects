# פרויקט 2 — עיצוב רסטר (`raster-studio/`)

**תפקיד:** עורך תמונות בשכבות בסגנון Photoshop — פותח תמונה או `.mbe`, מצייר, מתקן ומרכיב שכבות, ושומר `.mbe` מסוג
`raster` עם ייצוגים ש-Photoshop, GIMP וכל מציג פותחים. בעלים של המודולים המשותפים **שכבות וצבע** ו**מעטפת ממשק**.

קרא קודם: CLAUDE.md (מבנה כלי, `app.json`, השער, **אפליקציה עצמאית מהמעטפת**, צ'אט לא נוגע בפרויקט אחר) ·
`creative-suite/docs/master-spec.md` (בעיקר סעיף 4 — "עבודה במקביל" ו"כלל השתיים") · `creative-suite/docs/mbe-format.md`
(מחייב) · `creative-suite/mbe-core/README.md` (הספרייה שקוראת וכותבת `.mbe`) · הסקיל `phone-first-design`.

## תיקייה ותחום

`raster-studio/` — אפליקציה עצמאית: `app.json`, `gate: true`, משתמשים ונתונים משלה, בלי `require` מחוץ לתיקייה.
נתונים בשרת → `--exclude` ב-`deploy.yml` **לפני** הכתיבה הראשונה. לא נוגעים ב-`creative-suite/` מלבד המסמך הזה.

## גרסה 1 — מה בתחום (הצעה; האפיון שלך מכריע אחרי שאלות לבעל המערכת)

- **מסמך:** קנבס בגודל נבחר, פתיחת PNG / JPG / WebP, ופתיחה ושמירה של `.mbe` (`kind: "raster"`).
- **שכבות:** הוספה, מחיקה, סדר, הסתרה, נעילה, קבוצות, שקיפות, מצבי מיזוג (לפחות normal / multiply / screen / overlay).
- **כלים:** מכחול, מחק, דלי, בחירה מלבנית / אליפטית / לאסו, הזזה ושינוי גודל וסיבוב, חיתוך הקנבס, טקסט פשוט (עברית).
- **תיקונים:** בהירות / ניגודיות, גוון / רוויה, טשטוש.
- **ביטול / ביצוע** מרובה.
- **שמירה:** `.mbe` עם `renditions/preview.png`, ‏`image.png` (משוטחת) ו-`image.ora` (שכבות — GIMP / Krita). ייצוא PNG / JPG.
- **טלפון:** צפייה, זום וגלילה, וכלים בסיסיים בנגיעה; עבודה מלאה — טאבלט / מחשב.
- **מנוע:** Canvas 2D / WebGL בדפדפן, ספריות MIT/BSD/Apache בלבד ב-`vendor/`.
