  ריתוך, ציר, זווית, או כל אלמנט חיבור אחר.

## 13. מה שכבר קיים ב-`sukkah-sketch` — ולמה זה משנה הכול

הפרויקט `sukkah-sketch` הוא **מופע מוגמר** של בדיוק מה שהכלי הזה צריך לייצר.
הוא בנוי בקוד ולא בממשק, אבל **הוא כבר פתר את רוב השאלות הקשות.**

🔵 **המסגור שאני מציע:** `sketches-3d` = לקחת את `model.js` של הסוכה, ולהפוך
את מה שכתוב בו בקוד לנתונים שהמשתמש עורך בממשק. **הסוכה היא מבחן הקבלה:**
הכלי גמור כשאפשר לבנות בו את הסוכה בלי לכתוב שורת קוד.

### מה כבר נפתר שם

| נושא | הפתרון הקיים |
| --- | --- |
| **מנוע** | `three.js` r128, עותק מקומי ב-`vendor/` + שרשרת נפילה ל-CDN |
| **מצלמה בנייד** | נכתבה ידנית, **בלי `OrbitControls`** — שתי אצבעות מזיזות/מזמנות/מסובבות, זום אל הנקודה שמתחת לאצבע |
| **ארכיטקטורה** | `model.js` = גאומטריה טהורה, **בלי three.js ובלי DOM**. התצוגות בונות ממנו |
| **מקור אמת יחיד** | אף תצוגה לא מחשבת מידה בעצמה — לעולם לא שני מספרים לאותה קורה |
| **חישוב מיטר** | `m = 90 − cornerAngle/2` — מכל זווית פינה, לא רק 45° |
| **סוגי חיתוך** | `miter` · `wall` · `notch` · `face` |
| **חיתוך מפוצל** | קצה אחד עם **שני** חיתוכים בזוויות שונות (ק1, ק3) |
| **"נגמר על פני העמוד"** | `trimS()` — מחשב כמה לקצר לאורך הציר עד פני המארח |
| **נקודות עיגון** | `hostAt(key)` — מפתח עמוד, `@x` על פני הקיר, `#y` על קצהו |
| **מחבר ממשי** | שרוול + שן, עם סיבוב לכיוון הקורה בכל זווית |
| **מיטוב שאריות** | דיקטים — `first-fit decreasing`, שאריות נחתכות יחד |
| **פירוק (explode)** | מרים קורות מעל השרוולים כדי לראות את החיבור |
| **שכבות** | הדלקה/כיבוי של מסגרת, קיר, מחברים, תוויות |
| **מבטים** | תלת־ממד, מבט־על אורתוגרפי, דרום, מזרח |
| **הקשה על חלק** | שם, אורך חוץ ופנים, זוויות חיתוך, פרופיל |
| **ייצוא PDF** | וקטורי, A3 לרוחב, שקופית לעמוד, נבנה מהדף עצמו |
| **מאתר חלק** | בכל שקופית: איזומטרי + תוכנית, החלק בכתום, מצפן וסרגל גבהים |

### 🔴 התשובה לשאלה "איזה אורך נרשם"

**היא כבר שם: שניהם.** רשימת החיתוך מציגה `len.outer` ו-`len.inner` —

## שאלות פתוחות

### 🔴 מסלול המתאר — איך המשתמש מזין מצולע?

בסוכה `P` הוא מצולע בן 8 נקודות עם קואורדינטות מדויקות. **איך מזינים
אותו — ובמיוחד בטלפון?**

- ❓ הקשה על נקודות בתוך רשת?
- ❓ הזנה סדרתית — "248 צפונה, ואז 150.5 בזווית X"?
- ❓ גרירת קודקודים, והמספר מתעדכן?
- 🔵 דעתי: **הזנה סדרתית היא היחידה שעובדת באמת בטלפון.** גרירה מדויקת
  באצבע על מסך 6 אינץ' אינה מעשית, וזה בדיוק המקום שבו "מותאם לנייד"
  נשבר.

### 🔴 מפלסים — מושג ראשי במערכת?

בסוכה יש שני מפלסים אופקיים (280 ו-70) ועמודים שמחברים ביניהם.

- ❓ **"מפלס" הוא מושג מובנה?** כלומר: מתאר + רשימת גבהים ⟵ מסגרת בכל
  גובה + עמודים בפינות, אוטומטית?
- ❓ **העמודים נוצרים לבד** בפינות המתאר, או שהמשתמש מניח אותם?
  בסוכה יש גם עמודי ביניים שאינם בפינה.

### 🔴 המתאר — גבול השטח או ציר הפרופיל?

בסוכה `P` הוא **גבול השטח**, והמסגרת יושבת בתוכו עם מרווח (`GAP`) ואז
עובי הפרופיל. שלושה מצולעים נגזרים: חוץ, פנים ומרכז.

- ❓ המשתמש חושב ב**"השטח שיש לי"** או ב**"איפה הברזל"**? זו הבחנה
  שמשנה כל מספר שהוא מזין.

### 🔴 עומק מבחן הקבלה

לסוכה יש מאפיינים מאוד ספציפיים. **אילו מהם חייבים להיות ניתנים לשחזור
בכלי הגנרי?**

| מאפיין | חובה? |
| --- | --- |
| מסגרת ממתאר עם מיטרים | ❓ |
| מחבר שרוול + שן | ❓ |
| פלטות קיר (צד בלי עמודים) | ❓ |
| קורה שנגמרת על פני העמוד במפלס אחד ועוברת מעליו באחר | ❓ |
| קצה עם שני חיתוכים בזוויות שונות | ❓ |
| אריזת לוחות דיקט משאריות | ❓ |

- 🔵 הצעה: **המסגרת, המיטרים ורשימת החיתוך הם המבחן**. השאר — יעדי
  המשך. אחרת הגרסה הראשונה לא תצא לאוויר.
