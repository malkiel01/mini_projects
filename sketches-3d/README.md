# שרטוטים בתלת מימד

כלי לשרטוט ולצפייה במודלים תלת־ממדיים, בתוך אוסף הכלים.

## מצב נוכחי — שלד בלבד

הכלי עצמו טרם נכתב. מה שקיים כאן הוא התשתית שכל השאר ייבנה עליה:

| מה | איפה |
| --- | --- |
| דף הכלי | `index.html` |
| עיצוב | `assets/css/app.css` |
| קוד | `assets/js/app.js` |
| אייקון | `assets/icon.svg` |
| כרטיס בדף הראשי | `../index.html` |

הקובייה המסתובבת שבדף היא **מציין מקום**: ציור קווים על `<canvas>` בלי שום
ספרייה, שנועד להראות שהתיקייה חיה ושהנכסים נטענים מהשרת. היא תוחלף במנוע
האמיתי ברגע שיהיה אפיון.

## מה טרם הוכרע

הבחירות הבאות תלויות באפיון, ולכן לא נקבעו מראש:

- **המנוע** — `three.js`, WebGL ישיר, או ציור דו־ממדי של הטלה.
- **מקור המודלים** — שרטוט בתוך הכלי, ייבוא קבצים (STL/OBJ/GLTF), או שניהם.
- **אחסון** — הכול בדפדפן (כמו `file-merger`), או צד שרת עם `data/` (כמו
  `renovation-punchlist`). ההכרעה הזו משפיעה על `deploy.yml`: תיקיית נתונים
  שנכתבת בשרת חייבת `--exclude` משלה, אחרת פריסה תדרוס אותה.

## פריסה

התיקייה נפרסת אוטומטית עם שאר הריפו דרך `.github/workflows/deploy.yml`, ללא
הגדרה ייעודית. אין כאן כרגע קוד PHP ואין תיקיית נתונים.
