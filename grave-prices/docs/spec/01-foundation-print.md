# 01 — תשתית, נתוני ההתחלה, צפייה והדפסה

**הפרוסה הראשונה לקוד.** בסופה: נכנסים דרך הפלטפורמה, רואים את שני מחירוני ישראל, ומדפיסים כל אחד בכל
אפשרויות ההדפסה — עמוד A4 שנראה כמו המחירון של הבעלים. אין עדיין עריכה (פרוסה 02).

קריאת חובה: `00-overview.md`, `platform/docs/auth.md`, `platform/docs/sso.md` סעיף 0, `devloop/README.md`,
`.claude/skills/devloop/references/install.md`, הסקיל `phone-first-design`, והמקור:
`team/source/israel-2025-03-15.pdf`.

## 1. מה בונים

1. **מסד ומיגרציות** — הטבלאות של `00-overview.md` סעיף 2, ב-`data/app.sqlite`. מיגרציות ממוספרות, רצות בבקשה
   הראשונה, אף אחת לא מוחקת נתונים.
2. **נתוני ההתחלה** — `docs/spec/seed/editions.json` מועתק לאפליקציה ונטען במיגרציה **רק כשאין מחירונים**.
   נייר המכתבים — `seed/letterhead-*.jpg` מועתקים ל-`assets/img/`.
3. **התחברות** — מחוברת ומנותקת, לפי `00-overview.md` סעיף 4. חשבון נפתח בכניסה ראשונה; `is_dev` נקבע לפי
   `platform_admin` בכל כניסה.
4. **יומן פעולות** (`audit`) — בפרוסה הזו: `login`, `print` (מחירון + תצורה).
5. **מסך הבית — רשימת המחירונים**: שורה לכל מחירון, מהחדש לישן: "בתוקף החל מ- 15/03/2025", ותג **"בתוקף
   היום"** על המחירון האחרון שתאריכו ≤ היום. לחיצה → מסך המחירון.
6. **מסך המחירון** — התצוגה של סעיף 3 בטבלה רציפה (בלי נייר המכתבים): עמודת שורות, עמודת "תושבי ישראל", עמודת
   "תושבי חו"ל". מחיר ריק → "—". בטלפון: מתג "ישראל / חו"ל / שתיהן" מעל הטבלה, ברירת מחדל "שתיהן".
   כפתור **🖨️ הדפסה** עם ארבע האפשרויות (`00-overview.md` סעיף 3).
7. **דף ההדפסה** — `print.html?e=<pid>&mode=il|abroad|split|both`. נטען, מציג את העמוד/ים, ופותח
   `window.print()` לבד. גם בלי הדפסה — זו תצוגה מקדימה נאמנה.
8. **מסך המפתח** (רק `is_dev`): DevLoop (מטלות, 🐞 בכותרת, יומן בקשות ושגיאות), יומן הפעולות (100 אחרונות),
   ובדיקות תקינות: המסד נפתח, `data/` כתיבה, גרסה (`app.json`), מספר המחירונים.
9. **`dev/open-items.json`** — מפת הדרכים: GP-01, GP-02 (המבנה — `devloop/README.md`).
10. **בדיקות CLI** — `tests/run.php`: מיגרציה על מסד ריק, טעינת נתוני ההתחלה, ופענוח הסימון של התוויות.

## 2. מה לא בפרוסה הזו

עריכת מחיר, שורה, חתימה; מחירון חדש; העלאה באחוז; נעילה ואישור תיקון — כולם ב-02.

## 3. ההדפסה — כללים מדויקים

- `@page { size: A4 portrait; margin: 0 }`; כל עמוד הוא אלמנט בגובה A4 עם `page-break-after`. **מחירון אחד =
  עמוד אחד** בכל תצורה (ב-`split` — שני עמודים). אם התוכן ארוך — מקטינים את הגופן (עד 80%) ולא גולשים לעמוד נוסף.
- נייר מכתבים עליון בראש העמוד ברוחב מלא; תחתון בתחתית העמוד ברוחב מלא.
- כותרות: "מחירון חברה קדישא לעדת המערבים" — מודגש, גדול, ממורכז. מתחתיו "רכישת אחוזת קבר לתושבי ישראל" /
  "לתושבי חו"ל" / "לתושבי ישראל ולתושבי חו"ל", ו"המחירון בתוקף החל מ- DD/MM/YYYY".
- `section` — ממורכז, מודגש, קו תחתון. `subsection` — לימין, מודגש, גדול מהשורות. `heading` — לפי הסימון שבתווית.
  `item` — לפי הסימון; `indent: 1` מוזח. `fee` ו-`note` — גופן קטן יותר, מודגש כמו במקור.
- מחיר: מספר עם פסיק אלפים (`16,947`), מודגש, מיושר לשמאל של העמודה; `₪` בעמודה צרה משמאלו.
- ב-`both`: שתי עמודות מחיר, ומעליהן בשורה הראשונה "תושבי ישראל" · "תושבי חו"ל". שורה בלי מחיר לקבוצה — "—".
- ב-`il` / `abroad` / `split`: שורת מחיר בלי מחיר לקבוצה — **לא מודפסת**. כותרת (`section`/`subsection`/
  `heading`) שכל שורות המחיר שתחתיה הוסתרו — גם לא מודפסת. **אם אין לקבוצה אף מחיר** — במקום השורות: "טרם הוזנו
  מחירים לתושבי חו"ל" (במסך ובהדפסה).
- חתימות: שלוש עמודות שוות, שם מודגש מעל תפקיד, מעל נייר המכתבים התחתון.
- בהדפסה אין כפתורים, כותרת אפליקציה או 🐞. `print.html` עובר בשער כמו כל דף (לא ציבורי).

## 4. ה-API

| action | שיטה | מה |
| --- | --- | --- |
| `me` | GET | המשתמש: שם, `is_dev` |
| `editions` | GET | `[{pid, effective_from, in_effect}]` מהחדש לישן |
| `edition` | GET `pid` | המחירון המלא: `effective_from`, `signatures`, `rows[{kind, indent, label, prices:{il, abroad}}]` |
| `print-log` | POST `pid`, `mode` | רישום ביומן |
| `dev-*`, `devapi-*` | | DevLoop, לפי `devloop/README.md` |
| `health`, `audit` | GET | למפתח בלבד (403 לאחר) |

כל POST — עם כותרת CSRF. שגיאה — `{"error": "<עברית>"}` וקוד HTTP מתאים.

## 6. נקודות שהוכרעו כאן (הפיכות)

- `section`/`subsection` הם `kind` נפרדים ולא סימון בתווית — כדי שההסתרה בהדפסה הנפרדת (סעיף 3) תדע מה כותרת.
- "בתוקף היום" נקבע לפי שעון ישראל.
- הסדר במחירון — `sort` בלבד; אין קינון בטבלה (הקינון נגזר מ-`kind`).
