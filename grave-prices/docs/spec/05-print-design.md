# 05 — עיצוב הדפסה אחיד, כותרת אחת ואגרות מרוכזות בדף המשותף

**למה:** הבעלים בדק (GP-01, "הכל תקין") וביקש (owner-brief §1, נגזרות 14–16):

1. עיצוב **מתאים וזהה** לישראל ולחו"ל — בעיקר כשמדפיסים את שניהם באותו דף.
2. בדף המשותף — **כותרת אחת** של המחירון, בלי "לתושבי ישראל / חו"ל" למעלה; כל עמודה מתייחסת לקבוצה שלה.
3. בדף המשותף — **האגרות במרוכז למטה**: כלליות — כלליות; של חו"ל — עם ציון שהן לתושבי חו"ל.

הפרוסה נוגעת **רק בהדפסה** (`print.html`, `print.js`, `print.css`) ובסימון קטן במצב עריכה (§4). אין שינוי במודל
הנתונים, ואין שאלות לבעלים. גוברת על 01 §3, 03 §6 ו"הכרעות הבעלים" ב-03 בכל מה שסותר. עמוד A4 אחד — נשמר.

## 1. סולם טיפוגרפי אחד

**כל סוג שורה נראה אותו דבר בכל מחירון ובכל תצורה** (`one`, `split`, `both`). כל ההגדרות הייחודיות לקבוצה
(`.pl.abroad …` היום) — יוצאות. המידות ב-em מגודל הבסיס, כדי שההקטנה (עד 70%) תחול על הכול יחד:

| רכיב | גודל | משקל | יישור | מרווח מעל / מתחת |
| --- | --- | --- | --- | --- |
| בסיס (`item`) | 10.5pt = 1em | רגיל, לפי הסימון בתווית | ימין | 0 / 0, `line-height` 1.25 |
| מחיר + ₪ | 1em | מודגש | המחיר — ימין עמודת המחיר; ₪ בעמודה צרה משמאלו | — |
| כותרת המחירון (h1) | 1.6em | מודגש | מרכז | 0 / 0.3em |
| כותרת קבוצה (`subtitle` ב-`one`; "תושבי ישראל"/"תושבי חו"ל" ב-`both`) | 1.3em | רגיל ב-`one`, מודגש ב-`both` | מרכז | 0.5em / 0 |
| "המחירון בתוקף החל מ-" | 1em | רגיל | מרכז | 0.2em / 1em |
| `section` | 1.2em | מודגש + קו תחתון | מרכז | 1em / 0.4em |
| `band` | 1em | מודגש | מרכז, רקע `#d9d9d9` לרוחב הטבלה | 0.6em / 0.2em |
| `subsection` | 1.2em | מודגש | ימין | 0.8em / 0.3em |
| `heading` | 1em | לפי הסימון | ימין | 0.2em / 0 |
| `fee` — התווית | 0.9em | רגיל (הסימון בתווית גובר) | ימין | 0 / 0 |
| `fee` — המחיר | 0.9em | מודגש | כמו מחיר | — |
| `note` | 0.85em | רגיל (הסימון גובר) | ימין | 0 / 0 |
| המעבר לאזור האגרות (§1 של 04) | — | — | — | 1em מעל השורה הראשונה |

- **עמודות המחיר** ברוחב קבוע: מחיר 22mm, ₪ 6mm — זהה בכל עמוד ובכל עמודה של `both`.
- **אותו גופן** (Arial והחלופות שכבר מוגדרות) לכל העמוד.
- **ההקטנה:** מקדם אחד לכל העמוד — ב-`both` שתי העמודות והאגרות קטנות יחד, כדי שיישארו זהות.
- הסימון בתווית (`**`, `__`, `((…))`) — נשאר כמו שהוא; הוא מה שנותן את ההבדלים שבמקור.

## 2. הדף המשותף (`both`) — המבנה החדש

```
[נייר מכתבים עליון]
            מחירון חברה קדישא לעדת המערבים                ← h1, פעם אחת. בלי subtitle
┌──────────── ימין ────────────┐ ┌──────────── שמאל ───────────┐
│        תושבי ישראל           │ │        תושבי חו"ל           │  ← כותרת קבוצה, מודגש
│ המחירון בתוקף החל מ- 15/06/2026│ │ המחירון בתוקף החל מ- 15/06/2026│
│  השורות עד אזור האגרות       │ │  השורות עד אזור האגרות      │
└──────────────────────────────┘ └─────────────────────────────┘
                     תשלומי אגרות                                ← subsection, לרוחב הדף
  אגרות כלליות                       מחיר ₪
  אגרות של ישראל בלבד ((לתושבי ישראל))  מחיר ₪
  אגרות של חו"ל בלבד  ((לתושבי חו"ל))   מחיר ₪
  הערות (אותו כלל)
[חתימות — הסט הגלובלי, 04 §4]
[נייר מכתבים תחתון]
```

- **העמודות** מכילות רק את השורות שלפני אזור האגרות (04 §1). `subtitle` של המחירון — **לא** מודפס ב-`both`.
- **אזור האגרות המרוכז** — לרוחב הדף, בעמודות המחיר הרגילות (§1), עם הכותרת "תשלומי אגרות" (`subsection`, ממורכז
  כאן). כותרת `subsection` שבתוך אזור האגרות של מחירון (כמו "תשלומי אגרות" בחו"ל) — לא מודפסת; היא מוחלפת בכותרת
  המשותפת.

### איך מחליטים מה כללי

לכל שורת `fee` ו-`note` באזורי האגרות של שני המחירונים מחשבים **מפתח**: התווית בלי סימון (`**`, `__`, `((`, `))`),
בלי כוכביות ורווחים בהתחלה, בלי נקודה בסוף, ורווחים כפולים → רווח אחד.

| מצב | מודפס |
| --- | --- |
| אותו מפתח **ואותו מחיר** בשני המחירונים (`note` — אותו מפתח) | שורה אחת, **כללית**: התווית של ישראל, בלי ציון קבוצה |
| רק בישראל, או מחיר שונה | התווית של ישראל, ואחריה ` ((לתושבי ישראל))` |
| רק בחו"ל, או מחיר שונה | התווית של חו"ל, ואחריה ` ((לתושבי חו"ל))` |

- **הסדר:** כלליות (בסדר של ישראל) → ישראל בלבד → חו"ל בלבד; ובכל קבוצה — `fee` לפני `note`.
- שורה בלי מחיר (`fee` עם `null`) — לא מודפסת, כמו היום.
- **היום, בנתונים כמו שהם:** "תשלום עבור אגרת שמור מחיים" (400 בשניהם) — כללית. "תשלום עבור העברת בעלות לאחוזת קבר"
  (ישראל) ו"העברת בעלות שטר קבר" (חו"ל) — **טקסט שונה**, ולכן שתי שורות עם ציון קבוצה. הבעלים מאחד אותן בעריכת
  הטקסט באחד המחירונים (§4 מראה לו את זה). לא משנים את נתוני הבעלים במיגרציה.

## 3. `one` ו-`split`

- אותו סולם (§1), אותו נייר מכתבים, אותן חתימות. **אזור האגרות נשאר בתוך המחירון**, כמו במקור — הריכוז הוא רק ב-`both`.
- הכותרות: h1, ואחריו `subtitle` ו"בתוקף החל מ-" — כמו היום, במידות של §1.
- ב-`split` שני העמודים זהים במבנה ובמידות; ההבדל רק בתוכן.

## 4. סימון "כללית" במצב עריכה

במצב ✏️ עריכה, ליד כל שורת `fee` (ו-`note`) — תג קטן, לפי §2 מול המחירון של הקבוצה השנייה **שבתוקף היום**:

- **"כללית ✓"** — יש לה התאמה (מפתח ומחיר).
- **"רק ל<תושבי ישראל / חו"ל>"** — אין. ב-`title` של התג: "כדי שתודפס כאגרה כללית בדף המשותף — אותו טקסט ואותו מחיר
  במחירון של <הקבוצה השנייה>".

בלי פעולה נוספת, בלי שדה חדש. API: `edition` מחזיר לכל שורת `fee`/`note` את `shared: true|false` (מחושב בשרת באותו
כלל — פונקציה אחת, שגם `print.js` מקבל את תוצאתה דרך ה-API, כדי שהמסך וההדפסה לא יחלקו).

## 6. מה לא בפרוסה

שדה "אגרה כללית" במודל, איחוד אוטומטי של טקסטים דומים, עורך עיצוב, שינוי במסכים (מלבד התג של §4).
