# 05 — סקילים, תוספים ו-MCP מהממשק

## העיקרון
אין "חנות" שלנו. הכול נשמר ב-`~/.claude` של ה-Mac, דרך פקודות ה-CLI עצמו. מה שמותקן בממשק — קיים בטרמינל, ולהפך.

## מסך "תוספים"
| לשונית | מה רואים | פעולות (מה הגשר מריץ) |
| --- | --- | --- |
| סקילים | כל הסקילים הזמינים (אישיים, של הריפו, של תוספים), עם תיאור | הפעלה מהירה (`/שם`); צפייה בקובץ; **יצירה ועריכה מהממשק — עורך פשוט (הוכרע, Q16)** |
| תוספים | מותקנים + שוקי תוספים (marketplaces) | `claude plugin install / enable / disable / uninstall`, `configure` |
| MCP | שרתים מחוברים, מצב | `claude mcp add / remove / list`; התחברות OAuth — [לאמת: דורשת דפדפן במחשב] |
| סוכנים | סוכנים מוגדרים | צפייה, יצירה ועריכה (Q16) |

**[לאמת]** אילו מהפקודות האלה רצות בלי מסך אינטראקטיבי (`--values-stdin` קיים ב-`plugin configure`).

## "תוספים שמותאמים לי" — הוכרע (Q3): שניהם
כרטיסיות למעלה = קיצורי דרך וממשקים שמתחברים למערכת ול-Claude; כרטיסייה מוסיפים ידנית בהגדרות וגם דרך Claude. הלוח הקיים של `claude-tasks` נהיה כרטיסייה (Q24).
- **א. תוספים של Claude** (סקילים / plugins / MCP) שהבעלים כותב או מתקין — נכנס בדיוק למסך הזה.
- **ב. תוספות בממשק שלנו** — כפתורים מהירים ("📋 תריץ בדיקות", "🚀 תפרוס"), תבניות הודעה, חיבור ללוח המטלות הקיים,
  ווידג'טים (למשל מצב הפריסה של mini_projects). ייבנה כמנגנון "תוסף ממשק" קטן: קובץ JSON שמגדיר כפתור → טקסט שנשלח.
