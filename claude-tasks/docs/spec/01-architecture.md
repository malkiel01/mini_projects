# 01 — ארכיטקטורה

## הרכיבים

```
 טלפון / דפדפן                 השרת (PHP משותף, claude-tasks/)             ה-Mac של הבעלים
┌──────────────┐   HTTPS   ┌──────────────────────────────┐  HTTPS יוצא  ┌───────────────────────────┐
│ הממשק (צ'אט) │ ────────► │ chat-api.php + data/chat.sqlite│ ◄────────── │ הגשר (Node, LaunchAgent)  │
│ כמו Claude   │ ◄──────── │ שיחות, הודעות, אירועים, הגדרות│             │   │                        │
└──────────────┘           └──────────────────────────────┘             │   ▼                        │
       ▲                          │ "צלצול" בלי תוכן                     │ claude (ה-CLI המותקן)      │
       └──────── ntfy.sh ◄────────┘ ──────────────────────────────────► │ ~/.claude: סקילים, תוספים,│
                                                                        │ MCP, הגדרות, שיחות         │
                                                                        └───────────────────────────┘
```

1. **הממשק** — דף phone-first, RTL, בדפדפן + אפליקציה מותקנת בטלפון + חלון ב-Mac + אפליקציה ב-Windows (Q5; Mac קודם,
   הקוד מוכן לשניהם). כרטיסיות למעלה (Q3). **האפליקציה יושבת בריפו פרטי ייעודי, לא ב-mini_projects** (הכרעת מבנה 24.11).
2. **השרת** — מתווך בלבד: שומר שיחות ואירועים **לפי משתמש (בידוד מלא)**, מאמת, מצלצל. **לא מריץ Claude ולא מחזיק מפתח
   (Q18).** כל משתמש = גשר אחד על המחשב שלו; אין שום מצב משותף בין משתמשים.
3. **הגשר** — תהליך קטן על ה-Mac, פונה רק החוצה. מקבל הודעה, מפעיל את `claude`, מזרים חזרה את מה שקורה.
4. **Claude Code** — ה-CLI עצמו, עם `~/.claude` של הבעלים. מה שמותקן בטרמינל — קיים בצ'אט, ולהפך.

## איך הודעה עוברת

1. הבעלים שולח → השרת שומר (`queued`) → צלצול ל-ntfy (רק "יש הודעה", בלי תוכן).
2. הגשר מקבל צלצול → תופס את ההודעה (מבצע אחד בלבד) → מעביר ל-Claude Code.
3. Claude Code רץ במצב הזרמה (`--output-format stream-json`, `--include-partial-messages`) — כל אירוע (טקסט שנכתב, כלי
   שהופעל, תוצאה, בקשת אישור) נשלח לשרת **באצוות קטנות** (לא אירוע-אירוע), והשרת מצלצל לדף.
4. הדף מושך את האירועים החדשים ומציג אותם כמו ב-Claude — טקסט זורם, כרטיסי כלים.

**מנוע ההרצה** [החלטה טכנית — לאשר בבנייה]: אחת משתיים —
- **CLI** (`claude -p --input-format stream-json --output-format stream-json`): תהליך חי לכל שיחה פעילה, הודעות נכנסות
  ב-stdin. הכי קרוב ל"מה שמותקן", מתעדכן עם `claude`.
- **Agent SDK** (TypeScript): אותו מנוע, עם API נוח לאישורי הרשאות (`canUseTool`) ולפקודות. [לאמת: האם ה-SDK משתמש
  ב-`claude` המותקן או בעותק משלו — זה קובע אם "כל עדכון של Claude" מגיע לבד.]
ההמלצה: CLI, כי הוא *בדיוק* מה שהבעלים מריץ בטרמינל. SDK — רק אם ה-CLI לא נותן משהו נחוץ.
