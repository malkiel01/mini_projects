# פרוסה 04 — התקנה, הפעלה עם המחשב, עדכון

תלויה ב-01. ש4 הוכרע: **macOS**. Windows/Linux — אותו קוד, בהמשך.

## מה בונים
1. **בדיקת דרישות** (`bridge.mjs doctor`): Node ≥ 20, `claude` בנתיב ובגרסה שתומכת ב-`--permission-prompts`, התחברות
   (מפתח בקובץ או `claude` מחובר — לפי ש1), התיקייה קיימת, השרת עונה, ntfy עונה. כל שורה ✅/❌ עם מה לעשות.
2. **הפעלה עם המחשב:** `bridge.mjs install-service` — macOS: LaunchAgent ב-`~/Library/LaunchAgents` (בלי sudo), `KeepAlive`;
   בהמשך Windows (Task Scheduler) ו-Linux (`systemd --user`). `uninstall-service` מסיר.
3. **מסך "המחשב שלי"** בדף: שם, גרסה, תיקייה, נראה לאחרונה, "נתק מחשב" (פוסל את האסימון מיד), קוד צימוד חדש.
4. **עדכון:** `bridge-hello` מחזיר `latest_version`; גרסה ישנה → בדף "⬆️ יש גרסה חדשה לגשר" עם פקודה אחת להעתקה.
   **לא** עדכון עצמי אוטומטי (קוד שרץ במחשב לא מתחלף מרחוק בלי שהבעלים הריץ פקודה).
5. **הורדה:** `desk-bridge/` מוגש כקובץ אחד להורדה מהדף (`bridge.mjs`), עם גיבוב SHA-256 מוצג.

## קריטריוני קבלה
1. Mac עם Node ו-Claude Code: מהדף "חיבור מחשב" עד תשובה ראשונה — ≤ 3 פקודות מועתקות.
2. הפעלה מחדש של המחשב → הגשר עולה לבד, "🟢" תוך דקה מהכניסה.
3. "נתק מחשב" → הבקשה הבאה של הגשר 401, והגשר נעצר עם "המחשב נותק מהפלטפורמה — צימוד מחדש".
4. `doctor` עם `claude` חסר → ❌ עם קישור להתקנה הרשמית.
