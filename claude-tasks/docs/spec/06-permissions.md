# 06 — מה Claude רשאי, ואישור פעולות

## ההגדרה (ש2 — "הכול", כהגדרה)
בהגדרות, ובקובץ ההגדרות של הגשר במחשב (המקור המחייב — הפלטפורמה לא יכולה להרחיב מעבר לו):

| רמה | מה |
| --- | --- |
| **הכול** (בחירת הבעלים) | כמו בטרמינל בלי שאלות — כולל `git push` ופריסה |
| ריפו | עורך ומריץ, בלי `push` |
| קריאה | רק קורא ועונה |
| **שואל** | כמו בטרמינל הרגיל: מה שדורש אישור → כרטיס בממשק |

[שאלה Q17] ב"הכול" — אין שום כרטיס אישור, גם לא למחיקת קבצים או ל-`rm -rf`? או שיש רשימה קטנה של "תמיד לשאול"?

## כרטיס האישור (ברמת "שואל")
"Claude רוצה להריץ: `npm install` · [אשר פעם אחת] [אשר תמיד בשיחה] [דחה]". אין תשובה X דקות → נדחה, ו-Claude ממשיך.
מימוש: `--permission-prompts host` / `canUseTool` ב-SDK [לאמת מה מהם עובד עם תהליך חי].

## גבולות שלא נפתחים מהממשק בשום רמה
קובץ ההגדרות של הגשר עצמו; ההרשאות; המפתח. (כדי שמי שגנב כניסה לפלטפורמה לא יוכל להשתלט — 09.)
