# 00 — החזון

## במילים של הבעלים (24.11.2026)

> "אני רוצה לפתח לעצמי צ'אט ממש כמו צ'אט של קלוד, אפילו ממש דומה, שיהיו לי בו תוספים שמותאמים לי. אבל הוא יהיה מחובר
> ל-CLI של קלוד, כך שכל מה שניתן לעשות בקלוד — הרצת פקודות, התקנת סקילים, חיבור תוספים, כל עדכון שמתקבל בקלוד — יהיה
> גם אצלי."
>
> "זה משתמש בתוך החשבון פרו / מקס, או שהשימוש יהיה באמצעות טוקנים של קלוד פלטפורמה. את ההחלטה הזאת אנחנו מחליטים
> בהגדרות, וניתן לשינוי בכל רגע."
>
> "אוקיי אז אנחנו נתחיל מהמחשב שלי."

## מה זה אומר (ההבנה שלנו — לאשר)

1. **מוצר אחד: ממשק צ'אט** בפלטפורמה של הבעלים (`claude-tasks/`), שנראה ומרגיש כמו הצ'אט של Claude. [שאלה Q1: איזה
   Claude בדיוק — claude.ai או Claude Code?]
2. **המנוע הוא Claude Code האמיתי** שמותקן על ה-Mac של הבעלים — לא העתק, לא Messages API בלי כלים. לכן כל יכולת שיש לו
   (קבצים, פקודות, סקילים, תוספים, MCP, סוכני משנה, זיכרון שיחה) קיימת גם בצ'אט, **בלי שנבנה אותה מחדש**.
3. **עדכונים מגיעים לבד:** Claude Code מתעדכן במחשב, והצ'אט מפעיל את מה שמותקן. יכולת חדשה שמתבטאת בטקסט/כלים — מופיעה
   מיד. יכולת חדשה שדורשת מסך חדש (למשל בורר חדש) — מוסיפים ידנית כשצריך (**הוכרע, Q2**).
4. **"תוספים שמותאמים לי"** — **שניהם** (Q3): תוספים של Claude (סקילים/plugins/MCP) **וגם** כרטיסיות למעלה — קיצורי
   דרך וממשקים שמתחברים למערכת ול-Claude. כרטיסייה מוסיפים ידנית בהגדרות וגם דרך Claude. לוח המטלות הקיים נהיה כרטיסייה (Q24).
5. **חשבון = הגדרה:** מנוי Pro/Max (ה-`claude` המחובר במחשב) או מפתח API — מתג בהגדרות, משתנה בכל רגע, חל מההודעה הבאה.
6. **שלב ראשון: המחשב של הבעלים (macOS).** הצ'אט עובד כשה-Mac דלוק ומחובר. שרת שזמין תמיד — שלב מאוחר.
7. **למי: כל משתמש (Q4, הוכרע).** כל אחד מחבר את ה-Claude שלו, על המחשב שלו, עם החשבון והטוקנים שלו ("אני לא
   הספונסר של כולם"). **אין שום קשר בין האפליקציה של הבעלים לזו של משתמש אחר** — כל משתמש רואה רק את השיחות שלו. הזהות
   מהשער של הכלים הדיגיטליים; האפליקציה עצמאית (משתמש, מסד, עוגייה משלה) בריפו פרטי ייעודי, בדומיין משלה + כרטיס בכלים.

## המבחן

הבעלים פותח את הצ'אט בטלפון, כותב "תריץ את הבדיקות של funerals-dashboard ותגיד מה נפל", ובתוך שניות רואה את Claude
עובד — כמו ב-Claude: הטקסט זורם, הכלים שהוא מפעיל מופיעים — ובסוף תשובה. אחר כך כותב "/<סקיל שהתקין אתמול>" וזה עובד.
בערב, ב-Mac, ממשיך את אותה שיחה בטרמינל.
