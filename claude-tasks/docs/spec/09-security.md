# 09 — אבטחה

- **מי נכנס לממשק:** כל משתמש רשום — כניסה דרך השער של הפלטפורמה (SSO), משתמש אפליקציה משלו, בדיקת Origin. **אימות נוסף
  (Q22): מפתח גישה / טביעת אצבע**, כי הצ'אט שולט במחשב.
- **הגשר:** אסימון מצימוד חד-פעמי; בשרת — רק גיבוב; מורשה רק לפעולות הגשר. "נתק מחשב" בממשק פוסל מיד.
- **מה עובר בשרת:** תוכן השיחות (כדי שתוכל לקרוא מהטלפון). **הוכרע (Q23): מקובל בשלב 1** — בידוד מלא לפי משתמש (כל אחד רואה רק את שלו), בלי הצפנת תוכן נוספת.
- **מה לא עוזב את ה-Mac:** מפתח ה-API, התחברות המנוי, קובץ ההרשאות, קבצים שלא נשלחו בתשובה.
- **ntfy:** צלצול בלי תוכן, נושא אקראי 128 ביט.
- **טקסט מהדף ל-`claude`** — ב-stdin, לא בשורת הפקודה (בלי הזרקת פקודה).
