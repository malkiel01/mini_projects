## המתג "מנוי ↔ API"
- בממשק: מתג אחד, עם הסבר קצר מה כל אחד אומר. מה שמשתנה בפועל: האם הגשר מעביר `ANTHROPIC_API_KEY` ל-`claude`.
- **מה שצריך לדעת (לא מונע):** לפי תנאי Anthropic, מוצר שבנוי על Agent SDK אמור להשתמש במפתח API. כשהגשר מפעיל את
  ה-`claude` שלך עם המנוי שלך — זה קרוב לשימוש אישי בטרמינל, אבל זה תחום אפור. ההחלטה של הבעלים.
- **הוכרע (Q18):** כל משתמש משתמש במפתח או במנוי **שלו** ומשלם בעצמו. המפתח נשאר ב-`claude` שבמחשב של המשתמש (נכנס
  שם, בפקודת הגשר) — **השרת לא מחזיק ולא רואה אותו.** כך אין מפתחות של אחרים על שרת משותף.
- במצב API — עלות לכל הודעה ולכל יום. במצב מנוי — [לאמת: האם ה-CLI מדווח שימוש/מכסה].
