# פרוסה 05 — כרטיס "לאשר / לדחות" (מאוחרת)

תלויה ב-02 ובתשובה לש2. **לא לבנות לפני שהבעלים ענה ש2** — אם ענה א (רק קריאה) או ג (הכול), הפרוסה מצטמצמת או מתבטלת.

## הבעיה
ב-01 פעולה שלא ברשימה — נדחית (`--permission-prompts none`), ו-Claude מספר מה רצה. לפעמים הבעלים רוצה לאשר במקום.

## הכיוון (לאמת מול התיעוד לפני הבנייה)
- `--permission-prompt-tool` עם שרת MCP קטן שהגשר מריץ: הבקשה נשלחת לשרת (`bridge-ask`), צלצול לדף, כרטיס
  "Claude רוצה להריץ: `npm install` [אשר פעם אחת] [דחה]". הגשר מחכה לתשובה בבדיקה פעם ב-5 שניות **רק בזמן ההמתנה**, עד 10 דק',
  ואז דחייה. חלופה: Agent SDK עם `canUseTool`.
- גבולות שלא נפתחים מהדף בשום מקרה: `git push`, פריסה, קבצים מחוץ ל-cwd, קובץ ההגדרות של הגשר.

## קריטריוני קבלה (טיוטה)
1. "תתקין את התלויות" → כרטיס בדף תוך ≤ 3 שניות; אישור → הפקודה רצה; דחייה → Claude ממשיך בלי.
2. אין תשובה 10 דק' → דחייה, והריצה ממשיכה.
3. `git push` → נדחה בלי כרטיס.
