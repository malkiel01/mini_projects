# 04 — שיחות, זיכרון, והמשך בטרמינל

## שיחה
- שיחה בממשק = **סשן אחד של Claude Code** (`session_id`), בתיקייה אחת במחשב.
- ההודעה הראשונה פותחת סשן; כל הבאות — `--resume`. הזיכרון הוא של Claude Code עצמו, לא שלנו.
- התמלול המלא נשמר **גם** במסד שלנו (כדי לקרוא מהטלפון כשה-Mac כבוי).

## אותה שיחה גם בטרמינל (ש3 — נענתה: "כל מה שניתן לעשות בקלוד")
1. **מהממשק לטרמינל:** בכל שיחה "💻 המשך בטרמינל" → מעתיק `cd <תיקייה> && claude --resume <id>`.
2. **מהטרמינל לממשק:** מה שנכתב ונענה בטרמינל בשיחה מקושרת — מופיע בממשק, מתויג 💻 (hooks של Claude Code שהגשר מתקין:
   `UserPromptSubmit`, `Stop`).
3. **שיחה שהתחילה בטרמינל** — **כולן מופיעות בממשק (הוכרע, Q14).** משמעות: כל תוכן הטרמינל עולה לשרת (בידוד לפי משתמש, Q23).
4. **נעילה:** שיחה פתוחה בטרמינל — הודעה מהממשק ממתינה ("💻 השיחה פתוחה בטרמינל"), כי שני תהליכים על אותו סשן מאבדים
   הודעות (אזהרה רשמית בתיעוד).

## Mac כבוי
- ההודעה נשמרת, בממשק: "🔌 ה-Mac לא מחובר — תיענה כשיידלק".
- **הוכרע (Q15):** הודעה שחיכתה עד 12 שעות רצה מיד כשהמחשב עולה; אחרי 12 שעות — שואלים לפני שמריצים (הסיכון: פקודה
  ישנה שנכתבה לפני שהמצב השתנה, ובמצב "הכול מותר" אף אחד לא בדק אותה שוב).
- היסטוריה — נקראת מהשרת גם כשה-Mac כבוי.
