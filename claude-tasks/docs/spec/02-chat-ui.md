# 02 — הממשק: "ממש כמו Claude"

[שאלה Q1] קובעת את כל הקובץ הזה. ההנחה כרגע: **המראה של claude.ai** (רשימת שיחות בצד, שיחה במרכז, תיבת כתיבה למטה),
עם **התוכן של Claude Code** (כרטיסי כלים, שינויי קבצים, פקודות). בעברית, RTL, phone-first (הסקיל `phone-first-design`).

## המסכים

### רשימת שיחות (צד ימין במחשב; מגירה בטלפון)
- "➕ שיחה חדשה", חיפוש, שיחות לפי תאריך (היום / אתמול / השבוע), שינוי שם, הצמדה, ארכוב.
- ליד כל שיחה: התיקייה שבה היא רצה (למשל `mini_projects`), ונקודה אם Claude עובד בה עכשיו.
- [שאלה Q7] פרויקטים / תיקיות כקבוצות, כמו "Projects" ב-claude.ai?

### השיחה
- **ההודעות שלי** — בועה; **התשובות** — טקסט מלא ברוחב, Markdown, קוד עם כפתור העתקה.
- **הזרמה:** הטקסט מופיע תוך כדי כתיבה. [הנחה: עדכון כל ~1 שנייה, לא תו-תו — Q6]
- **כרטיסי כלים** (כמו ב-Claude Code): "📖 קורא `lib/db.php`", "✏️ עורך `app.js` (+12 −3)", "🔧 `npm test`" — מקופל,
  לחיצה פותחת פלט / diff. [שאלה Q8: כמה פירוט להציג כברירת מחדל]
- **חשיבה** (thinking) — מקופל, אם המודל מחזיר. [Q8]
- **סוכני משנה** — כרטיס מקונן.
- **בקשת אישור** — כרטיס "Claude רוצה להריץ `git push` · [אשר] [אשר תמיד] [דחה]" (06).
- **רשימת מטלות של Claude** (TodoWrite) — כמו בטרמינל, לוח קטן שמתעדכן.
- בסוף כל תשובה: משך, עלות (≈, במצב API), מודל.
- כפתורים: "⏹ עצור", "📋 העתק", "↻ נסה שוב", "✏️ ערוך הודעה" [לאמת: עריכה = rewind; ייתכן רק "שלח מחדש"].

### תיבת הכתיבה
- Enter שולח / Shift+Enter שורה (במחשב); בטלפון — כפתור שליחה.
- **`/` פותח רשימת פקודות** — כל הסקילים והפקודות שמותקנים במחשב, עם תיאור, נמשכים מה-CLI (03).
- **`@` מצרף קובץ** מהתיקייה של השיחה (חיפוש בשמות קבצים במחשב, דרך הגשר).
- **צרופות:** תמונה / קובץ מהטלפון → נשלח לגשר → Claude רואה אותו. [שאלה Q9: נחוץ בשלב הראשון?]
- **בורר מודל** ו**מצב** (רגיל / תכנון / אוטומטי) — ליד התיבה, כמו ב-Claude.
- [שאלה Q10] הקלטה קולית?
