# 03 — מה ה-CLI נותן, ואיך זה מופיע בממשק

העיקרון: **הממשק לא מממש יכולות — הוא מציג את מה ש-Claude Code עושה.** לכן כל מה שעובד ב-`claude -p` עובד לבד, וכל
מה שקיים רק במסך האינטראקטיבי של הטרמינל צריך תחליף בממשק.

גרסה במחשב הבדיקה: `claude 2.1.331`. **[לאמת]** כל שורה בטבלה במחשב של הבעלים לפני הבנייה.

| יכולת | עובד במצב ההזרמה? | בממשק |
| --- | --- | --- |
| כתיבה, קריאה, עריכת קבצים, הרצת פקודות | כן | כרטיסי כלים |
| זיכרון שיחה (`--resume`) | כן | כל שיחה = סשן של Claude Code |
| סקילים (`/שם-סקיל`) ופקודות מותאמות | כן [לאמת] | רשימת `/` |
| סוכני משנה, `--agents` | כן | כרטיס מקונן |
| MCP שמוגדר ב-`~/.claude` | כן | שקוף; רשימה בהגדרות |
| תוספים (plugins) מותקנים | כן | שקוף; ניהול ב-05 |
| CLAUDE.md, hooks, הגדרות הריפו | כן (בלי `--bare`) | שקוף |

## "כל עדכון של Claude יהיה גם אצלי"
- **מתעדכן לבד:** כל מה שבשורות "כן" — כי הגשר מפעיל את ה-`claude` המותקן, שמתעדכן לבד.
- **סוג אירוע חדש בזרם** שהממשק לא מכיר — מוצג כ"כרטיס כללי" (שם + תוכן גולמי מקופל), כך ששום דבר לא נעלם.
- **מסך אינטראקטיבי חדש** בטרמינל — דורש שנבנה לו תחליף. הגשר מדווח את גרסת ה-CLI; גרסה חדשה → הודעה קטנה בממשק
  "Claude Code עודכן ל-X" עם קישור לרשימת השינויים. [Q2]
