# 08 — הגשר על ה-Mac

- **מה:** `desk-bridge/` — Node 20+, בלי תלויות. רץ ברקע (LaunchAgent), עולה עם הכניסה למשתמש.
- **התקנה:** פקודה אחת להעתקה מהממשק (`curl … | sh` או `npx`) [שאלה Q19: נוח לך להריץ פקודה בטרמינל פעם אחת?].
  בודק: Node, `claude` מותקן ומחובר, תיקייה. צימוד בקוד חד-פעמי מהממשק.
- **פונה רק החוצה:** השרת (HTTPS) + ntfy (צלצול). בלי פורט פתוח, בלי VPN.
- **שיחות במקביל:** תהליך `claude` לכל שיחה פעילה; ברירת מחדל עד 3 במקביל [הנחה; Q20].
- **עדכון הגשר:** הממשק מראה "יש גרסה חדשה" + פקודה. לא מתעדכן לבד מרחוק (קוד שרץ אצלך לא מתחלף בלי שהרצת).
- **Claude Code עצמו** מתעדכן כרגיל (העדכון האוטומטי שלו) — הגשר רק מדווח את הגרסה.
- **יומן מקומי** בלי תוכן הודעות.
- **שינה של ה-Mac:** כשה-Mac נרדם, הגשר לא עונה. [שאלה Q21: למנוע שינה בזמן ש-Claude עובד (`caffeinate`)?]
