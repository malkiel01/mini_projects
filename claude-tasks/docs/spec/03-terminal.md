# פרוסה 03 — אותה שיחה גם בטרמינל

> **⏸ לא לבנות.** הבעלים לא הבין את ש3 (24.11), והבקרה מסבירה לו מחדש. זו טיוטה לפי ברירת המחדל בלבד.

תלויה ב-02. ברירת מחדל ש3-א: ממשיכים את אותה שיחה ב-`claude` בטרמינל של אותו מחשב, ומה שנכתב שם מופיע בפלטפורמה.
שיחות של claude.ai / אפליקציית Claude (ענן) — לא נתמכות כ"אותה שיחה" (נפרדות טכנית).

## מה שהתיעוד קובע (אומת 2026-11-24)
- סשן שנוצר ב-`claude -p` **לא** מופיע בבורר וב-`--continue`, אבל נפתח ב-`claude --resume <id>`, גם מתיקייה אחרת באותו מחשב.
- שני תהליכים על אותו סשן בו-זמנית כותבים לאותו תמלול, ו"הודעות של אחד מהם עלולות להיעדר" → אסור שהגשר ירוץ על שיחה
  שפתוחה בטרמינל.
- hooks: `UserPromptSubmit` מקבל `prompt`; `Stop` מקבל `last_assistant_message` (התיעוד ממליץ עליו במקום קריאת התמלול);
  לכולם `session_id`, `cwd`. `SessionStart` עם `source` (`startup|resume|…`), `SessionEnd`.
  **לאמת לפני הבנייה:** שה-hooks של `~/.claude/settings.json` רצים גם בריצות `-p` (הגשר מסנן לפי `CT_BRIDGE_RUN`, כך שזה
  לא משנה את הנכונות, רק את הצורך בסינון).

## מה בונים
1. **"המשך בטרמינל"** בכל שיחה: כפתור שמעתיק `claude --resume <cc_session_id>` (ותיקייה, אם שונה).
2. **שיקוף** — hooks מסוג `command` שהגשר מתקין ב-`~/.claude/settings.json` (`bridge.mjs install-hooks`, עם גיבוי של הקובץ
   ומיזוג, לא דריסה): `node bridge.mjs hook` קורא את ה-JSON מ-stdin.
   - `CT_BRIDGE_RUN=1` → יוצא מיד (הריצות של הגשר כבר נרשמות).
   - `session_id` שאינו של שיחה מוכרת (המפה נשמרת מקומית, מעודכנת מכל `bridge-done`) → יוצא מיד. **שיחות טרמינל אחרות
     לא נשלחות לשרת.**
   - `UserPromptSubmit` → `bridge-mirror {session_id, role: terminal_owner, body}`; `Stop` → `terminal_claude` עם
     `last_assistant_message`. timeout 5 שניות, כשל — שקט (לא חוסם את הטרמינל).
3. **נעילה:** `SessionStart` של שיחה מוכרת → `bridge-lock {session_id}`; `SessionEnd` → `bridge-unlock`. גם `UserPromptSubmit`
   מרענן את הנעילה. נעילה בת יותר מ-30 דק' בלי רענון — פגה.
   הודעה מהפלטפורמה לשיחה נעולה → נשארת `queued`, בדף "💻 השיחה פתוחה בטרמינל — תיענה כשתסגור אותה שם". בשחרור — צלצול.
4. **בדף:** הודעות הטרמינל עם תג "💻", באותו רצף.

## קריטריוני קבלה
1. שיחה מהפלטפורמה → "המשך בטרמינל" → `claude --resume …` במחשב → "מה דיברנו?" עונה לפי השיחה.
2. מה שנכתב ונענה בטרמינל מופיע בדף תוך ≤ 5 שניות מסוף התשובה, מתויג 💻.
3. בזמן שהשיחה פתוחה בטרמינל, הודעה מהפלטפורמה **לא** רצה; אחרי יציאה מהטרמינל — רצה, ורואה גם את מה שנאמר בטרמינל.
4. סשן טרמינל שאינו מקושר לשיחה — אפס בקשות לשרת (יומן הגשר).
5. `install-hooks` פעמיים → אין כפילות ב-settings; `uninstall-hooks` מחזיר את הקובץ למצבו.
