# מטלות לקלוד

לוח מטלות ש‑Claude עובד עליו לבד, מטלה אחר מטלה.

הבעיה שזה פותר: כשהכול יושב בצ׳אט אחד ארוך, אי אפשר לדעת מה ביקשת, מה נענה ומה נשאר תלוי. כאן כל בקשה היא רשומה עם מצב משלה.

**מה שהופך את זה ללולאה ולא לרשימה:** שאלה של Claude לא עוצרת את העבודה. הוא רושם אותה, משחרר את המטלה, וממשיך למטלה אחרת. ברגע שעניתם — המטלה חוזרת לתור **וקופצת לראשו**, כי כבר מחכים לה.

## קטלוג אוטומטי

זורקים שורה, המערכת מחליטה לאיזה נושא היא שייכת. שתי שכבות:

**מילות מפתח — ברירת המחדל, בחינם.** לכל נושא אפשר להגדיר מילים (מגירת הנושאים ← ✎). מטלה חדשה מנוקדת מול כל הנושאים, והשיוך נעשה רק כשיש גם ניקוד מספיק וגם פער ברור מהנושא הבא. אחרת היא נשארת ב"ללא נושא" — **שיוך שגוי גרוע מאי‑שיוך**: מטלה בלי נושא בולטת ומתוקנת בקליק, מטלה בנושא הלא נכון נעלמת.

הפרופיל של נושא נבנה משמו, מתיאורו, ממילות המפתח — **ומהמטלות שכבר שויכו אליו**. כלומר הוא משתפר מעצמו: אחרי כמה מטלות על המנוע, "רעש מהמנוע" יגיע לנושא "רכב" בלי שהוגדרה מילת מפתח אחת.

עברית נכתבת עם מיליות מחוברות ("מהמנוע", "לשיפוצים"), ולכן ההשוואה נעשית על כל צורות הקיצור של המילה ולא על השורש — "מנוע", "המנוע" ו"מהמנוע" נפגשות בצורה משותפת.

**מודל — אופציונלי, בתשלום.** בהגדרות אפשר להזין מפתח Anthropic. אז מודל קורא את המטלה, מבין טקסט חופשי שאין לו מילות מפתח, ויודע **להציע נושא חדש** כשאף קיים לא מתאים; ההצעה מופיעה על הכרטיס כ‑💡 ולחיצה עליה יוצרת את הנושא ומושכת אליו את כל המטלות שקיבלו את אותה הצעה.

המודל לעולם אינו נקודת כשל: נפילת רשת, מכסה שנגמרה או מפתח שפג — הקטלוג ממשיך לפי מילות מפתח, והמטלה נשמרת בכל מקרה. הסיבה מוצגת למשתמש ולא נבלעת.

מה שרץ תוך כדי הקלדה (החיווי "ישויך ל…") הוא **תמיד** מילות מפתח בלבד. פנייה בתשלום קורית רק בהוספה בפועל, בקטלוג מרוכז, ובסידור עם המודל — כלומר רק בפעולה שהמשתמש יזם.

## סדר העבודה בתוך נושא

התור מושך לפי `seq`, והוא מחושב אוטומטית בכל הוספה:

1. **שלב** — תשתית לפני לוגיקה, לוגיקה לפני עיצוב, בדיקות ותיעוד בסוף.
2. **עדיפות** — דחוף מוקדם.
3. **תלות מפורשת** — `#12` בטקסט אומר "אחרי מטלה 12", ונאכף גם על סדר שהמודל הציע. מעגל תלות לא תוקע את הרשימה.

הסידור האוטומטי בהוספה משתמש בכללים בלבד (מיידי, בלי עלות). "סידור עם המודל" הוא כפתור נפרד בחלונית הנושא.

## מצבי מטלה

| מצב | פירוש |
| --- | --- |
| `open` | בתור, ממתינה שעובד ייקח |
| `in_progress` | עובד מחזיק בה כרגע (נעילה ל‑30 דק׳) |
| `blocked` | Claude שאל — **ממתין לכם** |
| `answered` | עניתם; חוזרת לתור לפני כל מטלה אחרת |
| `done` / `cancelled` | סגורה |

המעבר `blocked → answered` קורה מאליו כשאדם מגיב על מטלה חסומה. אין סטטוס לזכור לשנות ביד.

## הפעלה

1. להיכנס לכתובת. **המשתמש הראשון שנרשם הופך למנהל**, וההרשמה נסגרת אחריו.
2. מנהל מוסיף משתמשים נוספים בהגדרות.
3. הגדרות ← "חיבור Claude" ← **הצגה** — זה האסימון שמחבר סשן Claude או cron.

⚠️ מי שמחזיק באסימון יכול למשוך ולסגור מטלות. אל תשתפו אותו בצ׳אט פתוח.

## אחסון

SQLite בקובץ יחיד, `data/tasks.sqlite`. נבחר על פני MySQL כי אין פרטי התחברות לנהל — אבל בעיקר בגלל התור: משיכת מטלה רצה ב‑`BEGIN IMMEDIATE`, כך ששני עובדים לעולם לא יקבלו את אותה מטלה. נבדק ב‑12 משיכות מקבילות.

`data/` חסומה ב‑`.htaccess`: המסד מכיל את כל המטלות והמשתמשים, ו‑`config.json` את אסימון העובד **ואת מפתח ה‑API** (הרשאות 0600). הכול מוגש רק דרך `api.php`, והמפתח עצמו לעולם לא חוזר ב‑API — רק ארבע ספרות אחרונות. אפשר גם להחזיק אותו במשתנה סביבה `ANTHROPIC_API_KEY`, והוא יגבר על הקובץ.

## API

`POST api.php?action=<פעולה>`, גוף JSON. בני אדם מזוהים בעוגיית סשן; עובדים בכותרות `X-Worker-Token` ו‑`X-Worker-Name`.

**בני אדם:** `login` · `logout` · `me` · `bootstrap-status` · `register-first` · `create-user` · `worker-token` · `topics` · `create-topic` · `update-topic` · `tasks` · `task` · `create-task` · `update-task` · `add-note`

**קטלוג:** `classify` (תצוגה מקדימה, מילות מפתח בלבד) · `catalog-backlog` (מקטלג מה שנשאר ללא נושא) · `apply-hint` (הופך הצעת נושא לנושא) · `reorder-topic` · `ai-status` · `set-ai` · `test-ai`

**עובדים:** `claim` · `heartbeat` · `block` · `complete` · `release`

מחזור עובד טיפוסי:

```
claim      → מקבל מטלה + כל השיחה עליה
heartbeat  → מאריך נעילה במטלה ארוכה
block      → רושם שאלה, משחרר, וממשיך הלאה
complete   → סוגר עם תוצאה
```

התיעוד המלא של הלולאה נמצא ב‑skill `claude-tasks-worker`.

## תחזוקה

כל הנתיבים יחסיים, כך שהתיקייה עובדת מכל מיקום בשרת. נדרש PHP עם `pdo_sqlite` (קיים כברירת מחדל כמעט בכל אירוח).

הנעילה על מטלה פגה אחרי 30 דקות ומשתחררת מעצמה — עובד שקרס אינו נועל מטלה לנצח, ואין צורך ב‑cron שינקה.
