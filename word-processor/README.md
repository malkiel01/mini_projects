# עורך תמלילים (`word-processor/`)

עורך מסמכים כמו Word — עמודים אמיתיים על המסך, כותרות, רשימות, טבלאות, תמונות ומספור עמודים — שמשמש
גם **כאפליקציה** (מסמכים של משתמשי האפליקציה) וגם **כעורך מוטמע** באפליקציות אחרות (הצרכן הראשון: הצעות
תקציב). האפיון: `org-budget-proposals/docs/word-processor-request.md`. פרוטוקול ההטמעה (מחייב):
`platform/docs/embed.md`.

**מעקב מול האפיון — [`docs/roadmap.md`](docs/roadmap.md):** השלבים, מה בוצע ומה הבא. כל PR של העורך מעדכן אותו
(סטטוס הפריטים ששינה + שורה ביומן).

כתובת: https://mbe-plus.com/mini_projects/word-processor/

## מה עובד (שלב 1)

### העורך
- **מנוע:** TipTap 3.31.3 / ProseMirror (MIT בלבד), מועתק ל-`vendor/` (לא CDN). העימוד, מספור העמודים,
  התמונות והרשימות העבריות — קוד שלנו ב-`assets/js/`.
- **עמודים אמיתיים** A4 / Letter, לאורך / לרוחב, שוליים במ"מ, **שבירה חיה** תוך כדי הקלדה
  (`pagination.js`): פסקה נשברת בין שורות (לפחות 2 שורות בכל צד), כותרת לא נשארת לבד בתחתית, פריט רשימה
  עובר עם התבליט שלו, מעבר עמוד ידני (Ctrl+Enter), ומעבר טור ידני (Ctrl+Shift+Enter; בטור אחד — כמו מעבר עמוד).
- **זום:** ברירת מחדל מותאמת למסך, − / + / ⤢.
- **מימין לשמאל** כברירת מחדל; פסקה משמאל לימין לפי בחירה (¶).
- **סגנונות:** רגיל, כותרת מסמך, כותרת 1–3 — כל אחד ניתן לעריכה (🅰: גופן, גודל, מודגש/נטוי/קו תחתון, צבע,
  יישור, ריווח לפני/אחרי, ריווח שורות לרגיל).
- **תווים:** גופנים עם עברית (David, Frank Ruehl, Arial, Narkisim, Miriam ועוד — עם גיבוי חופשי מקומי:
  David Libre, Frank Ruhl Libre, Miriam Libre, Heebo, Assistant…), גודל, מודגש, נטוי, קו תחתון, קו חוצה,
  צבע טקסט, הדגשה, עילי ותחתי, ניקוי עיצוב.
- **פסקה:** יישור (ימין/מרכז/שמאל/מיושר), הזחה, ריווח שורות (1 / 1.15 / 1.5 / 2 / מדויק), ריווח לפני ואחרי.
- **שבירת עמודים** (חלון הפסקה, כמו "שורות ומעברי עמוד" ב-Word): **שמירה עם הבא** (`keepNext` — לא נשארת לבד בתחתית
  העמוד), **שמירת שורות יחד** (`keepLines` — לא נחצית; רק כשכל הפסקה נכנסת בעמוד), **מעבר עמוד לפני** (`breakBefore`).
  זהה בעורך (`pagination.js`), בהדפסה וב-PDF (`lib/pdf/layout.php`); Word הלוך וחזור (`w:keepNext` / `w:keepLines` /
  `w:pageBreakBefore`); ב-HTML — `break-after` / `break-inside` / `break-before`. כשהמעבר נופל באמצע פסקה — עדיין לפחות
  2 שורות שלה בכל צד. כל "אישור" בחלון — צעד ביטול משלו.
- **רשימות:** תבליטים, ממוספרות `1.` / `א.` / `i.`, רב-רמות (Tab / Shift+Tab).
- **טבלאות:** הוספה, שורות ועמודות, מיזוג/פיצול תאים, שורת כותרת, מילוי תא, שינוי רוחב עמודות.
  **מאפייני טבלה** (⚙ בלשונית "טבלה"): **גבולות** — כולם / מסגרת בלבד / פנימיים בלבד / ללא, ו**צבע** (`borders`,
  `borderColor` — הגבול תמיד ברוחב 1px; כבוי — שקוף, ובמסך קו עדין; כך הגובה לא משתנה); **רוחב** באחוזים מהשורה
  ו**יישור** ימין / מרכז / שמאל (`width`, `align` — רוחבי העמודות מותאמים באותו יחס); **יישור אנכי בתא** (`valign`);
  **גובה שורה מינימלי** בנקודות (`tableRow.height`). זהה בעורך, בהדפסה וב-PDF; Word הלוך וחזור (`w:tblBorders`, `w:jc`,
  `w:vAlign`, `w:trHeight`); HTML. אישור — צעד ביטול אחד. **סגנונות טבלה** (🎨 בלשונית "טבלה" — רגיל, רשת כחולה, פסים כחולים / ירוקים / כתומים,
  אפור עדין, בלי קווים): גבולות וצבע, מילוי לשורה הראשונה ופסים לסירוגין — נכתבים כעיצוב רגיל של הטבלה והתאים, ולכן זהים
  בכל מקום (`TABLE_STYLES` ב-editor.js).
- **תמונות:** העלאה, הדבקה, גרירה; שינוי גודל בגרירת הפינה או ¼ / ½ / מלא / מקורי; **גלישת טקסט כמו ב-Word:**
  בשורה עם הטקסט · ריבוע · צמוד (סביב מלבן התמונה, במרחק קטן) · מעל ומתחת · מאחורי הטקסט · לפני הטקסט (בשני
  האחרונים — גוררים את התמונה למקום); יישור ימין/מרכז/שמאל; **מרחק מהטקסט**; **כיתוב** מתחת לתמונה; **גודל מדויק בס"מ** (⚙ — עם נעילת יחס, של מה שרואים אחרי חיתוך וסיבוב) ו**מיקום מדויק** לתמונה מאחורי / לפני הטקסט; **שכבות** — ⬒ הבאה לחזית / ⬓ שליחה לרקע (`z`; בעורך z-index, ב-PDF סדר הציור, ב-Word `relativeHeight`); **חיתוך**
  (✂, ארבעה צדדים, המקור נשמר); **סיבוב** ⟲ ⟳ ברבעים. (שלב 2)
- **ריווח בין תווים** (צפוף / רגיל / מרווח, על הטקסט המסומן) ו**העתקת עיצוב** 🖌 (לחיצה — פעם אחת; לחיצה כפולה — עד
  Esc; לחיצה בתוך מילה — המילה כולה). (שלב 2)
- **רקע הדף** (הגדרות עמוד ← רקע הדף, לכל המסמך): **צבע עמוד** (`page.page_color` — כל הדף כולל השוליים; בהדפסה —
  רקע של `@page`; ב-Word `w:background`) ו**סימן מים** (`page.watermark` — טקסט אפור באלכסון מאחורי הטקסט, גודל לפי האורך
  — `watermark_size` / `watermarkSize`; בהדפסה — אלמנט `fixed` שמודפס בכל עמוד; ב-Word צורת WordArt בכותרת, כמו ש-Word
  שומר "סימן מים מותאם", ונקלט בחזרה). לא משנה את העימוד ולא נכנס לטקסט של ה-PDF. ב-HTML — טרם.
- **מספור עמודים:** למעלה/למטה × ימין/מרכז/שמאל; `1` · `עמ' 1` · `1 מתוך 12` · `- 1 -` · `א, ב, ג`; מתחיל
  ממספר נבחר; בלי מספר בעמוד הראשון; כותרת עליונה ותחתונה (טקסט חופשי). 📄
- **ביטול / ביצוע**, **הדבקה מ-Word** עם העיצוב (כולל רשימות של Word שהופכות לרשימות אמיתיות).
- **PDF מהשרת** (📕 הורדה כ-PDF, ו-`doc_export format:"pdf"`) — מנוע משלנו ב-`lib/pdf/`, MIT, בלי ספרייה חיצונית
  ובלי דפדפן: גופנים מוטמעים (אותם גופנים חופשיים שהעורך מציג — `vendor/fonts/pdf/*.woff`), עברית מימין לשמאל עם
  מספרים ואנגלית בסדר הנכון (bidi), שבירת שורות ויישור לשני הצדדים, **אותה שבירת עמודים כמו בעורך**, כותרת עליונה
  ותחתונה ומספור עמודים בכל התבניות, סגנונות, רשימות, טבלאות (נשברות בין שורות, שורת הכותרת חוזרת) ותמונות
  (כל הגלישות, חיתוך, סיבוב, כיתוב). הטקסט ניתן לחיפוש ולהעתקה (ToUnicode). (שלב 2)
- **הדפסה** מהדפדפן — אותם עמודים כמו על המסך, מספרי העמודים בשולי הדף.

### האפליקציה (`index.html`)
- רשימת המסמכים של המשתמש, חיפוש, מסמך חדש, **ייבוא מ-Word**, שינוי שם, שכפול, מחיקה, הורדה כ-Word / טקסט /
  גיבוי JSON.
- **דוח ייבוא:** אחרי ייבוא מ-Word נפתח "דוח ייבוא" — מה לא עבר בדיוק (צורות ותיבות טקסט, נוסחאות,
  טבלה בתוך טבלה, שינויי עיצוב במעקב, שדות, טורים, כותרת שונה לעמוד ראשון/זוגי, סגנונות מותאמים,
  גבולות פסקה, הזחת שורה ראשונה, גופנים חסרים). מסמך שעבר כולו — הודעה קצרה בלבד. `IMPORT_REPORT` ב-`lib/import.php`.
  כותרת עליונה ותחתונה (טקסט), מספר העמוד (מיקום, יישור, תבנית, התחלה, בלי מספר בעמוד הראשון) והזחה — מיובאים.
- **גופן מוחלף:** גופן שאינו ברשימה (למשל מ-Word) מוצג ב-Heebo — במסך, בהדפסה וב-PDF, בכל מחשב; השם המקורי נשמר
  (וחוזר לייצוא ל-Word). בתיבת הגופן "(מוחלף)", ובשורת המצב "⚠ גופן מוחלף: X ← Heebo".
- **סל מחזור** (`#/trash`): מחיקה מהאפליקציה מעבירה לסל (`docs.deleted_at`) — "ביטול" בהודעה, או שחזור מהסל; אחרי
  30 יום (`TRASH_DAYS`) נמחק לצמיתות, או קודם — "מחיקה לצמיתות". מסמך בסל לא נפתח, לא נשמר ולא מיוצא (`doc_find`).
  פעולות: `my_delete` (לסל), `my_trash`, `my_restore`, `my_purge`. **בהטמעה** `doc_delete` נשאר מחיקה לצמיתות — זה
  פרוטוקול ההטמעה, ושינוי בו עובר דרך צ'אט הפלטפורמה. מסד קיים מוסב לבד (גרסת מסד 2).
- **משתמשים משלה** (`data/word-processor.sqlite`, טבלה `accounts`): מחוברת — `$_SERVER['PLATFORM_USER']`,
  חשבון נפתח מיד ומקושר ל-`sub` (איחוד לפי מייל); מנותקת — "כניסה עם הכלים הדיגיטליים" (`sso.php`, עוגייה
  משלנו `wp_session`). **החשבון הראשון שנפתח — מנהל העורך.**
- **אין מסך חיבור חשבונות** ("יש לי כבר חשבון", `docs/auth.md` סעיף 4) ואין סיסמה משלה: האפליקציה חדשה ואין בה
  משתמשים ישנים — כל חשבון נולד מקושר לחשבון הפלטפורמה.
- **שמירה אמינה** (`assets/js/saver.js`, משותף לאפליקציה ולהטמעה): כל שינוי נכתב מיד לטיוטה בדפדפן (IndexedDB),
  ולשרת אחרי 1.5 שניות. מצבים בכותרת: נשמר / לא נשמר / שומר / מנותק (ניסיון חוזר לבד) / התנגשות / קריאה בלבד.
  ייצוא, שכפול ויציאה **מחכים לשמירה**; נכשלה — עוצרים ושואלים (לנסות שוב / להוריד עותק / לצאת בכל זאת).
  טיוטה שנשארה (לשונית נסגרה, ניתוק) — מוצעת לשחזור בפתיחה הבאה. סגירת לשונית משחררת את הנעילה.
- **הגדרות העמוד והסגנונות בתוך המסמך** (`attrs.page` בצומת השורש): נשמרים עם התוכן **באותה גרסה**, ו-Ctrl+Z
  מבטל גם אותם. במסד הם בעמודה `page` כמו קודם — השרת מוציא אותם מה-JSON בשמירה ומחזיר בטעינה. `my_page` /
  `embed_page` נשארו לתאימות.
- **גרסת מבנה** (`attrs.schema`, היום 5; מה נוסף בכל גרסה — `SCHEMA_VERSION` ב-`extensions.js`, ומה כל מסמך צריך — `doc_schema_need`): `doc_migrate` בשרת ו-`assets/js/schema.js` ממירים מסמך ישן; מסמך ממבנה
  חדש מהקוד — נדחה (`schema_newer`), כדי שלשונית ישנה לא תשמור מבנה שהיא לא מבינה.
- **רישום פקודות** (`assets/js/commands.js`): כל פקודה פעם אחת — מזהה, שם, סמל, קיצור, קבוצה, פעולה ומצב
  (פעיל / זמין / ערך). הסרט, לשוניות ההקשר וחיפוש הפקודות נבנים ממנו; `ed.commands.run('bold')`. תפריט לחיצה ימנית
  וקיצורים להגדרה — ייבנו ממנו.
- **הסרט (Ribbon), כמו ב-Word:** לשוניות בית / הוספה / פריסה / תצוגה, בכל אחת קבוצות עם שם (גופן, פסקה, סגנונות…);
  לשונית הקשר "טבלה" כשהסמן בטבלה ו"תמונה" כשתמונה נבחרה (תמונה — נפתחת לבד, ובסוף חוזרים ללשונית הקודמת).
  ביטול/חזרה תמיד גלויים. כיווץ — ⌃ או Ctrl+F1; חצים בין הלשוניות ובין הפקדים. הלשונית והכיווץ נשמרים (localStorage).
  **שורת מצב:** עמוד X מתוך Y (לפי הסמן), מספר מילים, זום.
- **חיפוש פקודות ("מה ברצונך לעשות?", Alt+Q):** תיבה בראש הסרט; מחפשת בשם, בקבוצה ובקיצור, בלי תלות בניקוד.
  זמינות קודם; Enter מפעיל, וחצים בין התוצאות. פקודה שצריכה ערך (גופן, גודל, צבע) — מעבירה לפקד שלה בסרט.
- **תוכן עניינים** (`assets/js/toc.js`; הוספה ← תוכן עניינים): בלוק עם הכותרות עד רמה 3 ומספרי העמודים לפי העימוד, נקודות
  ומספר בקצה השורה; לחיצה על שורה — מעבר לכותרת. כמו ב-Word לא מתעדכן לבד — 🔄 "עדכון תוכן עניינים" (צעד ביטול אחד; עוד
  סבב אחרי שהעימוד זז). גובה: גופן × 1.6 לשורה — זהה ב-PDF (`toc()`); רשומה ארוכה **נשברת** לשורה הבאה (לא נחתכת — ביקורת 04), ומספר
  העמוד והנקודות — בשורה האחרונה שלה. Word: sdt
  "Table of Contents" עם שדה `TOC \o "1-3"` והשורות כתוצאה (אפשר "לעדכן שדה" ב-Word), ובחזרה; HTML — רשימה. תוכן
  עניינים ארוך מעמוד — לא נשבר (טרם).
- **תצוגה** (`assets/js/view.js`, לשונית "תצוגה" ← הצגה): 🔢 **ספירת מילים** (Ctrl+Shift+G, או לחיצה על מספר המילים
  בשורת המצב) — עמודים, מילים, תווים עם רווחים ובלי, פסקאות; במסמך ובבחירה (הערות השוליים לא נספרות, כמו ב-Word).
  🧭 **חלונית ניווט** — הכותרות של המסמך לפי הרמה; לחיצה — מעבר; הכותרת שבה הסמן מסומנת; בטלפון — מגירה מעל הדף.
  ¶ **סימני פסקה** (Ctrl+Shift+8) — ¶ בסוף פסקה, · לרווח, → לטאב; קישוטים בלי רוחב (לא משנים שבירה ועמודים), לא נשמרים
  ולא מודפסים. 📋 **אפשרויות הדבקה** — אחרי הדבקה עם עיצוב, כפתור ליד הטקסט: שמירת העיצוב / מיזוג עיצוב (בלי גופן,
  גודל, צבע והדגשת צבע — מודגש, נטוי וקישורים נשארים) / טקסט בלבד; נעלם בהקלדה או ב-Esc.
- **טיפוגרפיה:** A+ / A− (Ctrl+Shift+> / <) — לגודל הבא ברשימה, לפי הגודל של כל קטע (או של הסגנון); **סוג קו תחתון**
  (`underline.attrs.ul`: כפול, מנוקד, מקווקו, גלי, עבה — ב-PDF מצוירים, ב-Word `w:u`); **שורה ראשונה / תלויה** בחלון הפסקה
  (`firstLine` בנקודות, שלילי = תלויה: `text-indent` + `padding`; ב-PDF השורה הראשונה / השאר זזות; ב-Word `firstLine` /
  `hanging`). **טאב:** Tab באמצע הטקסט — תו טאב (בתחילת פסקה — הזחה); עצירות כל 36 נק' (`tab-size`, וב-PDF `TAB_STOP`;
  טאב שלא נכנס "תלוי" בסוף השורה כמו בדפדפן). **עצירות טאב מותאמות** (חלון הפסקה, `attrs.tabs`, `assets/js/tabs.js`):
  מיקום בס"מ מהשוליים בצד ההתחלה (לא מההזחה, כמו ב-Word), יישור לתחילה / לסוף / למרכז / לנקודה העשרונית, מוביל
  נקודות / מקפים / קו. בעורך כל טאב בפסקה כזו נמדד במקום; ב-PDF — `tabStop` ב-`lib/pdf/layout.php`, אותו חישוב;
  Word — `w:tabs` (בפסקה מימין לשמאל left / right הפוכים). אחרי העצירה האחרונה — כל 36 נק'. ב-HTML — עדיין אחידות.
- **מספור** (בית ← פסקה): ↺ התחלה מחדש ב-1, ⤵ המשך מספור (`cont` — אחרי הרשימה הממוספרת הקודמת באותו הורה; התוסף
  `listContinue` מעדכן את `start` אחרי כל שינוי, ולכן ה-PDF, Word וה-HTML מקבלים אותו מספר), # קביעת ערך. **1.1.1** — סוג
  רשימה `multi`: גם הרשימות הממוספרות שבתוכה מוצגות כך (מוני CSS `wpl`; ב-PDF — המסלול; ב-Word — הגדרה רב-רמתית
  `%1.%2.` אחת לכל הרמות). § **מספור כותרות** (`page.heading_numbers`): "1. " / "1.1 " / "1.1.1 " לפני הטקסט — בעורך מוני
  CSS, ב-PDF `heading_numbers()` (אותה מחרוזת), ב-Word מספור מקושר לסגנונות Heading. **ייבוא:** start / startOverride,
  רב-רמתי, אותו numId ברשימה נוספת = המשך מספור, וסגנון כותרת עם מספור = מספור כותרות.
- **סגנונות** (בית ← סגנונות): גלריה — כל כפתור נראה כמו הסגנון; הרשימה — כל הסגנונות, גם כותרות 4–9 (7–9 אינן תגיות
  HTML — `<h7>` עם `display:block`, וב-HTML המיוצא `p.wp-h7` עם `role="heading"`). ✚ **סגנון חדש מהבחירה** — שם, ועיצוב
  הפסקה (הסגנון שלה + העיצוב הישיר של תחילתה); הפסקה עוברת אליו. ⟲ **עדכון הסגנון לפי הבחירה** — כמו ב-Word, כל הפסקאות
  בסגנון משתנות. העיצוב הישיר שנכנס לסגנון יורד מהפסקה (רק אם הוא על כולה), והכול — ביטול אחד. סגנון של משתמש = `u<N>`
  ב-`page.styles` עם `name` (מעל "רגיל"); "עריכת סגנונות" — גם שינוי שם ומחיקה (הפסקאות חוזרות ל"רגיל"). **Word:** Heading1–9,
  `User<N>` בשם שלו; בייבוא סגנונות פסקה מותאמים נקלטים כסגנונות (רק סגנונות תו — בדוח הייבוא). **PDF:** אותו עימוד
  (באוסף — `styles`).
- **קישורים וסימניות** (הוספה ← קישורים): 🔗 / Ctrl+K — טקסט לתצוגה וכתובת (אתר, דוא"ל — `mailto:` ו-`https://`
  נוספים לבד) או סימניה במסמך; בתוך קישור — עריכה של כולו ו"הסרת הקישור". כתובת שהוקלדה (`https://…`, `www…`) ואחריה
  רווח — קישור. Ctrl+לחיצה פותחת (בקריאה בלבד — לחיצה); קישור "#שם" קופץ לסימניה. רק http(s) / mailto / tel / "#"
  (`safeHref` / `safe_href`) — `javascript:` לא נכנס. 🔖 סימניה: שם כמו ב-Word (אות בהתחלה, בלי רווחים), רשימה עם
  מעבר ומחיקה. **Word:** `w:hyperlink` (קשר External / `w:anchor`), סגנון Hyperlink, `bookmarkStart/End`; בייבוא גם
  שדה `HYPERLINK` (ובלי `_GoBack`). **PDF:** כחול עם קו תחתון, ולחיץ — כתובת נפתחת, "#שם" קופץ לסימניה; גם שורות תוכן העניינים ורשימת האיורים לחיצות. גרסת המבנה עלתה ל-2.
- **חיפוש והחלפה** (`assets/js/find.js`; 🔎 / Ctrl+F, ⇄ / Ctrl+H): פס מתחת לסרט; כל ההתאמות מסומנות, "3 מתוך 12",
  Enter / Shift+Enter — הבא / הקודם, מתחיל מהסמן. אפשרויות (⚙): התאמת רישיות, מילים שלמות, התעלמות מניקוד (ברירת
  מחדל — "שלום" מוצא "שָׁלוֹם"), ביטוי רגולרי ($1 בהחלפה). מחפש גם מעבר לגבולות עיצוב ובתוך טבלאות; "החלף הכול" —
  עסקה אחת, Ctrl+Z אחד. גם בתוך הערות שוליים וסיום: ההתאמה מסומנת על הסימן ("2 מתוך 5 · בהערת שוליים"), והחלפה
  משנה את טקסט ההערה עם העיצוב שלה.
- **תצוגה מקדימה להדפסה** (תצוגה ← תצוגה מקדימה): העמודים בלבד, בלי סרט ובלי עריכה; "הדפסה" או "חזרה לעריכה" / Escape.
- **שמירה ידנית** (💾 או Ctrl+S): שומרת מיד, בלי לחכות לשמירה האוטומטית; במסמך מוטמע — `save()` של ההטמעה.
- **טלפון (עד 700px):** שורת פעולות קבועה בתחתית (ביטול, מודגש, נטוי, קו תחתון, תבליטים, יישור — כל לחיצה ליישור הבא,
  ו"כלים"). "כלים" פותח את הסרט עצמו כגיליון מלמטה — אותן לשוניות וקבוצות, בשורות שנשברות, אזורי לחיצה 44px, בלי
  גלילה הצידה; בטבלה / תמונה — ישר בלשונית ההקשר. כשהמקלדת פתוחה (`visualViewport`) השורה והגיליון עולים מעליה,
  והגלילה אל הסמן משאירה מרווח מעל השורה (`scrollMargin`).
- **טבלה שעוברת בין עמודים** (אב-טיפוס, שלב 0): העימוד שובר בין שורות, ושורת הכותרת (שורה ראשונה שכולה כותרות)
  חוזרת בראש כל עמוד — עותק לקריאה בלבד, גם על המסך וגם בהדפסה, כמו ב-Word וב-PDF. שורת הכותרת לא נשארת לבד בתחתית.
- **מקטעים** (אב-טיפוס, שלב 0): צומת `sectionBreak` (מעבר מקטע — עמוד הבא) עם `attrs.page` — רק מה שמשתנה לעומת המקטע
  הקודם. כל עמוד בגודל ובכיוון של המקטע שלו, ממורכז ברוחב הגיליון; הטקסט של כל מקטע ברוחב העמוד שלו (גבולות
  שקופים לכל בלוק — לא נוגעים בהזחה); בהדפסה — עמוד בשם משלו (`@page wpsN`). כפתור ⧉ — העמוד הבא בכיוון ההפוך.
  **Word:** כל מקטע מסתיים בפסקה עם `sectPr` משלו (גודל, כיוון, שוליים, כותרות; המספור נמשך), והייבוא מ-Word
  בונה מהם שוב מעברי מקטע. **PDF מהשרת:** כל מקטע נפרס ומעומד בגיאומטריה שלו. **חלון הגדרות העמוד** פועל על המקטע שבו הסמן:
  גודל, כיוון, שוליים וכותרות — "המקטע הזה" או "כל המסמך" (הגופן והמספור — תמיד לכל המסמך). כל מעבר מקטע נכתב
  מחדש עם כל ההגדרות שלו, כדי ששינוי במקטע אחד לא יזלוג לבאים; הכול טרנזקציה אחת (ביטול אחד). בהדפסה — כותרות
  לכל מקטע.
- **הערות שוליים** (אב-טיפוס, שלב 0): צומת `footnote` בתוך הטקסט (הטקסט ב-`attrs.text`), ממוספר לבד לפי הסדר. ההערה
  בתחתית העמוד שבו הסימן: העימוד שומר לה מקום (שורה עם הערה עוברת עמוד יחד איתה), והאזור יושב לפני מעבר העמוד —
  לכן גם בהדפסה. הוספה: ¹ או Ctrl+Alt+F; עריכה — לחיצה על הסימן או על ההערה; טקסט ריק — מחיקה.
  **Word:** הערות שוליים אמיתיות (`word/footnotes.xml`, סגנונות footnote text / footnote reference), וגם בייבוא;
  בגוף לשילוב (ooxml) — הטקסט בסוגריים בכתב עילי. **PDF מהשרת:** ההערה בתחתית העמוד, והעימוד שומר לה מקום.
  **הערה ארוכה** שלא נכנסת כולה בתחתית העמוד נמשכת לעמוד הבא, כמו ב-Word: השורה עם הסימן נשארת, השורות של
  ההערה שנכנסות — בעמוד שלה, והשאר בראש אזור ההערות של העמוד הבא (בלי מספר). בעורך — חלון בגובה החלק
  (`.wp-fn-part`), ב-PDF — חלק מהשורות (`part` ב-`footnote()`). ב-Word — Word ממשיך לבד. **עיצוב בתוך ההערה:** מודגש, נטוי, קו תחתון, קו חוצה, עילי
  ותחתי — בעורך קטן בחלון ההערה. `attrs.content` (צמתי text עם marks), ו-`attrs.text` נשאר הטקסט הפשוט (חיפוש,
  תאימות). בשרת — `fn_inline()` (`lib/footnote.php`) משותפת ל-Word, לייבוא מ-Word ול-PDF.
- **הערות סיום** (שלב 4; הוספה ← הערות, או Ctrl+Alt+D): אותו צומת `footnote` עם `attrs.end = true`. הסימן ממוספר
  בספרות רומיות (i, ii…) במונה נפרד, וההערות מרוכזות **בסוף המסמך** אחרי הטקסט האחרון (קו מפריד ואז ההערות), לא
  בתחתית העמוד. בעורך — ווידג'טים בסוף המסמך (`Endnotes` ב-`pagination.js`), שכל אחד יחידה לעימוד, כך שהערות רבות
  נמשכות לעמוד הבא; עריכה — לחיצה על ההערה. **PDF:** `endnoteItems()` ב-`layout.php` — אחרי הבלוק האחרון. **Word:**
  `word/endnotes.xml` (סגנונות endnote text / endnote reference, `numFmt lowerRoman`), וגם בייבוא.
- **הערות** (שלב 4; סקירה ← הערה חדשה, Ctrl+Alt+M — כמו Comments ב-Word): הטווח מסומן בצהוב (סימון `comment` עם
  `attrs.id`; כמה הערות יכולות לחפוף), והשרשורים — ב-`attrs.comments` של המסמך: מחבר (שם המשתמש), תאריך, טקסט,
  תשובות ו"נפתר". חלונית "הערות" בצד: תשובה, ✓ נפתר / פתיחה מחדש (הצבע יורד מהטקסט), מחיקה; לחיצה על הטקסט —
  השרשור מסומן, לחיצה על השרשור — מעבר לטקסט. כל פעולה — צעד ביטול. הערה שהטקסט שלה נמחק כולו — לא מוצגת ולא
  מיוצאת. בהדפסה וב-PDF — בלי סימון. **Word:** `comments.xml` + `commentsExtended.xml` (תשובות — `paraIdParent`,
  נפתר — `done`), טווח שחוצה פסקאות — כמו ב-Word; וגם בייבוא (`comments.js`, ובשרת `commentRanges()` / `readComments()`).
- **מעבר מקטע — תמיד ברמה העליונה** (ביקורת 04, R01 / R02): מתוך רשימה או טבלה הוא נכנס אחרי כולה; מעבר שכבר נמצא
  בפנים (מסמך ישן, הדבקה) יוצא החוצה בפתיחה ובכל שינוי (`wpSectionTop`), ובשרת — `sections_top()` לפני PDF / Word / HTML.
  העימוד קובע את המקטע של כל עמוד לפי המיקום — אותו כלל כמו רוחב הבלוקים (`secOf` ב-`pagination.js`), כך שהעמוד
  שמצויר והרוחב של הטקסט עליו לא יכולים להתפצל. **שער גבולות** (`tests/e2e/lib/bounds.mjs`, קבוצה 45): כל מילה
  בתוך אזור התוכן של העמוד שלה ולא חתוכה, וסימוני המעבר ברוחב העמוד — על כל מסמכי האוסף ורצף פעולות.
- **הקשחה (ביקורת 04):** תצוגה מקדימה — העריכה בפועל היא `canEdit && !previewing` (הרשאה שבוטלה בזמן התצוגה לא
  חוזרת), ובלי סימני עריכה (¶, חיפוש, הערות, חלוניות). חיפוש רגולרי — `find-core.js`: התאמה ריקה מתקדמת בנקודת
  קוד שלמה, ותקציב התאמות / זמן; בפס החיפוש ביטוי נבדק קודם ב-`find-worker.js` שנעצר אחרי 1.5 שנ' — ביטוי איטי
  מבוטל עם הודעה ולא מקפיא. `root.wordEditor` — העטיפה (setEditable וכו'), לבדיקות.
- **שמירה — הקשחה (ביקורות 03 / 04):** טיוטה במכשיר נכתבת אחרי 250 מ"ש שקט ולכל המאוחר אחרי שנייה, גם ביציאה
  (`destroy`), עם תוצאה; כשל (אחסון חסום / מלא) — חיווי והורדת עותק, ובלי "שמור במכשיר" כשלא. `flushUntilClean` —
  שומר עד שהמסמך נקי. התנגשות → טעינה מחדש: העותק המקומי נשמר בנפרד (`draftKey:conflict`) עד החלטה. שחזור גרסה —
  בשרת (`doc_restore_version`): המצב שלפני והמשוחזר — שתי גרסאות שלא מתאחדות (עמודת `kind` בטבלת הגרסאות).
- **מעקב שינויים** (שלב 4; סקירה ← מעקב שינויים, Ctrl+Shift+E — כמו Track Changes ב-Word): כשהמעקב פועל
  (`attrs.track` של המסמך — נשמר איתו) כל הקלדה מסומנת `ins` וכל מחיקה — `del` (הטקסט נשאר, בקו חוצה), עם מחבר
  ותאריך, בצבע של המחבר. Backspace / Delete במעקב — שלנו: מסמנים במקום למחוק, ומחיקה של תוספת — מוחקת באמת; איחוד
  פסקאות ושינויי עיצוב — לא נרשמים (עדיין). אישור / דחייה של השינוי שבו הסמן (או של הבחירה), אישור / דחיית הכול,
  הקודם / הבא. בהדפסה וב-PDF — כמו בעורך; בטקסט ובגוף לשילוב — אחרי קבלת השינויים (`lib/track.php`).
  **Word:** `w:ins` / `w:del` (`w:delText`) עם מחבר ותאריך, ו-`trackRevisions`; וגם בייבוא (`track.js`).
- **כיתובים והפניות צולבות** (שלב 4; הוספה ← כיתובים): "הוספת כיתוב" מוסיף פסקה בסגנון **כיתוב** (9 נק', נטוי) —
  התווית (איור / טבלה / משוואה), המספר והטקסט — מתחת לפריט שבו הסמן או מעליו (בטבלה — מעליה). המספר הוא צומת `seq`
  (`attrs.label`, `attrs.id`) והוא מחושב לפי הסדר, לכל תווית בנפרד; "הפניה צולבת" — צומת `xref` (`target`, `show`:
  "איור 2" או "2"). המספרים לא נשמרים: מחיקה או הוספה של כיתוב באמצע מעדכנת מיד את כל המספרים וההפניות (`caption.js`,
  ובשרת `lib/caption.php`); הפניה לכיתוב שנמחק — "שגיאה! מקור ההפניה לא נמצא." כמו ב-Word. Ctrl+לחיצה — מעבר לכיתוב.
  **Word:** שדה `SEQ` בתוך סימניה נסתרת `_Ref<id>`, ושדה `REF … \h` (התווית — טקסט לפניו), וגם בייבוא — כולל
  כיתובים שנוצרו ב-Word עצמו (הסימניה עוטפת "Figure 1"). **PDF / HTML / טקסט:** המספרים כטקסט.
  **רשימת איורים** (כיתובים ← רשימת איורים): אותו בלוק של תוכן עניינים עם `attrs.seq` (התווית) — השורות הן הכיתובים
  עם התווית ומספרי העמודים, והכותרת "רשימת איורים / טבלאות / משוואות"; מתעדכנת ב"עדכון תוכן עניינים". ב-Word —
  שדה `TOC \c "איור"` (בתוך אותו sdt, כדי שהייבוא יזהה אותה).
- מונה עמודים בכותרת. **נעילה** ("פתוח לעריכה אצל X", 2 דקות בלי דופק), **גרסאות** (🕘 — כל שמירה,
  מאוחדות לאחת לכל משתמש בכל 10 דקות, עד 100; שחזור יוצר גרסה חדשה).
- **🔗 לקוחות הטמעה** (מנהל בלבד): רשימת האפליקציות הרשומות, אישור לקוח ממתין, כיבוי.

### מדריך ההתממשקות — לאפליקציה שרוצה את העורך
**`word-processor/docs/integration.md`** — כל מה שאפליקציה מארחת צריכה, צעד אחרי צעד, עם שני חלקים מוכנים:
- `client/WordProcessorClient.php` — **מעתיקים** לתיקיית האפליקציה: מפתחות (במסד שלה), רישום, חתימה, וכל `doc_*`.
- `assets/js/host.js` — נטען מהעורך בדף של המארחת: ה-iframe, בדיקת המקור, `expired`, גובה אוטומטי, `save()` לפני סגירה.

נבדק מקצה לקצה במארחת שנבנתה לפי המדריך בלבד, ממקור אחר: רישום → ממתין → אישור ב-🔗, עריכה, שמירה, מצב קטע,
רענון ה-iframe (expired), ייצוא text/pdf, יצירה/העתקה/מחיקה/רשימה.

### ההטמעה — `platform/docs/embed.md` כפי שהוא
- **רישום** `client_register` (פרק 1): המפתח מורד מ-`key_url`. פעיל מיד רק כש-`key_url` באותו מקור כמו העורך
  **ובתיקייה של הלקוח עצמו** (`/mini_projects/<client>/…`) — כך אפליקציה אחרת באותו דומיין לא יכולה להירשם בשם
  אחרת. אחרת — ממתין לאישור (🔗). שינוי `key_url`/`origins` — שוב לפי אותו כלל.
- **חתימה** Ed25519 על כל קריאה שרת-לשרת (פרק 2): ±300 שניות, nonce ל-10 דקות, הורדה מחדש של המפתח פעם אחת
  כשחתימה נכשלת (החלפת מפתח), שגיאות `bad_signature|stale|replay|unknown_client|pending`.
- **ה-API** (פרק 3): `embed_session`, `doc_create` (כולל `import`), `doc_copy` (עם `replace`), `doc_get`,
  `doc_export` (`html` / `ooxml` / `docx` / `pdf` / `text` / `json`, וגם `version`), `doc_import` (`lines` / `docx` / `html`),
  `doc_delete`, `doc_list`. לקוח רואה רק את המרחב שלו — מסמך של אחר = 404.
- **ה-iframe** (פרק 4): `embed.php?t=` עם `frame-ancestors` של הלקוח בלבד ו-`no-referrer`; הטוקן חד-פעמי, 60
  שניות, נמחק מהכתובת; הסשן בזיכרון בלבד (`Authorization: Bearer`, וגם `X-Embed-Session` למקרה שהשרת מוריד את
  Authorization), 8 שעות מתחדשות; נעילה; שמירה עם הגרסה (409 → `error {code:"conflict"}`).
- **אירועי postMessage** (פרק 6): `ready`, `change`, `saved`, `height`, `page`, `lock`, `expired`, `close`, `error`;
  ומהמארחת: `save`, `set_page`, `readonly`, `focus` — רק מ-`return_origin` ומהחלון המארח.
- **מצב קטע** (`mode:"section"`): `page` מ-`embed_session` נכנס למסמך; שינוי בעורך → אירוע `page` ונשמר
  (`doc_get` מחזיר).

### פרטים למארחת (הצעות תקציב)
- **בקשות שרת-לשרת לשרת הזה** — לשלוח גם `Cookie: humans_21909=1` (השרת מציג לפעמים אתגר JS ללקוח שאינו דפדפן;
  כמו `recipes-heartbeat.yml`). העורך שולח אותה כשהוא מוריד את `key_url`.
- **`ooxml`:** סגנונות בקידומת `wp` (`wpNormal`, `wpTitle`, `wpHeading1`…), מספורים מ-9001, קשרי תמונות
  `wpImg1…` ל-`media/wp_<n>.<ext>` — כדי לא להתנגש בשל המארחת. `numbering` = כל ה-`<w:abstractNum>` ואחריהם כל
  ה-`<w:num>`; ובנוסף `numbering_parts: {abstract, num}` — להכנסה נפרדת (Word דורש את כל ה-abstractNum לפני
  ה-num). `namespaces` — ה-xmlns שהגוף משתמש בהם.
- **`doc_import lines`:** כל שורה לא ריקה — פסקה (כמו שתכנית העבודה מוצגת היום, `plan_blocks`); `# ` כותרת 1,
  `## ` כותרת 2, `- ` תבליט. **האות של הפרק (א., ב.) לא נוספת** — אם רוצים אותה, לשלוח `# א. מבוא`.
- **`doc_export version`** — מספר גרסה של המסמך. גרסאות מאוחדות (10 דקות) — מספר שנבלע בגרסה מאוחדת מחזיר 404.

### בדיקות
- `php word-processor/tests/run.php` — 148 בדיקות: רישום, חתימה (זמן, nonce, גוף, פעולה, מפתח זר, החלפת מפתח),
  טוקן וסשן, הפרדה בין לקוחות, נעילה וגרסאות, ייצוא (html/text/ooxml/docx — כל XML תקין), ייבוא (lines/docx/html),
  העתקה ומחיקה, הגדרות עמוד, שמירה אטומית וגרסת מבנה, וגלישת תמונות / חיתוך / סיבוב / כיתוב / ריווח תווים — ייצוא וחזרה מ-docx, ו-PDF (מבנה הקובץ, גופנים, bidi, שבירת עמודים, טבלה ארוכה, תמונות; עם pdftotext — גם חילוץ הטקסט).
- **בדיקות דפדפן:** `cd word-processor/tests/e2e && npm install && npx playwright install chromium && node run.mjs`
  (או `node run.mjs parity` — רק חלק). מרים לבד שני שרתי `php -S` — העורך עם משתמש מדומה ומסד זמני (`prepend.php`),
  ומארחת בדיקה ממקור אחר (`host/`). הקבוצות (`suites/`): שמירה וניתוק, הטמעה, טלפון (צביטה), ו**אותם עמודים** —
  לכל מסמך באוסף (`tests/corpus`, נוצר מ-`make.php`) משווה את מספר העמודים ואת הטקסט שבתחילת כל עמוד בעורך,
  בהדפסה (PDF של הדפדפן במצב ההדפסה של העורך) וב-PDF מהשרת. הבדל ידוע (`known` / `known_pdf` באוסף) — ⚠ ולא כישלון.
- **בכל PR** שנוגע ב-`word-processor/`: `.github/workflows/word-processor-tests.yml` מריץ את שתיהן.
- **בדיקה חיה:** `api.php?action=selftest` — העורך רשום כלקוח של עצמו (`word-processor`, המפתח ב-`embed_key`) ועובר
  את כל המסלול ב-HTTP אמיתי מול השרת. רצה אוטומטית אחרי כל פריסה: `.github/workflows/word-processor-smoke.yml`.

**עמודים זהים בעורך, בהדפסה וב-PDF מהשרת** — בכל אוסף הבדיקות, בלי הבדלים ידועים. מה שנדרש לזה: שורה נמדדת
בכל גובה השורה; רווח בסוף שורה "תלוי" (pre-wrap, לא break-spaces); בלי kerning ובלי locl (ספרות "עבריות" צרות);
סימן הערה ברוחב של ה-PDF; בתא טבלה בלי רווח אחרי פסקה; מדידה מחדש — קודם בלי הרווחים הישנים.

## מה טרם (שלב 2 — המשך)
- שיתוף בזמן אמת (היום — נעילה).
- גבולות טבלה ניתנים לעריכה; שורה אחת גבוהה מעמוד שלם — לא נשברת (בתוך השורה).
- שורת כותרת עליונה/תחתונה עם עיצוב (היום — טקסט חופשי).
- ייבוא docx: צורות, תיבות טקסט ונוסחאות — לא מיובאים (ומופיעים בדוח הייבוא).
- **טורים** — בעורך תצוגת טיוטה (כמו Draft ב-Word): הטקסט ברוחב טור, כל טור במסגרת משלו ("עמוד 1 · טור 2"). בהדפסה
  וב-PDF — הטורים זה לצד זה, מימין לשמאל. מסמך עם מקטעים במספר טורים שונה מודפס דרך ה-PDF מהשרת (הדפדפן לא מחליף
  מספר טורים באמצע). מעבר טור ידני — Ctrl+Shift+Enter (או "פריסה ← מעברים"). עוד אין: טורים ברוחב שונה, איזון הטור האחרון.
- **לאמת ב-Word אמיתי** את היישור הלוגי (`w:jc start/end`, `w:ind start`) בפסקאות מימין לשמאל.
