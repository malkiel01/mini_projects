# מגדלור — ביקורת ביצוע: כל הגדרה, מי מבצע אותה, ואיך יודעים שבוצעה

עודכן: 22 באוקטובר 2026. נבנה מהקוד ומהבדיקות האוטומטיות. **שום שורה כאן לא נבדקה עדיין במכשיר אמיתי** —
העמודה "אימות במכשיר" אומרת בדיוק מה צריך לבדוק.

## מצבים שההורה רואה

ליד כל הגדרת מכשיר (אפליקציית ההורה ← ילד ← מכשירים ← ⚙️ הגדרות המכשיר). מקור: `lib/enforce.php`,
`deviceSettingsStatus`, ותוצאת הקריאה החוזרת במכשיר (`SettingsMath`).

| מצב | מתי |
| --- | --- |
| 💾 נשמר בשרת | אין מכשיר מחובר |
| ⏳ ממתין למכשיר | המכשיר עוד לא משך את המדיניות הנוכחית (כבוי / בלי רשת) |
| 📥 התקבל במכשיר | המכשיר משך אותה (`devices.policy_rev`), ועוד לא דיווח שהחיל |
| ☑️ הוחל | הקריאה למערכת הצליחה, אבל אי אפשר היה לקרוא בחזרה (או גרסה ישנה, `ok`) |
| ✅ אומת | המצב **נקרא בחזרה** מהמערכת ותואם לבחירה — עם זמן האימות |
| ❌ נכשל | הקריאה נכשלה, או שהמצב שנקרא שונה מהבחירה — גם כשההורה *התיר* |
| ➖ לא נתמך | אין הגבלה כזו בגרסת האנדרואיד |
| 📱 נדרשת פעולה במכשיר | בלי "בעל מכשיר", או צעד שאנדרואיד דורש מהמשתמש |
| 👉 נדרשת פעולה | ההורה צריך לשנות משהו אחר (למשל לפתוח את Google Play) |

"אומת" רק אחרי קריאה חוזרת. דוח מלפני שינוי, או בן יותר מיממה — אינו "אומת".

## הגדרות המכשיר ("בעל מכשיר")

כל אלה: `Enforcer.applySettings` ← `addUserRestriction` / `clearUserRestriction`, ואז `getUserRestrictions`
(קריאה חוזרת). דורשות **"בעל מכשיר"**; בלעדיו — `no_owner` ("נדרשת פעולה במכשיר"). הגבלות משתמש של DPM
נשמרות במערכת — **שורדות אתחול** ואינן תלויות ברשת. בניתוק — נשאר המצב האחרון שהוחל.

## בדיקת הגנה יזומה (שלב 12 ג)

אפליקציית ההורה ← ילד ← סיכום ← "🛡️ בדיקת הגנה". הבקשה משנה את `policyRev`, וכל מסלול סנכרון מביא אותה למכשיר
(`SelfTest.kt`). **בטוחה לילד:** שום כתובת לא נטענת ושום אפליקציה לא נפתחת.

| מה נבדק | איך | מה זה מוכיח — ומה לא |
| --- | --- | --- |
| אתר חסום / מותר / שאינו ברשימה / סוג תוכן חסום | המנוע של המכשיר (זה שהדפדפן משתמש בו) מכריע, ומושווה להכרעת השרת | שהמכשיר מחזיק את המדיניות הנכונה ומכריע כמו השרת. **לא** טוען את הדף בפועל |
| אפליקציות חסומות (עד 5 מותקנות) | `isPackageSuspended` — נקרא מהמערכת; אחרת — המדיניות + נגישות פעילה | השעיה — מצב אמיתי במערכת (אנדרואיד 10+). נגישות — רק שהשירות פעיל, לא שמסך החסימה עלה |
| הגדרות המכשיר | `Enforcer.readBack` — קריאה מ-DPM בלי להחיל | המצב שהמערכת מחזיקה עכשיו |
| בעל מכשיר, נגישות, הגנה מהסרה, זמן מאז סנכרון | `isDeviceOwnerApp`, הגדרות הנגישות, `isUninstallBlocked` | |

הפסיקה בשרת (`lib/selftest.php`), מהנתונים הגולמיים — מכשיר שמכריע אחרת מהשרת הוא "נכשל" גם אם לא דיווח כך.
הפרש שנובע משעות או ממכסה — "לתשומת לב", לא כשל. מכשיר כבוי — "ממתין למכשיר", בלי תוצאה ישנה שמוצגת כחדשה.

## מה עוד לא מכוסה

- שורות "אפליקציות", "אתרים" ו"זמנים" בטבלת האכיפה של ההורה עדיין במצבים הישנים (נאכף / חלקי / לא דווח),
  לא בשמונת המצבים — רק הגדרות המכשיר עברו.
- אין "זמן מסך" לאפליקציות אחרות.
- כל מה שבעמודת "אימות במכשיר" — לא נבדק.
