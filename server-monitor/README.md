# מוניטור השרת

דשבורד למנהל, שעוקב אחרי כל הפעילות של האתרים שלנו מול חשבון האחסון ב-Bluehost, ביחס למכסה:
- פניות לכל אפליקציה ולכל אתר
- שגיאות 429, ‏508 ו-5xx
- מי מציף
- בו-זמניות מול המגבלה
- התראה לפני שנחסמים

נפתח אחרי שכל mbe-plus.com נחסם ב-429 ב-2026-11-02.

**לא לבלבל עם `system-monitor/`**, שהיא אפליקציית אנדרואיד להתקנה ולאבחון של מכשירים.

**מצב: אפיון, ההכרעות התקבלו.** הפירוט המלא, כולל מה שנבדק בפועל בשרת: [`docs/spec.md`](docs/spec.md).
אין עדיין `app.json`, ולכן הכלי לא מופיע בדף הכלים. הרישום (`"gate": true`, ‏`"restricted": true`) יתווסף יחד עם הבנייה.
