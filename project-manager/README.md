## גישה

- `"gate": true` — כניסה ישירה בלי הרשאה נחסמת (`platform/README.md`, "השער").
- `"restricted": true` — **חסומה לכולם כברירת מחדל**: הרשאה לקטגוריה "פיתוח
  וניהול" לא פותחת אותה. רק המנהל, ומי שקיבל בממשק המנהל "✓ מותר" ישירות על
  האפליקציה הזו.
