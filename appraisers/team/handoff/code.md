## הכללים שנקבעו ב-07 (לא לפתוח מחדש)

- **כתובת ציבורית = `"public"` ב-`app.json` + `'public'` ב-`APR_ACCESS` + זרוע ב-match הציבורי שב-`apr_dispatch`.** `a-boundaries`
  בודק שהשלושה תואמים. הפורטל מקבל מהנתב רק `ip`, `portal_token`, `portal_name`, `portal_cookie` וקורא הגוף.
- **`apr_portal_link()` הוא הכניסה היחידה לפורטל.** אסימון שגוי / פג / בוטל / תיק שנמחק / משרד מושעה — `portal_invalid` זהה.
  תיק סגור — `portal_closed`. כל פעולה חדשה בפורטל: קודם `apr_portal_link`, אחר כך `apr_portal_usable` (סגור, "תמיד קוד").
- **האסימון לעולם לא בכתובת** (גוף JSON, או הכותרת `X-Portal-Token` בהעלאה), ולעולם לא ביומן. גם שם הקובץ בכותרת.
- **`portal/index.php` — שום סקריפט זר.** השער מזריק `diag.js` לכל דף PHP של אפליקציה מחוברת (`platform/lib/pwa.php`,
  `inject_html`); ההערה עם `platform/assets/diag.js` בדף גורמת לו לדלג, וה-CSP עם nonce חוסם בכל מקרה. **לא למחוק את ההערה.**
  **כל דף PHP ציבורי חדש** (webhook עם HTML, דף אישור) צריך את אותו טיפול — ובדיקה דרך השער האמיתי (ראו `z-http`, "🔴1").
- **הנעילה של 5 קודים שגויים חלה רק על אימות ושליחת קוד** (הכרעת הבקרה). תקרה לבקשה: 200MB / 60 קבצים.
- **לאפליקציה אין `.user.ini`** — השער יוצר אותו בפריסה, וקובץ כזה בגיט מפיל אותה. התקרה: `apr_file_max()` לפי `post_max_size`.
- **סורק ה-PDF:** קובץ שאי אפשר לבדוק (תקציב, Flate כפול, ריפוד חריג) נדחה כ-`file_unscannable`; לא מקבלים בשקט, ולא "משפרים" לניתוח מבנה.

## מלכודות (נוסף על אלה של 04 ו-06 — עדיין נכונות; ראו את קובץ ההעברה הקודם בהיסטוריית הגיט)

- **שרת הפיתוח רץ בלי השער.** מה שהשער מוסיף או חוסם (הזרקה ל-HTML, `public`, `.user.ini`) לא נראה ב-`php -S` הרגיל. `z-http` מרים
  שרת שני עם `gate-prepend.php` על עותק זמני של `platform/` — להשתמש בו לכל דף ציבורי.
- **סגור (arrow fn) לוכד לפי ערך ברגע היצירה:** `fn() => $l['id']` כש-`$l` עוד null — נשאר null. למשתנה שמתמלא אחר כך: `function () use (&$l)`.
- **`replaceChildren(null)` כותב "null" לדף** — לסנן (`.filter(Boolean)`). ב-`portal.js` אין `innerHTML`; `z-http` בודק זאת.
- **`$x['k'] ?? 'x'` מחזיר 'x' גם כשהערך null** — בבדיקה שמצפה ל-null להשתמש ב-`array_key_exists` או בגישה ישירה.
- **מוטציה ששוברת תחביר נראית כ"שרדה"** אם סופרים רק `✗`. `mut.php` (לא נשמר) צריך לזהות `Parse error` / `Fatal error`.
- **מייל בבדיקות HTTP:** `tests/dev-prepend.php` — הכותרת `X-Dev-Mail` "שולחת" ל-`dev-mail.log` בתיקיית הנתונים (רק תחת `cli-server`).
- **`portal()` בבדיקות מוחק מוני קצב** (`login_attempts` של `portal:%`) לפני כל קריאה, אלא אם `keep`.
- **`a-boundaries`:** אין `../` בשום קובץ (גם לא ב-JS של הפורטל — כתובת ה-API נגזרת מ-`location.pathname`); הרשימה `public` נבדקת מילה במילה.
- **לא נבדק עד היום:** מייל אמיתי מהשרת (07-D1, 07-D4), מסך ה-OTP וצפייה ב-PDF בדפדפן אמיתי, LiteSpeed מול `portal/`, גוף שעובר
  את `post_max_size` ב-HTTP. צעדי 👁 ב-AP-007.
- **לפני כל push:** `git fetch origin main`, ולבדוק שה-PR של הענף פתוח. force-push חסום — אחרי מיזוג: `git merge origin/main`, ו-PR חדש.
