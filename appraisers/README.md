# שמאות מקרקעין

פלטפורמה לניהול תיקי שמאות מקרקעין ולהפקת דוחות: פתיחת תיק וזיהוי הנכס,
איסוף מסמכים, בקשות לגורמים חיצוניים, מידע מרשויות, ביקור בנכס, עסקאות
השוואה, ועריכת הדוח.

**מצב: בפיתוח — שלד בלבד.** הקוד עוד לא נכתב.

## איפה מה

| מה | איפה |
| --- | --- |
| האפיון המקורי (גרסה 0.6) ומחקר הרשויות | `docs/source/` |
| האפיון לפי פרוסות מימוש | `docs/spec/` (נכתב בצ'אט האפיון) |
| שאלות פתוחות לבעלים, עם המלצה | `docs/open-questions.md` |
| כללי העבודה של הצוות | `team/PROTOCOL.md` |
| הלוח, המצב והיומנים | `team/board.md`, `team/STATE.md`, `team/log/` |
| מטלות לבעלים | `team/owner-tasks.md` |
| נתוני ריצה בשרת | `data/` — מוחרגת מהפריסה וחסומה מהדפדפן |

## מי בונה

ארבעה צ'אטים — אפיון, קוד, בקרה ומטלות — לפי `team/PROTOCOL.md`. הבעלים מדבר
רק עם הבקרה (הכרעות) ועם המטלות (דברים לבדוק ולעשות).

## מה טרם הוכרע

הכול מלבד מה שהאפיון מסמן "נקבע". ההחלטות הפתוחות מפרק 21 של האפיון עוברות
ל-`docs/open-questions.md`, כל אחת עם המלצה וברירת מחדל.
