# 20 — מפות וחיבורים אוטומטיים למקורות

**תלויה ב-09.** האפיון: 2.3, 9.1, 10.2, 17.2, 28; מחקר הרשויות: 3, 4, 9, 11, 14;
דרישות 17, 18; בדיקת קבלה 26.

**הפרוסה היחידה שתלויה בעולם שמחוץ למערכת.** היא בונה את **התשתית** לחיבור
אוטומטי למקור, ו**ניסוי אחד** — שירותי המפה של מינהל התכנון, המקור היחיד שמחקר
הרשויות מצא שפורסם להטמעה במערכות חיצוניות. שום חיבור אינו מוצג כפעיל לפני
שעבר בדיקת היתכנות ואישור של מנהל המערכת.

## 1. מה בונים

1. **מתאם מקור** — ממשק אחיד לחיבור אוטומטי.
2. **שער ההפעלה** — חיבור עובר ל"פעיל" רק אחרי כרטיס בדיקה מלא ואישור מפורש.
3. **מיקום הנכס** בתיק: נקודה או גבול, עם רמת ודאות ומקור.
4. **מתאם ניסוי: מינהל התכנון** — שאילתה מרחבית ← "תוכניות מועמדות לבדיקה".
5. **מפה** בתיק — לצפייה בלבד (ש-18).
6. **מטריצת רישיון** לכל מקור ושכבה, שנאכפת בקוד.

## 2. מה לא 🟢

- **אין אוטומציה של אתר** (גלישה ממוכנת, שאיבת דפים) — לשום מקור. רק ממשק שהגוף
  פרסם לשימוש מערכות חיצוניות.
- אין חיבור לרשות המסים, לטאבו, לרמ"י, ולעיריות — לא אומת ממשק מורשה (מחקר הרשויות
  5, 6, 8). הם נשארים במסלול הידני.
- אין שמירה של אריחי מפה, אין מפה בדוח, אין שמירה לא מקוונת, אין ניתוח תמונה.
- אין גאוקודינג אוטומטי מול GovMap עד שיתבררו תנאי הגישה (מחקר הרשויות 3.3).

## 4. מיקום הנכס (מחקר הרשויות 3)

- השמאי קובע מיקום **בעצמו**: נועץ נקודה במפה, או משרטט גבול. `source_kind =
  user_pin` / `user_drawn`.
- **`certainty`** — חובה: מאושר · מקורב · לא ידוע. ברירת המחדל לנעיצה: **מקורב**.
  "מאושר" — רק כשהשמאי מסמן שאימת מול מסמך.
- **איתור אוטומטי של מיקום הוא הצעה לאישור** (10.2). בפרוסה הזו אין איתור אוטומטי;
  כשיתווסף — תוצאה אחת או כמה, והמשתמש בוחר ומאשר. **אין בחירה שקטה.**
- **נקודה אינה זיהוי של זכויות** (מחקר הרשויות 3.2): מיקום הבניין אינו מזהה תת-חלקה.
  המיקום הוא נתון עזר לחיפוש מרחבי בלבד, ואינו מסמן שום מזהה נכס כ-`verified`.
- **מערכות קואורדינטות:** נשמר ב-WGS84; ההמרה לרשת ישראל החדשה (EPSG:2039) נעשית
  בקוד, עם בדיקת יחידה מול נקודות ייחוס ידועות. המרה שגויה במאות מטרים היא הכשל
  הצפוי כאן — ולכן יש לה קריטריון קבלה משלה.
- מיקום חדש מחליף את הקודם (`superseded_at`); ההיסטוריה נשמרת. בדיקות שנעשו על
  המיקום הקודם מסומנות "נעשתה על מיקום קודם".

## 5. שער ההפעלה (האפיון 28.1, 19.1)

חיבור נוצר במצב `draft`. כדי להגיע ל-`active` נדרש **כרטיס בדיקה מלא**:

| שדה בכרטיס | |
| --- | --- |
| בעל המקור, וכתובת רשמית | |
| המידע המבוקש, ומזהי החיפוש | |
| אופן ההזדהות | |
| **האם קיים ממשק מתועד לפעולה הזו** — עם קישור לתיעוד | חובה |
| **האם מותרת גישה ממוכנת ומסחרית** — עם קישור לתנאים | חובה |
| רישיון: הצגה · שמירה · לא מקוון · בדוח · הפצה · עיבוד בבינה | כל אחד: כן / לא / לא ידוע |
| חובת ייחוס, ונוסח הייחוס | |
| עלויות | |
| קצב עדכון; מגבלת קצב ורשומות | |
| סוגי שגיאות | |
| כיסוי ומגבלות | |
| **ניסוי:** כמה מקרי בדיקה, מה נמצא ידנית, מה החזיר החיבור, מה הוחמץ, מה הוחזר בטעות | חובה |
| מי בדק, ומתי | |

- `draft` ← `testing`: מנהל המערכת. במצב `testing` החיבור פועל **רק למנהל המערכת
  ולמפתח**, על תיקי בדיקה, ותוצאותיו מסומנות "ניסוי".
- `testing` ← `active`: מנהל המערכת, פעולה רגישה — ורק אם שני השדות המסומנים "חובה"
  הם **כן**, ויש תיעוד ניסוי. אחרת הכפתור כבוי, עם הסבר מה חסר.
- עם ההפעלה: `sources.access_mode` ← `connector`, `feasibility` ← `approved`.
- **הפעלה אינה מעניקה רישיון.** מה שמותר לעשות בתוצאות נקבע בנפרד, לפי `license`.

**הקוד אינו מכיל חיבור שהוא `active` מהזריעה.** הפעלה היא תמיד החלטה של אדם,
מתועדת.

## 6. מתאם מקור ⚙️

ממשק: `describe()` (מה השכבה תומכת בו), `query(geometry, options) → { items,
truncated, raw_meta }`, `health()`.

כל הרצה (`connector_runs`) עוברת את אותן בדיקות (מחקר הרשויות 12):

1. החיבור `active` (או `testing` + משתמש מורשה);
2. למשתמש `sources` בתיק;
3. יש מיקום, **ורמת הוודאות שלו נרשמת בבדיקה**; אין ← `awaiting_identification`;
4. מגבלת הקצב לא נחצתה (לכל המערכת — כל המשרדים חולקים את אותו מקור);
5. מזהה פעולה — אותה שאילתה באותו תיק בתוך 10 דקות אינה נשלחת שוב.

**כשלים:**

| מה קרה | מה נרשם |
| --- | --- |
| פסק זמן, שגיאת רשת, שגיאת שרת | הבדיקה `unavailable`; משימת השלמה ידנית. **לא "לא אותר"** 🟢 |
| תשובה תקינה, אפס תוצאות | `not_found`, עם `coverage_note` אוטומטי: השכבה, סוג הגיאומטריה, והערת הכיסוי של המקור |
| המקור חתך את התוצאות (מגבלת רשומות) | `partial`, `truncated = 1`: "ייתכנו תוצאות נוספות שלא הוחזרו" |
| מבנה התשובה השתנה (שדה צפוי חסר) | `failed`; התרעת `source.incident`; **אין ניחוש של מיפוי שדות** |
| 3 כשלים רצופים | החיבור ← `suspended`; המקור חוזר להציג את המסלול הידני |

**כשל בחיבור אינו מוחק מידע קיים ואינו חוסם עבודה ידנית** (17.2) — "פתיחת המקור"
ו"רישום תוצאה" תמיד זמינים.

## 7. הניסוי: מינהל התכנון (מחקר הרשויות 4)

**המתאם** `planning_admin_arcgis`: שאילתה מרחבית מול שירות מפה מסוג ArcGIS —
"אילו ישויות בשכבה חותכות את הגיאומטריה הזו".

- **הכתובת והשכבה אינן קבועות בקוד.** מנהל המערכת מזין אותן מהתיעוד הרשמי, והמתאם
  קורא את מאפייני השכבה (`describe`) לפני השימוש: שדות, מערכת קואורדינטות, מגבלת
  רשומות, תמיכה בחלוקה לעמודים. מחקר הרשויות מציין במפורש שהכתובת **לא אומתה**
  בזמן המחקר — לכן הצעד הראשון של הפרוסה הוא בדיקה חיה.
- **מיפוי שדות** הוא הגדרה של החיבור (למשל: מספר תוכנית ← `pl_number`, שם ←
  `pl_name`, שטח בדונם ← `pl_area_dunam` — השמות שבמדריך XPLAN). שדה שאינו קיים
  בשכבה ← נשאר ריק.

**מה נוצר מתוצאה** (מחקר הרשויות 4.3):

- לכל ישות ← `planning_items` מסוג `plan`, עם:
  - `applicability = unknown` — **תמיד**. חפיפה גיאוגרפית אינה תחולה.
  - `status_reported` — כפי שהתקבל, או ריק.
  - תווית: **"תוכנית מועמדת לבדיקה"**.
- הבדיקה (`source_checks`) נושאת: השכבה, סוג הגיאומטריה ששימשה (נקודה / גבול),
  רמת הוודאות שלה, מספר התוצאות, והאם נחתכו.
- **ההסתייגות הקבועה** מוצגת מעל הרשימה, ואינה ניתנת להסתרה:
  > "התוצאות הן תוכניות שהשכבה מציגה כחופפות למיקום שסומן. אין זו רשימה מלאה של
  > התוכניות החלות על הנכס. חיפוש לפי נקודה עלול להחמיץ תוכנית שחלה על חלק
  > מהחלקה. <הערת הכיסוי של המקור>. תחולה, סטטוס ומסמכים — לבדיקת השמאי."
- הרצה חוזרת: תוכנית שכבר קיימת בתיק (אותו מספר, אותו מקור) אינה נכפלת; תוכנית
  שהופיעה קודם ואינה מופיעה עכשיו **אינה נמחקת** — מסומנת "לא הופיעה בבדיקה האחרונה".
- **קישור** לפרטי התוכנית באתר המקור — נשמר רק אם `license.store` של השכבה מתיר;
  אחרת מוצג בלי להישמר.
- **אין שליפה של מסמכי תוכנית** (תשריט, הוראות) — רק מטא-דאטה.

**אם הניסוי נכשל** — השירות אינו זמין, השכבה אינה מתאימה, או הרישיון אינו מתיר —
**החיבור נשאר `draft`**, המסלול הידני ממשיך לעבוד, ובכרטיס המקור נרשם מה נבדק ומה
נמצא. **זו תוצאה תקינה של הפרוסה**; הפרוסה נחשבת גמורה כשהתשתית בנויה ונבדקת מול
שירות מדומה, ותוצאת הניסוי החי מתועדת.

## 8. מפה בתיק (האפיון 10.2, ש-18)

- **לצפייה בלבד.** רכיב מפה שמוטמע ממקור שתנאיו מתירים הטמעה, עם הייחוס שהמקור
  דורש. ברירת המחדל ⚙️: אריחי OpenStreetMap, עם הייחוס הנדרש — ובכפוף למדיניות
  השימוש שלהם; מנהל המערכת יכול להחליף מקור אריחים בהגדרות.
- אם מקור האריחים אינו זמין או לא הוגדר ← במקום המפה: טופס קואורדינטות, וקישור
  "פתיחה במפת המקור". **הפרוסה עובדת גם בלי מפה.**
- מוצגים: המיקום שסומן (עם רמת הוודאות — מקורב מוצג כעיגול, לא כסיכה), ועסקאות
  השוואה שיש להן מיקום מדויק.
- **מתחת למפה, תמיד:** המקור, ו"המפה להתמצאות בלבד. אינה אסמכתא לגבולות, לשטח או
  לזכויות, ואינה בהכרח עדכנית."
- **מה אין:** כפתור "שמירת תמונה"; צילום מסך לדוח; הורדה לביקור; שליחה לבינה.
  כל אחד מאלה הוא פעולה נפרדת מבחינת רישיון (מחקר הרשויות 9.1), ונבדק בקוד מול
  `license` — **`unknown` נחשב `no`**.
- שכבות תכנון מעל המפה — רק מחיבור `active` ש-`license.display` שלו `yes`.
- תצלום אוויר — לא בפרוסה הזו.

## 9. אכיפת הרישיון בקוד

פונקציה אחת: `license_allows(source_or_layer, action)`, עם שש הפעולות. **`unknown`
ו-`no` ← לא.** נקראת ב:

| פעולה | איפה נבדק |
| --- | --- |
| `display` | הצגת שכבה במפה |
| `store` | שמירת קישור או קובץ מהמקור בתיק (09, 20) |
| `offline` | הכללה בחבילת הביקור (14) |
| `in_report` | בלוק דוח שמקורו במקור הזה (17, 18) |
| `distribute` | הכללה במסירה או בפורטל |
| `ai` | שליחה ל-`ai_run` (11, 12) |

שינוי רישיון בקטלוג חל על פעולות חדשות; מה שכבר נשמר — נשאר, ומסומן אם הרישיון
הנוכחי כבר אינו מתיר.

**חריג אחד:** קובץ שהמשתמש העלה בעצמו והצהיר שיש לו זכות להשתמש בו (נסח שהפיק,
מסמך שקיבל) — אינו כפוף ל-`license` של המקור; ההצהרה נרשמת.

## 10. מסכים

| נתיב | מסך |
| --- | --- |
| כרטיס תיק ← מקורות ותכנון ← **מיקום** | המפה (או טופס הקואורדינטות); נעיצה / שרטוט; רמת ודאות |
| ← מקור עם חיבור פעיל | "הרצת בדיקה" לצד "פתיחת המקור" (הידני תמיד נשאר) |
| ← תכנון והיתרים | תוכניות מועמדות, עם ההסתייגות |
| `#/system/sources/<מקור>/connector` | הגדרת החיבור; כרטיס הבדיקה; ניסוי; הפעלה / השעיה; היסטוריית הרצות |
| `#/system/sources/<מקור>/layers` | שכבות ורישיון לכל אחת |
| מסך המפתח ← בדיקות תקינות | `health()` לכל חיבור פעיל |

## 12. מקרי קצה

1. **נכס על שתי חלקות.** גבול שמכסה את שתיהן, או שתי בדיקות. הבדיקה מציינת מה כוסה.
2. **נקודה על גבול בין שתי תוכניות.** שתיהן מוחזרות כמועמדות; ההסתייגות מסבירה.
3. **מיקום "מקורב".** הבדיקה רצה, ורושמת "נעשתה על מיקום מקורב" — מוצג ליד כל תוצאה.
4. **המקור מחזיר 1,000 תוצאות בדיוק** (המגבלה). `truncated`; `partial`.
5. **המקור עונה לאט** (40 שניות). הבדיקה רצה כמשימת רקע; המסך מציג "בתהליך".
6. **שני משרדים מריצים יחד.** מגבלת הקצב משותפת; מי שחרג ממתין בתור, לא נכשל.
7. **תוכנית ישנה שאינה בשכבה** (לפני 2011, ב-XPLAN). לא תוחזר — ולכן ההסתייגות
   הקבועה, והערת הכיסוי.
8. **השירות שינה כתובת.** `failed` ← `suspended` ← מסלול ידני; מנהל המערכת מעדכן.
9. **קואורדינטות מחוץ לישראל** (טעות הקלדה). נדחה בהזנה.
10. **הרישיון של שכבה שונה ל-`no` אחרי שנשמרו קישורים.** נשארים, מסומנים; אינם
    נכנסים לדוח חדש.
11. **אריחי המפה חסומים ברשת של המשתמש.** טופס הקואורדינטות, והודעה.
12. **חיבור `testing` בתיק אמיתי.** נחסם — רק תיקים שסומנו "תיק בדיקה".
