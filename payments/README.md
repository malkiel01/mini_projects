# 💳 תשלומים — תוסף

תוסף גבייה בפלטפורמה "הכלים הדיגיטליים": מנויים, תשלום לפי יחידה, ושימוש מדוד (טוקנים של AI) בקרדיט מראש
או בדיעבד; כל חברות הסליקה ואמצעי התשלום (כרטיס, ביט, פייבוקס ועוד) כמחברים; חשבוניות כחוק דרך Morning.
משרת את האפליקציות בכלים הדיגיטליים **ולכל אתר או מערכת** — אבל **רק מי שהמנהל אישר**.

**האפיון המלא:** [`docs/spec.md`](docs/spec.md) — 12 פרקים והכרעות.

## מצב

| | |
| --- | --- |
| שלב | **1 — שלד** (רישום, מסך פתיחה, תיקיית נתונים מוגנת, החרגה בפריסה) |
| מי נכנס | רק המנהל (`"plugin": true`, `"gate": true`). מנויים נוספים — אחרי [`docs/requests/plugin-direct-grants.md`](docs/requests/plugin-direct-grants.md) |
| הבא | שלב 2 — ליבה בלי כסף, מול סולק מדומה |

## מבנה

```
payments/
  app.json              תוסף, מאחורי השער
  index.html            ממשק המנהל (RTL, הטלפון קודם)
  assets/css/app.css    שפת העיצוב (מהסקיל phone-first-design)
  assets/js/app.js
  assets/icon.svg
  data/                 מסד, מפתחות, גיבויים — חסום (.htaccess), ומוחרג בפריסה
  docs/spec.md          האפיון
  docs/spec/            הפרקים
  docs/requests/        בקשות לצ'אט הפלטפורמה
```

## עקרונות שלא משנים

- **אין פרטי כרטיס אצלנו** — רק דף/iframe של הסולק וטוקן.
- **אפליקציות ואתרים מתחברים כמו לשירות חיצוני** — API חתום, בלי `require` לקבצים כאן.
- **אין `require` מחוץ לתיקייה** — התוסף עצמאי.
- **נתונים בשרת רק ב-`data/`**, וכל קובץ חדש שם — שורת `--exclude` ב-`deploy.yml`.

## מה טרם הוכרע

- ספק מסרונים (הודעות שהחוק מחייב לפני סוף מנוי שנתי/מבצע).
- גיבוי מחוץ לשרת — לאן.
- עמלה מהמנויים המאושרים — אם בכלל.
