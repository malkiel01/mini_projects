# 💳 תשלומים — תוסף

תוסף גבייה בפלטפורמה "הכלים הדיגיטליים": מנויים, תשלום לפי יחידה, ושימוש מדוד (טוקנים של AI) בקרדיט מראש
או בדיעבד; כל חברות הסליקה ואמצעי התשלום (כרטיס, ביט, פייבוקס ועוד) כמחברים; חשבוניות כחוק דרך Morning.
משרת את האפליקציות בכלים הדיגיטליים **ולכל אתר או מערכת** — אבל **רק מי שהמנהל אישר**.

**האפיון המלא:** [`docs/spec.md`](docs/spec.md) — 12 פרקים והכרעות.

## מה עובד (שלב 2)

- **ממשק ניהול:** עוסקים (פטור / מורשה / חברה), מערכות מחוברות, קודי גישה (סודי, גלוי, סוד webhook — בדיקות וחי),
  מוצרים ומחירים בגרסאות, לקוחות עם ארנק, טעינה/מתנה/תיקון ידניים, הענקת מנוי בלי חיוב, הודעות ויומן קריאות, ביקורת.
- **API חתום** (`api.php`): `ping`, `catalog`, `customer_upsert`, `customer_get`, `entitlement`, `wallet_get`,
  `usage_record`, `usage_batch`, `usage_reserve`, `usage_commit`, `usage_release`, `usage_summary`.
  חתימה בקוד סודי (HMAC) או Ed25519 (כמו `platform/docs/embed.md`). `api.php?action=key` — המפתח הציבורי של התוסף.
- **הודעות למערכות** (webhooks) חתומות, בתור עם ניסיונות חוזרים. `cron.php` — כל 5 דקות.
- **הארנק** במיליוניות ₪ — טוקן בודד יכול לעלות שבר אגורה בלי עיגול בכל אירוע.

## עקרונות שלא משנים

- **אין פרטי כרטיס אצלנו** — רק דף/iframe של הסולק וטוקן.
- **אפליקציות ואתרים מתחברים כמו לשירות חיצוני** — API חתום, בלי `require` לקבצים כאן.
- **אין `require` מחוץ לתיקייה** — התוסף עצמאי.
- **נתונים בשרת רק ב-`data/`**, וכל קובץ חדש שם — שורת `--exclude` ב-`deploy.yml`.

## מה טרם הוכרע

- ספק מסרונים (הודעות שהחוק מחייב לפני סוף מנוי שנתי/מבצע).
- גיבוי מחוץ לשרת — לאן.
- עמלה מהמנויים המאושרים — אם בכלל.
