# חיבור קארדקום — מדריך לבעל המערכת

> המחבר נבנה לפי התיעוד הרשמי של קארדקום (‏`secure.cardcom.solutions/swagger/v11/swagger.json`, גרסה 11),
> ונבדק מול "קארדקום מדומה" שבנוי לפי אותו תיעוד (`tests/cardcom.php`). **עוד לא נבדק מול השרת האמיתי שלהם** —
> מסוף הבדיקות הציבורי הישן (1000) כבר לא מקבל את הממשק החדש. הבדיקה הראשונה — עם מסוף בדיקות מקארדקום.

## מה צריך

- מסוף בקארדקום, עם **ממשק פיתוח** (‏API) פעיל.
- כדי שחידוש מנוי יעבוד: **שמירת כרטיס (טוקן)** מופעלת במסוף.
- להחזרים מתוך התוסף: **סיסמת ממשק**. בלעדיה ההחזר נעשה בממשק קארדקום ונרשם בתוסף ("רישום החזר").
- לקבלה מקארדקום: **מודול מסמכים** במסוף. אין? בוחרים "הקבלה ממורנינג" ומחברים גם מורנינג (רק למסמכים).
- ביט, אפל וגוגל — אם הופעלו במסוף אצל קארדקום.

## שלב א — בדיקות (בלי כסף אמיתי)

1. מבקשים מקארדקום **מסוף בדיקות** (מספר מסוף ושם משתמש לממשק).
2. בממשק קארדקום: הגדרות ← הגדרות חברה ← ניהול מפתחות ממשק — שם המשתמש והסיסמה.
3. בתוסף: הגדרות ← העוסק ← "+ קארדקום · בדיקות" ← מספר מסוף, שם משתמש, (סיסמה) ← בחירה מי מפיק את הקבלה ←
   שמירה. התוסף בודק לבד ומציג ✓ או את השגיאה.
4. אין מה להגדיר בצד שלהם להודעות: כתובת ההודעות נשלחת לקארדקום עם כל דף תשלום.
5. לנסות קנייה מאחת המערכות בסביבת הבדיקות; ברשימת "מוכנות לכסף אמיתי" יסומנו התשלום והקבלה.

## שלב ב — כסף אמיתי

אותו דבר, במסוף האמיתי, עם "+ קארדקום · כסף אמיתי" (רק הבעלים). ואז, בכל מערכת שגובה: "מאושרת לכסף אמיתי".
לפני שמפעילים ללקוחות — חיוב אמיתי של ₪1 והחזר שלו.

## מה קארדקום עושה, ומה התוסף

| | קארדקום | התוסף |
| --- | --- | --- |
| דף התשלום, פרטי הכרטיס | ✓ | — |
| שמירת הכרטיס (טוקן) — גם בלי חיוב (ניסיון חינם, החלפת כרטיס) | ✓ | שומר מוצפן את הטוקן והתוקף, ו-4 ספרות |
| חיוב חוזר מהטוקן, בלי כפילות (מפתח ייחודי לכל ניסיון) | ✓ | מחליט מתי ובכמה |
| החזר מלא או חלקי | ✓ (עם סיסמת ממשק) | מבקש, ורושם |
| חשבונית מס/קבלה או קבלה לפטור | ✓ אם יש מודול מסמכים | שומר את מספר המסמך; אחרת — מורנינג |
| מנויים, חידוש, ניסיון, מבצעים, ארנק, שימוש, ביטול, הודעות לפי החוק | — | ✓ |

## איך התוסף יודע ששולם

לא סומכים על החזרה מהדף ולא על ההודעה מקארדקום (היא לא חתומה): בשני המקרים התוסף **שואל את קארדקום** מה מצב
הדף (‏`GetLpResult`), ורק אם שולם **הסכום המדויק** — הקנייה נסגרת. השעון שואל שוב קניות פתוחות, למקרה שגם החזרה
וגם ההודעה אבדו.

## כשיש גם מורנינג לאותו עוסק

קארדקום היא הסולק; מורנינג — רק למסמכים (אם נבחר "הקבלה ממורנינג"). חשבונית זיכוי על החזר: אצל קארדקום — לפי
הגדרות המסוף שלהם (לבדוק פעם אחת, בהחזר של ₪1); במורנינג — התוסף מפיק לבד.
