# אנליסט להשקעות — מניות, מט"ח ובורסות

כלי לניתוח ולמעקב אחר השקעות: מניות, מדדים, מט"ח ובורסות. רשימות מעקב,
גרפים ואינדיקטורים, ניהול תיק, התראות, סורק ועוזר AI — הכול מעל שכבת
נתונים אחת שאוגרת אצלנו ומתחלפת בין ספקים.

> מצב: **אפיון בכתיבה** (נפתח 2026-10-30). סבב השאלות הראשון טרם נענה —
> ראו "מה טרם הוכרע". הבנייה מתחילה רק אחרי אישור האפיון, שלב אחר שלב.

---

## שלושה עקרונות שאינם פתוחים לדיון

1. **הכלי אינו ייעוץ השקעות.** כל מסך נושא הבהרה קבועה. אין "המלצת קנייה",
   יש "האינדיקטור חצה רף שהגדרת".
2. **אין מסחר בפועל.** הכלי קורא, מנתח ומתריע. חיבור לברוקר לביצוע הוא
   החלטה נפרדת, עם אפיון אבטחה משלה, אם בכלל.
3. **מפתחות API חיים רק בשרת.** הדפדפן פונה ל-`api.php` שלנו, והוא פונה
   לספקים. המפתחות ב-`data/config.json`, המטמון ב-`data/cache/`, ושניהם
   מוחרגים ב-`deploy.yml`.

## למה "תוספים" אינם הפרויקט הזה

בעולם המסחר יש שלושה סוגי שחקנים, ו"תוסף" פירושו דבר אחר בכל אחד:

| סוג | מה נותן | דוגמאות | איך מתחברים |
| --- | --- | --- | --- |
| ספקי נתונים | מחירים, היסטוריה, דוחות, חדשות. לא מסחר | Twelve Data, Finnhub, TASE Data Hub, בנק ישראל | API עם מפתח. אנחנו הלקוח |
| ברוקרים | החשבון: אחזקות, הזמנות, ביצוע | Colmex Pro, מיטב, IBI, Interactive Brokers | רק אם יש API פתוח. לרוב הישראליים אין |
| פלטפורמות גרפים | סביבה שכותבים בה סקריפטים | TradingView (Pine), MetaTrader (MQL) | קוד שחי אצלם, לא אצלנו |

**הכלי הזה הוא מהסוג הראשון:** כלי ניתוח עצמאי, שמושך ממי שנותן API ואוגר
אצלנו. ל-Colmex Pro אין API ציבורי (הפלטפורמה שלהם מבית TraderEvolution,
ההרחבה היחידה היא דרך האינטגרציה שלהם ל-TradingView). לכן:

- **ייבוא תיק מברוקר** — בשלב הראשון ידני או מקובץ (CSV/Excel שהברוקר מייצא).
- **חיבור לברוקר עם API** (Interactive Brokers וכדומה) — שלב מאוחר, דרך
  "מתאם ברוקר" נפרד, ורק לקריאה.
- **אינדיקטורים ל-TradingView** — פרויקט אחר, לא חלק מהאפיון הזה.

## שכבת הנתונים: מודול אחד, ספקים מתחלפים

זו ההכרעה הארכיטקטונית המרכזית. כל השאר (גרפים, אינדיקטורים, תיק, התראות)
עובד מול **הנתונים שלנו**, לא מול הספק.

### הממשק הקבוע (`lib/market.php`)

```
quote(symbol)                 מחיר אחרון, שינוי יומי, זמן העדכון, מקור
history(symbol, range, step)  נרות OHLCV: יום/שבוע/חודש, 1ד–1ש בתוך-יומי
profile(symbol)               שם, בורסה, מטבע, סקטור, שווי שוק
fx(pair, date?)               שער מט"ח, יציג או שוק
search(text)                  חיפוש נייר לפי שם או סימול
```

### המתאמים (`lib/providers/*.php`)

כל ספק הוא קובץ אחד שמממש את הממשק (או חלק ממנו). רשימת העדיפויות לכל
שוק יושבת ב-`data/config.json`: מי ראשון, מי גיבוי. מתאם שנכשל או חרג
ממכסה מעביר לבא בתור, והכישלון נרשם ביומן.

### מטמון ואגירה (`data/cache/`, `data/market.sqlite`)

| מה | איפה | כמה זמן |
| --- | --- | --- |
| ציטוט אחרון | SQLite, טבלת `quotes` | 60 שניות בשעות מסחר, עד הפתיחה הבאה מחוץ להן |
| נרות יומיים | SQLite, טבלת `candles` | לצמיתות. נמשך פעם אחת, ואחר כך רק ההשלמה |
| נרות תוך-יומיים | SQLite | 30 יום אחורה |
| פרופיל נייר | SQLite | שבוע |
| תשובות גולמיות | `data/cache/*.json` | לפי ספק, לתחקור בלבד |

**מכסות:** `api.php` סופר קריאות לכל ספק ביום ובדקה, ועוצר לפני המכסה.
כשמכסה נגמרת, עוברים לגיבוי או מגישים מהמטמון עם סימון "לא מעודכן".

### הספקים המועמדים

הנתונים כאן הם ממה שידוע נכון למועד הכתיבה; **המכסות והתנאים נבדקים
מחדש בעת ההרשמה**, כי הם משתנים.

| ספק | שווקים | טריות בחינם | מכסה חינמית (סדר גודל) | הערות |
| --- | --- | --- | --- | --- |
| Twelve Data | ארה"ב, אירופה, מט"ח, קריפטו; ת"א חלקית | מעוכב | ~800 ליום, 8 לדקה | ממשק נוח, היסטוריה טובה. **מועמד ראשון לארה"ב ולמט"ח** |
| Finnhub | ארה"ב בזמן אמת; שאר העולם מוגבל בחינם | ארה"ב: זמן אמת | ~60 לדקה | חדשות ודוחות טובים. גיבוי לארה"ב, מקור לחדשות |
| TASE Data Hub | בורסת ת"א, רשמי | סוף יום | 4 מוצרים חינמיים עם מפתח | ניירות, מדדים, קרנות. **המקור הרשמי לת"א**; תוך-יומי בתשלום |
| Yahoo Finance (לא רשמי) | הכול, כולל `.TA` | מעוכב 15 ד' | ללא מפתח | אין API רשמי; נשבר מדי פעם, תנאי שימוש אפורים. **גיבוי בלבד, לא מקור ראשי** |
| בנק ישראל | שערים יציגים | יומי | חינם, בלי מפתח | ה-API הרשמי (SDMX). **המקור לשקל** |
| Frankfurter (ECB) | צמדי מט"ח עולמיים | יומי | חינם, בלי מפתח | גיבוי למט"ח |
| CoinGecko | קריפטו | דקות | ~30 לדקה | רק אם קריפטו נכנס |
| EODHD / Polygon | היסטוריה עמוקה, ת"א מלאה | בתשלום | — | שדרוג עתידי, לא לשלב הראשון |

**ההמלצה לשלב הראשון:** Twelve Data (ארה"ב + מט"ח) + בנק ישראל (שקל) +
TASE Data Hub (ת"א סוף יום), עם Yahoo כגיבוי. עלות: אפס. כשיידרש זמן אמת
או ת"א תוך-יומי, משדרגים ספק אחד בלי לגעת בשאר.

### מה מותר לעשות עם הנתונים

כמעט כל ספק מתיר לשמור ולהציג **למשתמשי הכלי**, ואוסר להפיץ הלאה או למכור.
כל עוד הכלי משרת אותך וכמה משתמשים, זה בגדר המותר. ביום שהוא הופך למוצר
לציבור, זו עלות רישיון, ואז בודקים מחדש.

## משתמשים ונתונים

לפי `CLAUDE.md`: **משתמשי הפלטפורמה אינם משתמשי הכלי.** השער של הפלטפורמה
(`"gate": true`) קובע מי בכלל מגיע לתיקייה; בפנים, לכלי כניסה משלו, מסד
משלו ועוגייה בשם משלו (`ma_session`), בלי `require` מחוץ לתיקייה. כך הוא
יוכל לצאת לדומיין משלו.

- המשתמש הראשון נוצר במסך "הקמה" כשהמסד ריק (כמו בנגרות). אחר כך רק
  המנהל מוסיף משתמשים. אין הרשמה חופשית.
- כל משתמש רואה רק את רשימות המעקב, התיקים וההתראות שלו.
- נתוני השוק (נרות, ציטוטים) משותפים לכולם: נייר הוא נייר.
