# התקנה באתר מגרב — צעד אחר צעד

המדריך לבעל המערכת. כ-15 דקות, פעם אחת.

## 1. התקנת התוסף

1. מורידים מהריפו את התיקייה `kol-maroko/wordpress-plugin/kol-maroko/`, ודוחסים אותה ל-ZIP. בתוך ה-ZIP
   צריכה להיות תיקייה אחת, `kol-maroko`, ובה `kol-maroko.php`, `template.php` ו-`readme.txt`. (גרסה 1.2 ומעלה.)
   כבר מותקנת גרסה ישנה? מעלים את החדשה באותה דרך ובוחרים **"החלפת הגרסה הנוכחית"** — ההגדרות נשמרות.
2. בוורדפרס של maghreb.co.il: **תוספים ← הוספת תוסף ← העלאת תוסף** ← בוחרים את ה-ZIP ← **התקנה** ← **הפעלה**.

## 2. חיבור לסטודיו

1. בסטודיו: **⚙️ הגדרות** ← "המפתח הציבורי" ← **📋 העתקה**.
2. בוורדפרס: **הגדרות ← קול מרוקו**:
   - **המפתח הציבורי** — מדביקים.
   - **העמוד** — בוחרים את עמוד הלקסיקון.
   - **פעיל** — **להשאיר כבוי** בינתיים. כך העמוד ממשיך להיראות כמו היום.
   - **שמירה**.

## 3. העברת העמוד הקיים לסטודיו

1. באותו מסך בוורדפרס: **⬇️ ייצוא העמוד**. יורד קובץ ZIP — ההגדרות והמבוא של המילון, כל המילים והנושאים,
   והעיצוב. ההקלטות לא בתוכו — הן נשארות באתר, והסטודיו מפנה אליהן.
2. בסטודיו: **⚙️ הגדרות** ← **📥 העלאת קובץ הייצוא** ← בוחרים את ה-ZIP.
3. הטיוטה בסטודיו מתמלאת בעמוד כפי שהוא היום (רכיב "המילון"), והמילים — בלשונית **📚 מילים**. משם — עורכים.

מהרגע הזה המילים מנוהלות **רק בסטודיו**. מה שבוורדפרס נשאר כמו שהוא — וזה מה שחוזר אם בוחרים "חזרה לעמוד המקורי".

## 4. Cloudflare

ראו [`cloudflare.md`](cloudflare.md). בלי זה Cloudflare חוסם את השליחה מהסטודיו.

## 5. בדיקה ופרסום ראשון

1. בסטודיו: **⚙️ הגדרות** ← **בדיקת חיבור**. צריך לראות "✓ האתר ענה".
2. **🚀 פרסום** ← **פרסום הטיוטה לאתר**. הגרסה נשלחת לאתר, אבל לא מוצגת עדיין.
3. **🚀 פרסום** ← **▶️ להציג באתר את הגרסה מהסטודיו**. מעכשיו העמוד מציג את הגרסה מהסטודיו.
   (אפשר גם בוורדפרס: **הגדרות ← קול מרוקו** ← **פעיל** ✓ ← **שמירה**.)

## אם משהו לא בסדר

- **בסטודיו:** **🚀 פרסום** ← **↩️ חזרה לעמוד המקורי**. האתר חוזר מיד להיות בדיוק כמו לפני הכלי — התבנית
  והמילים שבוורדפרס. שום דבר לא נמחק, ואפשר להחליף שוב בכל רגע.
- **בוורדפרס:** "חזרה לתוכן המקורי" — אותו דבר.
- **גרסה קודמת:** בוורדפרס, ליד כל אחת מ-10 הגרסאות האחרונות — "להציג אותה". בסטודיו — **🚀 פרסום** ← הגרסה ← "פרסום מחדש".
