## 1. איך קוראים את הטבלאות — וכלל הסגירה

**לכל שורה שני חצאים נפרדים: "נערך חזותית" ו"נערך בקוד".** הבעלים דרש את שניהם (`owner-brief` §3.2, 1–2), ואחד אינו
תחליף לשני. "אפשר בקוד" אינו סוגר שורה שהבעלים ביקש לעשות בגרירה.

**שורה סגורה רק כששני החצאים מלאים, פרוסים לשרת, ונבדקו על העמוד האמיתי.**

| סימן | משמעות |
| --- | --- |
| ❌ | לא קיים |
| ◐ | קיים חלקית — כתוב מה חסר |
| ✅ | קיים, פרוס, ונבדק מול קריטריון קבלה. **אין היום אף שורה כזו בחצי החזותי**, ואין ✅ על דבר שהבעלים אמר שאינו עובד |
| ⊘ | לא חל על עמוד מבודד — עם הנימוק, ועם מה שבא במקומו |

**מה פירוש "נערך חזותית":** האלמנט נבחר בלחיצה על הקנבס; השינוי נעשה בגרירה, בידית, או בשליטה בפאנל; והתוצאה נראית
מיד. פתיחת קובץ, כתיבת בורר CSS או הקלדת HTML — אינן "חזותית".

**מה פירוש "נערך בקוד":** השינוי נעשה בקובץ פרויקט שבעל העמוד פותח במנהל הקבצים; נראה בתצוגה החיה; **ומגיע לגולש כמו
שנכתב, בלי סינון**. לכן החצי הזה אינו נסגר ב-F2 לבדו. הוא נסגר בשלושה צעדים, ולכולם קוראים בטבלאות **"קוד-כללי"**:

| צעד | פרוסה | מה נסגר |
| --- | --- | --- |
| לערוך | **F2** | כל קובץ נפתח, נערך, נוסף, נמחק |
| לראות | **F4** | התצוגה החיה המבודדת מריצה את הקבצים כמו שהם |
| להגיע לגולש | **M1 + M2** | החבילה מתפרסמת ומוגשת בלי סינון, מאחורי הקיר |

**"היום בקוד" בכל הטבלאות** פירושו: שלושה קבצים של המילון בלבד, בתחביר Mustache; HTML מסונן (`script`, `style`, `form
action`, `on*` נמחקים); CSS ממוקד בכוח; JS שנערך מעביר את המילון למסגרת (א-1.1). לכן גם מה שאפשר היום בקוד מסומן ◐ ולא ✅.

**שמות הפרוסות** כמו ב-`team/handoff/spec.md` §5, בשני שינויים שנועדו למנוע בלבול עם מזהים אחרים של האפיון (המספור
הסופי — של הבקרה): פרוסות הנתונים נקראות כאן **N1–N3** (ולא D, שתפוס להכרעות D1–D9), ופרוסת האנשים **P1** (ולא R1,
שתפוס להבטחה R1). נוספו שתי פרוסות שהפער חשף: **V15** (הגדרות עמוד, `<head>`, עמודים נוספים) ו-**V16** (ספריית
הרכיבים המוכנים).

## 5. מה לא חל על עמוד מבודד (⊘)

יכולות של Elementor Pro שקיימות רק מפני שהוא חלק מוורדפרס. העמוד מבודד מוורדפרס בדרישה (`owner-brief` §3.1), ולכן הן
אינן חסרות — אבל כל אחת רשומה כאן עם מה שבא במקומה, כדי שלא ייווצר "חסר" שקט.

| יכולת | למה לא חל | מה בא במקומה |
| --- | --- | --- |
| רכיבי פוסטים, ארכיון, תגובות, מחבר, פירורי לחם של וורדפרס | הנתונים של האתר — מחוץ לגבול | רשימות הנתונים של העמוד (4.9) |
| WooCommerce, כפתורי PayPal / Stripe | תוסף של האתר | קוד וקישור חיצוני; אין שירות תשלומים בכלי **[ש-11]** |
| התחברות משתמשי האתר (Login) | משתמשי האתר — מחוץ לגבול | אין; העמוד ציבורי |
| Theme Builder לכותרת / תחתית **של האתר** | של האתר | כותרת ותחתית של העמוד עצמו (8.4) |
| תנאי תצוגה לפי משתמש וורדפרס / תפקיד | משתמשי האתר | תנאים לפי נתונים, תאריך, מכשיר (4.15) |
| סרגלי צד ווידג'טים של וורדפרס, Shortcode | של האתר | רכיבים (V12) |
| אחסון בדפדפן, התקנה כאפליקציה, נגן יוטיוב מוטמע | **מגבלת ארגז החול בכתובת של האתר** — לא של העורך | מתאפשרים במלואם בכתובת משלו **[ש-2 ב]** |

השורה האחרונה היא היחידה שבה משהו שבעל העמוד **רוצה** עלול להיות חסום. היא הוצגה לבעלים בש-2, במילים פשוטות.
