## 1. מה בונים

אחרי V4 בעל העמוד **בונה ומסדר את העמוד בגרירה**: מוסיף רובריקה, קובע אם היא שורה או עמודה, מכניס רובריקה לתוך
רובריקה, גורר כל אלמנט לכל מקום, מוסיף כותרת, משכפל, עוטף ומפרק. זו הפרוסה של "לגרור כל רובריקה… ומה יופיע בתוך
הרובריקה; לגרור את הכותרות, להוסיף כותרת".

1. **"רובריקה"** — המילה של הבעלים, והיא המילה בממשק (לא "מכל"). רובריקה היא כל אלמנט שמכיל אלמנטים, בכל עומק.
2. **כיוון הרובריקה:** ↕ עמודה / ↔ שורה, ורווח בין הילדים. (הובא מ-V6 — בלעדיו "רובריקה אופקית" אינה קיימת.)
3. **הוספה** מהספרייה, ב"＋" בין אלמנטים, ובתוך רובריקה ריקה.
4. **גרירה** בקנבס וב-Navigator, עם קו הכנסה שמראה את הכיוון.
5. **שכפול, עטיפה, פירוק, החלפת תגית, העתק / הדבק.**

## 2. קריטריוני קבלה

### רובריקה וכיוון

- [ ] בסרגל של כל רובריקה נבחרת, ובראש לשונית "מתקדם" ← "פריסה": **מתג כיוון ↕ עמודה / ↔ שורה**, ושדה **רווח**
      (השליטה המספרית של V3, כל יחידה). המתג מציג את המצב **המחושב** של האלמנט, גם כשלא העורך כתב אותו.
- [ ] מה נכתב, תמיד דרך כלל היעד של V3 (המחלקה של הרובריקה; בלי מחלקה — מוצע שם קריא):
      | מצב קיים | ← שורה | ← עמודה |
      | --- | --- | --- |
      | זרימה רגילה (`block`) | `display:flex; flex-direction:row; flex-wrap:wrap` | אין שינוי — כבר עמודה. רווח שהוקלד כותב `display:flex; flex-direction:column; gap` |
      | flex | `flex-direction:row` | `flex-direction:column` |
      | grid, או `display` אחר (`inline`, `table`…) | המתג מציג "רשת" / את הערך; לחיצה מציעה "הפוך לשורה / לעמודה", ואומרת מה ישתנה. עריכת הרשת עצמה — V6 | |
- [ ] `row-reverse` / `column-reverse` שכבר בקוד — מוצגים כמו שהם ("שורה, הפוכה"), ואינם מנורמלים.
- [ ] **בעברית שורה מתחילה מימין.** הכיוון נקבע מ-`dir` המחושב; העורך אינו כותב `direction` ואינו כותב `row-reverse` כדי "לתקן".
- [ ] שינוי כיוון הוא עסקה אחת ("כיוון · `div.hero-titles` · עמודה ← שורה"); ביטול מחזיר קבצים זהים.
- [ ] מה שנדרס (`!important`, כלל חזק יותר) — לפי V3: נאמר לפני הכתיבה, עם שתי ההצעות. אין מתג שנלחץ ואינו משנה דבר.
- [ ] שאר הפריסה — יישור בשני הצירים, גלישה, גדילה וכיווץ, רוחב עמודות, grid — **V6**. עד אז היא נערכת בקוד; `flex-wrap`
      שהעורך כתב מופיע בפאנל כשורה לקריאה עם "פתח בקוד".

### הוספה

- [ ] **הספרייה** (לשונית ליד ה-Navigator): רובריקה · כותרת · טקסט · תמונה · כפתור · קישור · רשימה · מפריד · שמע · וידאו.
      מה נכתב לכל אחד — HTML מינימלי ותקני, בלי מחלקות של העורך ובלי `style=""`:
      `<div></div>` · `<h2>כותרת</h2>` · `<p>טקסט</p>` · `<img src="" alt="">` · `<button type="button">כפתור</button>` ·
      `<a href="">קישור</a>` · `<ul><li>פריט</li></ul>` · `<hr>` · `<audio controls>` · `<video controls>`.
- [ ] **כותרת חדשה מקבלת את התגית והמחלקות של הכותרת השכנה** כשהיא נוספת בין כותרות (כך הכותרת השביעית נראית כמו השש);
      אחרת `h2`. הטקסט נבחר מיד לעריכה במקום (V2).
- [ ] **"הוסף רובריקה" שואל כיוון כבר בהוספה:** ↕ / ↔, ו**מבנים מוכנים** — שורה של 2, 3 או 4 רובריקות. מבנה מוכן כותב
      רובריקת-שורה ובתוכה N רובריקות עם `flex:1 1 0; min-width:0` — עסקה אחת, שני קבצים (HTML + כלל CSS בשם קריא:
      `row-1`, `row-1-col`). שינוי היחס בין העמודות בגרירה — V6.
- [ ] שלוש דרכים להוסיף, שקולות: גרירה מהספרייה אל הקנבס או אל ה-Navigator · **"＋" שמופיע בריחוף בין שני אחים** ובקצות
      רובריקה · לחיצה על פריט בספרייה (נכנס אחרי האלמנט הנבחר; ברובריקה נבחרת — בסופה).
- [ ] **רובריקה ריקה אינה נעלמת:** בקנבס היא מוצגת עם גובה מינימלי של העורך, קו מקווקו ו"＋ גרור לכאן". הגובה הזה **אינו
      נכתב לקובץ** ואינו בתצוגה החיה; הפאנל אומר: "רובריקה ריקה — בתצוגה החיה גובהה 0".
- [ ] תמונה, שמע ווידאו שנוספו פותחים מיד את בחירת הקובץ מהספרייה (V2). ביטול הבחירה משאיר את האלמנט, מסומן "בלי קובץ".
- [ ] גרירת קובץ מהמחשב אל מקום בעמוד — כמו ב-V2; קו ההכנסה הוא זה של V4.

### גרירה

- [ ] כל אלמנט נגרר: מהידית ⠿, מגופו (אחרי תזוזה של 4px, כדי שלחיצה תישאר בחירה), ומהשורה שלו ב-Navigator. גם אלמנט
      מוסתר, ריק או בגודל אפס — מה-Navigator.
- [ ] **קו הכנסה** מראה בדיוק איפה האלמנט ייפול — **אופקי ברובריקת-עמודה, אנכי ברובריקת-שורה** — ותווית: "לפני `h1.title`
      · בתוך `div.hero-titles`". רובריקה שנכנסים **אל תוכה** מודגשת כולה. ב-grid: התא מסומן, והסדר נקבע לפי המקור.
- [ ] בחירת היעד כשכמה רובריקות מסתיימות באותה שפה: 8px החיצוניים שייכים להורה, הפנים — לרובריקה; **תזוזה אופקית
      (באנכית: אנכית) בזמן הגרירה עולה / יורדת רמה**, והתווית מתעדכנת. אין יעד שאפשר להגיע אליו רק ב-Navigator — ולהפך.
- [ ] ריחוף של 600ms מעל רובריקה סגורה (חלונית, `<details>`, אלמנט מוסתר) או שורה מקופלת ב-Navigator — פותח אותה לזמן הגרירה.
- [ ] גלילה אוטומטית ליד קצות הקנבס וה-Navigator. Esc מבטל. שחרור מחוץ ליעד — דבר אינו נכתב.
- [ ] **בחירה מרובה נגררת יחד,** ונוחתת ברצף, בסדר המקור.
- [ ] גרירה היא **עסקה אחת** ("גרירה · כותרת בצרפתית · אל לפני הכותרת בעברית"): הזזת טווח בקובץ, בלי לגעת בשאר.
      ביטול מחזיר קובץ זהה בייט בבייט.
- [ ] מקלדת: **Alt + ↑ ↓** מזיז בין אחים (ברובריקת-שורה: Alt + → ←, לפי הסדר הנראה); **Alt + Shift + חיצים** — מוציא
      מהרובריקה / מכניס לשכנה. (ב-V3, Alt + חיצים משנים שוליים **רק כשצד נבחר בתרשים הקופסה** — אחרת הם מזיזים.)
- [ ] **טלפון:** לחיצה ארוכה (400ms) ואז גרירה, עם גלילה אוטומטית; ובגיליון של האלמנט תמיד: ↑ ↓, "הכנס לרובריקה שלפני /
      הוצא", ו**"העבר אל…"** — בחירת יעד בעץ. כל יעד שהגרירה מגיעה אליו — גם מכאן.
- [ ] **ביצועים:** עם 1,496 מילים (60 בקנבס) קו ההכנסה עוקב אחרי הסמן מעל 30 תמונות בשנייה; השחרור ≤ 100ms.

### מה שהדפדפן אינו מרשה — נאמר, ומוצעת דרך

- [ ] **לפני כל כתיבת מבנה העורך בודק שהדפדפן יקרא את התוצאה כפי שנועדה** (ניתוח של הקטע המתוקן מול העץ המבוקש).
      כשלא — למשל רובריקה בתוך `<p>`, קישור בתוך קישור, אלמנט שאינו `<li>` ישר בתוך `<ul>`, תוכן ב-`<img>` / `<hr>` — היעד
      אינו נצבע כזמין, והתווית אומרת למה ומה כן: **"`<p>` אינו יכול להכיל רובריקה — הפוך אותו ל-`<div>` והכנס"** (פעולה
      אחת, עסקה אחת). זו אינה נעילה: אין מבנה תקני שהעורך מסרב לו.
- [ ] `<html>`, `<head>`, `<body>` אינם נגררים, אינם משוכפלים ואינם נעטפים (יש אחד מכל אחד); כל מה שבתוכם — כן.
- [ ] **אלמנט בלי תגית סגירה** (`<li>`, `<p>`, `<td>` שנכתבו בלי `</…>`): ההזזה כותבת את הטווח כפי שהמודל מגדיר אותו,
      והקנבס מרנדר מחדש את הרובריקה שלו (הספייק: האלמנט "בולע" את רווחי ההזחה של אחיו). בדיקת K2 ייעודית.
- [ ] שורה ריקה צמודה נעה עם האלמנט; אלמנט שהוזז מקבל את ההזחה של שכניו החדשים (`03` §2.3).

### `<template>` ורשימות הנתונים — לא לשבור

- [ ] רובריקה שיש בה `data-kol-list` / `data-kol-filter` נגררת, משוכפלת ונמחקת **כולה, עם ה-`<template>` שבתוכה**.
- [ ] גרירה, הוספה או הדבקה **אל תוך** `<template>`, והוצאה מתוכו — אינן מבוצעות ב-V4; התווית: "תבנית הכרטיס נערכת
      בגרירה ב-V11 — עד אז: פתח בקוד", ו"🐞" זמין. **זה פער גלוי, לא מגבלה** (סעיף 5).
- [ ] אלמנט "מוצג לעריכה" (חלון המשוב, חלוניות המבוא) נגרר ומקבל ילדים כמו כל אלמנט, כל עוד הוא מוצג.

### שכפול, עטיפה, פירוק, תגית

- [ ] **שכפול** (⧉, Ctrl+D): העתק מיד אחרי המקור, עם המחלקות. `id` כפול — ההעתק מקבל סיומת (`-2`), וה-`for` /
      `aria-labelledby` / `href="#…"` **שבתוך ההעתק** מתעדכנים אליו; העורך מציג מה שונה.
- [ ] **עטוף ברובריקה** (גם לבחירה מרובה של אחים רצופים): `<div>` סביב, נכתב בתוך השורה; מיד מוצע "סדר את הקוד של
      האלמנט" (`03` §2.3). בחירה שאינה רצופה — "עטוף כל אחד בנפרד" או "העבר לרובריקה אחת".
- [ ] **פרק רובריקה:** הרובריקה מוסרת, הילדים נשארים במקומה. אם כלל CSS שלה עיצב את הילדים או את הפריסה — העורך אומר מה
      ישתנה במראה לפני האישור. הכלל עצמו נשאר בקובץ (ומסומן "אין אלמנט שמשתמש בו").
- [ ] **החלפת תגית:** בפאנל, לכל אלמנט — רשימה לפי הקשר (`div`, `section`, `article`, `header`, `footer`, `main`, `nav`,
      `aside`, `ul` / `ol` / `li`, `h1`–`h6`, `p`, `span`, `a`, `button`) **והקלדה חופשית של כל שם תגית**. נכתב שם התגית
      בפתיחה ובסגירה בלבד. אם כלל CSS נשען על התגית (`.hero h1`) — נאמר לפני, עם ההצעות של V3.

### העתק / הדבק

- [ ] Ctrl+C / X / V ותפריט ⋯: בתוך העמוד ובין עמודים של הפרויקט. ההדבקה — אחרי הנבחר; ברובריקה נבחרת — "בתוכה" / "אחריה".
- [ ] בין עמודים: אם עמוד היעד אינו מקשר את קובץ ה-CSS שבו כללי המחלקות של האלמנט — מוצע "קשר את `css/…` לעמוד" (ברירת
      המחדל) או "הדבק בלי העיצוב". שום כלל אינו משוכפל בשקט.
- [ ] הלוח נשמר גם בלוח המערכת, כ-HTML — הדבקה בעורך הקוד נותנת את אותו קטע.

### אין אלמנט חובה

- [ ] כל אלמנט נמחק, מוזז ונעטף. כשקוד נשען עליו — **אזהרה, לא חסימה**, עם "בצע בכל זאת" ו"בטל":
      תכונת `data-kol-*` (מה יפסיק לעבוד: "החיפוש", "הרשימה") · `id` ש-`for` / `aria-*` / `href="#"` מפנה אליו · מחלקה או
      `id` שמופיעים כמחרוזת בקובץ JS של הפרויקט (חיפוש טקסט; נאמר "ייתכן").
- [ ] הזזה שמוציאה אלמנט קשור (`data-kol-text`) אל מחוץ לתבנית שלו — נכללת בכלל ה-`<template>` שלמעלה.
