# פרוסה V5 — רקע של רובריקה: תמונה, כיסוי, מעבר צבע, שכבות

> **אפיון:** `03-visual-editor.md` §4.3 (קבוצת "רקע"), §5.2 (תמונה), §7.3 צעדים 6–7. **תלות:** V3 (השליטה המספרית, כלל
> היעד, בוחר הצבע), V2 (בחירה מהספרייה, העלאה). V4 רצוי. **תלויה בתשובות הבעלים:** לא.
> **מה קיים בקוד — וזה מה שקובע את הפרוסה** (`lib/migrate.php`, `team/reviews/F3.md`): תמונת ה-hero **אינה `<img>`**. אחרי ההסבה:
> ```css
> /* css/page.css — נכתב בהסבה */
> .kadisha-lexicon-page .kadisha-hero.kadisha-hero--has-image { background-image: url('../media/hero.jpg'); --ka-hero-overlay: .45; }
> /* ה-CSS של הערכה, שהפך לקובץ פרויקט */
> .kadisha-hero { position: relative; background: var(--ka-navy) center / cover no-repeat; }
> .kadisha-hero--has-image::before { content: ""; position: absolute; inset: 0; background: rgba(10, 16, 32, var(--ka-hero-overlay)); }
> ```
> כלומר: התמונה — הצהרה אחת; המיקום והגודל — בתוך קיצור `background` **בכלל אחר**; ההכהיה — **פסאודו-אלמנט** עם משתנה.
> וכל עוד A2 לא הביאה את הקובץ, ה-`url()` הוא כתובת באתר המארח.

## 1. מה בונים

אחרי V5 בעל העמוד **מסיר את התמונה שעל הפס, שם אחרת, ומזיז אותה** — על המסך. "להסיר את התמונה, להוסיף תמונה אחרת" של
הבעלים הוא **כולו כאן**, והוא קריטריון הליבה.

1. קבוצת **"רקע"** בלשונית "עיצוב" של כל רובריקה: רשימת שכבות — תמונה, מעבר צבע, צבע.
2. **"התמונה של הרובריקה"** בסרגל הבחירה: 🖼 החלף · 🗑 הסר · ✥ הזז.
3. **כיסוי** (הכהיה) — גם זה שכתוב כפסאודו-אלמנט.
4. **הפוך לתמונה רגילה / הפוך לרקע.**

## 2. קריטריוני קבלה

### לזהות שיש כאן תמונה

- [ ] בחירת רובריקה שיש לה תמונת רקע מחושבת מציגה בסרגל **🖼 "תמונת רקע"**, ובפאנל — את התמונה הממוזערת, שם הקובץ,
      והמקור (קובץ, כלל, שורה). הפאנל אומר במפורש: **"זו תמונת רקע של הרובריקה, לא אלמנט תמונה"** (`03` §5.2).
- [ ] לחיצה על שטח תמונה שאין עליו אלמנט בוחרת את הרובריקה — ולכן מגיעים לתמונה בלחיצה אחת עליה.
- [ ] `url()` שמגיע ממשתנה (`var(--hero)`) — המקור מוצג כהגדרת המשתנה, והעריכה נכתבת שם.

### להסיר — צעד 6 של התרחיש

- [ ] 🗑 "הסר את התמונה": **ההצהרה `background-image` נמחקת מהכלל שבו היא כתובה** (בעמוד האמיתי: `css/page.css`). הרובריקה,
      התוכן שלה, הגובה, והצבע שמתחת — נשארים. עסקה אחת: "רקע · הסרת התמונה · `section.kadisha-hero`".
- [ ] **בהצהרה עם כמה שכבות** (`url(a), linear-gradient(…)`) מוסרת רק שכבת ה-`url()`, יחד עם הרכיב המקביל לה
      ב-`background-position` / `-size` / `-repeat` כשהם רשימות. **בתוך קיצור `background`** — הקיצור **אינו נערך ואינו
      מאופס** (איפוס של V3 מוחק קיצור כולו — כאן זה היה מוחק גם את הצבע): נכתבת הצהרה מפורשת **מיד אחריו, באותו כלל**
      (`background-image: none`, או רשימת השכבות שנשארו) — כמו `after-shorthand` של `style.js`.
- [ ] **מה שנשאר אחרי ההסרה נאמר מיד,** בהודעה עם פעולות: "נשאר כיסוי כהה (`::before`) — הסר גם אותו / השאר" · "נשאר צבע
      הרקע `var(--ka-navy)` — שנה". בעמוד האמיתי שתי ההודעות מופיעות.
- [ ] אם אחרי המחיקה עדיין נראית תמונה (כלל אחר, חלש יותר, נחשף) — הפאנל מציג אותה כתמונה הנוכחית, עם המקור שלה. אין
      "הסרתי ולא קרה כלום".
- [ ] המחלקה `kadisha-hero--has-image` אינה מוסרת מעצמה; "הסר גם את הכיסוי" מציע שתי דרכים: למחוק את הכלל של ה-`::before`,
      או להסיר את המחלקה מהאלמנט — ואומר על כמה אלמנטים כל אחת משפיעה.

      המיקום, הגודל ושאר ההצהרה אינם נוגעים.
- [ ] **הנתיב נכתב יחסית לקובץ ה-CSS** שבו ההצהרה (`../media/…` מתוך `css/`), ובסגנון המרכאות של הקובץ. בדיקה: התמונה
      נראית בקנבס, בתצוגה החיה, ובחבילת הפרסום.
- [ ] רובריקה בלי תמונה: "＋ תמונת רקע" — נכתב לכלל היעד (V3): `background-image`, ואם אין ערך מחושב אחר — גם

- [ ] גרירת קובץ תמונה מהמחשב על רובריקה שואלת: **"כאלמנט תמונה בתוך הרובריקה, או כרקע שלה?"** (ברירת המחדל: מה שהיה שם.)
- [ ] תמונה שהיא **כתובת באתר המארח** (לפני A2): מוצגת בקנבס, מסומנת "באתר — טרם הובאה", עם "הבא לספרייה" (A2). החלפה
      בתמונה מהספרייה עובדת בלי תלות ב-A2.
- [ ] תמונה מ**שרת אחר**: אינה מוצגת בקנבס (ה-CSP, `03` §2.1) — הפאנל אומר "לא מוצגת בעורך, נראית בתצוגה החיה", והכתובת נערכת.
- [ ] קובץ מעל 500KB — הערה עם המשקל. לא חסימה.

### מיקום, גודל, חזרה

- [ ] בפאנל, לכל שכבת תמונה: **מיקום** (רשת 3×3 + שני ערכים, כל יחידה) · **גודל** (`cover` / `contain` / `auto` / רוחב וגובה)
      · **חזרה** (לא / כן / אופקי / אנכי / `space` / `round`) · **קיבוע** (`scroll` / `fixed` / `local`) · `origin`, `clip` (כולל `text`).
- [ ] **✥ "הזז את התמונה" — על הקנבס:** במצב הזה גרירה בתוך הרובריקה משנה `background-position` (באחוזים), וגלגלת / צביטה /
      ידיות פינה משנות `background-size`. המספרים רצים ליד הסמן; עסקה אחת בשחרור; Esc יוצא. בטלפון — גם כפתורי חיצים ו-− / +.
- [ ] **כשהערך כתוב בקיצור `background` בכלל אחר** (המצב בעמוד האמיתי): הפאנל מציג את המקור, והבורר של V3 מציע —
      לכתוב הצהרה מפורשת (`background-position`) **מיד אחרי הקיצור, בכלל ההוא** ("משפיע על N אלמנטים"), או בכלל היעד. אחרי הכתיבה העורך מוודא שהערך המחושב השתנה; אם קיצור מאוחר יותר מאפס אותו — "נדרס" של V3, לפני הכתיבה.
- [ ] העורך **לעולם אינו מפרק קיצור `background` קיים** להצהרות נפרדות, ואינו ממזג הצהרות לקיצור.
- [ ] **תנאי בקוד הקיים (`style.js`):** היום `covered('background')` מחזיר רק `background-color`, ולכן "מקור" של
      `background-position` / `-size` / `-repeat` / `-image` שבאים מקיצור אינו נמצא (הפאנל היה אומר "ברירת מחדל של הדפדפן"
      על הפס האמיתי). V5 מרחיבה את `covered` ואת `componentOf` לקריאה של כל רכיבי `background` (כולל `/` בין מיקום לגודל
      ושכבות מופרדות בפסיק); `setComponent` נשאר `null` לקיצור הזה — הכתיבה תמיד אחריו. בדיקה ב-`style.mjs` על הכלל של הערכה.

### כיסוי (הכהיה)

- [ ] **כיסוי שכבר קיים כפסאודו-אלמנט** (`::before` / `::after` עם `content` ריק שמכסה את הרובריקה) מזוהה ומוצג בקבוצת
      "רקע" כשורה **"כיסוי"**, וב-Navigator כשורת-משנה של הרובריקה (`::before · כיסוי`). הוא נערך: צבע ושקיפות (בוחר הצבע
      של V3), מעבר צבע, מצב מיזוג, 👁 הסתרה אמיתית (`display:none` בכלל שלו) ו-🗑 (מחיקת הכלל).
- [ ] **כשהשקיפות מגיעה ממשתנה** (`rgba(10,16,32,var(--ka-hero-overlay))`): המחוון משנה את **הגדרת המשתנה**, במקום שבו היא
      כתובה (`css/page.css`), בלי הגבלה לערכים קבועים; הצבע עצמו — בכלל של ה-`::before`. שני המקורות מוצגים.
- [ ] **כיסוי חדש** ("＋ כיסוי") נכתב כשכבה עליונה ב-`background-image` של הרובריקה — `linear-gradient(<צבע>, <צבע>)` —
      בלי פסאודו-אלמנט ובלי לגעת ב-HTML.
- [ ] פסאודו-אלמנט שאינו כיסוי (יש לו תוכן, או אינו מכסה) — מופיע ב-Navigator ונבחר; עריכתו המלאה — V8.

### שכבות, מעבר צבע, צבע

- [ ] הרקע מוצג כ**רשימת שכבות**, בסדר שבו הן מצוירות; הוספה (תמונה / מעבר / צבע), מחיקה, 👁, וגרירה לשינוי סדר —
      הסדר נכתב בכל ההצהרות המקבילות יחד.
- [ ] **מעבר צבע:** קווי / מעגלי / חרוטי; זווית (גם בגרירת חוגה); עצירות נגררות על פס, הוספה בלחיצה, צבע לכל עצירה
      (כולל משתנים); `repeating-`.
- [ ] צבע הרקע — השליטה של V3, כשכבה התחתונה. **מצב מיזוג** (`background-blend-mode`) לכל שכבה.
- [ ] ערך שהעורך אינו מפרק (`image-set()`, `cross-fade()`, `element()`, תחביר שגוי) — מוצג כשכבת **"ערך מותאם"** עם שדה
      טקסט; נערך, ואינו נמחק ואינו מנורמל כשנוגעים בשכבה אחרת.

### גובה הרובריקה

### הפוך לתמונה רגילה — ולהפך

- [ ] ⋯ ← **"הפוך לתמונה רגילה"**: נוסף `<img src alt="">` כילד ראשון של הרובריקה, וההצהרה `background-image` נמחקת —
      עסקה אחת, שני קבצים. שתי אפשרויות, והעורך אומר מה כל אחת עושה למראה:
      **"מאחורי התוכן"** (ברירת המחדל; המראה נשמר: `position:absolute; inset:0; width:100%; height:100%; object-fit:cover`
      לתמונה, עם `object-position` מהמיקום הקודם, ו-`position:relative` לרובריקה אם חסר) · **"בזרימה"** (התמונה מעל התוכן).
- [ ] ⋯ על `<img>` ← **"הפוך לרקע של הרובריקה"**: הפעולה ההפוכה. ה-`alt` הולך לאיבוד — נאמר לפני.

## 5. השורה שעונה על המבחן

V5 סוגרת, בחצי החזותי: **ב-7** ("להסיר את התמונה") ו-**ב-8** ("להוסיף תמונה אחרת") — במילים של הבעלים, על התמונה

**אחרי V5 — אבן הדרך החלקית:** צעדים 1–4 ו-6–10 של התרחיש עוברים. צעד 5 (מיקום חופשי) — אחרי V6.

**מה נשאר שרואים ואי אפשר לשנות על המסך אחרי V5 — בגלוי:**
- תמונה וכיסוי **שונים בטלפון** (V7), ורקע **בריחוף** (V8) — עד אז בקוד בלבד.
- פסאודו-אלמנט שאינו כיסוי — נבחר, ונערך בקוד עד V8.
- תמונה משרת שאינו האתר המארח אינה **נראית** בעורך (נראית בתצוגה החיה); היא נערכת, ומוחלפת.
- בעמוד עצמו (ולא ב-`from-current/`) — רק אחרי שהבעלים הריץ את ההסבה בשרת (F3 עדיין 🧪). עד אז התמונה היא `style=""`
  שהכלי הישן כותב, ו-V5 אינה נוגעת בה.
