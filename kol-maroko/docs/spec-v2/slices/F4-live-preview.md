# פרוסה F4 — התצוגה החיה המבודדת

> **אפיון:** `00-overview.md` §7.1 (I1–I8), §8 (S1, S3–S5); `04-code-and-sync.md` §9; `07-publish-and-mount.md` §6.
> **תלות:** F2a (יש קבצים להגיש); F1. C1 שלב ב נמסר איתה. **תלויה בתשובות הבעלים:** לא.
> **למה לפני F3:** F3 נבדקת בתצוגה החיה. ובלעדיה בעל העמוד עורך קבצים שאינו יכול לראות.

## 1. מה בונים

1. **כתובת תצוגה** שמגישה את קבצי **הטיוטה** של הפרויקט, לפי אותם כללי הגשה שהתוסף יציית להם באתר.
2. **מסגרת מבודדת** בסטודיו שמציגה אותה, עם מצבי מכשיר, מסוף, וכלי בדיקה.
3. **ערכת ההתקפה מול הסטודיו.**

**העיקרון:** מה שעובד בתצוגה החיה יעבוד אצל הגולש, ומה שלא יעבוד אצל הגולש — נכשל כבר כאן. לכן התצוגה מגישה **תחת
אותן כותרות** (ארגז חול, בלי `allow-same-origin`), גם כשזה מגביל.

## 2. קריטריוני קבלה

### ההגשה

- [ ] כל קובץ של הטיוטה מוגש בנתיב שלו, כך שהפניות יחסיות (`css/page.css`, `../media/x.jpg`) עובדות בלי שינוי.
- [ ] **I1:** כל תשובה — כולל 404 ושגיאה — נושאת `Content-Security-Policy: sandbox allow-scripts allow-forms allow-popups
      allow-popups-to-escape-sandbox allow-modals allow-downloads allow-presentation`, **בלי `allow-same-origin`**.
- [ ] **I2:** `Content-Type` לפי סיומת מרשימה סגורה; כל סיומת אחרת ← `application/octet-stream` + הורדה. תמיד `nosniff`.
      `x.php` מוגש כטקסט להורדה, ואינו מורץ.
- [ ] **I4:** `Access-Control-Allow-Origin: *` — כדי שהעמוד, במקור אטום, יקרא את ה-JSON, המודולים והגופנים של עצמו.
- [ ] **I5:** נתיב שאינו בפרויקט ← 404 (ה-`404.html` של הפרויקט אם יש). בלי טיפוס מחוץ לפרויקט — בדיקה אוטומטית.
- [ ] **I7:** התשובות אינן קובעות עוגייה, **ואינן תלויות בעוגיית הסשן**: הכתובת נושאת אסימון חתום, קצר-מועד, שנוצר
      למי שמורשה לקרוא את הפרויקט. (מסגרת במקור אטום אינה שולחת עוגיות; ואסור שתצוגה של קוד לא מהימן תרוץ עם סשן.)
- [ ] שמע ווידאו מוגשים עם `Range`. `data/words.json` נבנה מהטבלה ברגע הבקשה (עד N1 — מהמילים כמו שהן).
- [ ] הכתובת רשומה ב-`"public"` שב-`app.json` אם השער חוסם אותה בלי עוגייה — **לבדיקה מול `platform/README.md`**.
      האסימון הוא ההרשאה; בלעדיו, או אחרי שפג — 403.

### המסגרת בסטודיו

- [ ] כפתור "▶️ תצוגה חיה" במנהל הקבצים ובעורך הקוד. המסגרת: `sandbox` עם `allow-scripts`, בלי `allow-same-origin`,
      בלי `allow-top-navigation`; נטענת **מהכתובת**, לא מ-`srcdoc`.
- [ ] ה-JS של העמוד רץ. בדיקה: קובץ עם `<script>document.title='ok'</script>` — מתבצע, בתוך המסגרת בלבד.
- [ ] מתרעננת אחרי שמירה: CSS בלי טעינה מחדש; HTML ו-JS עם טעינה מחדש ושמירת מיקום הגלילה.
- [ ] מצבי מכשיר לפי `kol.json`; רוחב חופשי בגרירה; "פתח בלשונית חדשה" (אותה כתובת, עם האסימון).
- [ ] **מסוף:** שגיאות JS, `console.*`, ומשאבים שנכשלו — עם קובץ ושורה ו"פתח בקוד". כל מחרוזת מוצגת **כטקסט בלבד** (S5).
- [ ] **כלי בדיקה:** מצביעים על אלמנט ← תגית, מחלקות, והקובץ והשורה כשהאלמנט כתוב בקובץ; "פתח בקוד".
- [ ] לולאה אינסופית בקוד העמוד תוקעת רק את המסגרת; "עצור ורענן" עובד, והסטודיו נשאר חי.
- [ ] סרגל קבוע כשיש בעמוד דבר שלא יעבוד בארגז החול (אחסון בדפדפן, Service Worker, הטמעת יוטיוב): מה, ולמה, ושזה
      ייפתר בכתובת משלו **[ש-2]**. מזוהה מהשגיאות בפועל, לא מניחוש.

### הבידוד — בדיקות התקפה אוטומטיות (G8, S1, S3–S5)

קובץ בפרויקט שמנסה, מתוך התצוגה החיה:

- [ ] `fetch('…/api.php?action=…', {credentials:'include'})` — נכשל, או נענה כמי שאינו מחובר. **נבדק כשהבודק מחובר כבעלים.**
- [ ] `document.cookie`, `localStorage` — ריק / חריגה. `parent.document`, `top.location=…` — חריגה / נחסם.
- [ ] `postMessage` להורה עם כל הודעה: הסטודיו מתעלם מכל מה שאינו מהסוגים המותרים (גובה, כותרת, שורת מסוף, "נלחץ
      אלמנט"), ואף הודעה אינה מפעילה פעולה — לא שמירה, לא פרסום, לא ניווט.
- [ ] פתיחת כתובת התצוגה ישירות בלשונית, עם ובלי אסימון: מקור אטום; בלי אסימון — 403.
- [ ] הודעת `console.log('<img src=x onerror=…>')` — מוצגת במסוף כטקסט.

### C1 שלב ב

- [ ] המסכים החדשים מקבלים את המדיניות המלאה של `C1-studio-csp.md` §2, ו-`frame-src` מתיר רק את כתובת התצוגה.

### מסך המפתח (`08` §5)

- [ ] בדיקת תקינות: כתובת התצוגה מחזירה את כותרות הבידוד. כפתור "הרץ את ערכת ההתקפה מול הסטודיו", עם התוצאה האחרונה.

## 3. איפה הנתונים

אין נתון חדש שנשמר: האסימון חתום ואינו נשמר; הקבצים — של F2.

## 4. מה לא כלול

קנבס העריכה (V0, V1) — מסמך אחר, דומם. הבנייה לפרסום (M1). ההגשה באתר (M2) — אותם כללים, קוד אחר.

## 5. לאימות לפני המימוש — בדיקה צרה אחת (`00` §12, שורות 1–2)

שכותרת `Content-Security-Policy: sandbox` על מסמך שנטען במסגרת נותנת מקור אטום גם בלי תכונת `sandbox` על המסגרת; מה
נדרש כדי ש-`fetch`, מודולים וגופנים מאותו שרת ייטענו במקור אטום; ושהשער של הפלטפורמה מעביר בקשה בלי עוגייה לכתובת
שב-`"public"`.

## 6. השורה שעונה על המבחן

F4 היא הצעד **"לראות"** של "קוד-כללי" (`01-gap` §1): אחריה, מה שבעל העמוד כותב בקובץ — הוא רואה רץ, בדיוק כפי שירוץ
אצל הגולש. היא סוגרת את `01-gap` 11.1 ו-11.10. **היא אינה סוגרת אף שורת עריכה לבדה:** הקבצים עדיין אינם העמוד החי (F3,
M2), ועדיין אין עריכה חזותית (V).
