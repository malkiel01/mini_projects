# פרוסה A3 — הפעולות על הקלטה

> **אפיון:** `05-audio-library.md` §3, §5, §6. **תלות:** A2 (מודל ההקלטה; וההקלטות "בכלי" — פעולות על קובץ דורשות קובץ).
> **תלויה בבעלים:** בעקיפין — A2 מופעלת בלחיצה שלו **[ש-14]**. הקוד של A3 אינו תלוי בתשובה.

## 1. מה בונים

אחרי A3, כל מה שהבעלים ביקש לעשות להקלטה — "להחליף, לשנות, להוסיף ולהסיר" — נעשה מהספרייה.

## 2. קריטריוני קבלה

- [ ] **החלפה** (קיים מ-A1) שומרת את הקודמת כ**גרסה**: "גרסאות" בשורה מציג אותן, משמיע, ו"חזור לגרסה הזו". הנתיב
      (`media/audio/<מזהה>`) והמזהה אינם משתנים.
- [ ] **הקלטה מהדפדפן:** האזנה לפני שמירה, "הקלט שוב", ושמירה.
- [ ] **הוספה:** העלאה של קובץ אחד או רבים (גם בגרירה). **התאמה למילה לפי שם הקובץ** — מזהה (`6.mp3`) או המילה עצמה —
      מוצגת ב**מסך אישור** לפני כל חיבור: הותאמו / לא הותאמו / מתנגשים עם הקלטה קיימת (ואז: החלף / דלג). שום חיבור
      אוטומטי בלי אישור.
- [ ] **חיבור וניתוק:** "חבר למילה…" (חיפוש מילה); "נתק" — המילה נשארת, מסומנת "בלי הקלטה"; ההקלטה נשארת בספרייה
      תחת "לא מחוברות".
- [ ] **שינוי שם** — השם לתצוגה. נערך בשורה. הנתיב אינו משתנה.
- [ ] **מחיקה** — לסל. הקלטה שמילה משתמשת בה: אזהרה עם שם המילה, לא חסימה. **שחזור מהסל מחזיר גם את החיבור למילה.**
      מחיקה סופית — רק מהסל, באישור מפורש.
- [ ] **הורדה:** אחת — הקובץ המקורי, כמו שהועלה. נבחרות או כולן — ZIP, עם קובץ רשימה (מזהה, מילה, שם הקובץ, משך).
      ZIP גדול נבנה בחלקים, עם התקדמות.
- [ ] **בחירה מרובה** (תיבות סימון; "בחר את כל המסוננות"): מחיקה, הורדה, ניתוק.
- [ ] **סינונים חדשים:** לא בשימוש · כפולות (אותו sha256 — מוצגות כקבוצה, עם "השאר אחת") · נכשלו בהבאה · לפי משך ולפי גודל.
- [ ] **משך** מוצג בכל שורה "בכלי"; "מדוד את כולן" (מ-A2) רץ ברקע.
- [ ] **אין המרה ואין הקטנה:** הקובץ שיורד בהורדה זהה בייט בבייט למה שהועלה (בדיקה אוטומטית, sha256).
- [ ] סוגים: mp3, m4a / aac, ogg, opus, wav, webm, flac — זיהוי לפי תוכן. תקרה לקובץ ותקרת דיסק — הגדרות של בעל האתר;
      חריגה נדחית בהודעה שאומרת מה המגבלה ומי משנה אותה.
- [ ] כל פעולה ביומן הפעולות. הרשאות: עורך תוכן ומעלה (`08` §3); מחיקה סופית — בעל העמוד.
- [ ] **מה שלעולם לא:** שום פעולה אינה נוגעת בהקלטה המקורית שבאתר. בדיקה: אין מסלול קוד ב-A3 שפונה לאתר.
- [ ] הקלטה שעדיין "באתר" (אם A2 לא הופעלה או נכשלה לגביה): הפעולות שדורשות קובץ מושבתות **עם הסבר** — "תיפתח אחרי
      ההבאה" — ו"החלף" נשאר זמין.
- [ ] בטלפון: כל הפעולות מתפריט השורה; בחירה מרובה בלחיצה ארוכה.

## 3. איפה הנתונים

גרסאות קודמות של הקלטה — קבצים בספריית המדיה (`data/files/`), רשומות ב-`data/kol.sqlite`. אין נתיב חדש. הגרסאות
נספרות בתקרת הדיסק, ומוצג כמה מקום הן תופסות, עם "נקה גרסאות ישנות מ-…".

## 4. מה לא כלול

עריכת שמע (חיתוך, עוצמה) — אינה בדרישה. ההקלטות כחלק מהחבילה המפורסמת — M2.

## 5. השורה שעונה על המבחן

A3 סוגרת את `01-gap` **ב-13** — "להחליף, לשנות, להוסיף ולהסיר" — ואת 12.1, 12.3, 12.5: אחריה אין בספרייה הקלטה
שהבעלים רואה ואינו יכול להחליף, לשנות לה שם, לחבר למילה אחרת, להוריד או להסיר. התנאי: שההקלטות יהיו "בכלי" (A2);
להקלטה שנשארה "באתר" נשארת רק ההחלפה, והמסך אומר זאת.
