# פרוסה V13 — נוחות: תפריט הקשר, העתק סגנון, היסטוריה עם שמות, קיצורים, תבניות

> **אפיון:** `03-visual-editor.md` §11; `04-code-and-sync.md` (היסטוריה אחת לעריכה חזותית ולקוד); `01-gap` 1.6, 1.7, 1.13, 1.14, 8.1 (תבנית), 8.2.
> **תלות:** V1–V4 (פעולות המבנה), V3 (כותב ה-CSS), V12 (רכיב — "שמור כרכיב" בתפריט), F2 ✔ (היסטוריית קבצים, ZIP). **תלויה בבעלים:** לא.
> **שני הכללים לכל פרוסת V:** במחשב — על כל המסך; כל שליטה גם בגרירה.
> **מה קיים:** בטל / חזור בזיכרון (V1a), בלי שמות; קיצורים מעטים; אין תפריט הקשר; F2b — ZIP של הפרויקט כולו.

## 1. מה בונים

הדברים הקטנים שבזכותם עורך מרגיש כמו Elementor ביום השני: לחיצה ימנית על כל דבר, "העתק סגנון" מאלמנט לאלמנט, היסטוריה שאפשר לקרוא
ולקפוץ בה, חיפוש פעולה במקלדת, ותבניות של מקטע או עמוד — שנשמרות כקבצים, ועוברות בין פרויקטים.

## 2. קריטריוני קבלה

### 2.1 תפריט הקשר (`01-gap` 1.7)

- [ ] לחיצה ימנית (במגע — לחיצה ארוכה) על אלמנט בקנבס **או** בשורה ב-Navigator: העתק · הדבק (לפני / אחרי / בתוך) · שכפל · מחק · עטוף ברובריקה
      (↕ / ↔) · הוצא מהרובריקה · בחר הורה · בחר את כל הדומים (אותה מחלקה) · העתק סגנון · הדבק סגנון · אפס סגנון · שמור כרכיב (V12) · שמור כתבנית
      (§2.4) · פתח בקוד · 🐞 לא הצלחתי לשנות את זה. פעולה שאינה אפשרית — מוצגת מושבתת **עם הסיבה** בריחוף.
- [ ] כל פעולה בתפריט — גם במקלדת (§2.3), ושמה מופיע בהיסטוריה (§2.2).

### 2.2 היסטוריה עם שמות (`01-gap` 1.13)

- [ ] לוח "🕘 היסטוריה": כל פעולה בשם קריא — "גודל · כותרת ראשית · 48 ← 56", "גרירה · כותרת בצרפתית ← מעל הכותרת בעברית", "קוד · `css/page.css`
      · 3 שורות", "המילה הזו · פירוש של 'בסטילה'". לחיצה — חזרה לנקודה (כל מה שאחריה מתבטל, ונשאר ב"חזור"). פעולות רצופות על אותו ערך (גרירת
      מחוון) — שורה אחת.
- [ ] **היסטוריה אחת לחזותי ולקוד** (`04`): עריכה בעורך הקוד של אותו קובץ נכנסת לאותה רשימה, ו-Ctrl+Z בקנבס מבטל גם אותה (ולהפך). עד 500 צעדים
      בזיכרון; **"גרסאות"** בתחתית הלוח — היסטוריית הקבצים של F2 (שמורה בשרת), עם "פתח" ו"חזור לגרסה".
- [ ] **אחרי רענון** — ההיסטוריה בזיכרון נעלמת (נאמר: "הגרסאות השמורות — למטה"); הגרסאות של F2 נשארות.

### 2.3 קיצורים וחיפוש פעולה (`01-gap` 1.14)

- [ ] Ctrl+Z / Ctrl+Y (ו-Ctrl+Shift+Z) · Ctrl+C / V / D · Delete · Esc (בחר הורה / בטל בחירה) · חיצים (אח קודם / הבא), Alt+חיצים — הזזה (V4) ·
      Ctrl+S · Ctrl+P (▶️ תצוגה חיה) · Ctrl+Shift+C / V (העתק / הדבק סגנון) · Ctrl+E — **חיפוש פעולה** · `?` — רשימת הקיצורים. ב-Mac — Cmd.
- [ ] **Ctrl+E:** חלון חיפוש על **כל** הפעולות **וכל השליטות** בפאנל, בעברית ובשמות CSS: "צל" ← קבוצת הצל של האלמנט הנבחר נפתחת ומודגשת;
      "letter-spacing" ← ריווח אותיות; "הוסף כותרת" ← הפעולה. שימוש אחרון — בראש.
- [ ] קיצור אינו פועל בתוך שדה טקסט / עריכה במקום (חוץ מ-Esc, Ctrl+Z בתוך הטקסט — של הדפדפן, ו-Ctrl+S).

### 2.4 העתק / הדבק / אפס סגנון (`01-gap` 1.6)

- [ ] **העתק סגנון:** אוסף את ההצהרות **שנכתבו לאלמנט** — בכלל של היעד שלו (`03` §4.2) וב-`style=""` — לכל מכשיר ומצב, בנפרד מהמחלקות המשותפות
      (שמוצגות: "המחלקה `btn` משותפת — להעתיק גם אותה?"). **הדבק סגנון** — על אלמנט אחד או בחירה מרובה: לפי כלל היעד של כל אחד, עם תצוגה מקדימה
      של השורות ("ייכתבו 7 הצהרות ל-3 אלמנטים").
- [ ] **בגרירה:** Alt+גרירה מאלמנט לאלמנט — "הדבק סגנון" (סמן מכחול); שחרור — אותה תצוגה מקדימה.
- [ ] **אפס סגנון:** מוחק את ההצהרות שנכתבו לאלמנט (לא של מחלקות משותפות), עם רשימה של מה יימחק. Ctrl+Z.

### 2.5 תבניות (`01-gap` 8.1, 8.2)

- [ ] **"שמור כתבנית"** (רובריקה, או העמוד כולו): נוצר `templates/<שם>/` בפרויקט — `template.html` (ה-HTML), `style.css` (הכללים שחלים רק עליו —
      אותה הצעה של V12 §2.5, **העתקה** כברירת מחדל), `template.json` (שם, סוג: מקטע / עמוד, תאריך), וצילום קטן `thumb.png` (מהקנבס). קבצים רגילים
      ב-📁; לא מתפרסמים (כלל ב-`build.php` כמו `components/*/component.json` — **שורה אחת**, בתיאום).
- [ ] בספריית ההוספה — לשונית "תבניות": גרירה לקנבס ← ה-HTML **מועתק** (לא מקושר — לקישור יש רכיב, V12), וה-CSS מתווסף לסוף `css/page.css` בבלוק עם
      הערה `/* תבנית: <שם> */`; מחלקה שכבר קיימת עם תוכן אחר ← שינוי שם אוטומטי (`-2`), עם הודעה. תבנית עמוד ← "עמוד חדש מתבנית" (V15).
- [ ] **ייצוא / ייבוא:** תבנית אחת ← ZIP (`templates/<שם>/` + קובצי המדיה שהיא מפנה אליהם, ב-`media/`); ייבוא ZIP של תבנית ← תצוגה מקדימה (הקבצים,
      התנגשויות שמות) ← הוספה. הפרויקט כולו — ה-ZIP של F2b (קיים), עם קישור מכאן.

### 2.6 כללי

- [ ] **במחשב — על כל המסך** (1920×1080, 1366×768): לוח ההיסטוריה ולשונית התבניות מתקפלים, ואינם מצמצמים את הקנבס לרוחב קבוע.
- [ ] בדיקות: `tests/browser/v13.cjs` — תפריט הקשר (כל פעולה, מושבתת עם סיבה), Ctrl+E ← שליטה, העתק / הדבק סגנון (גם Alt+גרירה) ← השורות, אפס,
      היסטוריה: שמות, קפיצה, קוד + חזותי ב-Ctrl+Z אחד, תבנית: שמירה ← הוספה לעמוד אחר ← שינוי שם מחלקה מתנגשת, ייצוא ← ייבוא.

## 3. בדיקת הבעלים (מטלה)

במחשב, על כל המסך: לחיצה ימנית על כותרת ← "העתק סגנון" ← לחיצה ימנית על כותרת אחרת ← "הדבק סגנון" · Alt+גרירה מכותרת לכותרת · 🕘 היסטוריה:
לקרוא את השמות ולקפוץ שלושה צעדים אחורה · Ctrl+E ← "צל" · לשמור את הפס כתבנית, ולהוסיף אותו שוב מתחת · לייצא את התבנית ל-ZIP.

## 4. מה לא כלול

ספריית תבניות מוכנות של הכלי — V16 (אם בכלל) · שיתוף תבניות בין משתמשים או פרויקטים בכלי — רק דרך ZIP · היסטוריה בזיכרון אחרי רענון — לא
(הגרסאות של F2 הן הזיכרון הקבוע).
