# פרוסה F1 — תשתית המפתח: DevLoop, מסך מפתח, יומן שגיאות, בדיקות

> **מקור הדרישה:** `team/PROTOCOL.md` §7 ("הבעלים הוא המפתח"). **תלות:** אין. **תלויה בתשובות הבעלים:** לא.
> **למה ראשונה:** כל פרוסה אחריה נבדקת בידי הבעלים. בלי 🐞, בלי יומן ובלי בדיקות — אין לו איך לדווח, ולנו אין איך לשחזר.

## 1. מה בונים

1. **DevLoop באפליקציה** — דרך המודול המשותף (`devloop/README.md`, "חיבור לאפליקציה"): קובץ חיבור בשרת, הפעולות בנתב,
   `DevLoop.setup` + `DevLoop.mount` בדפדפן, ו-`dev/open-items.json`. קידומת המטלות: `KM-`.
2. **איסוף שגיאות** — שרת ודפדפן, ליומן אחד.
3. **מסך מפתח** — יומן, פעולות, בדיקות תקינות, שירותי רקע.
4. **בדיקות אוטומטיות ראשונות** — על מה שנשמר מהכלי הקיים (`audit.md` 5.1).

## 2. מי רואה

"מפתח" = מי שהיום הוא הבעלים של האפליקציה (`audit.md` 4.4). **ההכרעה מי המפתח עוברת דרך פונקציה אחת** (`is_developer`),
כדי שהחלפת מערכת המשתמשים (שאלה פתוחה אצל הבעלים) תשנה מקום אחד. חבר שאינו מפתח אינו רואה את מסך המפתח ואת המטלות;
הוא **כן** רואה את 🐞 ויכול לדווח.

- [ ] מסך המטלות: רשימה, שרשור, "איך לבדוק", ראיות (PR, פריסה, commit), ו-✅ שרק המפתח לוחץ. מטלה נסגרת רק ב-✅ שלו.

### איסוף שגיאות

- [ ] **שרת:** כל חריגה, כל תשובת 5xx, וכל אזהרת PHP נרשמות עם: זמן, מזהה בקשה, הפעולה (`action`), המשתמש, הודעה, קובץ
      ושורה, ומחסנית. מזהה הבקשה חוזר בכותרת התשובה, ומופיע בהודעת השגיאה שהמשתמש רואה ("תקלה · מזהה abc123").
- [ ] **דפדפן:** `error`, `unhandledrejection`, ובקשת API שנכשלה נשלחות לשרת עם: המסך, הפעולה האחרונה, הדפדפן, גודל
      החלון, וגרסת האפליקציה. שגיאה שחוזרת — נספרת, לא מציפה (אותה חתימה: שורה אחת עם מונה).
- [ ] **מה לעולם לא נרשם:** סיסמאות, אסימונים, מפתחות, תוכן של `secrets.json`, וגוף של קובץ. נבדק בבדיקה אוטומטית
      ששולחת בקשה עם ערך מסומן ומוודאת שאינו ביומן.
- [ ] היומן חסום בגודל (ברירת מחדל: 5,000 רשומות או 30 יום — המוקדם), ומתנקה לבד.
- [ ] שגיאה בתוך מנגנון הרישום עצמו אינה מפילה את הבקשה.

### מסך המפתח

- [ ] **יומן בקשות ושגיאות** — סינון לפי זמן, סוג, משתמש ופעולה; חיפוש לפי מזהה בקשה; "📋 העתקה לצ'אט" לכל רשומה.
- [ ] **יומן פעולות (audit)** — מי עשה מה ומתי: כניסה, שמירה, פרסום, שחזור, מחיקה, שינוי חברים, שינוי הגדרות.
- [ ] **בדיקות תקינות**, כל אחת ירוק / אדום עם הסבר במילים ומה לעשות:
      המסד נפתח ונכתב, וגרסת הסכמה (`user_version`) · הרשאות כתיבה ל-`data/` ול-`data/files/` · מקום פנוי מול תקרת
      הדיסק · הרחבות PHP נדרשות (sodium, zip, pdo_sqlite, gd / imagick) · גרסת האפליקציה והקומיט · `data/.htaccess`
      חוסם גישה מהדפדפן (בקשה אמיתית שמצפה ל-403) · החיבור לאתר (`ping` חתום: עובר / נכשל, **וגרסת התוסף באתר** —

- [ ] **שירותי רקע** — לכל אחד: מתי רץ לאחרונה, התוצאה, ומתי הבא. היום: נקודת השחזור היומית, ניקוי הסל, ניקוי היומן.
- [ ] **מצב הנתונים** — מספרים בלבד: מילים, מילים עם הקלטה, הקלטות "באתר" מול "בכלי", קבצים, גרסאות, נקודות שחזור, חברים,
      גודל המסד. (עונה מהמסך על `audit.md` §7, שורות 2, 3, 5, 8.)
- [ ] כפתור "הרצת כל הבדיקות" ו"📋 העתקת הדוח".
- [ ] המסך נטען גם כשבדיקה נכשלת — בדיקה שנופלת מוצגת כאדומה ואינה שוברת את המסך.

## 4. איפה כל נתון חדש נשמר

**אין נתיב חדש תחת `data/`, ולכן לא נדרש `--exclude` חדש.** אם המימוש יחרוג מהטבלה — הקוד מודיע לבקרה לפני המיזוג.

| נתון | איפה | מוחרג בפריסה? |
| --- | --- | --- |
| מטלות, תגובות, אסימונים של DevLoop | טבלאות חדשות ב-`data/kol.sqlite` (מיגרציה מוסיפה בלבד) | כן — `data/*.sqlite*` |
| צילומי מסך וקבצים מצורפים של מטלות | `data/files/_dev/` | כן — `data/files/` |
| יומן הבקשות והשגיאות | טבלה חדשה ב-`data/kol.sqlite` | כן |
| תוצאות בדיקות התקינות וריצות שירותי הרקע | טבלה חדשה ב-`data/kol.sqlite` | כן |
| `dev/open-items.json` | בריפו — **קוד, לא נתון**; עולה בפריסה | לא צריך |
| מסד הבדיקות האוטומטיות | תיקייה זמנית של המערכת; לא ב-`data/` | לא רלוונטי |

## 5. מה לא כלול

- שום שינוי בעורך, בקבצים או בספרייה.
- שער בדיקות ב-`deploy.yml` — מחוץ ל-`kol-maroko/`; **בקשה לבקרה** (`PROTOCOL` §8).
- הרישום ב-`devloop/apps.json` וב-`.devloop.json` — **של הבקרה**; הקוד מבקש, הבקרה מבצעת ומריצה `sync.php`.

## 6. השורה שעונה על המבחן

F1 אינה משנה דבר ממה שבעל העמוד רואה בעמוד, ולכן **אינה סוגרת אף שורה של עריכה**. היא סוגרת את `01-gap` **ב-16**,
והיא התנאי לכך שהמבחן ייבדק בכלל: מ-F1 והלאה, כל דבר שהבעלים מצביע עליו ואינו מצליח לשנות נרשם ב-🐞 כמטלה פתוחה עם
צילום ויומן — ולא הולך לאיבוד.
