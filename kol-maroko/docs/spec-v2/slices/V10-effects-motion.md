# פרוסה V10 — מסגרת, צל, אפקטים, תנועה, sticky ורקע מתקדם

> **אפיון:** `03-visual-editor.md` §4.1–§4.4 (השליטות, כלל היעד), §4.3 (השורות של V10); `01-gap` 3.4, 3.6–3.8, 3.10, 4.10–4.13.
> **תלות:** V3 (כותב ה-CSS, בוחר הצבע, יחידות), V5 (שכבות רקע, הספרייה), V6 (ידיות גודל ומיקום על הקנבס, `position`), V7 (מכשיר),
> V8 (מצבים — ריחוף). **תלויה בבעלים:** לא.
> **שני כללים שהבקרה קבעה לכל פרוסת V (2026-11-12, מתלונת הבעלים):** (1) **במחשב — העורך על כל המסך, בלי ריק בצדדים**; (2) **כל
> שליטה גם בגרירה על הקנבס**, לא רק בשדה — בכל מקום שיש לה גודל או כיוון שאפשר לראות.

## 1. מה בונים

אחרי V10 כל מה שנשאר ב"עיצוב" וב"מתקדם" של Elementor — מסגרת, פינות, צל, שקיפות ופילטרים, מסיכה, מפריד צורה, וידאו ברקע,
מצגת, סיבוב והגדלה, מעבר, אנימציית כניסה, אפקטי גלילה, ונדבק — **נערך בפאנל ובגרירה, ונכתב ל-CSS (ו-HTML) רגיל בקבצים.**
מה שדורש JS — בקובץ מערכת אחד, גלוי וניתן לעריכה.

## 2. קריטריוני קבלה

### 2.1 מסגרת ופינות (`01-gap` 3.6)

- [ ] **מסגרת:** סוג (`solid`, `dashed`, `dotted`, `double`, `none`…), עובי וצבע — **לכל צד** או לכולם יחד (נעילת צדדים, כמו בשוליים של V3).
      נכתב בקיצור (`border: 2px solid var(--c)`) כשכל הצדדים שווים, ובמאפיינים לוגיים (`border-inline-start`) כשלא.
- [ ] **רדיוס:** לכל פינה (`border-start-start-radius`…) או לכולן; יחידות חופשיות; צורה אליפטית (`40px / 20px`).
- [ ] **בגרירה:** כשנבחר אלמנט — **ידית רדיוס** בכל פינה (נקודה קטנה במרחק הרדיוס מהפינה). גרירה ← רדיוס לכל הפינות; עם Alt ← לפינה אחת.
      ידית שאינה נוחה בטלפון — "לחיצה ארוכה על פינה" (V14).

### 2.2 צל וקו מתאר (`01-gap` 3.7)

- [ ] **צל קופסה — כמה שכבות:** לכל שכבה X, Y, טשטוש, פריסה, צבע (עם שקיפות ומשתנה), פנימי; הוספה, הסרה וגרירה לסדר. **צל טקסט** — אותו דבר
      (בלי פריסה ופנימי). **קו מתאר:** סוג, עובי, צבע, היסט.
- [ ] **בגרירה:** כשקבוצת הצל פתוחה — ידית "שמש" על האלמנט: גרירה מזיזה X/Y של השכבה הנבחרת; גלגלת עליה — טשטוש.
- [ ] ערכים קיימים בקוד שהפאנל אינו מפרק (למשל `box-shadow` עם `var()` בתוך שכבה) — מוצגים כשורה אחת ב"מאפיינים נוספים" (§4.4), ונערכים שם; לא
      נדרסים.

### 2.3 אפקטים (`01-gap` 3.8, 3.10)

- [ ] **שקיפות** (מחוון), **פילטרים** — טשטוש, בהירות, ניגודיות, גווני אפור, גוון, רוויה, ספיה, היפוך, צל-טיפה — כל אחד מחוון עם איפוס; **פילטר
      רקע** (`backdrop-filter`); **מצב מיזוג** (`mix-blend-mode`).
- [ ] **מסיכה:** תמונה מהספרייה / מעבר צבע / צורה מוכנה (עיגול, משושה, גל…) — `mask-image` עם גודל, מיקום וחזרה (אותן שליטות של רקע ב-V5),
      ועם `-webkit-mask-*` לצידו (נכתב בזוג, ומוצג כאחד).
- [ ] **מפריד צורה** בראש / בתחתית רובריקה: בוחרים צורה (גל, משולש, עננים, הר, זיגזג… — 10 לפחות), צבע, גובה, רוחב, היפוך, "מעל התוכן". נכתב
      כ**אלמנט רגיל** — `<div class="shape shape-top" aria-hidden="true"><svg …></svg></div>` — עם `fill: currentColor` ו-CSS במחלקה; **נבחר, נערך,
      נמחק** כמו כל אלמנט, וה-SVG — קוד גלוי. (לא פסאודו-אלמנט, כדי שיהיה מה לבחור.)
- [ ] הצורות המוכנות — `assets/editor-shapes/*.svg` של הכלי; בהוספה הן **מועתקות לקובץ** (inline), ואין קישור לכלי.

### 2.4 תנועה (`01-gap` 4.10, 4.11, 4.13)

- [ ] **Transform:** הזזה, סיבוב, קנה מידה (X/Y/נעול), הטיה, היפוך אופקי / אנכי, נקודת ציר (`transform-origin`). **בגרירה:** ידית סיבוב מעל
      האלמנט (Shift — בקפיצות של 15°); נקודת הציר — נקודה שאפשר לגרור; קנה מידה — ידיות הפינה של V6 עם Ctrl (V6 משנה רוחב/גובה, Ctrl —
      `scale`). **במצב ריחוף** (V8) — אותו דבר, וזה ה"גם בריחוף" של 4.13.
- [ ] **מעבר (transition):** מאפיין (הכול / רשימה), משך, השהיה, עקומה (רשימה + עורך `cubic-bezier` גרפי עם שתי ידיות גרירה).
- [ ] **אנימציית כניסה:** ספרייה (הופעה, החלקה מכל כיוון, הגדלה, סיבוב, קפיצה… — 12 לפחות), משך, השהיה, עקומה, "פעם אחת / בכל כניסה".
      נכתבת: `@keyframes` ב-`css/motion.css` (קובץ פרויקט, נוצר בשימוש הראשון ונוסף ל-`<head>`), ומחלקה על האלמנט (`kol-in kol-in-fade-up`)
      עם `--kol-in-delay` / `--kol-in-dur`.
- [ ] **אפקטי גלילה:** parallax (מהירות), שקיפות, טשטוש, הזזה, סיבוב, קנה מידה — לפי מיקום האלמנט במסך, עם טווח (התחלה / סוף). **CSS בלבד:**
      `animation-timeline: view()` + `animation-range`, בתוך `@supports (animation-timeline: view())`; דפדפן בלי תמיכה — האלמנט פשוט סטטי.
      **אפקטי עכבר** (הטיה בתלת-ממד, מעקב אחרי העכבר) — דורשים JS (§2.6).
- [ ] **נגישות:** כל אנימציה נכתבת בתוך `@media (prefers-reduced-motion: no-preference)`. מי שביקש פחות תנועה — רואה את המצב הסופי.

### 2.5 Sticky ורקע מתקדם (`01-gap` 4.12, 3.4)

- [ ] **Sticky:** ב"מיקום" (V6) — "נדבק למעלה / למטה", היסט, ו"עד סוף ההורה" (הסבר במילים: "נדבק כל עוד ההורה שלו על המסך"). הקנבס מראה
      את ההתנהגות בגלילה שלו (CSS בלבד — הקנבס בלי סקריפטים).
- [ ] **וידאו ברקע:** קובץ מהספרייה (לא YouTube — ש-2: נגן מוטמע לא עובד בארגז החול), תמונת פתיחה, "רק במחשב" (בטלפון — התמונה, V7).
      נכתב כ**אלמנט ראשון ברובריקה**: `<video class="bg-video" autoplay muted loop playsinline poster="…">` + CSS (`object-fit:cover`, מאחורי
      התוכן). נבחר מה-Navigator, ונערך כמו וידאו (V2).
- [ ] **מצגת רקע:** 2–10 תמונות, משך לכל אחת, מעבר (דהייה / החלקה), "קן ברנס". **CSS בלבד:** שכבות + `@keyframes` עם השהיות מחושבות. כל
      תמונה — שכבה שנבחרת ב-Navigator.

### 2.6 קובץ המערכת `js/kol-motion.js`

- [ ] נוצר בפרויקט **רק כשנבחר אפקט שדורש JS**: אנימציית כניסה "כשנראה במסך" (`IntersectionObserver` מוסיף `is-in`), אפקטי עכבר. קובץ מערכת
      (`02` §6, `"system"` ב-`kol.json`) — הכותרת שלו מסבירה כל תכונה, בעברית, כמו `kol-data.js`. **אין בו מילה שהגולש רואה, ואין אחסון.**
- [ ] בלי הקובץ (נמחק, או JS כבוי) — אנימציית כניסה מוצגת במצב הסופי (המחלקה `kol-in` מחכה ל-`is-in` רק בתוך `.kol-motion-on`, שהקובץ
      מוסיף ל-`<html>`). **אף פעם לא תוכן שנשאר שקוף.**

### 2.7 בקנבס

- [ ] אנימציות **מושהות** בקנבס כברירת מחדל (CSS של העורך, לא של הקובץ), עם "▶ הפעל אנימציות" בסרגל, ו"↻ הצג שוב" לאנימציית כניסה של
      האלמנט הנבחר. אפקט גלילה — מחוון "מיקום גלילה מדומה" בפאנל, כדי לראות כל נקודה בטווח.
- [ ] **במחשב — על כל המסך:** הקבוצות החדשות נכנסות לפאנל הקיים בלי להוסיף לו רוחב קבוע; בדיקת דפדפן ב-1920×1080 ו-1366×768 — הקנבס
      והפאנל ממלאים את הרוחב, בלי פס ריק בצדדים.
- [ ] **כל הכתיבה — כלל היעד** (`03` §4.2): מחלקה / מחלקה משותפת / תגית / כלל קיים / `style=""`; מכשיר (V7) ומצב (V8) — לכל שליטה כאן.
- [ ] Ctrl+Z לכל שינוי; "קוד" מראה את השורות שנכתבו.

### 2.8 בדיקות

- [ ] `tests/browser/v10.cjs`: לכל קבוצה — שינוי בפאנל ← השורה בקובץ ← הקנבס (צילום מסך מושווה) ← Ctrl+Z; גרירת ידית רדיוס, צל, סיבוב, נקודת ציר
      ← הערך בקובץ; מפריד צורה נבחר ונמחק; וידאו ברקע ב-Navigator; `kol-motion.js` נוצר רק עם כניסה "כשנראה"; `prefers-reduced-motion`
      (אמולציה) ← אין תנועה; 1920×1080 בלי ריק בצדדים.
