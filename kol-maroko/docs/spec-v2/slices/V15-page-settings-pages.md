# פרוסה V15 — הגדרות העמוד, ה-`<head>`, ועמודים נוספים

> **אפיון:** `03-visual-editor.md` §3 (ה-`<head>` ב-Navigator ← "הגדרות העמוד"); `02-project-model.md` §5 (`entry`, `pages`); `07` §3 (נתיב ← `index.html`
> שבתיקייה, `404.html` של החבילה); `01-gap` ע-18, 8.5, 8.6, 8.7.
> **תלות:** V1 (Navigator), V2 (שדות טקסט), V5 (בורר תמונה מהספרייה), F2 ✔ (מנוע הקבצים, היסטוריה), M1 ✔ / M2 ✔ (בנייה והגשה של כמה עמודים ו-404 —
> **כבר עובדות**). **תלויה בבעלים:** **[ש-3]** — ברירת המחדל א' (מותר, הגבול הוא הכתובת). תשובה ב' ⇒ רק §2.4 נשמטת; השאר נשאר.
> **שני הכללים:** במחשב — על כל המסך; כל שליטה גם בגרירה.
> **מה קיים:** ה-`<head>` מוצג ב-Navigator תחת "ראש העמוד" ונערך רק ב"פתח בקוד". הבנייה וההגשה תומכות ב-`about/index.html` וב-`404.html`, אבל אין
> בעורך דרך ליצור עמוד, לעבור בין עמודים או לערוך כותרת / תיאור / תמונת שיתוף בלי קוד.

## 1. מה בונים

שני מסכים ובורר: **"⚙️ הגדרות העמוד"** — כל מה שבתוך ה-`<head>` ומה שעל ה-`<html>` וה-`<body>`, כטופס שכותב ל-HTML עצמו (אין מקום שני); **"📄 עמודים"**
— יצירה, שכפול, שינוי שם וכתובת, מחיקה, סדר, דף ה-404; ו**בורר עמוד** בסרגל העורך. הכול — אותם קבצים שבעץ, כך שהקוד והעורך תמיד זהים.

## 2. קריטריוני קבלה

### 2.1 ⚙️ הגדרות העמוד — טופס מעל ה-HTML

- [ ] נפתח מהסרגל, מ"ראש העמוד" ב-Navigator, ומתפריט ההקשר על `<body>`. כל שדה **קורא מה-HTML וכותב אליו** דרך המודל של העורך (V2) — שינוי =
      patch על הקובץ, נראה ב"קוד" כשורה שהשתנתה, ב-Ctrl+Z אחד, ובהיסטוריה עם שם (V13: "הגדרות · כותרת · 'קול מרוקו' ← 'מילון מרוקאי'").
- [ ] **השדות:**
      | שדה | נכתב ל- |
      | --- | --- |
      | כותרת הלשונית | `<title>` |
      | תיאור (גוגל) — עם מונה תווים ותצוגת תוצאה בגוגל | `<meta name="description">` |
      | תמונת שיתוף — מהספרייה (V5), עם תצוגת כרטיס וואטסאפ / פייסבוק | `og:image` (+ `og:title`, `og:description` — "כמו הכותרת / התיאור" כברירת מחדל, ניתנים לניתוק) |
      | סמל (favicon) — תמונה מהספרייה | `<link rel="icon">` (+ `apple-touch-icon`) |
      | שפה וכיוון | `<html lang dir>` |
      | צבע הדפדפן בטלפון | `<meta name="theme-color">` |
      | גוגל: "לא להופיע בחיפוש" | `<meta name="robots" content="noindex">` |
      | כתובת קנונית | `<link rel="canonical">` |
      | רקע הגוף, גופן ברירת המחדל | **לא כאן** — בחירת `<body>` בקנבס ועריכה בפאנל (V3/V5/V9). בטופס — קישור "ערוך את הגוף ←" |
- [ ] שדה שאין לו תגית — ריק; מילוי **יוצר** את התגית במקום הצפוי ב-`<head>`; ריקון **מסיר** אותה. תגית שכתובה בקוד בצורה אחרת (למשל `property` מול `name`,
      או פעמיים) — מוצגת כמו שהיא, נערכת במקומה, והטופס אומר "נמצאו שתיים — הראשונה קובעת" עם "פתח בקוד".
- [ ] **"עוד בראש העמוד"** — כל תגית ב-`<head>` שהטופס אינו מכיר (`meta` אחר, `link`, `script`, `style`) ברשימה: שם, תקציר, ✎ (עריכת התכונות כרשימת
      שם=ערך), 🗑, ⇅ (גרירה לסידור), "פתח בקוד". **אין תגית ב-`<head>` שאינה נגישה מהמסך.**

### 2.2 קוד מותאם ל-`<head>` ולסוף ה-`<body>` (8.7)

- [ ] שני שדות קוד (Monaco, כמו `</> קוד`): "בראש העמוד" ו"בסוף העמוד". **אין קובץ נסתר:** הם האזור שבין שתי הערות סימון ב-`index.html` —
      `<!-- kol:head -->…<!-- /kol:head -->` ו-`<!-- kol:body-end -->…<!-- /kol:body-end -->` — נוצרות במילוי הראשון, ונראות בקוד כמו כל שורה.
- [ ] קוד שבעל העמוד מדביק (סטטיסטיקה, פיקסל) — רץ **רק בעמוד** (ארגז החול של M2; ה-CSP של C1 — מקור חיצוני חדש מתווסף לרשימה הגלויה **[ש-12]**,
      עם הודעה "כדי שהקוד הזה ירוץ, נוסף `googletagmanager.com` לרשימת המקורות"). בקנבס — **אינו רץ** (`03` §2) ומוצג כ"קוד בראש העמוד · ▶️ תצוגה חיה".

### 2.3 בורר עמוד בעורך

- [ ] בסרגל: "📄 index ▾" — רשימת העמודים (שם + כתובת), חיפוש, ➕. מעבר שומר את העמוד הנוכחי (אין שינוי שאובד) ופותח את הבא באותו מצב מכשיר.
- [ ] העמוד הפתוח נזכר לכל משתמש. "▶️ תצוגה חיה" פותחת את העמוד שבעורך, לא תמיד את `entry`.

### 2.4 📄 עמודים (8.5; **[ש-3]** א')

- [ ] **רשימה:** כל עמוד לפי `pages` (`"auto"` — כל `.html` מחוץ ל-`components/`), עם: שם (מ-`<title>`), כתובת (`…/lexicon/about/`), מתי שונה, ⭐ לעמוד
      הראשי (`entry`), 🚫 לדף ה-404.
- [ ] **➕ עמוד חדש:** שם וכתובת (נגזרת, ניתנת לשינוי, `^[a-z0-9-]+(/[a-z0-9-]+)*$`) · "מתחיל מ": ריק (`<head>` עם ה-CSS המשותף של `kol.json` `styles`) /
      שכפול של עמוד קיים / תבנית עמוד (V13). נוצר `about/index.html` דרך מנוע הקבצים (גרסה בהיסטוריה) ונפתח בעורך.
- [ ] **שינוי כתובת:** מזיז את הקובץ (`about/` ← `odot/`), ו**מעדכן קישורים** בכל העמודים (`href="about/"`, `href="/lexicon/about/"`, `../about/`) — תצוגת
      שינויים כמו קשירות N2 §3.3 (רשימה, סימון לכל אחת, עסקה אחת). קישור שנכתב ב-JS — "לבדיקה ידנית", לא מוחלף.
- [ ] **שכפול**, **מחיקה** (לסל של F2, עם "X עמודים מקשרים אליו" ושחזור), **"קבע כעמוד הראשי"** (`entry` ב-`kol.json`), **"קבע כדף 404"** (שינוי שם
      ל-`404.html`, או יצירה מתבנית "לא נמצא" עם קישור לראשי).
- [ ] **סדר** — גרירה ברשימה (וגם ↑ ↓); נשמר ל-`pages` כרשימה מפורשת ב-`kol.json` (ומאותו רגע `"auto"` מוחלף ברשימה — הטופס אומר זאת, ו"חזור לאוטומטי").
      הסדר משמש את בורר הקישור (§2.5) ותפריט ניווט שנוצר מרכיב (V12/V16).
- [ ] **הגבול:** כתובת מחוץ ל-`/lexicon/` אינה אפשרית — אין שדה ואין נתיב (`..`, `/` בהתחלה, `//`) שמגיע לשם; שרת — 400. (הבידוד — כלל העל, חצי 1.)

### 2.5 קישור לעמוד

- [ ] בבורר הקישור (V2): לשונית "עמוד בפרויקט" — העמודים לפי הסדר, ועוגנים (`id`) בתוכם; נכתב יחסי (`about/`). קישור לעמוד שנמחק — מסומן באדום
      בקנבס ובבדיקת הפרסום של M1 ("קישור שבור: `about/`").

### 2.6 פרסום ובדיקה

- [ ] "מה ישתנה" (M1) מונה עמודים: חדש / שונה / נמחק / כתובת שהשתנתה. כתובת שהשתנתה — אזהרה "קישורים מבחוץ לכתובת הישנה יקבלו 404" עם "השאר הפניה":
      יוצר `odot-old/index.html` עם `<meta http-equiv="refresh">` + `<link rel="canonical">` (קובץ רגיל, נראה בעץ — אין מנגנון נסתר).
- [ ] בדיקה: פרויקט עם `index.html`, `about/index.html`, `404.html` — נבנה, מוגש ב-`fake-wp.php` (M2): `/lexicon/` ← index, `/lexicon/about/` ← about,
      `/lexicon/xyz` ← 404.html בסטטוס 404; ה-`<title>`, `og:image` ו-favicon בתשובה כמו בטופס.

### 2.7 על כל המסך, ובטלפון

- [ ] **במחשב:** "הגדרות העמוד" — לוח רחב בצד הקנבס (הקנבס נשאר גלוי ומתעדכן — כותרת, צבע הדפדפן), לא חלון קטן במרכז; "📄 עמודים" — מסך מלא עם
      הרשימה ותצוגה מקדימה של העמוד הנבחר. 1920×1080 ו-1366×768 — בלי ריק בצדדים (בדיקת דפדפן).
- [ ] **בטלפון:** שניהם גיליון (V14); הסידור — לחיצה ארוכה + ↑ ↓.

## 3. מה לא כלול

עמודים דינמיים לכל מילה (`/lexicon/word/bastila/`) — לא בדרישה; היום עמוד אחד עם `#`. מפת אתר (`sitemap.xml`) — קובץ רגיל שבעל העמוד יכול ליצור; יצירה
אוטומטית — אם יבקש. ה-`<head>` של האתר המארח (M-B / M-C) — M4.

## 5. השורה שעונה על המבחן
