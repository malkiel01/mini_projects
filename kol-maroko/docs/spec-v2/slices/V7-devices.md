# פרוסה V7 — מכשירים: עריכה לפי גודל מסך

> **אפיון:** `03-visual-editor.md` §8.1, §4.1 ("מכשיר"), §4.2 (מכשיר ← `@media`); `02-project-model.md` §5 (`breakpoints` ב-`kol.json`).
> **תלות:** V3 (כלל היעד, השליטה המספרית). V4–V6 רצויות — כל שליטה שכבר קיימת מקבלת את המכשיר. **תלויה בבעלים:** לא.
> **מה קיים בקוד (V3, `README.md` חלק ד):** הכול נכתב לכלל הבסיסי. כשהערך הנראה מגיע מתוך `@media`, `Design.effTarget`
> מפנה את הכתיבה להצהרה ההיא, והפאנל אומר "בתוך @media". הקנבס משנה רוחב, אבל אין "מצב מכשיר".

## 1. מה בונים

אחרי V7 בעל העמוד **בוחר "טלפון", ומשנה את העמוד כפי שהוא נראה בטלפון — בלי לשנות את המחשב.** כל שליטה בפאנל, כל ידית
וכל גרירה של V3–V6 כותבות למכשיר שנבחר.

1. **בורר מכשיר** בסרגל העליון: מחשב (הבסיס) · טאבלט · טלפון — מתוך `kol.json`, עם הוספה, שינוי ומחיקה.
2. **כתיבה למכשיר:** ההצהרה נכתבת בתוך `@media` של נקודת השבירה.
3. **ירושה גלויה:** לכל ערך — "נכתב כאן" / "עובר ממחשב" / "עובר מטאבלט".
4. **הסתרה לפי מכשיר, וסדר שונה לפי מכשיר.**

## 2. קריטריוני קבלה

### בורר המכשיר

- [ ] בסרגל העליון: 🖥 מחשב · 📱 טאבלט · 📱 טלפון — הרשימה מ-`breakpoints` ב-`kol.json`, בסדר יורד של `max`. בחירה משנה את
      רוחב הקנבס ל-`preview` של הנקודה, ומסמנת את כל הפאנל בצבע המכשיר. הבחירה נשמרת לעמוד, בדפדפן.
- [ ] Ctrl+Shift+M — מעבר בין המכשירים. ידית הרוחב החופשי של הקנבס נשארת; ברוחב שאינו `preview` — הבורר מראה לאיזה מכשיר
      הרוחב **שייך** ("טלפון · 430px").
- [ ] **"נקודות שבירה…"**: רשימה נערכת — שם, `max`, `preview`; הוספה ומחיקה. נכתב ל-`kol.json` (עסקה אחת). **שינוי `max`
      של נקודה קיימת** מציע לעדכן גם את כל ה-`@media` שנכתבו בשבילה ("12 כללים ב-2 קבצים") — עסקה אחת, עם תצוגה מקדימה.
      מחיקת נקודה שיש לה כללים — אזהרה: הכללים נשארים בקבצים ("חלים כשהמסך צר מ-767px"), ואינם נמחקים בשקט.
- [ ] `kol.json` בלי `breakpoints` — ברירת המחדל של `02` §5 (1024 / 767), והעורך כותב אותה לקובץ בשינוי הראשון.

### הכתיבה

- [ ] במכשיר שאינו מחשב, כל כתיבה של V3–V6 נכתבת ל**אותו בורר של כלל היעד**, בתוך `@media (max-width: <max>px)`:
      - יש כבר כלל כזה (אותו בורר, אותו `@media`, אותו קובץ) ← ההצהרה נכתבת בו.
      - יש בקובץ בלוק `@media` זהה ← הכלל החדש נכתב **בתוכו**, בסופו.
      - אין ← בלוק חדש **מיד אחרי הכלל הבסיסי** (`03` §4.2), בסגנון הקובץ.
      יעד "רק האלמנט הזה" (`style=""`) **אינו יכול** לקבל מכשיר: העורך מציע ליצור מחלקה (V3 — שם קריא), ואומר למה.
- [ ] **נקודת שבירה = התנאי שב-`kol.json`, בדיוק.** `@media` שנכתב ביד ותנאיו זהים (`max-width: 767px`, `width <= 767px`,
      רווחים שונים) — מזוהה כאותו מכשיר. תנאי אחר (`min-width`, 782px, `prefers-reduced-motion`, `print`) — **אינו** מכשיר:
      ההצהרות שבו מוצגות ונערכות כמו שהן, עם התנאי ("חל כשהמסך צר מ-782px"), כמו היום ב-`effTarget`.
- [ ] **ערך שנראה במכשיר מגיע מ-`@media` שאינו מכשיר** (כך בערכה: 782px): הפאנל מציע — לערוך את ההצהרה ההיא (ברירת
      המחדל, כמו ב-V3), או לכתוב למכשיר הנוכחי, ואומר מי ינצח.
- [ ] כל כתיבה של V4–V6 שהיא **CSS** (כיוון, רווח, פריסה, גודל, מיקום חופשי, היסטים, `z-index`, רקע) — לפי מכשיר.
      כתיבה שהיא **HTML** (הזזה, הוספה, מחיקה, תגית, טקסט, `src`) — חלה על כל המכשירים, והפאנל אומר זאת בזמן שמכשיר נבחר:
      "שינוי מבנה חל על כל המכשירים".
- [ ] **מיקום חופשי במכשיר:** "✥ מיקום חופשי" בטלפון כותב `position` והיסטים ל-`@media`; "חזרה לזרימה במכשיר הזה" כותב
      `position: static` ל-`@media` (ולא מוחק את הבסיס). אלמנט ממוקם שאין לו ערך במכשיר הנוכחי — מסומן (`03` §7.2).
- [ ] הסימון "הונח במחשב — לא נבדק ברוחב אחר" של V6 מוחלף בסימון האמיתי: "יש מיקום למחשב; בטלפון — עובר ממחשב".

### ירושה ואיפוס

- [ ] **לכל ערך בפאנל — סמל מכשיר:** ● נכתב כאן · ○ עובר ממחשב / מטאבלט (עם הערך) · ⚠ נכתב כאן אבל נדרס.
      ריחוף מציג את הערך בכל מכשיר; לחיצה על "עובר מ-" — עוברת למכשיר ההוא.
- [ ] **"איפוס במכשיר הזה"** מוחק רק את ההצהרה שבתוך ה-`@media`; הכלל שנשאר ריק נמחק, ובלוק `@media` שנשאר ריק — נמחק
      (כאן כן, כי העורך יצר אותם או שהם ריקים לגמרי; בלוק עם הערה — נשאר).
- [ ] **"העתק לכל המכשירים"** / "החל מהמכשיר הזה ומטה" — פעולות בתפריט הערך.
- [ ] ידיות הקנבס (מרווח, גודל, מיקום) מציגות את הערך **של המכשיר הנוכחי**, וגרירתן כותבת אליו.

### הסתרה וסדר לפי מכשיר

- [ ] **"הסתר במכשיר הזה"** (👁 בסרגל, ובלשונית "מתקדם" ← "מכשירים": תיבות מחשב / טאבלט / טלפון): נכתב `display: none`
      ב-`@media`. "הצג" — מוחק אותה; אם `display` הבסיסי הוא `none` — כותב את ה-`display` הקודם של האלמנט (flex / grid…).
      בקנבס האלמנט המוסתר במכשיר מוצג **שקוף למחצה ומקווקו**, ונבחר — לא נעלם.
- [ ] **סדר שונה במכשיר:** גרירה (V4) בזמן שמכשיר נבחר שואלת: **"להזיז בכל המכשירים (ב-HTML), או רק כאן (`order`)?"** —
      ברירת המחדל: בכל המכשירים. "רק כאן" כותב `order` לאחים שנדרשים, ב-`@media`, ו-`display:flex` להורה אם אינו flex/grid
      (נאמר לפני). "היפוך סדר" ברובריקה — `flex-direction: *-reverse` ב-`@media`.
- [ ] ב-Navigator: אלמנט מוסתר במכשיר הנוכחי מסומן; אחים עם `order` — הסדר הנראה לצד סדר המקור.

### כללי

- [ ] כל שינוי: עסקה עם שם שכולל את המכשיר ("גודל · כותרת ראשית · טלפון · 48 ← 32"); ביטול מחזיר קבצים זהים.
- [ ] הרתמה — **K2 לכל סוג כתיבה חדש:** הצהרה בכלל קיים בתוך `@media` · כלל חדש בתוך בלוק קיים · בלוק חדש אחרי הבסיס ·
      מחיקת הצהרה אחרונה ← מחיקת הכלל והבלוק · עדכון `max` בכל הקבצים · `kol.json`. **שקילות המודל** אחרי כל אחת; ובדיקה ש-
      `@media` מקונן ו-`@supports` סביב `@media` נקראים נכון.
- [ ] **איפה הנתונים:** `kol.json` וקובצי ה-CSS של הפרויקט; הבחירה של המכשיר — בדפדפן. אין נתיב חדש בשרת.
- [ ] `v7.cjs` על `index.html` המוסב: בטלפון — גודל הכותרת 32, במחשב נשאר 48; הסתרה בטלפון ← נראית במחשב; `order` רק בטלפון;
      ביטול עד ההתחלה — קבצים זהים. ב-390px ו-1280px.

## 3. בדיקת הבעלים (מטלה)

על העמוד האמיתי: לבחור "טלפון" · להקטין את הכותרת הראשית ולקרב את הכותרות · להסתיר את שורת הקרדיט בטלפון בלבד · להחזיר
את הכותרת שהונחה בפינה (V6) לזרימה **רק בטלפון** · לחזור ל"מחשב" — הכול כמו שהיה · לפתוח "▶️ תצוגה חיה" בטלפון אמיתי ·
Ctrl+Z עד ההתחלה. "🐞" על כל דבר שהשתנה גם במכשיר השני.

## 4. מה לא כלול

מצבים (`:hover`) לפי מכשיר — V8 (אותו מנגנון, צירוף של שניהם) · עריכה **מהטלפון** עצמו (גיליונות, מגע) — V14 · `@container` —
נכתב ב"מאפיינים נוספים" ובקוד · תנאים שאינם רוחב (`orientation`, `prefers-color-scheme`) כמצב מכשיר — לא בתכנון; נערכים כמו שהם.

## 5. השורה שעונה על המבחן

V7 סוגרת: **ע-17** (התנהגות בטלפון ובטאבלט), `01-gap` 4.14, 5.1–5.5 — וכך גם את החלק של **ב-2, ב-4, ב-6** שנוגע למסך
צר: כל מרווח, גודל ומיקום שנקבעו במחשב — נקבעים גם בטלפון, בנפרד.

**מה נשאר:** עריכה מתוך טלפון אמיתי — V14; מצב ריחוף לפי מכשיר — V8; ושינוי מבנה (HTML) שונה לכל מכשיר אינו קיים
כמושג — יש "רק כאן" (`order`, הסתרה). שני אלמנטים שונים לשני מכשירים = שני אלמנטים, כל אחד מוסתר באחד — זו הדרך, והיא נאמרת.
