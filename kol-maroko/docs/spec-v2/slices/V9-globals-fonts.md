# פרוסה V9 — גלובליים: גופנים, משתנים, ברירות מחדל לתגיות

> **אפיון:** `03-visual-editor.md` §8.3; `02-project-model.md` §5 (`styles.tokens`, `styles.base`). **תלות:** V3 (בוחר
> הצבע, רשימת הגופנים, "צבעים בעמוד"); V8 רצויה (התגית כיעד). **תלויה בבעלים:** **[ש-12]** (גופן מרשת חיצונית — ברירת
> המחדל: מותר, ברשימה גלויה). נכתב לפי ברירת המחדל.
> **מה קיים בקוד (V3, `design.js` — `fonts()`):** רשימת הגופנים = Google Fonts שהעמוד טוען + `@font-face` בקבצים + משפחות
> שבשימוש + גופני מערכת; הקלדה חופשית של `font-family`. "צבעים בעמוד" מציג משתני צבע (`var(--…)`), ואינו עורך אותם.
> **החלוקה:** כמו שביקשה הבקרה — הליבה היא **הוספת גופן**. המשתנים וברירות המחדל לתגיות נשארים כאן (`03` §15): גופן
> שהועלה הוא משתנה ב-`tokens.css`, והתגית היא היעד שבו משתמשים בו לכל העמוד.

## 1. מה בונים

אחרי V9 בעל העמוד **מוסיף גופן משלו** (קובץ או Google Fonts), **משנה צבע אחד ורואה אותו משתנה בכל העמוד**, וקובע איך
נראית כל כותרת `h2` בעמוד — בלי לבחור אחת-אחת.

1. **גופנים:** העלאה, Google Fonts, "הבא לפרויקט", ניהול.
2. **משתנים:** צבעים, גופנים, מידות — רשימה נערכת, יצירה מערך, קשירה מכל שליטה.
3. **ברירות מחדל לתגיות** — `css/base.css`, באותו פאנל.
4. **מסך "סגנון כללי"** שמרכז את שלושתם.

## 2. קריטריוני קבלה

### גופנים — הליבה

- [ ] **"＋ הוסף גופן"** בבורר הגופן (V3) ובמסך "סגנון כללי". שלוש דרכים:
      1. **העלאת קובץ** (`woff2`, `woff`, `ttf`, `otf`; כמה קבצים יחד — משקלים ונטויים): הקבצים נשמרים ב-`media/fonts/`;
         המשפחה, המשקל והסגנון **נקראים מהקובץ** (טבלת `name` / `OS/2`), ומוצגים לאישור ולתיקון. נכתב `@font-face` לכל
         קובץ ב-`tokens.css` (`font-display: swap`, `src: url('../media/fonts/…') format('woff2')`).
      2. **Google Fonts:** חיפוש ברשימה (נטענת דרך השרת שלנו, לא מהדפדפן — `connect-src 'self'`), בחירת משקלים, תצוגה
         מקדימה בטקסט עברי. נכתב `<link>` ל-`fonts.googleapis.com` ב-`<head>` של כל עמוד (או `@import` ב-`tokens.css`, לפי
         מה שהעמוד כבר עושה). הגופן מופיע ברשימת המשאבים החיצוניים בפרסום **[ש-12]**.
      3. **"הבא לפרויקט"** לגופן חיצוני קיים (Google Fonts שהעמוד כבר טוען): השרת מוריד את קובצי ה-`woff2`, כותב `@font-face`
         מקומי, ומציע להסיר את ה-`<link>`. אחרי זה הגופן אינו בקשה חיצונית — לא בעורך ולא אצל הגולש (`C1` §2א).
- [ ] **אחרי ההוספה הגופן זמין מיד** בכל בורר גופן, עם תצוגה מקדימה בשמו; בחירה כותבת `font-family` עם **גופן גיבוי** מתאים
      (`'Assistant', sans-serif`), וכשיש משתנה לגופן — `var(--font-…)` (למטה).
- [ ] **בורר המשקל** מציג רק את המשקלים שהגופן באמת מספק (מקבצים מקומיים — לפי `@font-face`; Google — לפי ה-`<link>`), ו"הוסף
      משקל" מאותו מקור. גופן משתנה (variable) — מחוון רציף בטווח שלו.
- [ ] **ניהול:** רשימת הגופנים בפרויקט — שם, מקור (קובץ / Google / מערכת), משקלים, משקל הקבצים בק"ב, **איפה בשימוש** (כמה
      כללים; ריחוף מסמן בקנבס). מחיקת גופן בשימוש — אזהרה עם הרשימה, ו"החלף בגופן אחר בכל מקום" (עסקה אחת).
- [ ] **גופן עברי:** בחיפוש ב-Google — סינון "תומך עברית" כברירת מחדל; בקובץ שהועלה — בדיקה שיש בו את טווח העברית,
      ואזהרה אם לא ("הטקסט העברי יוצג בגופן הגיבוי").
- [ ] קובץ שאינו גופן תקין — נדחה עם הסבר. קובץ מעל 500KB — הערה. **הקובץ נשמר כמו שהוא** (אין המרה ואין חיתוך בשרת).

### משתנים

- [ ] מסך "סגנון כללי" ← **משתנים:** כל המאפיינים המותאמים (`--…`) שמוגדרים ב-`:root` / `html` בקובצי הפרויקט (לא רק ב-
      `tokens.css` — כך גם `--ka-*` של הערכה), מקובצים לפי סוג שהעורך מזהה מהערך: **צבע · גופן · מידה · אחר**.
- [ ] לכל משתנה: שם, ערך (בשליטה המתאימה — בוחר צבע, בורר גופן, השליטה המספרית), **איפה בשימוש** (N הצהרות), מקור (קובץ,
      שורה). **שינוי ערך מתעדכן בקנבס בכל מקום** — הצהרה אחת בקובץ. שינוי שם — בכל ההופעות (`var(--x)`), עם תצוגה מקדימה.
- [ ] **מכל שליטה ב-V3–V8:** "קשר למשתנה" (בחירה מרשימת המשתנים מהסוג המתאים — כותב `var(--…)`) ו**"צור משתנה מהערך"** (שם
      מוצע מהקשר: `--color-hero-title`; נכתב ב-`tokens.css`; ההצהרה הנוכחית הופכת ל-`var()`; ו"החלף גם ב-N מקומות אחרים
      שבהם מופיע אותו ערך" — תיבת סימון, עם הרשימה).
- [ ] ערך שקשור למשתנה מוצג בפאנל כשם המשתנה (צ'יפ), עם הערך המחושב; "נתק" — כותב את הערך במקום ה-`var()`.
- [ ] משתנה שמוגדר מחדש בתוך `@media` או בבורר אחר — מוצג עם כל ההגדרות; עריכה לפי מכשיר (V7).
- [ ] **`url()` בתוך ערך של משתנה** — לפי ההכרעה ב-`03` §4.1 ("כתובת בתוך ערך"): כתובת חיצונית נכתבת, מסומנת, ונכנסת לרשימת
      המשאבים החיצוניים.

### ברירות מחדל לתגיות

- [ ] "סגנון כללי" ← **תגיות:** גוף הטקסט (`body`), `h1`–`h6`, פסקה, קישור (ומצביו — V8), כפתור, תמונה, שדה טופס, רשימה.
      בחירה פותחת את **אותו פאנל** (עיצוב, מתקדם) עם היעד = הכלל של התגית ב-`styles.base`; התצוגה המקדימה — דף דוגמה של
      כל התגיות, ומתג "הצג על העמוד".
- [ ] כשכלל של מחלקה בעמוד דורס את התגית (כמעט תמיד בערכה המוסבת) — הפאנל אומר כמה אלמנטים **לא** ישתנו, ומסמן אותם.
- [ ] **הגדרות פריסה כלליות** (`01-gap` 6.4): רוחב תוכן מרבי ורווח ברירת מחדל — כמשתנים (`--content-max`, `--gap`) ב-
      `tokens.css`, מוצעים בשליטות של V6.

### כללי

- [ ] כל שינוי: עסקה עם שם; ביטול מחזיר קבצים זהים — **כולל קובצי גופן שהועלו** (ביטול ההעלאה מעביר אותם לסל, F2).
- [ ] הרתמה — K2 לכל סוג כתיבה חדש: `@font-face` ב-`tokens.css` · `<link>` ב-`<head>` של כל העמודים · הסרת `<link>` · הגדרת משתנה
      חדש ב-`:root` · שינוי ערך משתנה · החלפת ערך ב-`var()` ב-N מקומות · שינוי שם משתנה · כלל תגית ב-`base.css`. **שקילות המודל.**
- [ ] **בדיקת קלט:** שם משפחה ושם קובץ עם מרכאות, `<`, `)` — עוברים את `checkValue`; קובץ גופן אינו מוגש כ-HTML (`files.php` —
      `Content-Type` לפי הסוג, `nosniff`).
- [ ] **איפה הנתונים:** קובצי הגופן — `media/fonts/` במאגר הפרויקט הקיים (F2); רשימת Google Fonts — מטמון בשרת תחת
      `kol-maroko/data/` **אם** נשמרת לקובץ — אז **`--exclude` חדש ב-`deploy.yml` לפני הקוד** (בקשה לבקרה). עדיף: בזיכרון / במסד הקיים.
- [ ] `v9.cjs`: העלאת `woff2` ← `@font-face` נכתב ← הכותרת בגופן החדש בקנבס ובתצוגה החיה · שינוי `--ka-navy` ← הפס והכפתורים
      משתנים · `h2` ב-`base.css` · ביטול עד ההתחלה — קבצים זהים.

## 3. בדיקת הבעלים (מטלה)

להעלות קובץ גופן עברי מהמחשב ולשים אותו על הכותרות · להוסיף גופן מ-Google ולהביא אותו לפרויקט · לשנות את הצבע הכחול של
הערכה פעם אחת ולראות את כל העמוד משתנה · ליצור משתנה מצבע של כותרת · לקבוע גודל ל-`h2` בכל העמוד · Ctrl+Z עד ההתחלה.

## 4. מה לא כלול

ערכת אייקונים — V16 · ערכות צבע מוכנות ("theme") — לא בתכנון · `@font-face` עם `unicode-range` וחיתוך גופן — נכתבים בקוד ·
גופני Adobe / שירותים אחרים בתשלום — כגופן חיצוני רגיל, בכתובת, בקוד.

## 5. השורה שעונה על המבחן

V9 סוגרת: **ע-15** (הגופנים של העמוד), **ע-16** (הצבעים והעיצוב הכללי), `01-gap` 6.1–6.5 (גופן), 6.7. אחריה שום צבע, גופן או
מידה "של הערכה" אינם קבועים: כולם משתנים או כללים בקבצים, נערכים במקום אחד.

**מה נשאר:** אייקונים (V16); ו-**[ש-12]** — אם הבעלים יבחר "אסור משאבים מבחוץ", Google Fonts עוברים כולם ל"הבא לפרויקט" בפרסום.
