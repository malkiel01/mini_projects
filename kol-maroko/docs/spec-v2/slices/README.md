# הפרוסות

כל פרוסה בקובץ משלה: **תלות · מה בונים · קריטריוני קבלה שאפשר לבדוק · מה לא כלול · השורה שעונה על המבחן.**
המספור הסופי והלוח — של הבקרה (`team/board.md`). השמות כאן לפי `01-gap.md` §1.

**כלל לכל פרוסה:** היא נסגרת רק כשהיא פרוסה לשרת ונבדקה על הנתונים האמיתיים; וכל קריטריון מנוסח כך שמי שלא כתב את
הקוד יכול לבדוק אותו. "השורה שעונה על המבחן" אומרת בגלוי מה הפרוסה סוגרת ב-`01-gap.md` — **ומה היא עדיין לא סוגרת.**
