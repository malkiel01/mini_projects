## 1. מה בונים

אחרי V6 בעל העמוד **מניח כותרת בכל מקום על התמונה**, קובע לכל רובריקה איך ילדיה מסתדרים, ומשנה כל גודל בגרירה.

1. **פריסה מלאה** לרובריקה: יישור, גלישה, grid; ולכל ילד — גדילה, כיווץ, יישור עצמי. (כיוון ורווח — כבר ב-V4.)
2. **גודל:** רוחב, גובה, מינימום, מקסימום, יחס, overflow — במספר ובגרירת שפות האלמנט.
3. **מיקום חופשי:** מתג, גרירה, עוגן, קווי עזר. **שכבות:** קדימה / אחורה.

## 2. קריטריוני קבלה

### פריסה — רובריקה שהיא flex

- [ ] קבוצת "פריסה" (לשונית "מתקדם"), מתחת למתג הכיוון של V4: **יישור בציר הראשי** (`justify-content`: התחלה, מרכז, סוף,
      רווח בין / סביב / שווה) · **יישור בציר הניצב** (`align-items`: התחלה, מרכז, סוף, מתיחה, קו בסיס) · **גלישה**
      (`flex-wrap`, ו-`align-content` כשיש גלישה) · רווח שורות / עמודות. כל כפתור גם כערך בהקלדה חופשית.
- [ ] **הסמלים מציירים את התוצאה בפועל** — מתחלפים לפי הכיוון (שורה / עמודה / הפוכה) ולפי `dir`: "התחלה" בשורה בעברית היא ימין.
- [ ] **לילד של רובריקת flex:** גדילה, כיווץ, בסיס (`flex-grow` / `-shrink` / `-basis`; קיצור `flex` קיים נערך בתוכו) ·
      יישור עצמי · "דחוף לקצה" (`margin-inline-start:auto` וכד') · סדר (`order`) — עם ההערה: "משנה את הסדר הנראה בלבד; לסדר
      אמיתי — גרור" (V4).
- [ ] **ידית בין שני ילדים של רובריקת-שורה משנה את החלוקה ביניהם.** מה נכתב: לשניהם `flex-grow` (כשהבסיס 0 — כמו במבנים
      המוכנים של V4), אחרת `flex-basis` באחוזים לזה שנגרר. האחוזים רצים ליד הסמן; Shift — צעדים של 5%. (ידית **הרווח** של
      V3 נשארת; שתי הידיות נבדלות בצורה ובתווית.)

### פריסה — grid

- [ ] `display` — בורר: זרימה רגילה / flex / grid / בתוך שורה (`inline`, `inline-block`, `inline-flex`) / וכל ערך בהקלדה.
      `none` — "הסתר", עם ההערה שהאלמנט נשאר ב-Navigator ("מוצג לעריכה").
- [ ] **עמודות ושורות:** רשימת מסילות נערכת — הוספה, מחיקה, גרירה לשינוי סדר; לכל מסילה ערך ביחידה חופשית (`fr`, px, %,
      `auto`, `min-content`, `minmax()`, `fit-content()`); `repeat()` קיים מוצג כקבוצה ונערך כמו שהוא, בלי פירוק.
- [ ] **על הקנבס:** רובריקת grid נבחרת מציגה את קווי המסילות; **גרירת קו משנה את גודל המסילה**; גרירת שפת פריט על פני
      תאים משנה את ה-`span` שלו (`grid-column` / `grid-row`).
- [ ] `grid-template-areas` — מוצג כטבלת שמות נערכת; `grid-auto-flow`, `grid-auto-rows/columns`, `justify-items`,
      `align-items`, `place-content` — שליטות. לפריט: `grid-area`, `justify-self`, `align-self`.

### גודל

- [ ] בפאנל: רוחב, גובה, מינימום ומקסימום לכל אחד, `aspect-ratio`, `overflow` (לכל ציר), `box-sizing` — השליטה המספרית
      של V3 (יחידות חופשיות, מקור, נדרס, איפוס).
- [ ] **גרירת שפות האלמנט משנה גודל:** שמונה ידיות (פינות ואמצעי צלעות). היחידה הקיימת נשמרת (`%` נשאר `%`); בלי ערך
      קיים — px, עם מתג יחידה ליד הסמן. Shift — שומר יחס; Alt — משני הצדדים. עסקה אחת בשחרור.
- [ ] **ידיות הגודל וידיות המרווח של V3 אינן מתבלבלות:** ריבועים על קו המסגרת — גודל; הרצועות הצבועות — מרווח. התווית
      שליד הסמן אומרת **איזה מאפיין ישתנה לפני שמתחילים לגרור**.
- [ ] **אין ידית שנגררת ואינה משנה דבר:** כשהגודל אינו בידי האלמנט (ילד נמתח ב-flex, אלמנט `inline`, `max-width` שמגביל,
      גובה שנקבע מהתוכן) — העורך אומר מה קובע אותו, ומציע את הפעולה ("בטל מתיחה", "שנה את `max-width`", "הפוך ל-`inline-block`").
- [ ] תוכן שגולש מהאלמנט אחרי שינוי גודל — מסומן בקנבס, עם קיצור ל-`overflow`.

### מיקום חופשי — צעד 5 של התרחיש

- [ ] **מתג "✥ מיקום חופשי"** בסרגל של כל אלמנט. בהפעלה **האלמנט אינו קופץ**: ההיסטים ההתחלתיים מחושבים מהמקום שבו הוא
      נראה באותו רגע.
- [ ] מה נכתב (עסקה אחת, דרך כלל היעד של V3): לאלמנט — `position:absolute` ושני היסטים; לרובריקת הייחוס — `position:relative`
      **אם אין לה `position`**, והעורך אומר: "נוסף `position:relative` ל-`section.kadisha-hero`".
- [ ] **"ביחס אל" — בורר רובריקת הייחוס.** ברירת המחדל: האב הממוקם הקרוב. הבורר מציג את שרשרת האבות, והריחוף מסמן כל
      אחד בקנבס. בחירת אב **רחוק יותר מהאב הממוקם הקרוב** (בעמוד האמיתי: הפס כולו, ולא `.kadisha-hero-inner` הצר)
      **מעבירה את האלמנט ב-HTML להיות ילד ישיר של האב שנבחר** — באותה עסקה, והעורך אומר זאת. כך "בפינת התמונה" היא
      פינת התמונה, ולא פינת העמודה שבאמצע.
- [ ] **גרירה מזיזה את האלמנט בתוך רובריקת הייחוס** — וגם אל מחוצה לה (ערכים שליליים). נכתבים ההיסטים **במאפיינים לוגיים**
      (`inset-inline-start`, `inset-block-start`…), **באחוזים** כברירת מחדל; מתג ל-px, וכל יחידה בהקלדה.
- [ ] **עוגן:** רשת 3×3 — לאיזו פינה / צלע / מרכז האלמנט צמוד. ברירת המחדל: הפינה הקרובה אחרי הגרירה (אלמנט שהונח ליד
      הפינה התחתונה נכתב ב-`inset-block-end` + `inset-inline-end`, ונשאר בפינה כשהרובריקה משנה גודל). עוגן מרכז נכתב
      כ-50% ו-`translate`. שינוי עוגן אינו מזיז את האלמנט.
- [ ] **קווי עזר והצמדה:** מרכז וקצוות של רובריקת הייחוס; קצוות ומרכזים של אחים; מרווח שווה בין שלושה. Ctrl — בלי הצמדה.
      חיצים — פיקסל; Shift — 10. המרחקים מהקצוות מוצגים בזמן הגרירה.
- [ ] **מה שקורה לאחרים נאמר:** האלמנט יצא מהזרימה, ואחיו נסגרים על מקומו; ואם הרובריקה איבדה את גובהה (כל ילדיה
      ממוקמים) — הערה עם "קבע גובה מינימלי".
- [ ] **אלמנט ממוקם שמכוסה** (אחרי שחרור, אלמנט אחר נמצא מעליו ברוב שטחו — כיסוי, אח, `z-index`) — הערה עם "הבא לחזית".
      אלמנט שנחתך ב-`overflow:hidden` של אב — הערה עם שם האב.
- [ ] **כיבוי המתג — "חזרה לזרימה":** נמחקים `position`, ההיסטים וה-`translate` שהעורך כתב; האלמנט חוזר למקומו במקור
      (ואם הועבר ב-HTML — מוצע "החזר גם למקומו הקודם"). ה-`position:relative` של רובריקת הייחוס נשאר, ונאמר.
- [ ] בפאנל "מיקום": `static` / `relative` / `absolute` / `fixed` / כל ערך; ארבעת ההיסטים; `z-index`. `relative` עם היסט
      נגרר באותה דרך ("הזזה ממקומו"). `sticky` נכתב ונערך כערך; ההתנהגות והתצוגה שלו — V10.
- [ ] קוד קיים עם `top` / `left` / `right` נערך כמו שהוא; העורך אינו ממיר אותו ללוגי.
- [ ] **לכל מכשיר מיקום משלו — V7.** ב-V6 אלמנט ממוקם מסומן "הונח במחשב — לא נבדק ברוחב אחר", עם כפתור שמצר את
      הקנבס ל-390px כדי לראות. (האחוזים שומרים על המקום היחסי; זה אינו תחליף לבדיקה.)
- [ ] **סדר הקריאה אינו משתנה** (המקור לא זז, אלא אם הוחלפה רובריקת הייחוס) — נאמר בפאנל, כי קורא מסך ומנוע חיפוש
      קוראים לפי המקור.

### שכבות

- [ ] בסרגל של אלמנט שחופף לאחר: **קדימה · אחורה · לחזית · לרקע.** נכתב `z-index`, בערך הקטן ביותר שמשיג את הסדר, בלי
      למספר מחדש אלמנטים אחרים אלא אם אין ברירה (ואז — עסקה אחת, והעורך אומר מי השתנה).

- [ ] Alt + לחיצה (V1) עובר בין החופפים; ב-Navigator — סימון לאלמנט ממוקם, וסדר הערימה בריחוף.
