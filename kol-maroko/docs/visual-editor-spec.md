### 1.2 הפער — שלוש טעויות הבנה שלנו

1. **"שומרים על אותו HTML כמו התבנית" הפך ל"התבנית היא קופסה סגורה".** ההכרעה הנכונה (פרק 16: מראה והתנהגות
   זהים לאתר) מומשה כטקסט Mustache אחד. אין בו צמתים, ולכן אין מה לבחור. בעל האתר רואה כפתור — אנחנו רואים מחרוזת.
2. **"עיצוב = שדות קבועים" (פרק 3) נבנה בשביל בטיחות, ונשאר דל.** הבטיחות נכונה (בלי CSS חופשי בתוך HTML), אבל
   המסקנה הייתה "מעט שדות". הנכון: **הרבה שדות, כולם מוקלדים ומאומתים** — כך מקבלים גם בטיחות וגם גמישות של אלמנטור.
3. **הסטודיו נבנה "טלפון קודם", והמחשב נשאר אחרי.** `main { max-width: 860px }` חל גם על `</> קוד` (רק לסטודיו יש
   חריגה); הפאנל 340px קבוע; ובתוך התצוגה ה-CSS של ערכת הנושא חסר את המכל של העמוד (ראה 2).

## 2. פריסת מחשב (1280–2560) — משימה VE-01, דחופה

- **מסך עריכה = כל החלון.** מחלקה כללית (למשל `body.wide-on`) מבטלת את `max-width: 860px` בסטודיו, ב-`</> קוד`,
  ב-📚 מילים וב-🗂️ קבצים. שאר המסכים (חברים, פרסום, שחזור, הגדרות) נשארים צרים — טופס רחב קשה לקריאה.
- **הסטודיו (≥1000px):** `grid-template-columns: [navigator] var(--nav, 0) [canvas] 1fr [panel] var(--panel, 380px)`.
  הפאנל נגרר בין 300 ל-560 (נשמר ב-localStorage); ה-Navigator ייכנס ב-VE-05 — כרגע רוחב 0.
- **התצוגה בסטודיו:** "🖥️ מחשב" — כל רוחב הקנבס; "טאבלט" — 768; "📱" — 390, ממורכזים, עם מסגרת. ה-iframe מקבל רוחב
  אמיתי, כדי שה-media queries של המילון (600px) יחולו באמת.
- **החצי הריק בתצוגה:** ה-iframe עצמו ברוחב מלא — הבעיה בתוכן. לבדוק בצילום עם הטיוטה האמיתית, לא לנחש. החשודים:
  (א) `.kadisha-container` מוגדר ב-CSS הראשי של ערכת הנושא ולא ב-`lexicon.css`, כך שבתצוגה אין לו רוחב ומרכוז, וב-RTL
  התוכן נצמד לימין; (ב) כלל על `html`/`body` שהפך למכל אחרי `css_scope`; (ג) פסי `kol-sec`/`kol-inner` מקוננים.
  התיקון — בבסיס של מסגרת התצוגה (`FRAME`), כך שתצוגת "🖥️" תיראה כמו העמוד באתר באותו רוחב.
- **`</> קוד` (≥1000px):** עורך | תצוגה זה לצד זה במלוא הרוחב, מפצל נגרר (נשמר), כפתור "⤢ תצוגה במסך מלא",
  ומתג מכשיר גם כאן. הגובה עד תחתית החלון — בלי גלילה של הדף.
- **הטלפון לא משתנה** (מתחת ל-1000px — בדיוק כמו היום).

## 3. המודל: המילון כעץ אלמנטים

### 3.1 מקור אמת אחד

רכיב "המילון" מקבל `props.tree` — עץ JSON. **ממנו נגזרים** תבנית ה-Mustache (`lexicon.html`) וה-CSS שנוצר — באותו
צינור שקיים היום (רינדור בשרת, ניקוי, `css_scope`, פרסום חתום). התוסף לא משתנה: הוא ממשיך לקבל HTML + CSS.

```
node = { id, type, name?, props:{…}, style:{ desktop:{…}, tablet:{…}, mobile:{…} }, hidden?:{desktop,tablet,mobile},
         cond?, children?:[node] }
```

- `id` — 8 תווים, יציב. ב-HTML: `data-kel="<id>"`, וה-CSS ממוקד אליו: `.kadisha-lexicon-page [data-kel="<id>"]`.
- `style.desktop` הוא הבסיס; `tablet` (≤1024) ו-`mobile` (≤767) — רק מה ששונה (כמו אלמנטור).
- `name` — שם בעברית ל-Navigator ("כותרת ראשית", "כפתור מבוא").

### 3.2 סוגי האלמנטים

| סוג | `props` | הערות |
| --- | --- | --- |
| `box` (מכל) | `tag: div/section/header/footer/nav/article`, `layout: flex/grid`, `dir`, `wrap`, `justify`, `align`, `gap`, `cols` | Container של אלמנטור. מקונן בלי הגבלה (עד עומק 12) |
| `heading` | `text` (עשיר מוגבל), `level: 1–6` | |
| `text` | `html` (allowlist של פרק 10) | |
| `button` | `label`, `icon?`, `href?` / `action` | `action` — פעולה של המילון (פתיחת מבוא/הקדמה) |
| `image`, `icon`, `divider`, `spacer` | כמו בפרק 3 | |
| `html` | `html` מנוקה (`tpl_clean_html`) | מה שנערך בקוד ולא זוהה כאלמנט — לא הולך לאיבוד |
| `lex-search` | `placeholder`, `label`, `fields: word/meaning/topics`, `min_chars`, `clear_btn` | תיבת החיפוש |
| `lex-topics` | `all_label`, `show_counts`, `mode: single/multi`, `order: abc/count/manual` | צ'יפי הנושאים |
| `lex-counter` | `template: "{{n}} מילים"`, `empty_text` | המונה |
| `lex-gate` + `lex-panel` | `label`, `panel` ↔ `html`, `more_label`, `less_label` | כפתורי ההקדמה/המבוא והחלונית שהם פותחים |
| `lex-loop` | `sort`, `page_size`, `more_label`, `empty_text`, `layout: list/grid`, `cols` | Loop Grid. ילד יחיד: `lex-card` |
| `lex-card` | — | **Loop Item — התבנית האחת שחלה על כל המילים** |
| `lex-word`, `lex-meaning`, `lex-player`, `lex-tags`, `lex-feedback`, `lex-num` | `tag`, `label`, `player: theme/minimal/icon` | **שדות דינמיים** — רק בתוך `lex-card` |

הגבלות מבנה (נאכפות בשרת וב-UI): שדות דינמיים — רק בתוך `lex-card`; `lex-card` — רק ב-`lex-loop`; כל `lex-*` — רק
בתוך המילון; אלמנטים "חובה" (`lex-search`, `lex-loop`) אפשר להסתיר אבל לא למחוק (שאר ה-JS נשען עליהם).

### 3.3 חוזה ה-hooks — למה ה-JS של ערכת הנושא ממשיך לעבוד

היום באתר רץ `lexicon.js` של ערכת הנושא, ולא שום JS מהכלי (פרק 17). הוא מוצא את החיפוש, הצ'יפים, הכרטיסים והנגן
לפי מחלקות ומזהים. לכן **לכל סוג `lex-*` יש hooks קבועים** (מחלקות, `id`, `data-*`, מבנה פנימי מינימלי) שהמהדר מוסיף
תמיד, והמשתמש לא יכול להסיר. מעליהם — כל עיצוב, סדר, עטיפה ומיקום.

- **המשימה VE-04 מתחילה בהוצאת החוזה** מ-`lexicon.js` של ערכת הנושא (`imported_js` / הקובץ שיובא): כל בורר שהוא
  מחפש, מה הוא מצפה למצוא בתוכו, ואיזה סדר. נכתב לטבלה ב-`docs/lexicon-hooks.md`.
- בדיקה: כל בורר בחוזה מוצא בדיוק את מה שמצא קודם, גם אחרי הזזת אלמנטים ועטיפתם במכלים.
- מי שערך את ה-JS (`lexicon.js` מהכלי) עובר ממילא למסגרת המבודדת — כמו היום. העורך החזותי לא דורש זאת.

### 3.4 מעבר מהתבנית של היום

- המרה חד-פעמית: התבנית המובנית (או `lexicon.html` שנערך) ← עץ. **המבחן: צילום מסך זהה** לפני ואחרי, ב-390, 1280 ו-1920
  (הפרש פיקסלים זניח), ו-HTML שה-JS של ערכת הנושא מתנהג עליו אותו דבר (חיפוש, נושא, נגן, מבוא, משוב).
- נקודת שחזור "לפני העורך החזותי" לפני ההמרה. "↩️ חזרה לתבנית" ממשיך לעבוד.
- ההגדרות הישנות (`title_size`, `hero_overlay`…) הופכות לערכי סגנון של האלמנטים המתאימים.

## 4. העורך

### 4.1 בחירה בתצוגה

- **מעבר עכבר** — מסגרת דקה ותווית קטנה עם שם האלמנט. **לחיצה** — בחירה (מסגרת כחולה, ידיות ↑↓ ⧉ 🗑 ⋮).
- **לחיצה כפולה על טקסט** — עריכה במקום (contenteditable בתוך התצוגה, נשלח לפאנל ב-postMessage; Enter/Esc).
- **בתוך המילון לחיצה בוחרת**, ולא מפעילה. מתג "▶️ מצב תצוגה" בסרגל — מחזיר את ההתנהגות (חיפוש, נגן) כדי לבדוק.
- **שביל ניווט** מעל הפאנל: `עמוד › מילון › רשימה › כרטיס › פירוש` — לחיצה עולה לאב. מקש Esc — לאב.
- **כרטיס מילה:** לחיצה על אלמנט בכל כרטיס בוחרת את אלמנט התבנית; כל המופעים מסומנים בקו מקווקו, ובראש הפאנל:
  "🔁 תבנית כרטיס — חל על 1,496 מילים". בורר "מילה לתצוגה" (חיפוש מילה), וקיצורים: פירוש ארוך במיוחד / בלי הקלטה /
  הרבה נושאים / בלי משוב — כדי לבדוק את המקרים הקשים.

### 4.2 Navigator (עמודה בצד, ≥1280; גיליון בטלפון)

עץ מלא עם חיצי קיפול; בחירה מסונכרנת עם התצוגה; גרירה לשינוי סדר ולהעברה בין מכלים (עם קו יעד, ונדחה אם מפר את
הגבלות 3.2); שינוי שם בלחיצה כפולה; 👁 הסתרה (לכל המכשירים או לנוכחי); ⧉ שכפול; 🗑 מחיקה (לא לחובה).

### 4.3 הפאנל — שלוש לשוניות

- **✏️ תוכן** — השדות שב-`props` של הסוג (טבלה 3.2).
- **🎨 עיצוב**:
  - טיפוגרפיה: גופן (אסימון גלובלי או מרשימה), גודל, משקל, גובה שורה, ריווח אותיות, נטוי, רישיות, קו תחתון.
  - צבע טקסט; רקע: צבע / מעבר צבע / תמונה (מהספרייה) + שכבת כהות; מסגרת: עובי, סגנון, צבע, לכל צד; פינות (4, נעולות
    יחד או בנפרד); צל; שקיפות.
  - **מצבים:** רגיל / ריחוף / פעיל — לכפתור, צ'יפ וקישור.
- **⚙️ מתקדם** — ריפוד ושוליים (4 צדדים, נעילה), רוחב / רוחב מרבי / גובה מינימלי, יישור עצמי, סדר (order), z-index,
  מיקום יחסי (היסט), הסתרה במחשב / טאבלט / טלפון, מחלקה, ו-**CSS לאלמנט** עם `selector` (עובר `css_scope`).
- **כל שדה עיצוב מגיב למכשיר הנבחר** (🖥️/טאבלט/📱 בסרגל): אייקון מכשיר ליד השדה, ונקודה כשיש ערך שונה מהבסיס;
  "↺" מוחק את הערך של המכשיר הזה.
- **יחידות:** `px`, `em`, `rem`, `%`, `vw` — מבחר לכל שדה. ערכים מוקלדים ונבדקים בשרת (ראה 6).
- **העתקת סגנון / הדבקת סגנון** (⋮ ו-Ctrl+Shift+C/V), "איפוס סגנון".

### 4.4 הוספה

"+ אלמנט" פותח ספרייה (מכל, כותרת, טקסט, כפתור, תמונה, אייקון, קו, רווח, HTML, ושדות המילון — בתוך הכרטיס בלבד).
גרירה לתצוגה או ל-Navigator, או לחיצה — מוסיף אחרי הנבחר. שכפול שומר סגנון. בתוך הכרטיס אפשר להוסיף גם טקסט קבוע
(למשל "פירוש:"), וגם שדה דינמי שני (למשל מספר המילה).

### 4.5 גלובליים (⚙️ ← 🎨 צבעים וגופנים)

- צבעים: ראשי, משני, טקסט, הדגשה + מותאמים (שם + צבע). גופנים: ראשי, משני, טקסט, הדגשה (משפחה, משקל, גודל בסיס).
- נגזרים למשתני CSS: `--kol-c-primary`, `--kol-f-primary`… על `.kadisha-lexicon-page`. שדה עיצוב שמפנה לאסימון —
  שומר `{"$c":"primary"}`, ובפאנל רואים עיגול צבע עם שם; שינוי באסימון משנה הכול מיד.
- **ייבוא אסימונים מהאתר:** בהמרה (3.4) — הצבעים והגופנים הבולטים ב-CSS של המילון הופכים לאסימונים.
- גופן: רשימת Google Fonts עם עברית (Heebo, Assistant, Rubik, Frank Ruhl Libre, Noto Sans Hebrew, Secular One, Alef…)
  + הגופנים שהעמוד כבר טוען. הקישור לגופנים — כמו `settings.fonts` היום.

### 4.6 היסטוריה

כל פעולה — רשומה ב-↶/↷ עם שם ("שינוי צבע · כפתור מבוא"); שינוי שדה ברצף (גרירת מחוון) — רשומה אחת. העץ הוא חלק
מהטיוטה ולכן נכנס להיסטוריה, לנקודות השחזור ולגרסאות בלי שינוי בפרק 18 (לוודא בבדיקה).

## 5. קוד ↔ חזותי

- **`lexicon.html`** — נגזר מהעץ (Mustache עם `data-kel`). **אפשר לערוך אותו**: בשמירה השרת מפרק אותו חזרה לעץ —
  אלמנט עם `data-kel` מוכר שומר מזהה; תגית חדשה הופכת לאלמנט מתאים (h1–h6 ← heading, p ← text, button/a ← button,
  div/section ← box); מה שלא מזוהה — `html`. בלוקי `{{#words}}…{{/words}}` ← `lex-loop`/`lex-card`. hook חסר —
  השמירה נדחית עם הסבר ("החיפוש חייב להישאר `id="kadisha-lex-search"`").
- **`lexicon.css`** — שני חלקים: **"נוצר מהעורך"** (קריאה בלבד ב-Monaco, כל בלוק עם הערה `/* כפתור מבוא · kel:ab12cd34 */`
  ו-Ctrl+לחיצה קופצת לאלמנט בסטודיו) ו-**"CSS משלי"** (חופשי, אחרי הנוצר, עובר `css_scope`).
- **`lexicon.js`** — כמו היום (עריכה ← מסגרת מבודדת).
- **הסנכרון:** סטודיו ו-`</> קוד` עובדים על אותה טיוטה עם `rev` (פרק 17). מעבר לשונית — טעינה מחדש; שינוי בקוד
  שנשמר — מופיע בסטודיו; שינוי חזותי — מופיע בקוד. בחירת אלמנט בסטודיו ← "</> פתח בקוד" מגלגל לשורה שלו.

## 6. אבטחה וחוק הברזל — מה לא משתנה

- הכלי עדיין שולח רק גרסה חתומה; HTML מנוקה (`tpl_clean_html`), CSS ממוקד (`css_scope`), ניקוי שני בתוסף. **אין JS
  מהעורך החזותי.** אין צורך בגרסת תוסף חדשה, אלא אם יתברר אחרת ב-VE-04.
- **ערכי עיצוב מוקלדים:** מספר + יחידה מרשימה; צבע — `#rgb/#rrggbb/#rrggbbaa`, `rgb()/hsl()` או אסימון; גופן — מרשימה;
  תמונת רקע — `kol-file:` או https; enum לכל השאר. **ערך שאינו עובר — נדחה בשרת**, לא "מנוקה בשקט".
- תווית/טקסט — טקסט או allowlist. `href` — https, `mailto:`, `tel:`, `#`. CSS לאלמנט ו"CSS משלי" — `css_scope` כמו היום.
- גבולות: עד 2,000 צמתים, עומק 12, 200KB לעץ, 200KB ל-CSS משלי.

## 7. 🗂️ קבצים — כל ההקלטות

### 7.1 למה ריק

המילים יובאו עם **כתובת** ההקלטה באתר בלבד (`audio_kind = site`). המסך מציג את טבלת `files`, ושם אין אותן. ייצוא ה-ZIP
של תוסף 1.3 קיים, אבל דורש מבעל האתר להוריד ולהעלות כמה קבצים של 300MB.

### 7.2 הבאה ישירה מהאתר — נבדק

בדיקה מהקונטיינר (2026-11-10, קריאה בלבד): `/lexicon/` ו-`/wp-content/uploads/` (תיקייה) — **403 עם
`cf-mitigated: challenge`**; אבל קובץ שמע בנתיב `/wp-content/uploads/…/x.mp3` — **הגיע לשרת האתר** (404 אמיתי, בלי
אתגר), ו-`robots.txt` — 200. כלומר Cloudflare מאתגר דפים, ולא קבצים סטטיים. **סביר שהשרת שלנו יכול להוריד את ההקלטות
בעצמו** — זו קריאה של קבצים ציבוריים שכל מבקר שומע, לא נגיעה באתר.

- **"📥 הבאת ההקלטות מהאתר"** (בעלים/עורך): עבודה בשרת, בקבוצות (כ-10 בכל בקשה, הדפדפן ממשיך לבד; אפשר לסגור ולחזור —
  ממשיכה מאיפה שנעצרה). לכל כתובת: רק `GET`, רק המארח של האתר (`site_host()`, עם/בלי www), רק תחת
  `/wp-content/uploads/`, סיומת מרשימה (mp3, m4a, aac, wav, ogg, oga, opus, webm), עד 50MB, בדיקת MIME מהתוכן, בלי מעקב
  הפניות למארח אחר, הפסקה של שנייה בין קבוצות (לא להעמיס).
- כל קובץ נכנס לספרייה עם `files.origin` = הכתובת — **אותו מסלול כמו ייבוא ה-ZIP** (פרק 16), ולכן בפרסום לא נשלח שוב.
  כתובת שכבר יש לה עותק — מדולגת. אותו תוכן בשתי כתובות — קובץ אחד.
- סיכום בסוף: כמה הובאו, כמה דולגו, וכמה נכשלו — עם הסיבה לכל אחת (403 Cloudflare / 404 / גדול מדי / לא שמע) וכפתור
  "נסה שוב את הכושלות".
- **אם השרת שלנו מקבל 403** (ה-IP של שרת אחסון יכול להיות מאותגר יותר מהקונטיינר): הכלי מציג לבעל האתר שתי דרכים —
  (א) כלל Cloudflare אחד, כמו ב-`docs/cloudflare.md`: `GET` ל-`/wp-content/uploads/*` מה-IP של השרת — Skip;
  (ב) הדרך של היום: ייצוא ה-ZIP מהתוסף והעלאה. VE-02 כותב את ההוראות למסך ול-`docs/cloudflare.md`.

### 7.3 מנהל ההקלטות

- **רשימה** — שורה לכל הקלטה: ▶️, המילה (או המילים) שמשתמשות בה, משך, גודל, מקור (מהאתר / עותק / הועלה כאן / חסר),
  תאריך. חיפוש לפי מילה; סינון: נושא, מקור, "לא בשימוש", "מילים בלי הקלטה", "חסרות".
- **נגן אחד קבוע בתחתית**: ▶️/⏸, ⏮ ⏭ (הקודמת/הבאה ברשימה המסוננת), מהירות 0.75–1.5, פס התקדמות. רווח — נגן/עצור,
  ↑↓ — הבא/הקודם, Enter — פתיחת ההקלטה. "▶️ השמעה ברצף" — לעבור על כולן ולבדוק.
- **הקלטה פתוחה:** נגן, צורת גל (אם קל), המילה והפירוש, ופעולות: **🔁 החלפה** (העלאה או 🎙️ הקלטה — קובץ חדש, הקודם לסל,
  המילה מצביעה לחדש); **✂️ חיתוך** התחלה/סוף (אופציונלי, בשלב מאוחר); שינוי שם; הורדה; קישור למילה אחרת; 🗑 לסל.
- **כמה בבת אחת:** בחירה מרובה ← הורדה כ-ZIP / העברה לסל.
- "מילים בלי הקלטה" — 🎙️ ישר מהשורה.
- במחשב — רשימה + חלונית פרטים בצד; בטלפון — רשימה וגיליון.
