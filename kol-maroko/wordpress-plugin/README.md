# תוסף הוורדפרס של קול מרוקו

קוד **לאתר מגרב** (maghreb.co.il), לא לפלטפורמה — התיקייה מוחרגת מהפריסה. בעל המערכת מתקין אותו באתר.

התוסף מקבל רק "גרסה חדשה של עמוד קול מרוקו", בודק את החתימה מול המפתח הציבורי, דוחה גרסה ישנה, ומציג
אותה בעמוד `/lexicon/`. האפיון: `../docs/spec.md`, פרקים 6–7. נבנה בשלב 6.
