# ערכת ההתקפה — קול מרוקו 2.0 (פרוסה M2)

חבילת בדיקה **קבועה** (`07` §6, H1–H15): מתפרסמת למקבל של התוסף, נפתחת בדפדפן, ומדווחת ✓ / ✗ על כל ניסיון לגעת באתר.

| קובץ | מה |
| --- | --- |
| `index.html`, `kit.js`, `kit.css` | העמוד: הבדיקות שבתוך העמוד (H1–H4, H11, H15, והזרקת H5), טבלה, ושורת `KOLKIT2 {...}` במסוף |
| `probe.html` | H11 — קובץ מהחבילה שנפתח בלשונית משלו: מדווח `KOLKIT-PROBE {"origin":"null",…}` |
| `x.php`, `x.phtml`, `x.php.jpg`, `.htaccess`, `.user.ini` | H6 — קבצים עוינים. אם אחד מהם רץ בשרת — מופיע `RAN-42` |
| `x.svg` | H6 — SVG עם סקריפט: נפתח ישירות במקור אטום |
| `404.html` | עמוד ה-404 של החבילה (I5) |

- **מקומית:** `node tests/browser/m2.cjs` — מפרסם את התיקייה הזו ל-`tests/plugin/wp.php` (התוסף האמיתי) ובודק גם את מה שמבחוץ.
- **באתר (מטלה לבעלים):** פרסום לעמוד הבדיקה, ופתיחה ב-Chrome, Firefox ו-Safari כשמחוברים כמנהלים. הטבלה מצולמת.
- הבדיקות שבתוך העמוד הן עותק מותאם של ה-probe ב-`assets/js/attack-kit.js` (F4) — הקובץ ההוא אינו נערך כאן.
- התיקייה מוחרגת מהפריסה (`--exclude='/kol-maroko/tests/'`) וחסומה ב-`tests/.htaccess` — הקבצים העוינים לא מגיעים לשרת הכלים.
