# קול מרוקו

סטודיו עריכה חזותי, בסגנון אלמנטור, לעמוד **אחד**: https://maghreb.co.il/lexicon/.

- **עריכה:** כותרות וטקסטים, הוספה והזזה של רכיבים, תמונות, הקלטות (עד 50MB) וקבצים, קטעי קוד (במסגרת
  מבודדת), וטקסטים ארוכים בעורך התמלילים.
- **עוזר AI:** מבקשים שינוי, רואים מה ישתנה ומאשרים. מכסת טוקנים לכל חבר.
- **טיוטה ופרסום:** הכול נשמר כטיוטה. רק "פרסום" (תפקיד מפרסם) שולח גרסה חתומה לאתר.
- **חוק ברזל:** לכלי אין שום גישה לאתר. הוא שולח רק גרסה חתומה ב-Ed25519; האתר מחזיק את המפתח הציבורי
  בלבד (תוסף ב-`wordpress-plugin/`).

האפיון המלא: [`docs/spec.md`](docs/spec.md). התקנה באתר: [`docs/install.md`](docs/install.md) · Cloudflare: [`docs/cloudflare.md`](docs/cloudflare.md).

## כלים למפתח (פרוסה F1)

"מפתח" = הבעלים של האפליקציה. ההכרעה במקום אחד: `is_developer()` ב-`lib/dev.php`.

- **🐞 בכותרת של כל מסך** — לכל חבר עם תפקיד. דיווח פותח מטלה `KM-NNN` עם צילום, המסך, הגרסה, ו-20 הבקשות והשגיאות
  האחרונות. את המטלות עצמן רואה רק המפתח.
- **🛠️ מפתח** (לשונית, למפתח בלבד): 📋 מטלות (`#/dev/tasks`) · 📜 יומן בקשות ושגיאות (`#/dev/log`) · 👣 יומן פעולות ·
  🩺 בדיקות תקינות · 📊 מצב הנתונים ושירותי הרקע.
- **DevLoop** — המודול המשותף (`devloop/README.md`). `lib/devloop.php`, `assets/js/devloop.js`, `assets/css/devloop.css`
  הם **עותק מסונכרן — לא עורכים אותם**; החיבור ב-`lib/dev.php` וב-`assets/js/dev.js`. מפת הדרכים: `dev/open-items.json`.
  אסימון ל-Claude: 🛠️ מפתח ← מטלות ← "🔑 גישה ל-Claude" (`devapi-feed`, `devapi-comment` — בכותרת `X-Dev-Token`).
- **יומן** (`lib/devlog.php`) — כל בקשה, חריגה (עם מחסנית), תשובת 5xx ואזהרת PHP; ושגיאות דפדפן (`error`,
  `unhandledrejection`, בקשה שנכשלה). מזהה הבקשה חוזר בכותרת `X-Request-Id` ובהודעה למשתמש ("תקלה בשרת · מזהה abc123").
  **לא נרשמים לעולם:** גוף של בקשה או קובץ, סיסמאות, אסימונים, מפתחות. עד 5,000 שורות או 30 יום, ומתנקה לבד (קודם
  שורות רגילות — שגיאות נשארות). הצלחות של בקשות תכופות (`lock`, `render`, `upload_chunk`, `media`, `file`) לא נרשמות.
  שגיאת דפדפן שחוזרת בתוך יממה — שורה אחת עם מונה.
- **הקומיט בבדיקת התקינות** נקרא מ-`dev/build.json` (`{"commit": "...", "at": "..."}`) שהפריסה כותבת; בלעדיו הבדיקה אדומה.

### בדיקות אוטומטיות

```
php kol-maroko/tests/run.php            # הכול
php kol-maroko/tests/run.php פרסום      # רק בדיקות ששמן מכיל את המילה
```

בלי Composer ובלי תלות חיצונית. רץ על מסד בתיקייה זמנית של המערכת — `data/` לא נפתחת. מעלה שני שרתי PHP מקומיים:
`tests/router.php` (ה-`api.php` האמיתי; הזהות מהכותרת `X-Test-User` במקום מהשער) ו-`tests/fake-wp.php` (אתר מדומה
שטוען את **קובץ התוסף האמיתי**, כך שהחתימה, ה-nonce ומספר הגרסה נבדקים בקוד שרץ באתר). שניהם רצים רק בשרת המובנה
של PHP עם משתנה סביבה של הבדיקות; `tests/.htaccess` חוסם את התיקייה בשרת.

**להוסיף בדיקה:** קובץ ב-`tests/cases/` (נטענים לפי סדר השם), ובו:

```php
test('מה נבדק, במשפט', function () {
    $r = http('GET', '/api.php?action=words', ['user' => U_EDITOR]);   // או קריאה ישירה לפונקציה מ-lib/
    eq(200, $r['status']);
    ok(is_array($r['json']['words']), 'רשימת המילים');
});
```

עוזרים: `ok(תנאי, הסבר)` · `eq(מצופה, התקבל)` · `throws(fn)` (מצפה ל-`ApiError`) · `http(method, url, [user, json, raw, headers])` ·
המשתמשים `U_OWNER`, `U_PUBLISHER`, `U_EDITOR`, `U_STRANGER`. **פעולה חדשה ב-`api.php` חייבת שורה ב-`API_MIN_ROLE`**
(`tests/cases/20-api.php`) — אחרת הבדיקה נופלת.

לפני push: `php -l` לכל PHP, `node --check` לכל JS, `php platform/check-apps.php`, `php devloop/tools/sync.php --check`,
ו-`php kol-maroko/tests/run.php`.

## 🌐 הבאת ההקלטות מהאתר (פרוסה A2)

`docs/spec-v2/slices/A2-audio-fetch.md`. בספרייה ← 🎙️ הקלטות, **לבעל האתר בלבד**: "🌐 הבאה מהאתר".

- **המודל** (`lib/recordings.php`): טבלה `recordings` — רשומה לכל מילה עם הקלטה (המפתח: מזהה המילה), מצב `site` / `tool`
  / `failed`, המקור (הכתובת באתר — נשמר תמיד), הקובץ, המשך, ותוצאות הבדיקה וההבאה. **הרשומות נגזרות מהמילים**
  (`rec_sync`) ושדה `audio` של המילה אינו משתנה — לא במיגרציה ולא בהבאה; עד M2 העמוד החי ממשיך להפנות לאתר.
  הטבלה נוצרת ב-`CREATE TABLE IF NOT EXISTS` (מוסיף בלבד, בלי מספר מיגרציה). הספרייה (A1) קוראת מהמודל.
- **שום בייט אינו יורד בלי לחיצה:** "בדוק מה יש באתר" (HEAD בלבד) ← מסך אישור (כמה, מאיפה, נפח, כמה יישאר) ← "כן,
  הבא". ההבאה רצה בצעדים קצרים שהדפדפן מבקש; כל הקלטה מסומנת כשהסתיימה, ולכן סגירת הדפדפן — ופתיחה מחדש ← "המשך"
  — ממשיכה מאותה נקודה. שתי הורדות במקביל כברירת מחדל (⚙️ קצב ותקרה בחלון). חסימה גורפת (Cloudflare) עוצרת את
  הבדיקה ומציגה את שתי הדרכים: ייצוא ידני, או כלל ב-Cloudflare (הביטוי מוצג בחלון).
- **הגבולות** (`rec_url_check`, `rec_target`, `rec_http`): רק `https`, רק הדומיין של האתר, רק תחת `/wp-content/uploads/`;
  בלי IP, `localhost`, פורט אחר, שם משתמש או `..`; הדומיין חייב להיפתר לכתובת ציבורית, והיא ננעלת (`CURLOPT_RESOLVE`);
  הפניה נבדקת כמו כתובת חדשה (עד 3); בלי עוגיות, הרשאה או פרוקסי; רק GET / HEAD; תקרת גודל וזמן, וקובץ חלקי נמחק.
  הקובץ: סוג לפי התוכן (שמע בלבד — דף HTML נדחה), sha256, ונשמר דרך `file_store` עם `origin` = המקור.
- **איפה הנתונים:** הקבצים — ספריית המדיה הקיימת `data/files/` (כבר מוחרגת); זמניים — `data/files/tmp/`; הרשומות
  והעבודה — `recordings` ו-`settings.rec_*` ב-`data/kol.sqlite` (מוחרג). **אין `--exclude` חדש.**
- **משך:** נמדד בדפדפן בהשמעה ונשמר (`rec_duration`, רק לקובץ שבכלי); "⏱️ מדוד את כולן" — לכל ההקלטות שבכלי.
- **ייבוא ה-ZIP** (⚙️ הגדרות): ההתאמה קודם לפי מזהה המילה (`word_id` בייצוא = `wp_id`, או מספר בשם הקובץ), אחר כך
  לפי הכתובת; מה שלא הותאם — מוצג ברשימה. ⚠️ הייבוא, כמו קודם, קושר את המילה לקובץ (`audio` = מזהה הקובץ), וההבאה לא.
- **יומן המפתח:** `audio` — התחלה, סיום, עצירה, וכל כישלון עם מזהה המילה והכתובת.
- **בדיקות:** `tests/cases/85-recordings.php` (ב-`run.php`); דפדפן — `node kol-maroko/tests/browser/a2.cjs`. "האתר" בשתיהן
  הוא `tests/fake-audio.php` על 127.0.0.1 — בלי רשת אמיתית. המיפוי (`kol_rec_test_map`) פועל רק ב-CLI.
- **טרם נבנה:** קבצים שאינם מחוברים למילה (ש-13 — עד התשובה המסך אומר זאת). גרסאות, שינוי שם, מחיקה, הורדה — A3 (למטה).

## 🎙️ הפעולות על הקלטה (פרוסה A3)

`docs/spec-v2/slices/A3-audio-actions.md`. בספרייה ← 🎙️ הקלטות: ⋯ בכל שורה פותח את **כל** הפעולות (כך גם בטלפון);
תיבת סימון לבחירה מרובה (בטלפון — לחיצה ארוכה). שרת: `lib/rec_actions.php`; דפדפן: `assets/js/library-actions.js`.

- **החלפה** (קובץ או הקלטה מהדפדפן — האזנה, "↻ הקלט שוב", שמירה): הקודמת נשמרת כ**גרסה** (`rec_versions`) — "🕘 גרסאות"
  משמיע אותן, ו"↩️ חזור לגרסה הזו" שומר את הנוכחית כגרסה. גם החלפה מ-📚 מילים נשמרת כגרסה (`rec_sync`). הגרסה של
  הקלטה שהייתה "באתר" היא הכתובת — "חזור" מחזיר את הכתובת לשדה של המילה. הנתיב בעץ (`media/audio/<מזהה>.<סיומת>`)
  והמזהה אינם משתנים; הנתיב רק מצביע על הקובץ החדש.
- **הקשר מילה ↔ הקלטה** הוא שדה `audio` של המילה (ממנו העמוד קורא): חיבור, ניתוק, החלפה, מחיקה ושחזור כותבים אותו.
  הקלטה **לא מחוברת** = רשומה עם `word_id NULL` (סינון "לא בשימוש"); מילה שמצביעה שוב על הקובץ שלה מתחברת לאותה רשומה.
  מילה שנמחקה או נותקה ב-📚 מילים — ההקלטה שלה נשארת בספרייה כלא מחוברת (לא נמחקת).
- **הוספה** (➕ או גרירה, אחד או רבים): קודם `rec_match` — ההתאמה לפי שם הקובץ (מזהה: `6.mp3`; או המילה עצמה, בלי
  ניקוד) — ומסך אישור: הותאמו / מתנגשים (החלף — הקיימת נשמרת כגרסה · דלג) / לא הותאמו (להוסיף כלא מחוברת) / נדחו.
  **שום דבר לא עולה ולא מתחבר לפני האישור**; אחריו — העלאה רגילה (`upload_*`) ו-`rec_add` לכל קובץ.
- **מחיקה** — לסל (עמודות `deleted_*` ב-`recordings`): אזהרה עם שם המילה, לא חסימה; "♻️ שחזור" מחזיר גם את החיבור (אם
  למילה יש בינתיים הקלטה אחרת — חוזרת כלא מחוברת, וכתוב למה). **מחיקה סופית** — רק מהסל, רק בעל העמוד, באישור מפורש;
  קובץ נמחק מהדיסק רק כשאף דבר (מילה, הקלטה, גרסה, עץ, גרסה מפורסמת) אינו מפנה אליו.
- **הורדה:** אחת — הקובץ המקורי (`action=file&download=1`). נבחרות / כולן — ZIP שנבנה **בצעדים** (`rec_zip_start` ←
  `rec_zip_step` …) עם התקדמות, בלי דחיסה ובלי המרה (זהה בבייט; עד ~4GB), עם `recordings.csv` (מזהה, מילה, שם, הקובץ
  המקורי, משך, גודל, sha256; ערך שמתחיל ב-`= + - @` מנוטרל). שמות בארכיון: `<מזהה>.<סיומת>`, ולא מחוברות — `extra/`.
- **כפולות** (אותו sha256) — מוצגות כקבוצה; "השאר את זו": מילים שהשתמשו בעותק אחר עוברות לעותק שנשאר (הקודם — גרסה),
  עותקים לא מחוברים — לסל. **גרסאות** נספרות בתקרת הדיסק; המסך מראה כמה מקום הן תופסות, ו"נקה גרסאות ישנות מ-…" (בעלים).
- **הקלטה שעדיין "באתר":** הפעולות שדורשות קובץ מושבתות עם "תיפתח אחרי ההבאה לכלי", ו"החלף" זמין — גם בשרת.

## 🛡️ כותרות האבטחה — CSP ככותרת שרת (פרוסה C1)

החוזה: `docs/spec-v2/slices/C1-studio-csp.md`. הקוד: `lib/csp.php` — המקום היחיד של המדיניות.

| מה | איפה | הכותרות |
| --- | --- | --- |
| **הסטודיו** (שלב א) | `index.php` — מגיש את `studio.html` (המעטפת, לשעבר `index.html`) כמו שהוא | `Content-Security-Policy: object-src 'none'; base-uri 'self'; form-action 'self'` (נאכף) · המדיניות המלאה ב-`Content-Security-Policy-Report-Only` · `nosniff` · `Referrer-Policy` |
| **העורך ועורך הקוד** (שלב ב) | `editor.php` | המדיניות המלאה (§2, §2א), `editor_csp()` |
| **התצוגה החיה** | `live.php` | המדיניות של F4 |
| **כל תשובת API** | `api.php`, `agent.php`, `csp.php` | `default-src 'none'; frame-ancestors 'none'; sandbox` · `nosniff` · `Referrer-Policy` |

לכל מסמך `report-uri csp.php?p=<studio|editor|live>`. `preview/` — מקור אטום עם המדיניות של `00` §7.1, לא נוגעים.

- **למה PHP ולא `.htaccess`:** השער של הפלטפורמה מגיש כל קובץ סטטי (גם `index.html`) בהפניה פנימית ל-`platform/gate.php`,
  ו-`Header set` של התיקייה אינו חל אחרי הפניה כזו. לכן הסטודיו עבר ל-`index.php` (`app.json`: `"entry": "index.php"`).
  המעטפת עברה ל-`studio.html` — הגוף של שני המסמכים (`readfile`) — והיא **חסומה לגישה ישירה** (`.htaccess`: `Require all
  denied`, ו-`DirectoryIndex index.php`); אין כתובת שמגישה את הסטודיו בלי הכותרות. **`index.html` — הכתובת הישנה** (קישור,
  קיצור דרך בטלפון, PWA מותקן שה-`start_url` שלו עוד ישן) — **302 ל-`index.php`**, עם השאילתה (הגיבוב נשמר בדפדפן). הקובץ אינו
  קיים, ולכן הכללים של השער (שדורשים קובץ קיים) לא תופסים אותו והכלל של C1 הוא שחל. לשוניות העורך מובילות ל-`index.php#/…`.
- **דוחות ההפרה** (`csp.php`, מאחורי השער): נצברים בטבלה `csp_reports` — שורה לכל (מדיניות, אכיפה, הנחיה, מקור חסום, מסמך)
  עם מונה, עד 500 קבוצות (ואז קבוצת `*`); כתובת נשמרת כמקור בלבד (בלי נתיב, שאילתה או סיסמה), הדגימה אחרי `devlog_scrub`.
  מה שאינו צפוי נכתב גם ליומן המפתח — `category = csp`, שורה מקופלת ליממה (`warn` לדיווח בלבד, `error` לנאכף). **חסימה צפויה**
  (תמונה/שמע/גופן/סגנון זר בעורך — §2א) נספרת בטבלה (`expected`) ואינה שגיאה. הרשימה למפתח: `api.php?action=csp-reports`
  (`&expected=0|1`). בלי CSRF: הדפדפן שולח את הדוח בעצמו; דוח בלי זהות מהשער — נזרק.
- **פער ידוע:** הפרה **בתוך** התצוגה של הסטודיו הישן (`iframe sandbox` בלי same-origin — מקור אטום) נשלחת בלי העוגייה, ולכן
  אינה נקלטת. לשלב ב אין בה צורך: המסך הישן נשאר בשלב א עד שהוא מוסר (אחרי M3).
- **לא נבדק:** ש-`Require` בתוך `<Files>`, ה-302 ו-`DirectoryIndex` מתנהגים ב-LiteSpeed של השרת כמו ב-Apache (§5.2). לאימות אחרי
  הפריסה: `studio.html` ישירות → 403; `index.html#/words` → `index.php#/words`; `kol-maroko/` → הסטודיו, עם הכותרות; `preview/<אסימון>/index.html` → העמוד.

```
php kol-maroko/tests/run.php C1            # הכותרות, studio.html חסום, index.html → 302, build-gate על עותק, הדוחות (קיבוץ, צפוי, עקיפה, תקרה)
node kol-maroko/tests/browser/c1.cjs       # האכיפה בדפדפן: שלב א, שלב ב, API, שמות HTML — עם ביקורת חיובית לכל חסימה
```

## 📄 data/words.json — הפנים השניות של טבלת המילים (N1)

החוזה: `docs/spec-v2/slices/N1-data-as-file.md`. הקוד: `lib/lexicon.php` (המנוע), `lib/project.php` (הקובץ בעץ),
`assets/js/project.js`, `assets/js/words.js`.

- **הקובץ בעץ** — `data/words.json` (המיקום: `kol.json` ← `data.words.file`), עם 🔗 "נבנה מטבלת המילים — שמירה מעדכנת את
  הטבלה". אין לו שורה ב-`pf_files` ואין גוש: הוא נבנה מהטבלה **ברגע הקריאה** ב-`words_json()` — אותה פונקציה של התצוגה
  החיה ושל הבנייה (`pv_words` קוראת לה). ה-`rev` שלו = חותמת התוכן, כך שעורך פתוח יודע שהטבלה השתנתה.
- **שמירה (Ctrl+S, ייבוא ZIP)** — אימות לפני כל כתיבה, ושגיאה עם שורה ועמודה (מסומנת בעורך) ← **"מה ישתנה"** לפי `id`
  ← "החל". עסקה אחת; מילה שאינה בקובץ ← לסל (עם ההקלטה); לפני מחיקה כלשהי או שינוי של יותר מ-20 — נקודת שחזור; מחיקה
  של יותר מ-20 — מפרסם. פריט בלי `id` ← מילה חדשה (המזהה חוזר לקובץ). נושא חדש — רק ב"צור נושא". אין שמירה אוטומטית.
- **מחיקה / שכפול** במנהל הקבצים — אינם מוחקים מילים: מחיקה מסירה את `data.words` מ-`kol.json` (אחרי אישור), שכפול יוצר
  עותק סטטי רגיל.
- **הסדר** — `words.sort_order` (מיגרציה 17). כל עוד ריק — הסדר של לפני N1 בדיוק (`lex_sort`), ונכתב רק בפעולה שמשנה סדר.
  בטבלה: ידית ⠿, בחירה מרובה, ו"העבר ל…" (המספר בתחילת השורה). `data-kol-sort="manual"` = סדר הקובץ; לפי שדה —
  `Intl.Collator` בשפה של `data-kol-sort-lang` (ברירת מחדל `he`).
- **אקסל** — אותו מנוע: תצוגה של מה ישתנה, "זוהה קידוד" (UTF-8 עם / בלי BOM, Windows-1255), אינו מוחק — אלא ב"החלף הכול"
  (מפרסם). בייצוא: `סדר`, `מזהה באתר`, וההקלטה כמו בקובץ; תא שמתחיל ב-`= + - @` מקבל `'` (נוסחה לא רצה באקסל).
- **הבדיקות:** `tests/cases/95-words-file.php`, `tests/browser/n1.cjs`.

## 📬 טפסים ותיבת פניות (M5)

החוזה: `docs/spec-v2/slices/M5-forms-inbox.md`. הקוד: `form.php` (הנקודה הציבורית), `lib/forms.php` (הכול), `assets/js/inbox.js`,

- **בעמוד** — `<form data-kol-form="שם">` **בלי `action`** נשלח (`fetch`, `FormData`, `credentials: 'omit'`) לכתובת שב-
  `<meta name="kol-form-endpoint">`. את ה-meta כותבים **הבנייה** (`forms_build`, בסוף `build_finish`; המקור במאגר לא משתנה) ו**התצוגה
  החיה** (`?test=1`). ההודעות — אלמנטים של בעל העמוד: `[data-kol-form-done]` / `[data-kol-form-error]` (`hidden` מתחלף). מלכודת —
  `data-kol-trap`. טופס עם `action` משלו — הדפדפן שולח לשם, ומסומן "חיצוני".
- **`form.php`** — ב-`"public"` של `app.json`. POST בלבד; בלי session, בלי עוגייה, בלי `auth.php`. התשובה — רק `{"ok":true}` או
  `{"ok":false,"reason":"rate|size|invalid|closed"}`. מתקבל רק טופס שברישום: האיחוד של `pkg_builds.forms` ב-10 הגרסאות האחרונות
  שנשלחו (בתצוגה — הסריקה של הטיוטה). שדה שאינו ברשימה — נזרק ונספר. ספאם (מלכודת, `_t` קצר) ← `ok` בלי לשמור.
- **המגבלות** (נאכפות בשרת; המפתח משנה ב-🛠️ ← 📬 טפסים): 10KB · 20 שדות · 5,000 תווים · 5 לכתובת ב-10 דקות · 200 בשעה ·
  1,000 ביום (מעליה `closed` עד חצות UTC) · `_t` ≥ 3 שניות. **ה-IP** — `HMAC-SHA256` במפתח `forms_ip_key` מ-`data/secrets.json`,
  רק ב-`form_hits`, נמחק אחרי 30 יום. הפנייה אינה שומרת IP / User-Agent / Referer.
- **התיבה** (לשונית 📬, עם מונה "לא נקראו"): ערכים — **רק כטקסט**; נקרא / טופל (מי ומתי), סינון, חיפוש, CSV של הסינון (BOM, תא
  שמתחיל ב-`= + - @` מקבל `'`). קריאה, סימון, ייצוא — עורך; מחיקה לסל ו"מחק ישנות" (אצווה אחת בסל) — מפרסם; מגבלות ומייל — המפתח.
  פניות 🧪 (מהתצוגה) — רק בסינון "בדיקות", נמחקות אחרי 7 ימים. `snap_state` **אינו** כולל פניות.
- **מייל** — כבוי כברירת מחדל. "✉️ שלח מייל בדיקה" (`mail()`), ורק אחרי בדיקה שהצליחה — הדלקה. תקציר בלבד ("N פניות חדשות בטופס …"
  + קישור), לכל היותר אחד ל-15 דקות, בלי 🧪; 3 כישלונות ברצף ← כבוי אוטומטית + הודעה. הכותרות קבועות; כתובות — בלי CR/LF.
- **הנתונים:** `form_entries`, `form_hits`, `form_rejects`, `forms_trash`, `pkg_builds.forms` — מיגרציה 19, ב-`data/kol.sqlite`. אין קובץ
  חדש ב-`data/` ואין `--exclude` חדש.
- **הבדיקות:** `tests/cases/96-forms.php`, `tests/browser/m5.cjs`.
