# M6b — התקנת תוסף קול מרוקו 2.3.0 (לבעלים)

**מה משתנה:** התוסף מפסיק לקבל ולהציג את הגרסאות הישנות (1.x). העמוד החדש שבאתר לא משתנה. שום נתון לא נמחק.

צעד אחד בכל פעם. בסוף כל צעד — מה אמור להיראות.

## 1. להוריד את התוסף מהכלי
בכלי: ⚙️ בעל האתר ← "⬇️ הורד את התוסף (zip)". יורד קובץ ZIP.
**אמור להיראות:** קובץ בשם `kol-maroko-2.3.0.zip` בתיקיית ההורדות.

## 2. לבדוק לפני ההתקנה שהעמוד באוויר
לפתוח בטלפון או במחשב: https://maghreb.co.il/lexicon/
**אמור להיראות:** העמוד החדש של קול מרוקו, עם המילים.

## 3. להעלות את התוסף לוורדפרס
בוורדפרס: תוספים ← הוספת תוסף ← העלאת תוסף ← לבחור את קובץ ה-ZIP ← "התקנה".
וורדפרס ישאל אם להחליף את הגרסה הקיימת — לבחור **"החלפת הקיים בגרסה שהועלתה"**.
**אמור להיראות:** "התוסף עודכן בהצלחה".

## 4. לוודא שהתוסף פעיל
תוספים ← "קול מרוקו — קבלת גרסאות".
**אמור להיראות:** גרסה 2.3.0, והתוסף פעיל (יש קישור "השבתה").

## 5. לבדוק שהמפסק עדיין דולק
הגדרות ← קול מרוקו ← החלק של "העמוד החדש".
**אמור להיראות:** "העמוד החדש" — דולק, עם מספר הגרסה שבאתר. (הסימון הישן "פעיל — להציג בעמוד את הגרסה מהסטודיו" ורשימת "גרסאות שהתקבלו" — כבר אינם. זה מכוון.)

## 6. לבדוק שהעמוד עדיין באוויר
לפתוח שוב https://maghreb.co.il/lexicon/ — כדאי גם בחלון גלישה בסתר.
**אמור להיראות:** בדיוק כמו בצעד 2. ללחוץ על הקלטה אחת — היא מתנגנת.

## 7. לבדוק את החיבור מהכלי
בכלי: 🚀 פרסום ← "📡 הדרך לאתר" ← "🔄 בדוק עכשיו".
**אמור להיראות:** תוך דקה — "📡 האתר משך עכשיו". ובכלי: 🛠️ מפתח ← תקינות ← "החיבור לאתר" — ירוק, עם "תוסף 2.3.0".

## אם משהו לא נראה נכון
- **העמוד ב-/lexicon/ לא נטען או נראה שבור:** הגדרות ← קול מרוקו ← לכבות את "העמוד החדש". העמוד המקורי של וורדפרס חוזר מיד. לכתוב לנו מה ראית.
- **צריך לחזור לתוסף הקודם:** קודם לכבות את "העמוד החדש" (העמוד המקורי חוזר), ולכתוב לנו. אם שמרת את ה-ZIP של 2.2.1 — אפשר להעלות אותו באותה דרך (צעד 3). כלום לא נמחק, ולכן הכול חוזר כמו שהיה.
