# M6 — מה נעלם מהממשק (לבעלים, §2.5)

שורה אחת לכל דבר שהיה בכלי ואינו עוד. הבקרה מציגה את הרשימה לבעלים לפני המיזוג.

| מה היה | מה במקומו |
| --- | --- |
| 🎨 סטודיו (הלשונית הישנה, מודל הרכיבים) | 🎨 עורך — הלשונית הראשונה. מי שנכנס לקישור ישן (`#/studio`) מגיע ל-🎨 עורך |
| `</> קוד` (שלושת הקבצים lexicon.html / .css / .js) | 📁 פרויקט — כל הקבצים של העמוד. קישור ישן (`#/code`) מגיע ל-📁 פרויקט |
| 🚀 פרסום ← "🚀 פרסום הטיוטה לאתר" (פרסום 1.x, הכפתור שנחסם ב-403) | 🚀 פרסום ← "🏗️ בנה גרסה מהפרויקט", ואחריה 🔁 מעבר |
| 🚀 פרסום ← רשימת "גרסאות", "↻ שליחה שוב", "⤴️ חזרה לגרסה הזו" | 🚀 פרסום ← 🗄️ ארכיון — לקריאה בלבד: לראות כל גרסה ישנה, ו"⬇️ הורד כ-HTML" |
| ⚙️ בעל האתר ← "📥 ייבוא העמוד הקיים מהאתר" | לא נדרש עוד — העמוד בפרויקט |
| 📁 פרויקט ← "🔄 ייבוא מחדש מהעמוד של היום" (🪄 ההסבה), גם בתפריט ⋯ בטלפון | לא נדרש עוד — הפרויקט הוא המקור; הסבה חוזרת הייתה דורסת אותו |
| "⚠️ העמוד של היום עוד לא יובא · 🔄 ייבוא עכשיו" | הפס נשאר רק כשהפרויקט עדיין שלד ריק — בלי כפתור |
| ✨ עוזר הבינה ו-📝 טקסט ארוך של הסטודיו הישן | ✨ ו-📝 ב-📁 פרויקט / 🎨 עורך (X1) |
| 🤖 עבודה מצ'אט (היה רק בסטודיו הישן) | ✨ עוזר הבינה ← "🤖 עבודה מצ'אט" |
| ↩️ שחזור ← תצוגה של העמוד הישן בתוך נקודה | הנקודה נפתחת ומשוחזרת כרגיל; מוצג "🗄️ כולל גם את העמוד הישן (לא בשימוש)" |
| 🚀 פרסום ← "▶️ להציג באתר את הגרסה מהסטודיו" / "↩️ חזרה לעמוד המקורי" (המפסק של 1.x — הדליק את הגרסה הישנה) | המפסק "העמוד החדש" בוורדפרס (הגדרות ← קול מרוקו); מצבו מוצג ב-🚀 פרסום ← 🔁 מעבר |

**מה לא נמחק:** הנתונים של הסטודיו הישן — הטיוטה, היסטוריית השמירות, הגרסאות שפורסמו, שלושת קובצי הקוד וההיסטוריה שלהם —
נשארים במסד כמו שהם. 🛠️ מפתח ← נתונים מראה כמה שורות יש בכל טבלה.
