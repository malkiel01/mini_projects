## 1. "＋ תמונת רקע" — תמונת הרקע המקורית "באתר" בבורר
- **שרת — `lib/site_images.php` (חדש):** `site_images` (GET, content_editor) — `library_site_images()` + העותק שכבר בכלי (אם יש);
  `site_image_take` (POST, editor) — מוריד את התמונה אל הספרייה של הכלי ומחזיר `{file, reused}`.
- **גבולות (SSRF):** הכתובת חייבת (1) לעבור `rec_url_check` — https, הדומיין של האתר (`lex_host`), תחת `/wp-content/uploads/`, בלי IP /
  נקודה בסוף / פורט / משתמש; ו-(2) להופיע **בדיוק** ברשימת "באתר" של הטיוטה — כתובת שהדפדפן ממציא נדחית (404) גם באותו דומיין.
  ההורדה — רק דרך `rec_http` (IP ציבורי ננעל ב-RESOLVE, בלי הפניה החוצה, בלי עוגיות/הרשאה), עד `FILE_MAX` (50MB, כמו העלאה), ובתוך תקרת הדיסק.
  סוג — לפי התוכן (`finfo`) + `file_store` (עיבוד מחדש של התמונה, בלי SVG). דף HTML / טקסט ← 415, ולא נשאר קובץ.
- **עותק קיים:** `files.origin = <הכתובת>` (כמו בהקלטות) — בחירה שנייה לא מורידה שוב (`reused: true`).
- **לקוח — `screen.js` pick():** לסוג image — שורה "באתר" לכל תמונה (תצוגה מקדימה `referrerpolicy=no-referrer`, `data-pick-site`); בחירה ←
  `site_image_take` ← `linkToProject` (media/, כמו כל קובץ מהספרייה). עותק שכבר בספרייה לא מופיע פעמיים ("בספרייה של הכלי").
- שער A2 ("מסלול ההורדה היחיד", 85-recordings.php) הורחב במדויק: ב-site_images.php רק `site_image_take` קורא ל-`rec_http`, פעם אחת.
- נתונים: הקובץ נשמר ב-`data/files/` — כבר מוחרג ב-deploy.yml (`--exclude='kol-maroko/data/files/'`). בלי מיגרציה (העמודה `origin` קיימת).
