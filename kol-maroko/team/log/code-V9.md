## הכרעות מראש (נקודות רגישות)

1. **בקשות יוצאות** — `lib/fonts.php`, פונקציה אחת (`font_http`). מותר רק `https://fonts.googleapis.com/css2?…` (הכתובת נבנית
   בשרת משם משפחה שעבר תבנית `^[A-Za-z0-9 ]{1,60}$` ומשקלים מספריים) ו-`https://fonts.gstatic.com/<נתיב>` (כתובת מתוך ה-CSS של
   Google — נבדקת: https, המארח בדיוק, בלי פורט/משתמש, נתיב בתווים מותרים). **אין מעקב הפניות** (3xx = שגיאה), פרוטוקול https
   בלבד, זמן 10 ש', גודל: CSS ≤ 256KB, קובץ ≤ 2MB (נעצר באמצע ההורדה). כתובת IP של המארח נפתרת מראש; כתובת פרטית/שמורה
   (127/8, 10/8, 172.16/12, 192.168/16, 169.254/16, ::1, fc00::/7 …) — נדחית, והחיבור ננעל לכתובת שנבדקה (`CURLOPT_RESOLVE`).
   כתובת שהמשתמש נותן — לעולם לא נשלפת: המשתמש נותן שם משפחה בלבד.
2. **העלאת גופן** — פעולה `font_upload`: חתימה (`wOF2` / `wOFF` / `\0\1\0\0` / `true` / `OTTO`), הסיומת נקבעת מהחתימה ולא
   מהשם; השם מנוקה ל-`[A-Za-z0-9_-]` (עברית ← `font`), תמיד `media/fonts/<שם>.<סיומת>`, בלי `..`; כפילות ← `-2`. גודל ≤ 2MB
   (מגבלת הטקסט של הפרויקט), מעל 500KB — הערה. נשמר כמו שהוא. ההרשאה — שורה ב-`ACTION_ROLES` (שאלה לבקרה).
3. **כתיבה ל-CSS** — שם משפחה: `^[\p{L}\p{N} _-]{1,60}$` (בלי מרכאות, `<`, `;`, `{}`, `()`); שם משתנה: `^--[A-Za-z_][\w-]{0,60}$`;
   ערך — `checkValue` (קיים: `<`, `CSS.supports`) + בדיקת `{ } ;` ; כתובת `url()` — רק דרך `urlCss`/`checkUrl`.
4. **מטמון** — אין. הרשימה של Google Fonts — רשימה קבועה בקוד (משפחות שתומכות בעברית + נפוצות); המשקלים — `css2` בזמן ההוספה.
   **אין קובץ חדש תחת `data/`, אין מיגרציה, אין `--exclude`.**
