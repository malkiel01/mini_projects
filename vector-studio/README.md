# וקטורי (`vector-studio/`)

עורך גרפיקה וקטורית בסגנון Illustrator — לוגואים, אייקונים, איורים ושרטוטים. שומר `.mbe` מסוג `vector`, עם
`drawing.svg`, ‏`document.pdf` ו-`preview.png` מוכנים בפנים. פרויקט 3 בחבילת היצירה; ההנחיות:
`creative-suite/docs/projects/vector-studio.md`.

> סטטוס: **אפיון גרסה 1 — טרם נכתב קוד.** ההכרעות של בעל המערכת (2026-10-24) — בטבלה למטה.

## המודל — שכבה `vector` ב-`document.json`

הסכמה הרשמית משאירה את `paths` פתוח (`"type": "array"`). ההצעה — תיסגר ותעבור כבקשה לצ'אט המתכלל
(`creative-suite/docs/requests/vector-studio-paths.md`) לפני שהשמירה הראשונה נפרסת:

```json
{ "id": "L2", "name": "לוגו", "type": "vector", "opacity": 1, "blend": "normal", "visible": true, "locked": false,
  "paths": [
    { "id": "p1", "d": "M10 10 C 40 0 60 0 90 10 Z", "transform": [1,0,0,1,0,0],
      "fill": { "color": "#1f3a5f" }, "stroke": { "color": "#000000", "width": 1, "cap": "round", "join": "round", "dash": [] },
      "shape": { "type": "rect", "box": [10,10,80,40], "radius": 6 } }
  ] }
```

- `d` — תחביר נתיב של SVG, **רק בפקודות מוחלטות M L C Q Z** (מנורמל בשמירה). כך כל קורא — גם בלי ספרייה — מצייר.
- `shape` — אופציונלי: הפרמטרים של צורה חיה. אפליקציה שלא מכירה אותה מציירת את `d` ושומרת את `shape` כמו שהוא.
- טקסט — שכבה `frame` קצרה עם שטף ProseMirror (כמו העימוד), כדי לא להמציא מודל טקסט שני.

## ארכיטקטורה (הצעה)

- **הכול בדפדפן**, ES modules בלי בנייה. ליבת `.mbe` — עותק מסונכרן ב-`assets/js/mbe/` (כניסה ל-`apps.json` של
  הליבה — בהסכמת הצ'אט הזה, בבקשה דרך הצ'אט המתכלל).
- **גאומטריה ונתיבים** (בעלים: וקטורי) — `assets/js/geometry/`: פענוח וכתיבה של `d`, תיבה חוסמת, בדיקת פגיעה,
  טרנספורמציות, צורות → נתיב. כתוב כך שיהיה אפשר לחלץ אותו כמו שהוא כשהעימוד יצטרך ("כלל השתיים").
- **תצוגה — קנבס** (ההכרעה): ציור מחדש לפי זום (חד בכל רמה, `devicePixelRatio`), בדיקת פגיעה שלנו במודול הגאומטריה,
  ושכבת-על נפרדת לבחירה ולידיות. ה-SVG לייצוא נבנה מהמודל, לא מהתצוגה.
- **משתמשים ונתונים** — מערכת משתמשים, מסד ועוגייה משלה (ההתחברות מהשער, `platform/docs/auth.md`); `gate: true`.
  נתונים בשרת → `--exclude` ב-`deploy.yml` **לפני הכתיבה הראשונה**.
- **PDF — בדפדפן:** כותב PDF וקטורי קטן משלנו (נתיבים, מילוי, מתאר, שקיפות, טקסט כקווי מתאר). לא תלוי במנוע של עורך התמלילים.
- **מראה** — `phone-first-design`: סרגל כלים, לוח שכבות, לוח מאפיינים; בטלפון — גיליונות במקום לוחות.
