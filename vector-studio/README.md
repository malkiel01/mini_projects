# וקטורי (`vector-studio/`)

עורך גרפיקה וקטורית בסגנון Illustrator — לוגואים, אייקונים, איורים ושרטוטים. שומר `.mbe` מסוג `vector`, עם
`drawing.svg`, ‏`document.pdf` ו-`preview.png` מוכנים בפנים. פרויקט 3 בחבילת היצירה; ההנחיות:
`creative-suite/docs/projects/vector-studio.md`.

> סטטוס: **עורך** — לוח עבודה, זום, בחירה, הזזה ושינוי גודל, צורות, מילוי ומתאר, עט ועריכת נקודות, קבוצות, שכבות,
> יישור ופיזור, סדר הצגה, הצמדה ורשת, טקסט בעברית, ייצוא SVG / PDF / PNG וייבוא SVG; ספרייה בשרת עם גרסאות.
> ‎.mbe — הורדה ופתיחה דרך הליבה, עם גופנים מוטמעים וייצוגים. גרסה 1 — כל היעדים הושלמו. ההכרעות — בטבלה למטה.

## המודל — שכבה `vector` ב-`document.json`

הסכמה הרשמית משאירה את `paths` פתוח (`"type": "array"`). ההצעה — תיסגר ותעבור כבקשה לצ'אט המתכלל
(`creative-suite/docs/requests/vector-studio-paths.md`) לפני שהשמירה הראשונה נפרסת:

```json
{ "id": "L2", "name": "לוגו", "type": "vector", "opacity": 1, "blend": "normal", "visible": true, "locked": false,
  "paths": [
    { "id": "p1", "d": "M10 10 C 40 0 60 0 90 10 Z", "transform": [1,0,0,1,0,0],
      "fill": { "color": "#1f3a5f" }, "stroke": { "color": "#000000", "width": 1, "cap": "round", "join": "round", "dash": [] },
      "shape": { "type": "rect", "box": [10,10,80,40], "radius": 6 } }
  ] }
```

- `d` — תחביר נתיב של SVG, **רק בפקודות מוחלטות M L C Q Z** (מנורמל בשמירה). כך כל קורא — גם בלי ספרייה — מצייר.
- `shape` — אופציונלי: הפרמטרים של צורה חיה. אפליקציה שלא מכירה אותה מציירת את `d` ושומרת את `shape` כמו שהוא.
- טקסט — שכבה `frame` קצרה עם שטף ProseMirror (כמו העימוד), כדי לא להמציא מודל טקסט שני.

## ארכיטקטורה (הצעה)

- **הכול בדפדפן**, ES modules בלי בנייה. ליבת `.mbe` — עותק מסונכרן ב-`assets/js/mbe/` (כניסה ל-`apps.json` של
  הליבה — בהסכמת הצ'אט הזה, בבקשה דרך הצ'אט המתכלל).
- **גאומטריה ונתיבים** (בעלים: וקטורי) — `assets/js/geometry/`: פענוח וכתיבה של `d`, תיבה חוסמת, בדיקת פגיעה,
  טרנספורמציות, צורות → נתיב. כתוב כך שיהיה אפשר לחלץ אותו כמו שהוא כשהעימוד יצטרך ("כלל השתיים").
- **תצוגה — קנבס** (ההכרעה): ציור מחדש לפי זום (חד בכל רמה, `devicePixelRatio`), בדיקת פגיעה שלנו במודול הגאומטריה,
  ושכבת-על נפרדת לבחירה ולידיות. ה-SVG לייצוא נבנה מהמודל, לא מהתצוגה.
- **משתמשים ונתונים** — מערכת משתמשים, מסד ועוגייה משלה (ההתחברות מהשער, `platform/docs/auth.md`); `gate: true`.
  נתונים בשרת → `--exclude` ב-`deploy.yml` **לפני הכתיבה הראשונה**.
- **PDF — בדפדפן:** כותב PDF וקטורי קטן משלנו (נתיבים, מילוי, מתאר, שקיפות, טקסט כקווי מתאר). לא תלוי במנוע של עורך התמלילים.
- **מראה** — `phone-first-design`: סרגל כלים, לוח שכבות, לוח מאפיינים; בטלפון — גיליונות במקום לוחות.

**שליטה:** עכבר — גרירה על רקע בוחרת במלבן, Ctrl+גלגלת — זום, רווח+גרירה — הזזת תצוגה. מגע — אצבע על רקע
מזיזה את התצוגה, שתיים — זום. הקשה עם כלי צורה — צורה בגודל 100pt. Shift — ריבוע / יחס קבוע / קו ב-45° / ציר
אחד בהזזה. מקשים: V (בחירה) A (נקודות) P (עט) M L \ · Delete · חיצים (Shift — 10pt) · Ctrl+Z / Ctrl+Shift+Z · Ctrl+D · Ctrl+A · Ctrl+0 · Ctrl+G / Ctrl+Shift+G (קיבוץ / פירוק) · Ctrl+] / Ctrl+[ (קדימה / אחורה; עם Shift — לקצה).
🧲 — הצמדה (Ctrl בזמן גרירה — בלי), # — רשת.

**עט:** הקשה — נקודה חדה, גרירה — עקומה, הקשה על הנקודה הראשונה — סגירה; "✓ סיום" / Enter — נתיב פתוח.
**עריכת נקודות:** גרירת נקודה או ידית (Alt — שובר את החלקות); הקשה על הקו — נקודה חדשה; הקשה כפולה / Alt —
חלקה ↔ פינה; "🗑️ נקודה" / Delete. צורה חיה שנערכת בנקודות הופכת לנתיב רגיל.

**קבוצה** — פריט ב-`paths` עם `type: "group"` ו-`children` (נוסף לבקשה לצ'אט המתכלל). **שכבות** — לשונית בלוח
המאפיינים: הצגה / הסתרה, נעילה, סדר, שם; אובייקט חדש נכנס לשכבה המסומנת.

**טקסט:** T — הקשה פותחת טקסט נקודה (הקצה הימני בנקודה), גרירה — טקסט בתיבה שגולש. הקלדה במקום; Esc / Ctrl+Enter
— סיום; הקשה כפולה — עריכה. גופן, גודל, מודגש, יישור ומרווח — בלוח. טקסט ריק לא נשאר. פריט `text` בתוך `paths`
(בבקשה לצ'אט המתכלל, סעיף 2).

**קובץ (📁):** ייצוא SVG (הלוח שנבחר), PDF (כל הלוחות, עמוד לכל אחד), PNG (×1 / ×2 / ×4, רקע לבן או שקוף).
טקסט יוצא כקווי מתאר. ייבוא SVG נכנס כקבוצה לשכבה הפעילה; טקסט, תמונות, מעברי צבע ו-CSS — נאמרים בהודעה.

**מעבר צבע:** במילוי — "צבע / מעבר צבע", שני צבעים וזווית; זז וגדל עם הצורה; יוצא ל-SVG (‏linearGradient) ול-PDF
(‏Pattern צירי), ומיובא מ-SVG (‏linearGradient, גם objectBoundingBox).

**‎.mbe:** 📁 ← ‎.mbe — הקובץ של החבילה (`kind: "vector"`): המסמך כמו שהוא בספרייה, הגופנים של הטקסטים ב-media
(OFL), ו-preview.png, ‏drawing.svg (הלוח הראשון) ו-document.pdf (כל הלוחות), כל אחד עם gaps. **📂 פתיחה** (בדף
הפתיחה או ב-📁) — הקובץ נבדק בליבה ונכנס לספרייה יחד עם המקור, כדי שבהורדה הבאה יישמר בית-לבית כל מה שהעורך לא
מבין (שכבות רסטר, מדיה, `apps/` של אפליקציות אחרות). שכבות שאינן וקטוריות לא מוצגות בעורך — ונאמר בפתיחה.

**ספרייה בשרת:** כל ציור נשמר אוטומטית שנייה אחרי שינוי (גם ביציאה מהדף), עם תמונה ממוזערת. המסמך נשמר כמחרוזת
ה-JSON כמו שהיא — בלי פענוח וכתיבה מחדש. שני חלונות על אותו ציור: השני שישמור מקבל "נשמר מחלון אחר", לא דורס.
בלי חיבור — גיבוי במכשיר, ניסיון חוזר כל 15 שניות, והצעה לשחזר בפתיחה הבאה. 📁 ← גרסאות קודמות ושחזור. טיוטות
ישנות מהמכשיר עוברות לספרייה כשפותחים אותן. המסמך בספרייה הוא document.json של ה-‎.mbe.

**כניסה:** רק דרך השער (האפליקציה מחוברת). אין סיסמה ואין מסך חיבור — אין חשבונות ישנים לחבר. כשהאפליקציה
תצא לדומיין משלה — "כניסה עם הכלים הדיגיטליים" (`platform/docs/sso.md`) וסיסמה משלה.

## מה טרם הוכרע

- סכמת `paths` המלאה בליבה (גרסה 1.1) — אצל הליבה; עד אז הליבה מקבלת כל רשימה, והאפליקציה כותבת לפי המבנה שאושר
  (`mbe-format.md`, "תוכן שכבה `vector`").
- טקסט כקווי מתאר: ניקוד וסימנים מעל אותיות — עוד לא ממוקמים כמו בקנבס. מעבר צבע: ליניארי בלבד; שקיפות בתוך
  מעבר — לא יוצאת ב-PDF.
- הצגת שכבות רסטר ומסגרות מאפליקציות אחרות — בגרסה הבאה (היום: נשמרות, לא מוצגות).
