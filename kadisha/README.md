# ניהול חברה קדישא — אפליקציה חיצונית

האפליקציה עצמה **לא בריפו הזה**. היא רצה בדומיין משלה, `kadisha.mbe-plus.com`, עם משתמשים
ומסד נתונים משלה. התיקייה הזו רק רושמת אותה בפלטפורמה, כדי שתופיע בדף הכלים:

| מה | כתובת |
| --- | --- |
| כניסה למערכת (דפדפן) | https://kadisha.mbe-plus.com/ |
| דף ההורדה לאנדרואיד | https://kadisha.mbe-plus.com/app |
| ה-APK | https://kadisha.mbe-plus.com/downloads/kadisha.apk |
| פרטי הגרסה (שם, גרסה, SHA-256) | https://kadisha.mbe-plus.com/app/manifest.json |

## מה הוכרע

- **`"restricted": true`** — מערכת עסקית: הרשאה לקטגוריה לא פותחת אותה, רק אישור ישיר
  לאפליקציה בממשק המנהל.
- **התקנה:** קישור ה-APK מוצג למשתמשים רק אחרי שהמנהל מסמן "📲 התקנה והורדה" בממשק המנהל.
  זו אפליקציית אנדרואיד מלאה, ולא PWA (`"pwa": false`).
- **מה לא חל עליה:** השער ומעקב הכניסות של הפלטפורמה. הבקשות אליה לא עוברות בשרת של
  `mini_projects`, ולכן הכניסה למערכת נשארת הכניסה שלה.
- **שינוי כתובת:** מעדכנים רק את `app.json` כאן. האפליקציה עצמה מנוהלת בפרויקט שלה.
