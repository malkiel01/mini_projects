# ההתקדמות שלי בלינוקס

מעקב אישי אחרי תרגולי לינוקס. דף אחד, בלי מנהלים, בלי תלמידים, בלי שרת נוסף.

## הנתונים
הנתונים נמצאים ב-`data/progress.json`. כל פריט:
- `date` — תאריך (YYYY-MM-DD)
- `topic` — מה תרגלת
- `status` — `done` (בוצע) או `verified` (אומת)
- `note` — הערה אופציונלית

`verified` מסומן רק לפי בקשה מפורשת שלך.

## עדכון
מוסיפים תרגול בצ'אט, והקובץ מתעדכן בריפו. אין עריכה מהאפליקציה.
