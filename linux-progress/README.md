# ההתקדמות שלי בלינוקס

מעקב אישי אחרי תרגולי לינוקס.

## איפה הנתונים
הנתונים נמצאים בריפו `malkiel01/offensive-cyber-academy`, בקובץ `progress/linux-progress.json`.
השרת קורא אותו בלבד (לא כותב). הסוד לקריאה נשמר בשרת מחוץ לאתר דרך מסך ההגדרות (`admin.html`), ולא מגיע לדפדפן.

## פורמט הקובץ
- `items`: רשימה של תרגולים. כל פריט:
  - `date` — YYYY-MM-DD
  - `topic` — מה תרגלת
  - `status` — `done` (בוצע) או `verified` (אומת)
  - `note` — אופציונלי, עד 500 תווים

קובץ שלא עומד בפורמט לא יוצג, ויופיע הודעה מתאימה.

## מצבים
- `no_token` — לא הוגדר סוד. הגדר במסך ההגדרות.
- `no_file` — הקובץ עדיין לא נוצר בריפו.
- `unauthorized` — הסוד לא מתאים לריפו.
- `invalid` — הקובץ בפורמט שגוי.
- `unavailable` — השרת לא הצליח לקרוא כרגע.

## בדיקות
`php linux-progress/tests/run.php` (בלי רשת).
