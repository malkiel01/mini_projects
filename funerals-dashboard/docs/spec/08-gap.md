# 08 — הקוד הקיים מול האפיון

נכתב בידי הבקרה, 24.11. הקוד בשרת: פרוסות 01–09.

## מה שעובד ונשאר

- ארגונים, חברים וסינון לפי ארגון, שאילתות מסוננות בשכבה אחת.
- לקוח Dropbox בשרת: OAuth, העלאה, webhook, cursor ותמונות ממוזערות.
- היסטוריה (`events`), סודות מוצפנים, מיגרציות שלא מוחקות.
- API חיצוני ו-MCP + OAuth ל-ChatGPT.

## ההמלצה (א14 — הבקרה מחליטה)

**לתקן, לא לבנות מאפס.** השרת, ההרשאות, הלקוח של Dropbox וחיבור ChatGPT נבדקו ועובדים. מחליפים את מה שלא מתאים:
1. **שכבת הבינה:** זיהוי, מיון, שאלות וקובץ למידה. זה הלב החדש.
2. **הגדרות:** בדיקות ותפקידים גמישים.
3. **ממשק חדש מאפס**, על tokens שאפשר להחליף.
4. **קישור 22 התיקים** דרך הבינה, כבדיקת קבלה ראשונה.

סדר הפרוסות ייקבע אחרי שהבעלים מאשר את האפיון.
