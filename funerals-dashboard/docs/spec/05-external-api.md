# 05 — API חיצוני: אסימונים, OpenAPI, פרומפט ל-GPT

תלויה ב-: 02 (ו-03 לפעולות הקבצים). דרישה: D4. שאלה: ש5 (ברירת מחדל: GPT מותאם עם Actions).
הארכיטקטורה: `00-overview.md` §3.3; הכרעות ה7, ה8.

## 1. המטרה

הבעלים כותב ל-ChatGPT "תוסיף לכהן: רישיון קבורה 12345" — וזה מופיע בתיק. "תסרוק את התיקייה של לוי ותגיד מה חסר" —
והצ'אט עונה מתוך האפליקציה ו-Dropbox.

## 2. מה בונים

### 2.1 אסימונים אישיים

1. ⚙️ הגדרות ← "צ'אט חיצוני": "יצירת אסימון" — שם ("GPT של משה"), ארגון (הפעיל), תוקף (30 / 90 / 365 יום, ברירת
   מחדל 90). מוצג פעם אחת, בקידומת `fdx_`. נשמר כ-SHA-256 ב-`tokens` (`user_id`, `org_id`, `name`, `hash`, `created_at`,
   `expires_at`, `last_used_at`, `revoked_at`).
2. ההרשאות = התפקיד של המשתמש בארגון **ברגע הבקשה** (משתמש שהושבת או הורד בתפקיד — האסימון יורד איתו).
3. רשימת האסימונים שלי, עם "שימוש אחרון" וביטול. מנהל רואה ומבטל את כל אסימוני הארגון.
4. עד 10 אסימונים פעילים למשתמש. 60 בקשות לדקה לאסימון; מעבר → 429.

### 2.2 `ext.php` — הפעולות

Bearer בלבד, בלי עוגייה ובלי session. כל תשובה JSON, ושגיאה `{"error": "<הסבר בעברית>"}`.

| פעולה | מה |
| --- | --- |
| `GET whoami` | המשתמש, הארגון, התפקיד, ואילו פעולות מותרות לו |
| `GET cases?month=&q=&status=` | רשימה מקוצרת: מזהה, שם, תאריך, "הבא בתור", מונים |
| `GET case?id=` | התיק המלא, עם הבדיקות, הקבצים ו-10 אירועים אחרונים |
| `GET schema` | רשימת הבדיקות (מפתח ← שם בעברית), הסטטוסים, וסוגי המסמכים — כדי שהצ'אט ידע איך לכתוב |
| `POST case_update` | `{id, fields?, checks?, note?}` — שינוי חלקי. מחזיר את מה שנשמר בפועל (כולל המרה ל"לאימות", 02 §2.3) |
| `POST case_create` | תיק חדש (משרד ומעלה) |
| `GET files?id=` | קבצי התיק |
| `GET file_text?file=` | הטקסט של קובץ (PDF עם שכבת טקסט; תמונה — אין, עם הסבר), עד 200KB |
| `GET find?q=` | חיפוש תיק לפי שם, כדי שהצ'אט לא ינחש מזהה |

אין פעולת מחיקה. כל כתיבה: `via: api`, `actor` = שם המשתמש + " (צ'אט)", שורה ב-`events`.

### 2.3 OpenAPI ופרומפט

1. **`openapi.json`** — OpenAPI 3.1, נוצר מאותה טבלת פעולות שבקוד (מקור אחד), עם `servers` של הכתובת בשרת ו-
   `securitySchemes: bearer`. ציבורי (אין בו סוד). תיאורי הפעולות בעברית ובאנגלית — GPT קורא את שניהם.
2. **הפרומפט** — טקסט שהאפליקציה מייצרת (`ext.php?action=prompt` למשתמש מחובר, או בממשק), ובו:
   מי אתה ומה המטרה; תמיד `find` לפני עדכון, ושאלה כשיש יותר מתוצאה אחת; לא לנחש ערך שלא מופיע במסמך או בדברי המשתמש;
   מה זה "לאימות" ולמה הוא לא "אומת"; להציג למשתמש מה נשמר בפועל; עברית.
3. **מסך "חיבור ל-ChatGPT"**: שלושה כפתורי העתקה — הפרומפט, כתובת ה-OpenAPI, והאסימון (בעת יצירה) — והוראות קצרות
   בחמישה צעדים ל-GPT מותאם (Configure ← Instructions ← Actions ← Import from URL ← Authentication: API Key, Bearer).
   אותו פרומפט, לחלופין, להדבקה בפרויקט GPT או בתחילת שיחה (ש5).

### 2.4 `ingest.php`

נשאר כמו שהוא (הכרעה ה9). במסך "צ'אט חיצוני" מוצג שהוא קיים, ומתי השתמשו בו לאחרונה.

## 4. קריטריוני קבלה

| # | הקריטריון |
| --- | --- |
| E1 | בלי אסימון / אסימון שגוי / פג / בוטל → 401; עוגיית session לבדה → 401 |
| E2 | אסימון של ארגון א' → `case?id=` של ארגון ב' → 404 |
| E3 | אסימון של `field` → `case_update` של תשלום → 403; של בדיקה → 200 |
| E4 | `case_update` עם `verified` → נשמר "לאימות", והתשובה אומרת זאת במפורש |
| E5 | משתמש שהושבת → האסימון שלו 401 מיד |
| E6 | האסימון נשמר רק כ-hash; לא מופיע ביומן הבקשות |
| E7 | 61 בקשות בדקה → האחרונה 429 |
| E8 | `openapi.json` עובר ולידציה של OpenAPI 3.1, ומכיל בדיוק את הפעולות שבטבלת הקוד |
| E9 | כל כתיבה דרך `ext.php` → שורה ב-`events` עם `via: api` ושם המשתמש |
| E10 | `ext.php` ו-`openapi.json` ב-`"public"` של `app.json`; `php platform/check-apps.php` עובר |
| E11 | (ידני, אחרי פריסה) GPT מותאם עם הפרומפט והאסימון: "תוסיף ל<שם>: הערה בדיקה" → ההערה בתיק, וביומן "(צ'אט)" |
