# 07 — API לתוכנת הניהול של חברה קדישא

**הבעלים (ק6):** "אתה קובע את המבנה, אחר כך נתאים את תוכנת הניהול למבנה הזה." לכן זה כבר לא רק "לעתיד" — המבנה
נקבע באפיון, והבנייה אחרי הליבה.

- **קריאה:** תיקים, בדיקות, תשלומים וקבצים בפורמט JSON מתועד (OpenAPI), לפי ארגון, באסימון של הארגון.
- **אירועים:** כל שינוי בתיק נרשם עם מספר רץ. תוכנה חיצונית מושכת "מה השתנה מאז N", ובהמשך webhook יוצא חתום.
- **כתיבה:** לא בשלב הראשון.
- הפירוט (שדות, דוגמאות) — במסמך נפרד כשהפרוסה מתחילה.
