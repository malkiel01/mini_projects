# 04 — עובד שטח בטלפון: העלאה, צילום קבר, עדכון

תלויה ב-: 02, 03. דרישה: D3 ("עובד שטח מעדכן, שולח קבצים ומצלם קבר"). הרשאות: `01-infrastructure.md` §2.3.

## 1. המטרה

עובד שטח, בטלפון, ליד הקבר: פותח את התיק, מצלם, שולח — והתמונה בתיקייה ב-Dropbox ובתיק. בלי ללמוד את המערכת.

## 2. מה בונים

1. **מסך "היום" לעובד שטח** (ברירת המחדל לתפקיד `field`): תיקי היום ומחר של הארגון, לפי שעה, עם "מה חסר מהשטח"
   בכל אחד. חיפוש בשם לכל תיק אחר בחודש.
2. **בתיק, שלושה כפתורים גדולים:**
   - 📷 **צילום קבר** — `<input type="file" accept="image/*" capture="environment">`. הקובץ עולה לתיקיית התיק בשם
     `קבר <שם> <YYYY-MM-DD HHMM>.jpg`, `kind: grave_photo`.
   - 📎 **שליחת קובץ** — מסמך או תמונה מהטלפון, עם בחירת סוג (רשימת סוגי המסמכים שכבר בתיק: `documents[].kind`,
     ו"אחר").
   - ✏️ **עדכון** — רק השדות ש-`field` רשאי לשנות (01 §2.3): בדיקות, הערה, מיקום קבר.
3. **הקטנה בדפדפן:** תמונה מעל 2,560 פיקסלים בצלע הארוכה מוקטנת לפני השליחה (JPEG 85%), כדי שתעלה גם בקליטה חלשה.
   ה-EXIF של המיקום **נשמר** (מיקום הקבר); כל השאר נמחק.
4. **בלי קליטה:** הקובץ נשמר בתור במכשיר (IndexedDB) עם "ממתין לשליחה", ונשלח כשחוזרת רשת — גם אחרי סגירת המסך.
   כל פריט בתור: ניסיון חוזר, ביטול, ו"נשלח ✓" עם קישור לקובץ. מזהה חד-פעמי לכל העלאה, כך ששליחה כפולה לא יוצרת
   שני קבצים.
5. **שיוך לבדיקה:** קובץ שנשלח עם סוג שמתאים לבדיקה (למשל רישיון קבורה) → הבדיקה עוברת ל-`document_present`
   ("לאימות"), `via: field`. העובד יכול גם לסמן "אומת" בעצמו — לפי 02 §2.3 זה מותר ל-`field`.
6. **Dropbox לא מחובר:** הכפתורים מוצגים, וההעלאה נכשלת בהודעה ברורה: "Dropbox של הארגון לא מחובר — פנה למנהל".
   הקובץ נשאר בתור.

## 3. מה לא בונים כאן

אפליקציית אנדרואיד / התקנה (בהמשך, אם הבעלים יבקש — `manifest.webmanifest` מספיק להתקנה מהדפדפן ואפשר להוסיף
כאן בלי עלות). זיהוי תוכן המסמך (06).

## 4. קריטריוני קבלה

| # | הקריטריון |
| --- | --- |
| W1 | משתמש `field` נכנס → מסך "היום" עם תיקי היום ומחר בלבד; תיק מחודש אחר נמצא בחיפוש |
| W2 | צילום קבר → קובץ בתיקיית התיק (במדומה) בשם הצפוי, `kind: grave_photo`, `added_via: field`, ושורה ב-`events` |
| W3 | שליחה כפולה עם אותו מזהה העלאה → קובץ אחד |
| W4 | קובץ מסוג "רישיון קבורה" → הבדיקה המתאימה `document_present`, `via: field` |
| W5 | `field` שמנסה לשנות שם נפטר או תשלום דרך ה-API → 403 |
| W6 | תמונה של 4,000 פיקסלים יוצאת מהדפדפן ב-2,560 לכל היותר (בדיקת JS) |
| W7 | Dropbox מנותק → הודעה ברורה, הקובץ בתור, ושום שגיאה שקטה |
| W8 | (ידני, בטלפון) מצב טיסה → צילום → "ממתין"; חזרת רשת → "נשלח ✓", והתמונה ב-Dropbox |
