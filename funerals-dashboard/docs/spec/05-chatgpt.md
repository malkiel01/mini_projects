# 05 — ChatGPT (א10)

**חשוב כמו הבינה המובנית.** ChatGPT רואה ועושה את אותו הדבר: אותן פעולות, אותן הרשאות ואותו יומן.

- **חיבור ישיר (MCP + התחברות OAuth):** המשתמש מחבר את ChatGPT לחשבון שלו באפליקציה, וכל פעולה נרשמת "שם המשתמש
  (ChatGPT)". בנוי בפרוסה 09 ועוד לא נבדק אצל הבעלים.
- **פעולות:** חיפוש תיק, מה חסר, קריאת קבצים מהתיקייה, עדכון ערך, העלאת קובץ, מענה על שאלות של הבינה.
- **אין מחיקה** דרך ChatGPT.
- **הנחיות לפרויקט ChatGPT:** האפליקציה מייצרת אותן, ויש כפתור "העתקה".
- **תנאי לאישור:** בדיקה אמיתית מול ChatGPT של הבעלים לפני שממשיכים לבנות עליה.
