# פרוסה 08 — תיקונים קטנים + מעבר לפרויקט ChatGPT

**מקור:** בקשת הבעלים (24.11, 18:20, דרך מנהל הצוותים) והפריטים הפתוחים בבקרה. נכתב בידי בקרה 3 (טורבו, האפיון רדום).

## רקע

OpenAI הפסיקה ליצור Custom GPT בחשבונות פרטיים, והשירות נסגר (11.12.2026 לפי מקור אחד, פברואר 2027 לפי אחר). התחליף הוא
Plugins, ו-Actions לא עוברים אליהם לבד. הבעלים עובר בינתיים ל**פרויקט ChatGPT** בשם "ניהול לוויות": ההנחיות בפרויקט, ייצוא 📤
של החודש כקובץ בפרויקט, GPT מכין JSON `{"schema_version":1,"month","records"}` והבעלים מייבא אותו ב-📥.
(`id` מהייצוא; ב-`checks` רק `document_present` / `unreadable` / `missing` / `not_applicable`, **אף פעם** `verified`.)
מנהל הצוותים בדק על עותק מקומי: עדכון חלקי לא דורס, תיק חדש נוצר, ייבוא כפול לא משכפל. זה מחליף את ברירת המחדל של ש5.

## מה בונים

| P2 | **הנחיות לפרויקט**: גרסה של `gpt-prompt.md` לזרימת הקובץ (בלי Actions): מבנה ה-JSON, המפתחות מ-`form.js`, הכלל "אף פעם verified", `id` מהייצוא, תיק חדש בלי `id`. נוצר מאותו מקור (`tools/build-ext.php`) ונבדק בשער. | כפתור 📋 מעתיק אותן; מקור אחד, בלי כפילות ידנית. |
