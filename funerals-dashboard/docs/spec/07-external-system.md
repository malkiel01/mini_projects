# 07 — נקודת הרחבה לתוכנה חיצונית — חוזה בלבד

דרישה: D7 — "בעתיד, לא כרגע!". **הפרוסה הזו לא נבנית.** היא קובעת מה שאר הפרוסות לא שוברות, כדי שהחיבור יהיה תוספת.

## 1. מה כבר מוכן מהפרוסות האחרות

- **`events`** (01): כל שינוי בתיק, עם מספר רץ, ארגון, מקור ו-`diff`. זה הזרם שתוכנה חיצונית תקרא.
- **מזהה תיק יציב** (`id`), שלא משתנה כשמשנים שם או תאריך.
- **API עם אסימונים ו-OpenAPI** (05): תוכנה חיצונית יכולה כבר היום למשוך (`cases`, `case`) באסימון של משתמש ייעודי.

## 2. הכללים לפרוסות 01–06

1. כל כתיבה לתיק — דרך הפונקציה האחת שכותבת ל-`events`. אין `UPDATE funerals` עוקף.
2. `events` לא נמחקת ולא נדחסת (מותר לארכב מעל שנה לטבלה אחרת, עם אותם מספרים).
3. `diff` הוא JSON של שמות השדות כמו ב-API (לא שמות עמודות פנימיים).

## 3. מה ייבנה כשהבעלים יבקש

- **מנויים:** טבלת `subscriptions` (ארגון, כתובת, סוגי אירועים, סוד), ושליחה חתומה (HMAC, `X-FD-Signature`) של כל אירוע
  חדש, לפי מספר רץ, עם ניסיונות חוזרים ו"נקודת המשך".
- **`GET ext.php?action=events&after=<n>`** — משיכה למי שלא יכול לקבל webhook.
- **מיפוי שדות** לתוכנה הספציפית — כשיהיה ידוע איזו תוכנה.
