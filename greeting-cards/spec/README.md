# אפיון: כרטיסי ברכה ← עורך עיצוב (Canva + Photoshop), עם הצ'אט כמחולל רקעים

נכתב ב-2026-10-22. זהו אפיון לשכתוב מלא. הוא אינו משנה את הקוד הקיים.

## השורה התחתונה

1. **הגרסה הקיימת לא שווה תיקון — לכתוב מחדש.** הבעיות (איטיות, זום חסום, עברית שבורה ב-PDF, אפס נגישות)
   נובעות מהמבנה: קובץ אחד של 6,900 שורות עם מצב גלובלי. → `01-current-state.md`
2. **לפני השכתוב — תיקון חירום אבטחה.** יש פרצות בצד השרת. הן מוגבלות היום רק כי השער של הפלטפורמה מכניס
   משתמשים מורשים בלבד. → `01-current-state.md`, "אבטחה"; `09-roadmap.md`, שלב 0
3. **"לשלוף תמונות מהחשבון ב-ChatGPT" — אי אפשר, בשום פלטפורמה.** אין API לחשבון של משתמש. **אפשר בכיוון
   ההפוך:** GPT מותאם ב-ChatGPT עם Action שולח אלינו את התמונות שנוצרו בשיחה (`openaiFileIdRefs`). זו הפלטפורמה
   היחידה עם מנגנון רשמי לכך היום. Gemini ו-Claude — דרך סקיל וייבוא קובץ. → `04-ai-chat-skill.md`
4. **הצ'אט מייצר רקע בלי טקסט + `design.json`; העורך הופך אותם לשכבות חיות.** זה עוקף את העברית השבורה של
   מחוללי התמונות, ומשאיר את כל הטקסט ניתן לעריכה. → `../editor/skill/SKILL.md`, `schema/design.schema.json`
5. **מסלול ישיר עם "טוקנים" — במכסת קרדיטים**, שהמנהל המפתח מקצה לכל משתמש, עם ספר תנועות ותקרה כוללת בדולרים.
   משתמש בלי מכסה ממשיך דרך הצ'אט. → `05-ai-direct-tokens.md`, `06-users-and-admin.md`

## איך לבדוק את הסקיל כבר היום

1. להעתיק את `../editor/skill/SKILL.md` (או מהעורך: "🤖 סקיל לצ'אט") לתחילת שיחה ב-ChatGPT או ב-Gemini (או להעלות כ-Skill ב-Claude).
2. לבקש: "תכין לי רקע למודעה של מבצע סוף עונה בחנות בגדים, לפוסט באינסטגרם".
3. לבדוק: האם שאל לפני שייצר? האם יש טקסט בתמונה (אסור)? האם ה-`design.json` תקין?

כך אפשר לכוונן את הסקיל עוד לפני ששורת קוד אחת נכתבה.
