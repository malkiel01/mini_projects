# 05 — מסלול ישיר: בינה מלאכותית בתוך האפליקציה, עם מכסות

## העיקרון

רק משתמש **שהמנהל המפתח הקצה לו מכסה** רואה את לשונית "✨ AI" במצב ישיר. כל השאר רואים בה את מסלול הצ'אט
(סקיל + ייבוא), כך שאף משתמש לא נתקע.

**המפתחות של ספקי הבינה נמצאים רק בשרת.** הדפדפן לא רואה אותם אף פעם; כל בקשה עוברת דרך `api/ai/*`, שבודק
הרשאה ומכסה לפני שהוא קורא לספק.

## מה אפשר לעשות במצב ישיר

| פעולה | ספקים אפשריים | הערה |
| --- | --- | --- |
| **יצירת רקע** מתיאור | OpenAI Images, Google Gemini/Imagen, Flux/Stability (דרך ספק כמו fal או Replicate) | תמיד עם "בלי טקסט" בהנחיה |
| **יצירת אלמנט** עם רקע שקוף | OpenAI (רקע שקוף נתמך), או יצירה + הסרת רקע | |
| **עריכת תמונה** — "תחליף את השמיים", מילוי אזור (inpainting) | OpenAI / Gemini | מסכה שמסמנים בקנבס |
| **הרחבת תמונה** (outpainting) לגודל אחר | OpenAI / Gemini | למשל פוסט ← סטורי |
| **הסרת רקע** | בדפדפן (WASM, חינם) או ספק בשרת | הדפדפן — ברירת מחדל |
| **הגדלת רזולוציה** (upscale) | ספק בשרת | לייצוא PDF להדפסה |
| **טקסטים** — "תציע 3 כותרות למבצע" | כל מודל שפה | זול מאוד; אפשר גם במכסה נפרדת |
| **"עצב לי"** — פריסה מלאה מתיאור | מודל שפה מוציא `design.json` + קריאה ליצירת רקע | אותו פורמט כמו מסלול הצ'אט |

**שכבת ספקים אחת** (`ProviderAdapter`): כל ספק מממש `generate`, `edit`, `removeBackground`, `upscale`. המנהל בוחר
ספק ברירת מחדל לכל פעולה, ואפשר להחליף ספק בלי לגעת בעורך.

## מכסות: "קרדיטים", לא טוקנים

ספקי תמונות גובים **לפי תמונה, גודל ואיכות**, ולא לפי טוקנים. מספר טוקנים לא אומר למשתמש כלום. לכן:

- **יחידה פנימית — קרדיט.** טבלת מחירים שהמנהל מגדיר, למשל: רקע רגיל = 4, רקע באיכות גבוהה = 10,
  הסרת רקע בשרת = 1, 3 הצעות טקסט = 0.2. המחיר בקרדיטים נגזר מהעלות בפועל אצל הספק. **לבדוק את המחירים
  העדכניים לפני שקובעים** — הם משתנים.
- **לכל משתמש:** מכסה חודשית (מתחדשת ב-1 לחודש), יתרה חד-פעמית (תוספת), ותקרה יומית — נגד ניצול חריג.
- **ספר תנועות (ledger):** כל חיוב וכל זיכוי נשמרים כשורה — מי, מתי, איזו פעולה, איזה ספק, כמה קרדיטים, העלות
  בפועל בדולרים, ומזהה הבקשה אצל הספק. היתרה = סכום התנועות. אין "שדה יתרה" שמתעדכן בלי תיעוד.
- **שמירה מראש (reservation):** לפני הקריאה לספק נשמרת יתרה; אם הקריאה נכשלת — הקרדיטים מוחזרים אוטומטית.
- **עצירה קשיחה:** אין יתרה ← אין קריאה, ומוצעת חלופה: "נגמרה המכסה — אפשר להמשיך דרך הצ'אט (חינם) 📋".
- **תקרה כוללת למערכת:** סכום חודשי מקסימלי בדולרים. בהגעה ל-80% — התראה למנהל; ב-100% — המסלול הישיר
  נסגר לכולם עד שהמנהל מחליט.

## מה המשתמש רואה

- בלשונית ✨: "נשארו 46 קרדיטים החודש", ועל כל כפתור — המחיר שלו ("✨ צור רקע · 4").
- תוצאה: **4 וריאציות** (המחיר מוצג מראש), בחירה באחת ← נכנסת לקנבס כשכבה.
- היסטוריה: כל התמונות שנוצרו נשמרות ב"התמונות שלי", ואפשר לחזור אליהן בלי לשלם שוב.

## בטיחות ותוכן

- הספקים מפעילים סינון משלהם; הודעת סירוב מוצגת בעברית ובנימוס ("הבקשה נחסמה על ידי ספק הבינה").
- יומן: כל הנחיה נשמרת עם המשתמש — לבירור תלונות, ולמנהל בלבד.
- בלי העלאת תמונות של אנשים אמיתיים לעריכה בלי אישור — סעיף בתנאי השימוש.
