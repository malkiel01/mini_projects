# 04 — מסלול "דרך הצ'אט": סקיל, ייבוא, ובאיזו פלטפורמה זה אפשרי

## התשובה הקצרה לשאלה "מאיזו פלטפורמה אפשר לשלוף תמונות מהחשבון של המשתמש"

**אף פלטפורמה לא מאפשרת לאפליקציה חיצונית להיכנס לחשבון ה-ChatGPT של משתמש ולשלוף ממנו תמונות.**
ל-OpenAI אין API לספריית התמונות או לשיחות של משתמש, וכך גם ל-Gemini ול-Claude.

**מה כן אפשרי — בכיוון ההפוך: הצ'אט שולח אלינו.** הצ'אט יוצר את התמונה, ובלחיצה של המשתמש היא נשלחת
לשרת שלנו. רק ב-**ChatGPT** קיים היום מנגנון רשמי שמעביר קבצים מהשיחה, **כולל תמונות שנוצרו בה**, לשרת חיצוני:

| פלטפורמה | יוצרת תמונות? | שליחת התמונה מהשיחה לשרת שלנו | מה נבנה בשבילה |
| --- | --- | --- | --- |
| **ChatGPT — GPT מותאם עם Action** | כן | **כן, רשמי.** פרמטר בשם `openaiFileIdRefs`: עד 10 קבצים בבקשה, כולל תמונות שנוצרו בשיחה. כל קובץ מגיע עם `download_link` שתקף 5 דקות | **GPT "מעצב הכרטיסים"** — מסלול ב' למטה |
| **ChatGPT — אפליקציה (Apps SDK, MCP)** | כן | כן, דרך `openai/fileParams` בהגדרת הכלי (מגיע `download_url` + `file_id`). **אבל** יש דיווחים שמהאפליקציה בטלפון מגיעה רק הפניה בלי קישור הורדה | שלב מאוחר — מסלול ג' |
| **Gemini (Gems)** | כן | **לא.** ל-Gem אין פעולות חיצוניות | סקיל להדבקה + ייבוא קובץ (מסלול א') |
| **Claude (Skills, מחברי MCP)** | **לא** יוצר תמונות פיקסל. יוצר SVG, פריסה ו-JSON מצוינים | אפשר לבנות מחבר MCP שיוצר עיצוב אצלנו מ-JSON, אבל בלי תמונת AI | סקיל (קובץ `SKILL.md`) + ייבוא; מחבר MCP — בהמשך |
| **כל צ'אט אחר** | תלוי | לא | מסלול א' |

> **ההמלצה:** לבנות קודם את **מסלול א'** (עובד בכל צ'אט, בלי שום תלות), ומיד אחריו את **מסלול ב'** (GPT עם
> Action) — הוא נותן את חוויית "לחיצה אחת והעיצוב באפליקציה" שתוארה, וזה המקום היחיד שבו היא אפשרית היום.
> לבדוק מחדש לפני הפיתוח: המנגנונים האלה משתנים מהר (ראו "מקורות" בסוף).

## למה הצ'אט מייצר רקע **בלי טקסט**

מחוללי תמונות עדיין כותבים עברית משובשת (אותיות הפוכות, מילים מומצאות), וגם טקסט תקין שנאפה לתוך תמונה
אי אפשר לערוך. לכן חלוקת העבודה היא:

- **הצ'אט:** רקע ותמונות — **בלי שום טקסט**, ועם "אזורים שקטים" במקומות שבהם יבוא טקסט.
- **הצ'אט, בנוסף:** קובץ `design.json` — הצעת פריסה: גודל, אילו טקסטים, איפה, באיזה פונט וצבע.
- **האפליקציה:** בונה מזה שכבות חיות — הטקסטים ניתנים לעריכה, להזזה ולהחלפה.

## מסלול א' — סקיל + ייבוא קובץ (בכל צ'אט, בלי טוקנים)

```
אפליקציה          →  צ'אט (של המשתמש)                         →  אפליקציה
"קבל סקיל" 📋       שיחה: מה צריך, גודל, טקסטים, סגנון             "ייבוא מהצ'אט" 📥
                    ← תמונת רקע (בלי טקסט)                       תמונה + design.json
                    ← בלוק design.json                           → שכבות חיות על הקנבס
```

### 1. "קבל סקיל"

מסך באפליקציה עם שלוש לשוניות, לפי הצ'אט שהמשתמש עובד איתו:

| לשונית | מה מקבלים | איך משתמשים |
| --- | --- | --- |
| **ChatGPT** | קישור ל-GPT המוכן (מסלול ב'), וגם טקסט הוראות להדבקה | פותחים את ה-GPT, או מדביקים את ההוראות בתחילת שיחה / ב-Project |
| **Gemini** | טקסט הוראות | יוצרים Gem ומדביקים, או מדביקים בתחילת שיחה |
| **Claude** | קובץ `SKILL.md` להורדה (תיקייה מכווצת) | Settings → Capabilities → Skills → העלאה. בלי יצירת תמונות — הוא נותן פריסה ו-SVG |

כפתורים: 📋 העתקה · ⬇️ הורדה · ↗ פתיחת הצ'אט. הטקסט עצמו: `skill/SKILL.md` בתיקייה הזו.

**הסקיל מותאם אישית:** בהורדה מוטמעים בו הגדלים, הפונטים והצבעים של המשתמש (ערכת מותג, אם הגדיר), וקוד
ייבוא קצר. כך הצ'אט מציע רק פונטים שקיימים באפליקציה.

### 2. בצ'אט — מה הסקיל גורם לצ'אט לעשות

1. **לשאול לפני שמייצרים** — עד 4 שאלות: למה זה (מודעה/הזמנה/ברכה/פוסט), איפה יפורסם (גודל), אילו טקסטים
   חייבים להופיע, ואיזה סגנון וצבעים.
2. **לייצר רקע בלי טקסט**, ביחס הגובה-רוחב המדויק, עם אזורים שקטים.
3. **להוציא `design.json`** בבלוק קוד אחד, לפי הסכמה (`schema/design.schema.json`).
4. **ב-ChatGPT עם כלי קוד** — לארוז הכול ל-`design.gcard` (ZIP: `design.json` + `assets/`) להורדה אחת.
5. **אלמנטים נוספים לפי בקשה** — אייקונים, קישוטים, מסגרות — כתמונות PNG עם רקע שקוף, כל אחד בנפרד.
6. **סבב תיקונים** — "יותר כהה", "בלי האנשים" — מייצר מחדש רק את מה שהשתנה.

### 3. "ייבוא מהצ'אט" באפליקציה

אזור אחד שמקבל **כל מה שיש למשתמש**:

- גרירה או בחירה של **`design.gcard`** — הכי שלם.
- **תמונה אחת או יותר** + הדבקת ה-JSON (שדה טקסט, וכפתור "📋 הדבקה" שקורא מהלוח).
- **תמונה בלבד** — נכנסת כרקע לעיצוב חדש בגודל שלה. גם זה תקין.
- **שיתוף מהטלפון** — מאפליקציית ChatGPT/Gemini: "שיתוף" ← "כרטיסי ברכה". באנדרואיד: intent-filter של
  `ACTION_SEND` לתמונות ולטקסט; ב-PWA: `share_target` במניפסט.

**אימות הקלט:** ה-JSON נבדק מול הסכמה. שגיאות מתוקנות כשאפשר (פונט לא קיים ← הפונט הקרוב; מיקום מחוץ לדף ←
מוזז פנימה) ומוצגות כרשימה קצרה: "2 תיקונים: הפונט 'X' הוחלף ב-Heebo". JSON שבור לגמרי ← ייבוא התמונות לבד,
עם הסבר.

**אבטחה:** תמונות מפוענחות מחדש בשרת (ולא נשמרות כמו שהן), SVG עובר ניקוי (בלי סקריפטים וקישורים חיצוניים),
מגבלת גודל (20MB לקובץ, 50MB ל-gcard), ו-ZIP נבדק נגד path traversal ו"פצצת ZIP".

## מסלול ב' — GPT מותאם עם Action: "שלח לעורך" בלחיצה

```
ChatGPT (GPT "מעצב הכרטיסים")                 השרת שלנו                         האפליקציה
המשתמש: "שלח לעורך"                       POST /api/chat-import
Action: openaiFileIdRefs[] + design   →   מוריד את הקבצים מיד (5 דק'!)
                                          שומר "ייבוא ממתין" + קוד
                                      ←   { url: ".../#import=K7Q2-9M" }
"✓ העיצוב מוכן — לחצו לפתיחה"  ───────────────────────────────────→   נפתח עם השכבות
```

- **ה-Action מוריד את הקבצים מיד**, בתוך אותה בקשה — הקישורים פגים אחרי 5 דקות.
- **שיוך למשתמש — שני שלבים:**
  - **v1, בלי התחברות ב-GPT:** הייבוא נשמר עם קוד חד-פעמי (תקף 24 שעות). הקישור פותח את האפליקציה; אחרי
    כניסה הייבוא משויך לחשבון. פשוט, ולא דורש OAuth.
  - **v2, עם OAuth:** ה-Action מתחבר לחשבון שלנו ("התחברות לכרטיסי ברכה" בפעם הראשונה), והעיצוב נכנס ישר
    לרשימת העיצובים של המשתמש.
- **הגבלות:** קצב (10 ייבואים בשעה לכתובת IP בלי התחברות), גודל, ובדיקת סוג קובץ אמיתית (magic bytes).
- **פרטיות:** מדיניות פרטיות ציבורית היא תנאי לפרסום GPT עם Action — יש כבר `privacy.html`, צריך לעדכן.

## מסלול ג' — אפליקציית ChatGPT (Apps SDK) — בהמשך

אפליקציה בתוך ChatGPT עם תצוגה מקדימה של העיצוב בתוך השיחה, וכלי `create_design` שמקבל קבצים דרך
`openai/fileParams`. זו החוויה העשירה ביותר, אבל המנגנון חדש יותר, ויש דיווחים על באג בטלפון (מגיעה רק הפניה
בלי קישור הורדה). **לא לבנות לפני שמסלול ב' עובד ונבדק בטלפון.** שרת ה-MCP יכול לשמש גם מחבר ל-Claude.

## פורמט `design.gcard`

ZIP עם סיומת משלו:

```
design.gcard
├── design.json        לפי schema/design.schema.json
└── assets/
    ├── background.png
    └── star.png
```

אותו פורמט משמש **שמירה וטעינה של עיצוב** ו**שיתוף תבנית** בין משתמשים.
