# 03 — העורך

## מבנה המסך

### בטלפון (320–430px)

```
┌──────────────────────────────┐
│ ‹  שם העיצוב ✏️     ↶ ↷  ⬇️  │  כותרת דביקה 48px: חזרה, שם, ביטול/חזרה, ייצוא
├──────────────────────────────┤
│                              │
│          הקנבס               │  ממלא את השטח; זום וגרירה בשתי אצבעות
│                              │
├──────────────────────────────┤
│ [סרגל הקשר — לפי מה שנבחר]    │  טקסט: פונט · גודל · צבע · יישור · עוד
├──────────────────────────────┤
│ ➕ הוספה  🧱 שכבות  🖼️ רקע  ✨ AI │  סרגל תחתון קבוע, 56px + safe-area
└──────────────────────────────┘
```

- **סרגל תחתון** — 4–5 לשוניות עם אייקון ומילה. לחיצה פותחת **גיליון תחתון** (bottom sheet) בחצי גובה,
  שאפשר למשוך לגובה מלא. הקנבס נשאר גלוי מעליו, ולכן רואים את השינוי בזמן אמת.
- **סרגל הקשר** — מופיע רק כשאלמנט נבחר, ומשתנה לפי הסוג. הוא נגלל אופקית **בתוך עצמו** (לא הדף).
- **אין טופס ארוך מעל הקנבס.** כל ההגדרות בגיליונות.

### במחשב (≥ 1024px)

שלוש עמודות: סרגל כלים (ימין, ב-RTL) · קנבס (מרכז) · מאפיינים ושכבות (שמאל). קיצורי מקלדת מלאים.

## מודל הנתונים — עיצוב = מסמך שכבות

הכול נשמר כ-JSON אחד (`schema/design.schema.json`). אותו פורמט משמש את הייבוא מהצ'אט, השמירה בשרת
ותבניות.

```json
{
  "version": 1,
  "page": { "width": 1080, "height": 1350, "unit": "px", "background": "#ffffff" },
  "assets": { "bg1": { "type": "image", "src": "assets/bg1.webp", "width": 1080, "height": 1350 } },
  "layers": [
    { "id": "l1", "type": "image", "asset": "bg1", "x": 0, "y": 0, "w": 1080, "h": 1350, "locked": true, "role": "background" },
    { "id": "l2", "type": "text", "text": "מבצע סוף עונה", "x": 90, "y": 120, "w": 900, "h": 160,
      "style": { "font": "Heebo", "weight": 800, "size": 120, "color": "#ffffff", "align": "center", "dir": "rtl" } }
  ]
}
```

- **יחידות בפיקסלים של המסמך**, לא של המסך. הזום הוא רק תצוגה, ולא משנה ערכים.
- **`role`** — `background`, `title`, `subtitle`, `body`, `cta`, `logo`, `photo`, `decoration`. כך הסקיל בצ'אט
  יכול לומר "כאן שים כותרת", והעורך יודע מה להחליף במיזוג נתונים.
- **שדות מיזוג** — `{{שם}}` בתוך טקסט. כל עמודה באקסל = משתנה.

## סוגי שכבות

| סוג | מאפיינים עיקריים |
| --- | --- |
| `text` | טקסט, פונט, משקל, גודל, צבע/מעבר צבע, יישור, ריווח שורות ואותיות, קו מתאר, צל, רקע לטקסט, התאמה אוטומטית לתיבה (הקטנת הגודל עד שנכנס) |
| `image` | חיתוך (crop), סיבוב, היפוך, שקיפות, פילטרים, מסכה בצורה, מסגרת, הסרת רקע |
| `shape` | מלבן (עם רדיוס), עיגול, קו, חץ, מצולע, כוכב; מילוי, קו מתאר, שקיפות |
| `icon` | SVG מספרייה פנימית (מוחלף צבע) |
| `group` | שכבות מקובצות — זזות ומשתנות יחד |

## פעולות על אלמנט

- **בחירה**: הקשה. ידיות: 8 ידיות שינוי גודל + ידית סיבוב. **יעד לחיצה של 40px**, גם אם הידית נראית קטנה.
- **הזזה**: גרירה באצבע אחת. **הצמדה (snap)** לאמצע הדף, לשוליים ולאלמנטים אחרים, עם קווי עזר בצבע המותג.
  החזקה של Shift (או כפתור "בלי הצמדה") מבטלת.
- **שינוי גודל**: ידיות פינה שומרות יחס; ידיות צד — רק ציר אחד. בטקסט — שינוי רוחב התיבה, לא מתיחת האותיות.
- **סיבוב**: ידית, עם הצמדה ל-0/45/90 מעלות.
- **סדר**: קדימה / אחורה / לראש / לתחתית; גרירה ברשימת השכבות.
- **שכפול, מחיקה, נעילה, הסתרה, קיבוץ, יישור** (ימין/מרכז/שמאל/למעלה/אמצע/למטה) **ופיזור שווה**.
- **עריכת טקסט**: הקשה כפולה פותחת עריכה במקום (contenteditable מעל הקנבס, באותו פונט וגודל), כך שהמקלדת
  של הטלפון, ההשלמה האוטומטית וההכתבה עובדות כרגיל.

## מחוות וזום — הבעיה המרכזית היום

**הכלל:** הצביטה מגדילה **רק את הקנבס**, לא את הדף, ומחוץ לקנבס הדף נגלל כרגיל.

| מחווה | על הקנבס | מחוץ לקנבס |
| --- | --- | --- |
| אצבע אחת על אלמנט | גרירת האלמנט | — |
| אצבע אחת על רקע ריק / רקע נעול | **הזזת התצוגה (pan)** כשמוגדל; גלילת הדף כשלא מוגדל | גלילת הדף |
| שתי אצבעות | זום + הזזה של הקנבס סביב נקודת המגע | זום של הדפדפן (לא חוסמים) |
| הקשה כפולה | על טקסט — עריכה; על רקע — מעבר בין "התאם למסך" ל-100% | — |
| גלגלת (מחשב) | גלילה; Ctrl/⌘+גלגלת — זום סביב העכבר | גלילה |

**מימוש:**
- `<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover">` — **בלי**
  `user-scalable=no` ובלי `maximum-scale`. חסימת זום של הדף היא כשל נגישות (WCAG 1.4.4).
- על אזור הקנבס בלבד: `touch-action: none`, ו-Pointer Events (`pointerdown/move/up`) עם מעקב אחרי כמה
  מצביעים פעילים. **שום** `preventDefault` על `touchmove` ברמת `document`.
- הזום והגלילה של הקנבס = טרנספורמציה אחת (`scale` + `translate`) על שכבת התצוגה, ב-`requestAnimationFrame`.
- כפתורי זום גלויים: − · 100% · + · "התאם", ותצוגת אחוז. בורר זום גם במקלדת: Ctrl/⌘ + `=` / `-` / `0`.
- ב-WebView של אנדרואיד — `setSupportZoom(false)` **לדף**, כי הזום מטופל בתוך הקנבס, ו-`builtInZoomControls`
  לא מתנגש בו. הגלילה הרגילה של הדף נשארת.

## ביטול וחזרה, שמירה, גרסאות

- **היסטוריה** כרשימת פעולות (command pattern), 200 צעדים. גרירה רציפה = צעד אחד.
- **שמירה אוטומטית**: מקומית (IndexedDB) כל 2 שניות אחרי שינוי, ובשרת כל 15 שניות כשיש רשת. סימון מצב בכותרת:
  "נשמר ✓" / "שומר…" / "לא מחובר — נשמר במכשיר".
- **גרסאות**: צילום מצב אוטומטי בכל פתיחה ובכל ייצוא, ושמירה ידנית "שמור גרסה". שחזור בלחיצה.

## רקע

- צבע אחיד, מעבר צבעים, תמונה (מהמכשיר, מהספרייה, מהצ'אט, או מ-AI ישיר).
- התאמת תמונת רקע: מילוי (cover), התאמה (contain), מתיחה, חיתוך ידני.
- **רקע מהצ'אט נכנס כשכבה נעולה** בתחתית — כדי שגרירה עליו לא תזיז אותו בטעות. ביטול נעילה בלחיצה.

## פונטים

- ספרייה של פונטים עבריים חופשיים (Heebo, Assistant, Rubik, Frank Ruhl Libre, Secular One, Varela Round,
  Alef, Suez One, Karantina, Amatic SC…), מקומיים בשרת (לא Google Fonts בזמן ריצה), `font-display: swap`,
  ונטענים **רק כשבוחרים בהם**.
- העלאת פונט של המשתמש (TTF/OTF/WOFF2), נשמר בחשבון שלו. בדיקת תקינות בשרת.
- **תצוגת הפונט ברשימה** — שם הפונט כתוב בפונט עצמו (נטען בעצלתיים בזמן גלילה).

## מיזוג נתונים (כרטיס לכל נמען)

1. טעינת אקסל/CSV (או הדבקה מגיליון), זיהוי כותרות.
2. מיפוי: כל `{{משתנה}}` בעיצוב ← עמודה. תצוגה מקדימה עם ‹ › בין שורות.
3. אזהרות: טקסט שלא נכנס בתיבה בשורה מסוימת ("בשורה 14 השם ארוך מדי").
4. ייצוא: **ב-Web Worker**, עם פס התקדמות אמיתי ("37 מתוך 200"), ביטול באמצע, והורדת ZIP או שליחה.
5. שליחה בוואטסאפ דרך האפליקציה (הגשר הקיים באנדרואיד), עם תור שממשיך אחרי החזרה מוואטסאפ.

## ייצוא

| פורמט | פרטים |
| --- | --- |
| PNG / JPG / WebP | 1×, 2×, 3×; JPG עם בחירת איכות; רקע שקוף ב-PNG |
| PDF | וקטורי (טקסט נשאר טקסט, הפונט מוטמע); ל-A4/A5 — שולי חיתוך (bleed) וסימני חיתוך, בחירה |
| ZIP | כל כרטיסי המיזוג |
| שיתוף | Web Share API (וואטסאפ, מייל…) — קובץ, לא קישור |
| קישור | קישור צפייה ציבורי לעיצוב (אופציונלי, בהמשך) |

**הייצוא מחושב מהמסמך, לא מצילום מסך** — לכן אין הבדל בין מה שרואים בזום כלשהו לבין הקובץ.
