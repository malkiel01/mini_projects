# מוניטור מערכת

אפליקציית אנדרואיד נייטיב אחת (`com.mbeplus.systemmonitor`) וצד שרת וממשק ווב כאן, לשלושה דברים:

- **חנות / מתקין** — התקנה בלחיצה ועדכונים ברקע לאפליקציות `com.mbeplus.*`, בלי לפתוח קבצים.
- **מדווח** — מה מותקן ובאיזו גרסה, ממקום אחד.
- **אבחון** — אירועים ולוגים מהמכשיר, לקריאה בממשק ולקריאה של Claude.

**מצב: אפיון בלבד.** האפיון המלא, כולל מה אנדרואיד מאפשר ומה לא: [`docs/spec.md`](docs/spec.md).
לא נבנה דבר לפני אישור בעל המערכת.

## טרם הוכרע

- `READ_LOGS` (חיבור חד-פעמי ל-adb) — כן או לא.
- האם המוניטור מחליף את הדופק היומי שבכל אפליקציה.
- מה עושים עם אפליקציות שהותקנו מגוגל פליי.

## לפני הפריסה הראשונה שכותבת נתונים

`system-monitor/data/` (מסד, מפתח, העלאות) צריך `--exclude` ב-`deploy.yml` — מבקשים מצ'אט הפלטפורמה.
