# הנחיה לכל אפליקציה — שער, התחברות וחנות

מקור: האפיון (`auth.md`, 2026-10-19) וההנחיה מצ'אט המתכונים (תיקיית חנות, `assetlinks.json` משותף).
**כל צ'אט נוגע רק בתיקייה שלו.** חריג: קדישא (`kadisha/`) — חיצונית, לא נכנסת לכל זה.

## הצעדים — אותם לכל אפליקציה

1. **שער** — `"gate": true` ו-`"public"` ממופים **מהקוד, לא מהזיכרון**: קישורים במייל, עובדים, cron, webhooks,
   API של אפליקציה נייטיב, manifest, service worker ואייקונים (הדפדפן מוריד manifest בלי עוגיות), וכל `action`
   שדף ציבורי קורא לו. בדיקה בחלון גלישה בסתר. דוגמה: `recipes-app/README.md`, "מאחורי השער של הפלטפורמה".
2. **סאב-דומיין קיים** — להפנות אותו ב-cPanel לתיקייה **לפני** המיזוג (platform/README.md, "השער").
   עובד שמעיר את עצמו ב-HTTP — `CURLOPT_FOLLOWLOCATION`.
3. **התחברות** — לפי `auth.md` ו-`sso.md` סעיף 0:
   - מחוברת: `$_SERVER['PLATFORM_USER']` — כניסה אוטומטית; קישור לפי `sub`, ואז לפי מייל; בלי התאמה — מסך
     החיבור החד-פעמי (`auth.md`, סעיף 4) ואז חשבון חדש **פעיל**. כניסה והרשמה עצמאיות — חסומות.
   - מנותקת: `sso.php?action=config` → `login.password` / `login.google`, ו"כניסה עם הכלים הדיגיטליים"
     (`"sso": {"return": [...]}` ב-app.json).
   - משתתפים מבחוץ (קישור אישי, קוד) — לא נוגעים.
   - הסיסמה הישנה לא נמחקת — רק חסומה כל עוד מחוברת.
4. **משתמשים קיימים מבחוץ** — חשבון בפלטפורמה והרשאה, **לפני** המיזוג.
5. **אנדרואיד ותיקיית חנות** (כשמעלים לחנות) — התבנית: `recipes-app/android/` ו-`recipes-twa.yml`, מעתיקים
   לתיקייה (לא משנים את המקור). משתנים: `appPath`, חבילה `com.mbeplus.<app>`, מפתח העלאה משלה (מוצפן בתיקייה).
   **סיסמה אחת לכל המפתחות** (הוכרע 2026-10-19): הסוד `ANDROID_KEYSTORE_PASSWORD` ב-GitHub — כל workflow קורא
   אותו. (המתכונים — `RECIPES_KEYSTORE_PASSWORD` היום; עוברת ל-`ANDROID_KEYSTORE_PASSWORD`, עם הישן כגיבוי.)
   Release `<app>-store`, וב-app.json: `"install": {"release": "<app>-store"}`. אפליקציה עם APK נייטיב —
   מוסיפים AAB, `store-listing.zip` ותיקיית חנות באותו מבנה.
