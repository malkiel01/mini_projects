# בדיקת שרת לשלב 4 (השער)

לפני שבונים שער לכלים צריך לדעת מה השרת מסוגל לעשות, ואין לנו גישה אליו אלא
דרך הדפדפן. כל תת-תיקייה כאן בודקת יכולת אחת, ו"🩺 בדיקת שרת" בממשק המנהל
מריץ את כולן ומציג את התוצאה.

| תיקייה | מה נבדק | למה זה חשוב לשער |
| --- | --- | --- |
| `r/` | `mod_rewrite` ב-`.htaccess`, גם על קובץ קיים | כך מעבירים קובץ סטטי (HTML/JS) דרך בדיקת הרשאה |
| `u/` | `.user.ini` עם `auto_prepend_file` | כך מריצים בדיקה לפני כל קובץ PHP בשרת FPM/CGI |
| `h/` | `php_value` ב-`.htaccess` | אותו דבר, בשרת mod_php או LiteSpeed. בשרת FPM — שגיאה 500, וזו גם תשובה |

`.user.ini` נקרא מחדש רק אחרי `user_ini.cache_ttl` (בדרך כלל 5 דקות) — תוצאה
שלילית מיד אחרי פריסה אינה סופית.

התיקייה תימחק אחרי שהשער ייבנה.
